    Cloud Computing Models (IaaS, PaaS, SaaS) & Shared Responsibility
    IaaS (EC2) provides hardware virtualization, PaaS (Elastic Beanstalk) manages runtimes, and SaaS (WorkMail) delivers complete apps; the Shared Responsibility Model demarcates AWS cloud security vs customer in-the-cloud compliance.

  2. ☆

    🎬YT🌐Doc
  3. ☆
    IAM Fundamentals: Root User Security, IAM Users, Groups & Policies
    Root user account lock-down with hardware MFA; least-privilege IAM users and group inheritance governed by JSON identity policies with explicit Allow/Deny evaluation rules.
    🎬YT🌐Doc
  4. ☆
    IAM Roles, Instance Profiles & STS AssumeRole Delegation
    Temporary credential generation via AWS STS AssumeRole; instance profiles attach IAM roles directly to EC2 and container ENIs, eliminating long-lived hardcoded credentials.
    🎬YT🌐Doc

    Policy Evaluation Logic: Explicit Deny, SCPs & Permission Boundaries
    Deterministic JSON policy evaluation order: explicit deny overrides all; multi-account guardrail ceilings enforced by AWS Organizations SCPs and developer IAM permission boundaries.

AWS VPC & Network Architecture

5 concepts
Masterclass lessons covering AWS VPC & Network Architecture architecture, operational mechanisms, and failure modes.
  1. ☆
    VPC Fundamentals: CIDR Blocks, Public vs Private Subnets & Route Tables
    Logical network isolation defined by private CIDR blocks (/16); subnets (/24) partitioned into public vs private tiers with route tables directing traffic to designated gateways.
    🎬YT🌐Doc
  2. ☆
    Internet Gateways (IGW), NAT Gateways & Egress-Only Gateways
    Internet Gateways provide two-way 1:1 NAT for public subnets; managed NAT Gateways enable secure outbound-only internet connectivity for private subnets across multiple AZs.
    🎬YT🌐Doc
  3. ☆
    Security Groups (Stateful) vs Network ACLs (Stateless)
    Security Groups are stateful firewalls operating at the elastic network interface (ENI) layer; Network ACLs provide stateless, numbered subnet-level perimeter packet filtering.
    🎬YT🌐Doc
  4. ☆
    VPC Peering, Transit Gateway & Direct Connect Hybrid Networking
    VPC Peering provides non-transitive 1:1 network routing; AWS Transit Gateway acts as a central hub simplifying multi-VPC meshes and hybrid AWS Direct Connect circuits.
    🎬YT🌐Doc
  5. ☆
    VPC Endpoints (Gateway vs Interface PrivateLink Endpoints)
    Gateway Endpoints route S3 and DynamoDB traffic privately via route tables at zero hourly cost; Interface Endpoints (AWS PrivateLink) create private ENIs inside VPC subnets.
    🎬YT🌐Doc

AWS Compute: EC2, Elastic Load Balancing & Auto Scaling

5 concepts
Masterclass lessons covering AWS Compute: EC2, Elastic Load Balancing & Auto Scaling architecture, operational mechanisms, and failure modes.
  1. ☆
    EC2 Architecture: Instance Types, AMIs & User Data Bootstrap Scripts
    Nitro system hypervisors powering general-purpose, compute-optimized, and memory-optimized instances; bootstrap automated provisioning via EC2 UserData scripts and custom AMIs.
    🎬YT🌐Doc
  2. ☆
    EC2 Pricing Models: On-Demand, Savings Plans, Reserved & Spot Instances
    On-Demand for unpredictable traffic, Savings Plans and Reserved Instances for steady-state baselines (up to 72% discount), and Spot Instances for fault-tolerant batch workloads.
    🎬YT🌐Doc
  3. ☆
    Elastic Load Balancers: ALB (Layer 7) vs NLB (Layer 4) Architecture
    Application Load Balancer (ALB) inspects Layer 7 HTTP/HTTPS headers, paths, and host headers; Network Load Balancer (NLB) routes Layer 4 TCP/UDP traffic with static IPs in ultra-low microseconds.
    🎬YT🌐Doc
  4. ☆
    Target Groups, Health Checks & Cross-Zone Load Balancing
    Target Groups route traffic across EC2, Lambda, or IP targets; active health checks remove unhealthy instances while cross-zone balancing distributes requests uniformly across AZs.
    🎬YT🌐Doc
  5. ☆
    Auto Scaling Groups (ASG): Launch Templates & Dynamic Scaling Policies
    Auto Scaling Groups (ASGs) maintain fleet availability using Launch Templates; dynamic target-tracking, step-scaling, and predictive scaling adapt capacity to real-time CPU/traffic loads.
    🎬YT🌐Doc

AWS Storage: S3 Object Storage, EBS Block Storage & EFS

5 concepts
Masterclass lessons covering AWS Storage: S3 Object Storage, EBS Block Storage & EFS architecture, operational mechanisms, and failure modes.
  1. ☆
    Amazon S3 Architecture: Buckets, Keys & Consistency Guarantees
    Globally unique bucket namespace with key-value object storage; provides 99.999999999% (11 9s) durability with strong read-after-write consistency across multiple AZs.
    🎬YT🌐Doc
  2. ☆
    S3 Storage Classes: Standard, Intelligent-Tiering, Glacier & Lifecycle Rules
    S3 Standard for hot data, Intelligent-Tiering for automatic cost optimization, Standard-IA for infrequent access, and Glacier Flexible/Deep Archive for low-cost compliance retention.
    🎬YT🌐Doc
  3. ☆
    S3 Security: Bucket Policies, Pre-Signed URLs, CORS & KMS Encryption
    Server-side encryption via SSE-S3 or KMS (SSE-KMS); granular access controls via Bucket Policies, Block Public Access, and time-limited pre-signed URLs for secure client uploads.
    🎬YT🌐Doc
  4. ☆
    EBS Volume Types: gp3 vs io2 Block Express & Snapshot Snapshots
    Low-latency block storage for EC2: general purpose gp3 with baseline 3,000 IOPS, provisioned IOPS io2 Block Express for mission-critical databases, and incremental S3-backed snapshots.
    🎬YT🌐Doc

    Amazon EFS Distributed Network File System & Amazon FSx for High Performance
    Comprehensive production architecture, core execution mechanisms, and operational trade-offs for Amazon EFS Distributed Network File System & Amazon FSx for High Performance.
