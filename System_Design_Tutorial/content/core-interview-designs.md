# Core Interview Designs

## Overview
Welcome to the module on **Core Interview Designs**. This page covers the following related subtopics:

- Chat / WhatsApp / Slack — WebSockets, message ordering, presence, fan-out
- Twitter / X — fan-out on write vs read; hybrid for celebrities
- YouTube / Netflix — upload pipeline, transcoding, adaptive bitrate streaming, CDN
- Instagram / Photo sharing — media upload, feed generation, S3+CDN
- Notification System — multi-channel (push/email/SMS), queues, templates, dedup
- Ticketmaster / Seat Booking — inventory locks, payment timeout, distributed txns
- Tinder / Matching — geospatial indexing, swiping at scale, recommendations
- TikTok / Short Video — ML-powered feed, CDN, video encoding pipeline
- Airbnb / Booking — double-booking prevention, calendar availability, search
- Payment System — idempotency, double-entry bookkeeping, audit logs, PCI-DSS
- Distributed Message Queue (Kafka design) — ordering, partitions, consumer groups
- Reddit / HN — voting, ranking, comment threads, subreddit feeds
- Autocomplete / Typeahead — trie, top-K, Redis sorted sets, prefix cache
