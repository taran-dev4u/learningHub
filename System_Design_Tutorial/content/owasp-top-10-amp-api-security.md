# OWASP Top 10 &amp; API Security

## Overview
Welcome to the module on **OWASP Top 10 &amp; API Security**. This page covers the following related subtopics:

- SQL/NoSQL/OS injection — user input as code; fix: parameterized queries
- XSS (Cross-Site Scripting) — injected JS in pages; fix: escape output, CSP
- CSRF (Cross-Site Request Forgery) — forged requests; fix: CSRF tokens, SameSite
- SSRF (Server-Side Request Forgery) — server fetches internal URLs; exploits cloud metadata
- Broken authentication — weak passwords, no MFA, exposed session IDs
- API security: always authenticate, validate input, log all calls, rate limit
