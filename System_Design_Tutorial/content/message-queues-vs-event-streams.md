# Message Queues vs Event Streams

## Overview
Welcome to the module on **Message Queues vs Event Streams**. This page covers the following related subtopics:

- Message queue (SQS, RabbitMQ) — message consumed → gone, work distribution
- Event stream (Kafka, Kinesis) — durable append-only log, replay, multiple consumer groups
- Pub/Sub (SNS, Google Pub/Sub) — topic fan-out to many subscribers
- DB-as-queue antipattern — polling creates lock contention, never do this
