# Replication &amp; Read Scaling

## Overview
Welcome to the module on **Replication &amp; Read Scaling**. This page covers the following related subtopics:

- Single-leader (primary-replica) — all writes to primary, reads to replicas
- Replication lag — async replicas may serve stale reads
- Multi-leader replication — conflict resolution required (LWW or CRDTs)
- Leaderless (Cassandra/Dynamo) — quorum R+W&gt;N for strong consistency
- Synchronous vs asynchronous replication — durability vs performance tradeoff
- Change Data Capture (CDC) — stream DB changes as events (Debezium, Netflix DBLog)
