# Indexes &amp; Query Optimization

## Overview
Welcome to the module on **Indexes &amp; Query Optimization**. This page covers the following related subtopics:

- B-tree index — balanced tree, good for range + equality queries (default)
- Hash index — O(1) equality, no range queries
- Composite index + leftmost prefix rule
- Covering index — all needed cols in index, no table read
- LSM tree (Cassandra, RocksDB) — write-optimized, sorted runs + compaction
- EXPLAIN ANALYZE — read query plan, spot Seq Scans on big tables
- Index selectivity — high cardinality cols are good candidates
