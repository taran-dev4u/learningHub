# ACID, Transactions &amp; Isolation

## Overview
Welcome to the module on **ACID, Transactions &amp; Isolation**. This page covers the following related subtopics:

- Atomicity — all-or-nothing, rollback on failure
- Consistency — valid state to valid state (app-defined invariants)
- Isolation — concurrent txns appear serial (isolation levels control this)
- Durability — committed txns survive crashes (WAL, fsync)
- Isolation levels: Read Uncommitted → Committed → Repeatable Read → Serializable
- MVCC (Postgres, Oracle) — snapshot reads, no read locks
- BASE model — Basically Available, Soft state, Eventual consistency (NoSQL alternative)
