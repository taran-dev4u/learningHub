# Advanced Senior-Level Designs

## Overview
Welcome to the module on **Advanced Senior-Level Designs**. This page covers the following related subtopics:

- Uber / Rideshare — geospatial indexing (quad-tree/geohash), matching, real-time location
- Google Search — crawling, indexing, ranking (PageRank), serving
- Google Drive / Dropbox — chunked upload, dedup (hashing), sync, conflict resolution
- Google Maps — tile generation, routing (Dijkstra at scale), real-time traffic
- Google Docs / Collaborative Editing — OT (Operational Transform) or CRDTs, conflict resolution
- Stock Exchange — ultra-low latency, order matching engine, FIFO fairness
- Facebook News Feed — social graph, ranking, fan-out strategies at 3B users
- Distributed Locking Service (like Chubby) — consensus + lease renewal + callbacks
