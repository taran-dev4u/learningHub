# Graceful Degradation &amp; Load Shedding

## Overview
Welcome to the module on **Graceful Degradation &amp; Load Shedding**. This page covers the following related subtopics:

- Fallback responses — return stale cache or default when upstream is down
- Feature flags / kill switches — turn off expensive features under load
- Load shedding — reject low-priority requests early (return 503) before overload
- Priority queues — critical work executes even when system is degraded
