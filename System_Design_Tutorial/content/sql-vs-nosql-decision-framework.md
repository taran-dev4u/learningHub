# SQL vs NoSQL Decision Framework

## Overview
Welcome to the module on **SQL vs NoSQL Decision Framework**. This page covers the following related subtopics:

- SQL (RDBMS) — ACID, joins, schema, mature tooling (default pick)
- Document stores (MongoDB, CouchDB) — flexible schema, nested objects
- Key-Value (Redis, DynamoDB) — sub-ms lookups, cache, sessions
- Wide-column (Cassandra, HBase, ScyllaDB) — massive write throughput, time-series
- Graph DBs (Neo4j, Neptune) — many-to-many, fraud detection, social graphs
- Time-series (InfluxDB, TimescaleDB) — append-heavy, retention policies, IoT metrics
- Search engines (Elasticsearch / OpenSearch) — inverted index, full-text
