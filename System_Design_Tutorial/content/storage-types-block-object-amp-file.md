# Storage Types: Block, Object &amp; File

## Overview
Welcome to the module on **Storage Types: Block, Object &amp; File**. This page covers the following related subtopics:

- Block storage (EBS, Azure Disk) — attach to one VM, high IOPS, DBs/OS disks
- File storage (EFS, NFS, Azure Files) — multi-mount, POSIX semantics
- Object storage (S3, GCS, Azure Blob) — flat namespace, infinite scale, HTTP API
- S3 key design — prefix distribution for parallel requests (avoid sequential prefixes)
- Distributed file system (HDFS, Ceph) — large dataset processing, MapReduce
