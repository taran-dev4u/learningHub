# Cache Strategies

## Overview
Welcome to the module on **Cache Strategies**. This page covers the following related subtopics:

- Cache-aside (lazy loading) — app checks cache, miss → read DB + write cache
- Read-through — cache library handles miss + load automatically
- Write-through — write to cache + DB synchronously, always consistent
- Write-behind (write-back) — write to cache, async to DB, risk of data loss
- Refresh-ahead — proactively refresh hot keys before TTL expires
