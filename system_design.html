5 concepts

    Users → requests → QPS → storage → bandwidth. Round aggressively.
    🎬YT🌐G
  2. ☆
    QPS, storage and bandwidth math
    DAU x actions / 86,400s. Peak = 2-5x average.

    Latency numbers to memorize

    Peak vs average traffic sizing
    Design for peak, pay for average. Autoscaling bridges the gap.
    🎬YT🌐G

    Read/write ratio implications
    Read-heavy → cache + replicas. Write-heavy → partitioning + LSM stores.

HLD vs LLD Boundaries

4 concepts
Know which level of detail the interviewer is asking for.
  1. ☆
    High-level design scope
    Services, data flow, storage, queues, caches, scaling, and failure modes.
    🔍YT🔍G
  2. ☆
    Low-level design scope
    Classes, interfaces, methods, object relationships, schemas, and in-process behavior.
    🔍YT🔍G
  3. ☆
    When to switch from HLD to LLD
    Switch only after requirements, scale, and major components are clear or the interviewer asks.
    🔍YT🔍G
  4. ☆
    API contract vs class contract
    HLD APIs define service boundaries; LLD interfaces define code boundaries.
    🔍YT🔍G
15.2

Object-Oriented Foundations

4 concepts
The vocabulary for implementation-level design.
  1. ☆
    Encapsulation
    Hide state behind behavior; expose stable methods instead of internal fields.
    🔍YT🔍G
  2. ☆
    Abstraction
    Model only what the problem needs; avoid leaking implementation details.
    🔍YT🔍G
  3. ☆
    Inheritance vs composition
    Prefer composition for flexible behavior; use inheritance for true is-a relationships.
    🔍YT🔍G
  4. ☆
    Polymorphism
    Depend on interfaces so behavior can vary without branching everywhere.
    🔍YT🔍G
