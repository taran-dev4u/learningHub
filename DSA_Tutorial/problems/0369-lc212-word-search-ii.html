📋 The problem

Given a letter grid and a word list, return every word that can be traced through adjacent cells without reusing a cell.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an m x n board of characters and a list of strings words, return all words on the board.

💡 Key insight: Running Word Search I for each word independently takes O(W × M × N × 3^L), which TLEs. Instead, insert all words into a Prefix Tree (Trie). A single 2D DFS walks the grid while simultaneously walking down the Trie! When node.word is found, append it and set node.word = None (preventing duplicate results).

class TrieNode:
    def __init__(self):
        self.children = {}
        self.word = None

def findWords(board: list[list[str]], words: list[str]) -> list[str]:
    """
    Finds all dictionary words in grid simultaneously via Trie-guided 2D backtracking.
    """
    root = TrieNode()
    for w in words:
        curr = root
        for c in w:
            if c not in curr.children:
                curr.children[c] = TrieNode()
            curr = curr.children[c]
        curr.word = w
        
    m, n = len(board) , len(board[0])
    res = []
    
    def dfs(r, c, node):
        char = board[r][c]
        curr_node = node.children[char]
        
        if curr_node.word:
            res.append(curr_node.word)
            curr_node.word = None  # Prevent duplicate insertions
            
        board[r][c] = '#'  # Mark visited
        
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < m and 0 <= nc < n and board[nr][nc] in curr_node.children:
                dfs(nr, nc, curr_node)
                
        board[r][c] = char  # Backtrack
        
        # Optimization: prune leaf nodes to speed up subsequent searches
        if not curr_node.children:
            del node.children[char]
            
    for r in range(m):
        for c in range(n):
            if board[r][c] in root.children:
                dfs(r, c, root)
                
    return res

⚡ Complexity analysis

  • Time Complexity: O(M × N × 4 × 3^(L-1)) where L is max word length.
  • Space Complexity: O(Total letters in words) for the Trie.
