#1283 Find the Smallest Divisor Given a Threshold MediumLeetCode

📋 The problem

Find the smallest divisor d so that the sum of ceil(x/d) over the array stays within a threshold (binary search on d).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an array of integers nums and an integer threshold, we need to choose a positive integer divisor, divide all the array by it, and sum the division's result. Find the smallest divisor such that the result mentioned above is less than or equal to threshold. Each division result is rounded up to the nearest integer greater than or equal to that element (e.g. 7/3 = 3).

🐢 Brute force first

Try divisors d = 1, 2, ... max(nums). Stop at first d with sum <= threshold. O(n * max(nums)) TLEs.

💡 Key insight: As divisor increases, ceil(num / divisor) monotonically decreases, so total sum monotonically decreases! Binary search in range [1, max(nums)].

🪜 The approach, step by step

  1. left = 1, right = max(nums).
  2. Helper computeSum(d): returns sum((x + d - 1) // d for x in nums).
  3. While left < right:
  4. mid = left + (right - left) // 2.
  5. If computeSum(mid) <= threshold: mid works, search for smaller: right = mid.
  6. Else: mid produces too large a sum, divisor must be larger: left = mid + 1.
  7. Return left.

🎞️ Visual dry run — nums = [1, 2, 5, 9], threshold = 6

Range: [1, 9]
Iter 1: mid = 5 → ceil(1/5)+ceil(2/5)+ceil(5/5)+ceil(9/5) = 1+1+1+2 = 5 <= 6 → right = 5
Iter 2: left = 1, right = 5 → mid = 3 → ceil: 1+1+2+3 = 7 > 6 → left = 4
Iter 3: left = 4, right = 5 → mid = 4 → ceil: 1+1+2+3 = 7 > 6 → left = 5
left == right == 5.
Smallest divisor = 5. ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
def smallestDivisor(nums, threshold):
    left, right = 1, max(nums)
    
    while left < right:
        mid = left + (right - left) // 2
        total = sum((x + mid - 1) // mid for x in nums)
        
        if total <= threshold:
            right = mid
        else:
            left = mid + 1
            
    return left

⏱️ Complexity

Time O(n * log(max(nums))). Space O(1).

⚠️ Edge cases

  • threshold == len(nums): divisor must be max(nums) since minimum contribution of each element is 1.
