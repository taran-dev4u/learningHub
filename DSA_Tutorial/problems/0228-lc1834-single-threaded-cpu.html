📋 The problem

Simulate a single-threaded CPU choosing, among available tasks, the shortest processing time first; return execution order.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given tasks with [enqueueTime, processingTime], a single-threaded CPU picks available tasks. When idle, it takes the earliest arriving task. Among available tasks, it picks the one with the shortest processing time (tie-breaker: smallest index). This is the Shortest Job First (SJF) scheduling algorithm.

🐢 Brute force first

Scan all tasks at each CPU tick to find available ones and pick the minimum → O(total_time * n), infeasible.

💡 Key insight: sort tasks by enqueueTime. Maintain a min-heap of available tasks ordered by (processingTime, originalIndex). Fast-forward current time time to the next task's enqueue time if the heap is empty.

🪜 The approach, step by step

  1. Store tasks with original indices: tasks = [(eq, proc, i) for i, (eq, proc) in enumerate(tasks)].
  2. Sort tasks by eq time.
  3. Initialize heap = [], time = 0, i = 0, res = [].
  4. While i < n or heap:
  5. If heap is empty and time < tasks[i][0], jump time = tasks[i][0].
  6. Push all tasks with eq <= time into heap as (proc, index).
  7. Pop (proc, index), advance time += proc, append index to res.
  8. Return res.

✅ The solution

import heapq

def getOrder(tasks):
    # Decorate with original index and sort by enqueue time
    indexed_tasks = sorted([(eq, proc, i) for i, (eq, proc) in enumerate(tasks)])
    
    res = []
    heap = []   # stores (processing_time, original_index)
    time = 0
    i = 0
    n = len(tasks)
    
    while i < n or heap:
        # If CPU is idle, advance time to next task arrival
        if not heap and time < indexed_tasks[i][0]:
            time = indexed_tasks[i][0]
            
        # Enqueue all tasks that have arrived by current time
        while i < n and indexed_tasks[i][0] <= time:
            heapq.heappush(heap, (indexed_tasks[i][1], indexed_tasks[i][2]))
            i += 1
            
        # Process task with shortest duration
        proc, idx = heapq.heappop(heap)
        time += proc
        res.append(idx)
        
    return res

⏱️ Complexity

Time O(n log n) — sorting tasks takes O(n log n), and each task is pushed/popped from the heap once in O(log n). Space O(n) — for indexed tasks and the heap.

⚠️ Edge cases

  • Large gaps between task arrivals: time-jump logic prevents TLE.
  • Multiple tasks with equal processing times: tie-breaking by original index handled by Python tuple comparison.
