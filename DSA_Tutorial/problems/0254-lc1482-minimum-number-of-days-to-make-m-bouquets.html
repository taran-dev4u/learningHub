#1482 Minimum Number of Days to Make m Bouquets MediumLeetCode

 

Pattern: Binary Search Patterns › Subpattern 8.3: On Answer / Condition Function · Problem 254 of 699

📋 The problem

Make m bouquets needing k adjacent bloomed flowers each; find the earliest day possible (binary search over days).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an integer array bloomDay, an integer m and an integer k. You want to make m bouquets. To make a bouquet, you need to use k adjacent flowers from the garden. The garden consists of n flowers, the i-th flower will bloom in the bloomDay[i]. Return the minimum number of days you need to wait to be able to make m bouquets from the garden. If it is impossible, return -1.

🐢 Brute force first

If m * k > len(bloomDay), impossible, return -1. Otherwise try day 1, 2... up to max(bloomDay). For each day, simulate flower availability and greedily count adjacent groups of size k. O(max(bloomDay) * n) TLE.

💡 Key insight: The number of bloomed flowers increases over time. More flowers can only make it easier to form bouquets. Monotonic predicate canMake(day) -> bool enables binary search on [min(bloomDay), max(bloomDay)]!

🪜 The approach, step by step

  1. If m * k > len(bloomDay), return -1.
  2. left = min(bloomDay), right = max(bloomDay).
  3. Helper canMake(day):
    • Iterate through bloomDay: if b <= day, increment consecutive count. If consecutive == k, bouquet count += 1, reset consecutive = 0.
    • If b > day, reset consecutive = 0.
    • Return bouquets >= m.
  4. While left < right: if canMake(mid): right = mid; else left = mid + 1.
  5. Return left.

✅ The solution

Reveal the commented solution (attempt it first!) 
def minDays(bloomDay, m, k):
    if m * k > len(bloomDay):
        return -1
        
    def canMake(days):
        bouquets = 0
        flowers = 0
        for b in bloomDay:
            if b <= days:
                flowers += 1
                if flowers == k:
                    bouquets += 1
                    flowers = 0
            else:
                flowers = 0
        return bouquets >= m
        
    left, right = min(bloomDay), max(bloomDay)
    while left < right:
        mid = left + (right - left) // 2
        if canMake(mid):
            right = mid
        else:
            left = mid + 1
            
    return left

⏱️ Complexity

Time O(n * log(max(bloomDay) - min(bloomDay))). Space O(1).

⚠️ Edge cases

  • m * k > n: impossible, return -1.
  • k = 1: any bloomed flower forms a bouquet independently.
