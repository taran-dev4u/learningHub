#1135 Connecting Cities With Minimum Cost MediumLeetCode

 

Pattern: Graph Traversal Patterns (DFS & BFS) › Subpattern 9.10: Graph - Minimum Spanning Tree · Problem 321 of 699

📋 The problem

Connect n cities at minimum total cost given possible connections (minimum spanning tree; -1 if disconnected).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There are n cities labeled 1 to n. You are given an array connections where connections[i] = [city1, city2, cost] represents the cost to build a bidirectional road between two cities. Return the minimum cost to connect all n cities such that there is a path between any pair of cities. If it is impossible, return -1.

This is a classic Minimum Spanning Tree problem on a sparse graph with explicit edge costs, solved directly by Kruskal's Algorithm using Disjoint Set Union (DSU).

🐢 Brute force vs optimal

Kruskal's algorithm greedily considers edges in increasing order of weight. If the edge connects two cities that are not yet in the same connected component, we add it to the spanning tree. If all n cities are connected using exactly n - 1 edges, the sum of weights is guaranteed to be minimal!

💡 Key insight: Sort edges by cost in ascending order. Process each edge: if union(city1, city2) successfully merges two previously disjoint components, increment our edge counter and accumulate the cost. If we place n - 1 edges, return total cost; if edges run out before reaching n - 1 edges, the graph is disconnected → return -1!

🪜 The approach, step by step

  1. If len(connections) < n - 1, return -1 immediately (impossible to connect n nodes).
  2. Sort connections by cost: connections.sort(key=lambda x: x[2]).
  3. Initialize DSU with parent = list(range(n + 1)) (1-indexed) and rank = [1] * (n + 1).
  4. Initialize total_cost = 0, edges_used = 0.
  5. For each u, v, cost in sorted connections:
    • If union(u, v) succeeds:
      • total_cost += cost
      • edges_used += 1
      • If edges_used == n - 1, break early!
  6. Return total_cost if edges_used == n - 1 else -1.

🎞️ Visual dry run — n=3, connections=[[1,2,5],[1,3,6],[2,3,1]]:

1. Sort by cost: [[2,3,1], [1,2,5], [1,3,6]]
2. Edge [2,3,1]: union(2,3) -> success! cost = 1, edges_used = 1.
3. Edge [1,2,5]: union(1,2) -> success! cost = 1 + 5 = 6, edges_used = 2.
4. edges_used == n - 1 (3 - 1 = 2) -> Done!

def minimumCost(n: int, connections: list[list[int]]) -> int:
    """
    Computes minimum cost to connect n cities via Kruskal's MST algorithm.
    """
    if len(connections) < n - 1:
        return -1
        
    # 1. Sort edges by weight
    connections.sort(key=lambda x: x[2])
    
    parent = list(range(n + 1))
    rank = [1] * (n + 1)
    
    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]
        
    def union(x, y):
        rx, ry = find(x), find(y)
        if rx == ry:
            return False
        if rank[rx] < rank[ry]:
            parent[rx] = ry
        elif rank[rx] > rank[ry]:
            parent[ry] = rx
        else:
            parent[ry] = rx
            rank[rx] += 1
        return True
        
    total_cost = 0
    edges_count = 0
    
    for u, v, cost in connections:
        if union(u, v):
            total_cost += cost
            edges_count += 1
            if edges_count == n - 1:
                return total_cost
                
    return -1

⚡ Complexity analysis

  • Time Complexity: O(E log E) to sort the edges, where E = len(connections). The DSU operations take near-linear O(E × α(V)) time.
  • Space Complexity: O(V) for the parent and rank arrays.

🚨 Edge cases to watch out for

  • Fewer than n-1 edges: Handled by upfront check len(connections) < n - 1.
  • Disconnected components: If edge count never reaches n - 1, returns -1.
