📋 The problem

Given points on a plane, return the maximum number of points that lie on one straight line.

Problem Overview

Given an array of points where points[i] = [xi, yi] represents a point on the X-Y plane, return the maximum number of points that lie on the same straight line.

Key Insights

For each point {2, 3, 5}i{2, 3, 5}, calculate the slope to every other point {2, 3, 5}j > i{2, 3, 5} and find the maximum frequency in a hash map.

Python 3 Solution (Exact Coprime Slope Hashing) 
from typing import List
from collections import defaultdict
import math

class Solution:
    def maxPoints(self, points: List[List[int]]) -> int:
        n = len(points)
        if n <= 2:
            return n
            
        max_pts = 1
        for i in range(n):
            slopes = defaultdict(int)
            x1, y1 = points[i]
            for j in range(i + 1, n):
                x2, y2 = points[j]
                dx = x2 - x1
                dy = y2 - y1
                g = math.gcd(dx, dy)
                dx //= g
                dy //= g
                # Ensure canonical orientation
                if dx < 0 or (dx == 0 and dy < 0):
                    dx, dy = -dx, -dy
                slopes[(dx, dy)] += 1
                
            if slopes:
                max_pts = max(max_pts, max(slopes.values()) + 1)
                
        return max_pts
