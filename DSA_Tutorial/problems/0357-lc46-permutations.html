📋 The problem

Return all permutations of an array of distinct numbers.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an array nums of distinct integers, return all the possible permutations in any order.

For an array of length n, there are exactly n! permutations. At each step of the recursion tree, any element not yet used in the current prefix can be placed next.

💡 Key insight: Two standard approaches:
  1. Visited Boolean Array: Maintain visited = [False] * n. Loop i from 0 to n - 1: if not visited, mark visited, push to path, recurse, pop and unmark.
  2. In-place Swapping: In backtrack(first), swap nums[first] with nums[i] for i ∈ [first, n-1]. Requires zero auxiliary visited set!

✅ The solution

def permute(nums: list[int]) -> list[list[int]]:
    """
    Generates all permutations using backtracking with a visited tracking array.
    """
    n = len(nums)
    res = []
    path = []
    used = [False] * n
    
    def backtrack():
        if len(path) == n:
            res.append(list(path))
            return
            
        for i in range(n):
            if not used[i]:
                used[i] = True
                path.append(nums[i])
                backtrack()
                path.pop()
                used[i] = False
                
    backtrack()
    return res

⚡ Complexity analysis

  • Time Complexity: O(N × N!). There are N! permutations, and each takes O(N) to copy into the result.
  • Space Complexity: O(N) for the recursion stack and used array.
