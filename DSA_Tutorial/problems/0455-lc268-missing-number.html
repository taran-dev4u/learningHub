📋 The problem

An array holds n distinct numbers from 0..n; return the one number missing from the range.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an array nums containing n distinct numbers in the range [0, n], return the only number in the range that is missing from the array.

XOR Invariance: XOR all numbers in nums and all indices from $0$ to $n$: $$ ext{missing} = n \oplus \left( \bigoplus_{i=0}^{n-1} (i \oplus nums[i]) \right)$$ Every number that is present appears twice (once in range $[0, n]$, once in nums) and cancels out to 0. The missing number appears only once!

🐢 Brute force vs optimal

Gauss sum $ rac{n(n+1)}{2} - \sum nums$ can suffer integer overflow in 32-bit fixed integer types. XOR avoids all arithmetic overflow completely in $O(n)$ time and $O(1)$ space.

💡 Key insight: res = len(nums); for i, x in enumerate(nums): res ^= i ^ x. Returns the missing number in $O(n)$ time and $O(1)$ space.

✅ The solution

Reveal the commented solution (attempt it first!) 
def missingNumber(nums: list[int]) -> int:
    res = len(nums)
    for i, x in enumerate(nums):
        res ^= i ^ x
    return res

Complexity

Time: $O(n)$ — Single linear loop.
Space: $O(1)$ — Single accumulator variable.
