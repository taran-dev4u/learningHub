📋 The problem

Return every sentence you can form by segmenting a string into dictionary words.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given a string s and a dictionary of strings wordDict, add spaces in s to construct a sentence where each word is a valid dictionary word. Return all such possible sentences.

Key Insights

Store wordDict in a Trie (or HashSet) for $O(1)$ prefix matches. Use DFS with Memoization: memo[start_idx] stores all valid sentence tails from index start_idx to end of string $s$. At index $i$, match prefixes of $s[i:]$ against the Trie. For every matching word ending at $j$, recursively obtain sentences for $s[j:]$, prepending the matched word.

Python 3 Solution (DFS with Memoization) 
from typing import List

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> List[str]:
        words = set(wordDict)
        memo = {}
        
        def dfs(start: int) -> List[str]:
            if start == len(s):
                return [""]
            if start in memo:
                return memo[start]
                
            res = []
            for end in range(start + 1, len(s) + 1):
                word = s[start:end]
                if word in words:
                    sub_sentences = dfs(end)
                    for sub in sub_sentences:
                        if sub:
                            res.append(word + " " + sub)
                        else:
                            res.append(word)
                            
            memo[start] = res
            return res
            
        return dfs(0)

Complexity & Edge Cases

  • Time Complexity: $O(2^N)$ worst-case output sentences, bounded by memoization on non-matching subproblems.
  • Space Complexity: $O(N imes 2^N)$ to store sentences.
