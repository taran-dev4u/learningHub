#135 Candy HardLeetCode

 

Pattern: Greedy Patterns › Subpattern 10.7: Assign / Resource Allocation · Problem 346 of 699

📋 The problem

Children in a line have ratings; give each at least one candy so higher-rated kids get more than their neighbors, minimizing total candy.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There are n children standing in a line. Each child is assigned a rating value given in the integer array ratings. You are giving candies to these children subjected to the following requirements:

  1. Each child must have at least one candy.
  2. Children with a higher rating get more candies than their neighbors.
Return the minimum number of candies you need to have to distribute the candies to the children.

🐢 Brute force vs optimal

Each child has two neighbors: left neighbor and right neighbor. A two-pass greedy strategy satisfies both constraints independently:

  1. Left-to-Right Pass: If ratings[i] > ratings[i - 1], child i must have more candies than child i - 1: candies[i] = candies[i - 1] + 1.
  2. Right-to-Left Pass: If ratings[i] > ratings[i + 1], child i must also have more candies than child i + 1: candies[i] = max(candies[i], candies[i + 1] + 1).
💡 Key insight: Two passes guarantee that both local conditions (left-neighbor and right-neighbor) are simultaneously satisfied while using the minimum possible candies.

🎞️ Visual dry run — ratings = [1, 0, 2]:

1. Initialize: candies = [1, 1, 1]
2. Left-to-right:
   i=1: ratings[1]=0 <= ratings[0]=1 -> candies[1] stays 1
   i=2: ratings[2]=2 > ratings[1]=0 -> candies[2] = candies[1] + 1 = 2
   candies after L-to-R: [1, 1, 2]
3. Right-to-left:
   i=1: ratings[1]=0 <= ratings[2]=2 -> stays 1
   i=0: ratings[0]=1 > ratings[1]=0 -> candies[0] = max(1, candies[1] + 1) = 2!
   candies after R-to-L: [2, 1, 2]
Total candies = 2 + 1 + 2 = 5 ✓

✅ The solution

def candy(ratings: list[int]) -> int:
    """
    Distributes minimum candies satisfying neighbor rating constraints via two passes.
    """
    n = len(ratings)
    candies = [1] * n
    
    # Left-to-right pass
    for i in range(1, n):
        if ratings[i] > ratings[i - 1]:
            candies[i] = candies[i - 1] + 1
            
    # Right-to-left pass
    for i in range(n - 2, -1, -1):
        if ratings[i] > ratings[i + 1]:
            candies[i] = max(candies[i], candies[i + 1] + 1)
            
    return sum(candies)

⚡ Complexity analysis

  • Time Complexity: O(N). Two linear passes.
  • Space Complexity: O(N) for the candies array.
