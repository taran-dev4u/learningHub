📋 The problem

Return the k most frequent elements of an array.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an integer array nums and an integer $k$, return the $k$ most frequent elements. The algorithm must be better than $O(n \log n)$.

Key Insights

We can count frequencies using a hash map in $O(n)$ time. To extract the top $k$ without sorting all distinct keys in $O(u \log u)$, we have two optimal approaches:

  1. Min-Heap: Keep a min-heap of size $k$ based on frequency: $O(n \log k)$ time, $O(n)$ space.
  2. Bucket Sort (Optimal Linear Time): Frequencies can range only from $1$ to $n$. We create a list of buckets where buckets[f] contains all elements that appear with frequency $f$. We iterate backwards from bucket $n$ down to $1$ to collect $k$ elements in $O(n)$ time!
Python 3 Solution (Bucket Sort - O(N)) 
from typing import List
from collections import Counter

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        counts = Counter(nums)
        n = len(nums)
        # buckets[i] will store list of elements with frequency i
        buckets = [[] for _ in range(n + 1)]
        
        for num, freq in counts.items():
            buckets[freq].append(num)
            
        res = []
        for freq in range(n, 0, -1):
            for num in buckets[freq]:
                res.append(num)
                if len(res) == k:
                    return res
        return res

Complexity & Edge Cases

  • Time Complexity: $O(n)$ total. Counter generation takes $O(n)$, bucket population takes $O(u) \le O(n)$, and iterating backwards takes at most $O(n)$ steps.
  • Space Complexity: $O(n)$ for the frequency map and buckets.
  • Edge Cases: $k$ equals number of unique elements, all elements identical ($freq = n$), negative values.
