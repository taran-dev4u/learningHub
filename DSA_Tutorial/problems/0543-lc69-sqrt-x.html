Problem Overview

Given a non-negative integer {2, 3, 5}x{2, 3, 5}, compute and return the square root of {2, 3, 5}x{2, 3, 5} rounded down to the nearest integer. Do not use any built-in exponent functions or operators like pow(x, 0.5) or x ** 0.5.

Key Insights

For {2, 3, 5}x \ge 1{2, 3, 5}, {2, 3, 5}\lfloor \sqrt{x} floor{2, 3, 5} is an integer in the range {2, 3, 5}[1, x // 2 + 1]{2, 3, 5}. Because the sequence {2, 3, 5}1^2, 2^2, 3^2, \dots{2, 3, 5} is monotonically increasing, we can use Binary Search to find the largest integer {2, 3, 5}m{2, 3, 5} such that {2, 3, 5}m^2 \le x{2, 3, 5}.

Python 3 Solution (Binary Search) 
class Solution:
    def mySqrt(self, x: int) -> int:
        if x < 2:
            return x
        
        left, right = 1, x // 2
        ans = 1
        
        while left <= right:
            mid = (left + right) // 2
            sq = mid * mid
            if sq == x:
                return mid
            elif sq < x:
                ans = mid  # mid is a valid candidate
                left = mid + 1
            else:
                right = mid - 1
                
        return ans

  • Time Complexity: {2, 3, 5}O(\log x){2, 3, 5} operations.
  • Space Complexity: {2, 3, 5}O(1){2, 3, 5}.
  • Edge Cases: {2, 3, 5}x = 0{2, 3, 5} (returns 0), {2, 3, 5}x = 1{2, 3, 5} (returns 1), large values like {2, 3, 5}x = 2^{31} - 1{2, 3, 5}.
