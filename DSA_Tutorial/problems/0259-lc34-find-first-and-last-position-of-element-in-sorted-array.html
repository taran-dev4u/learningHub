📋 The problem

In a sorted array with duplicates, find the first and last index of a target value in O(log n); return [-1,-1] if absent.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Find First/Last Occurrence — Two-pass or single-pass lower/upper bound to find the first or last occurrence of a target.

💡 Key idea
Two lower-bound searches: first index ≥ target, and first index ≥ target+1, minus one.

Why this pattern?

  • sorted (or rotated-sorted) array + find/insert position
  • "minimize the maximum" / "maximize the minimum"
  • a feasibility check that flips once as a parameter grows
  • O(log n) demanded explicitly

Pattern template to adapt

# Lower-bound shape: smallest index where check(i) is True
lo, hi = 0, n            # hi = n allows "no answer" result
while lo < hi:
    mid = (lo + hi) // 2
    if check(mid):        # True region is on the right side's left edge
        hi = mid          # mid might be the answer — keep it in range
    else:
        lo = mid + 1      # mid is definitely not — discard it
return lo                 # first True (or n if none)
