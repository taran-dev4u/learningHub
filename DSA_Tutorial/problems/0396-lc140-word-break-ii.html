📋 The problem

Return every sentence you can form by segmenting a string into dictionary words.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a string s and a dictionary of strings wordDict, add spaces in s to construct a sentence where each word is a valid dictionary word. Return all such possible sentences in any order.

Unlike Word Break I (LC 139) which asks for a boolean existence, Word Break II asks to construct all sentences. If every partition is valid, the number of outputs can be exponential (e.g. s = "aaaaa", wordDict = ["a", "aa"]). We use memoized backtracking (top-down DP) to cache results for subproblems dfs(i) returning all valid suffixes starting at index i.

🐢 Brute force vs optimal

Plain backtracking explores overlapping suffixes multiple times. Memoizing memo[i] = list of valid sentences for s[i:] ensures each unique suffix is computed only once, skipping doomed branches instantly.

💡 Key insight: Top-down DFS with memoization: memo[start] stores all valid sentences formable from suffix s[start:]. Prunes dead ends immediately.

✅ The solution

def wordBreak(s: str, wordDict: list[str]) -> list[str]:
    word_set = set(wordDict)
    memo = {}
    
    def dfs(start: int) -> list[str]:
        if start in memo:
            return memo[start]
        if start == len(s):
            return [""]
            
        res = []
        for end in range(start + 1, len(s) + 1):
            word = s[start:end]
            if word in word_set:
                sub_sentences = dfs(end)
                for sub in sub_sentences:
                    res.append(word + ("" if not sub else " " + sub))
                    
        memo[start] = res
        return res
        
    return dfs(0)

Complexity

Time: $O(n^2 + 2^n)$ in worst-case dense matchings, but heavily pruned in practice.
Space: $O(n \times 2^n)$ to store all reconstructed paths and recursion stack.
