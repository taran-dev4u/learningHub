📋 The problem

Design a calendar that books an event only if it doesn't double-book (overlap any existing event).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are implementing a program to use as your calendar. We can add a new event if adding the event will not cause a double booking (two events having some non-empty intersection $[start, end)$).

Maintain booked events in sorted order of start times: Use binary search (bisect_right) to locate where the new interval $[start, end)$ should be inserted. Check only two neighbors: 1. The preceding interval $[prev_s, prev_e)$: must have $prev_e \le start$. 2. The succeeding interval $[next_s, next_e)$: must have $end \le next_s$. If both checks pass, insert the interval and return True!

🐢 Brute force vs optimal

Linear check of all intervals takes $O(N)$. Binary search checks in $O(\log N)$ time and inserts in $O(N)$ time.

💡 Key insight: Sorted intervals: binary search finds insertion index in $O(\log N)$. Only verify non-overlap with immediate left neighbor (prev_end <= start) and right neighbor (end <= next_start).

✅ The solution

Reveal the commented solution (attempt it first!) 
import bisect

class MyCalendar:
    def __init__(self):
        self.calendar = [] # sorted list of (start, end)

    def book(self, start: int, end: int) -> bool:
        idx = bisect.bisect_right(self.calendar, (start, end))
        
        # Check left neighbor
        if idx > 0 and self.calendar[idx - 1][1] > start:
            return False
            
        # Check right neighbor
        if idx < len(self.calendar) and self.calendar[idx][0] < end:
            return False
            
        self.calendar.insert(idx, (start, end))
        return True

Complexity

Time: $O(\log N)$ search + $O(N)$ insertion.
Space: $O(N)$ — Sorted calendar intervals.
