#95 Unique Binary Search Trees II MediumLeetCode

 

Pattern: Dynamic Programming (DP) Patterns › Subpattern 12.10: Catalan Numbers · Problem 414 of 699

📋 The problem

Generate all structurally unique binary search trees that store the values 1..n.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer n, return all structurally unique BST's (binary search trees) which has exactly n nodes of unique values from 1 to n.

Every number $i \in [1, n]$ can serve as the root node. Because of BST properties: - All values $< i$ (i.e. $[1 \dots i-1]$) must go into the left subtree. - All values $> i$ (i.e. $[i+1 \dots n]$) must go into the right subtree.

Use divide and conquer: generate all possible left subtrees for $[start, i-1]$ and all possible right subtrees for $[i+1, end]$, then form Cartesian product combinations with root $i$.

🐢 Brute force vs optimal

The total number of structurally unique BSTs is the $n$-th Catalan number $C_n = \frac{1}{n+1}\binom{2n}{n}$. Memoizing intervals (start, end) prevents re-generating identical subtrees.

💡 Key insight: generate(start, end): for root $i \in [start, end]$, Cartesian product of left_trees and right_trees attached to TreeNode(i).

✅ The solution

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def generateTrees(n: int) -> list[TreeNode]:
    if n == 0:
        return []
        
    memo = {}
    
    def build(start: int, end: int) -> list[TreeNode]:
        if start > end:
            return [None]
        if (start, end) in memo:
            return memo[(start, end)]
            
        all_trees = []
        for root_val in range(start, end + 1):
            left_trees = build(start, root_val - 1)
            right_trees = build(root_val + 1, end)
            
            for l in left_trees:
                for r in right_trees:
                    root = TreeNode(root_val, l, r)
                    all_trees.append(root)
                    
        memo[(start, end)] = all_trees
        return all_trees
        
    return build(1, n)

Complexity

Time: $O(4^n / n^{3/2})$ — Governed by Catalan number generation.
Space: $O(4^n / n^{3/2})$ — Space to store all unique tree structures.
