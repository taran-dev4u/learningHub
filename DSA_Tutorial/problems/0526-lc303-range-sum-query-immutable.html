📋 The problem

Precompute over an immutable array so sumRange(i, j) queries answer in O(1).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer array nums, handle multiple queries of calculating the sum of elements between indices left and right inclusive where the array is immutable.

Precompute the Prefix Sum Array in the constructor: $$prefix[0] = 0, \quad prefix[i] = prefix[i - 1] + nums[i - 1]$$ Then any range sum is answered in strict $O(1)$ time: $$ ext{sumRange}(left, right) = prefix[right + 1] - prefix[left]$$

🐢 Brute force vs optimal

Summing elements on every query takes $O(n)$ per call. Prefix sum array answers in $O(1)$ time with $O(n)$ precomputation.

💡 Key insight: Prefix sum array: prefix[i] = prefix[i-1] + nums[i-1]. Range sum $[l, r]$ is prefix[r + 1] - prefix[l] in $O(1)$!

✅ The solution

Reveal the commented solution (attempt it first!) 
class NumArray:
    def __init__(self, nums: list[int]):
        self.prefix = [0]
        for x in nums:
            self.prefix.append(self.prefix[-1] + x)

    def sumRange(self, left: int, right: int) -> int:
        return self.prefix[right + 1] - self.prefix[left]

Complexity

Time: Constructor: $O(n)$. sumRange: $O(1)$ instant difference.
Space: $O(n)$ — Prefix sum array.
