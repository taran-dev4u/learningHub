📋 The problem

Search a target in a matrix where each row and each column is sorted ascending.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Write an efficient algorithm that searches for a value in an m x n matrix where integers in each row are sorted in ascending from left to right, and integers in each column are sorted in ascending from top to bottom. Unlike LC 74, the first element of row i+1 is NOT necessarily greater than the last element of row i.

🐢 Brute force first

Linear scan of all cells takes O(m * n). Running binary search on each row takes O(m log n). Can we do O(m + n)?

💡 Key insight: Start at the top-right corner (or bottom-left). At position (row, col) = (0, n-1): all elements in the same row to the left are smaller; all elements in the same column downward are larger! This creates a Binary Search Tree (BST) property rooted at the top-right corner. If val > target, decrement col; if val < target, increment row.

🪜 The approach, step by step

  1. Start at row = 0, col = n - 1 (top-right corner).
  2. While row < m and col >= 0:
  3. Let val = matrix[row][col].
  4. If val == target, return True.
  5. If val > target, target cannot be in column col (all elements below are even larger), so eliminate this column: col -= 1.
  6. If val < target, target cannot be in row row (all elements to the left are even smaller), so eliminate this row: row += 1.
  7. If boundaries are crossed without finding target, return False.

✅ The solution

Reveal the commented solution (attempt it first!) 
def searchMatrix(matrix, target):
    """
    Z-search / Top-right corner traversal leveraging BST property.
    """
    if not matrix or not matrix[0]:
        return False
        
    m, n = len(matrix), len(matrix[0])
    row, col = 0, n - 1
    
    while row < m and col >= 0:
        val = matrix[row][col]
        if val == target:
            return True
        elif val > target:
            col -= 1  # eliminate column
        else:
            row += 1  # eliminate row
            
    return False

⏱️ Complexity

Time O(m + n) — Each step either decrements col or increments row. At most m + n steps. Space O(1).

⚠️ Edge cases

  • Empty matrix or row with 0 length.
  • Target smaller than top-left or larger than bottom-right.
  • Matrix of 1x1.
