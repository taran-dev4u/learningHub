📋 The problem

From a list of unique words, return all index pairs whose concatenation forms a palindrome.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given a list of unique words, return all pairs of distinct indices (i, j) such that the concatenation words[i] + words[j] is a palindrome.

Key Insights

Checking every pair takes $O(N^2 imes L)$ (TLE). Notice: For $w_1 + w_2$ to be a palindrome:

  1. If $|w_1| == |w_2|$, $w_2$ must be the exact reverse of $w_1$.
  2. If $|w_1| > |w_2|$, $w_1$ can be split into prefix + suffix:
    • If prefix is a palindrome, $w_2$ must be the reverse of suffix!
    • If suffix is a palindrome, $w_2$ must be the reverse of prefix!
We insert words into a hash map {word: index}. For each word, check all valid split points $k$ where one half is a palindrome and the reverse of the other half exists in our dictionary.

Python 3 Solution (Prefix/Suffix Palindrome Decomposition) 
from typing import List

class Solution:
    def palindromePairs(self, words: List[str]) -> List[List[int]]:
        def is_pal(s: str) -> bool:
            return s == s[::-1]
            
        word_to_idx = {w: i for i, w in enumerate(words)}
        res = []
        
        for i, w in enumerate(words):
            L = len(w)
            for j in range(L + 1):
                pref, suff = w[:j], w[j:]
                
                # Case 1: pref is palindrome -> need rev(suff) + pref + suff
                if is_pal(pref):
                    rev_suff = suff[::-1]
                    if rev_suff in word_to_idx and word_to_idx[rev_suff] != i:
                        res.append([word_to_idx[rev_suff], i])
                        
                # Case 2: suff is palindrome -> need pref + suff + rev(pref)
                # j < L avoids duplicate when j == L (already covered when j == 0)
                if j < L and is_pal(suff):
                    rev_pref = pref[::-1]
                    if rev_pref in word_to_idx and word_to_idx[rev_pref] != i:
                        res.append([i, word_to_idx[rev_pref]])
                        
        return res

Complexity & Edge Cases

  • Time Complexity: $O(N imes L^2)$ where $N$ is number of words and $L$ is word length.
  • Space Complexity: $O(N imes L)$ hash map.
  • Edge Cases: Empty string "" paired with any palindrome word.
