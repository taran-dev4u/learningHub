📋 The problem

Design a structure that adds, removes, and queries coverage of number ranges (interval set with add/remove/query).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

A Range Module is a module that tracks ranges of numbers. Design a data structure to add, query, and remove intervals in half-open intervals $[left, right)$.

Disjoint Sorted Intervals with Binary Search: Maintain a 1D flat list of boundary coordinates: [l0, r0, l1, r1, ...]. Every pair track[2*i] and track[2*i + 1] forms a valid half-open interval $[l_i, r_i)$. - bisect_left and bisect_right identify the exact overlapping insertion range in $O(\log N)$ time. - Slice replacement merges or punches holes cleanly.

🐢 Brute force vs optimal

Interval list with binary search provides $O(\log N)$ query time and $O(N)$ modification time.

💡 Key insight: Flat boundary list with parity indexing: odd index indicates inside an active interval; even index indicates outside. Binary search determines state in $O(\log N)$.

✅ The solution

import bisect

class RangeModule:
    def __init__(self):
        self.track = []

    def addRange(self, left: int, right: int) -> None:
        l = bisect.bisect_left(self.track, left)
        r = bisect.bisect_right(self.track, right)
        sub = []
        if l % 2 == 0:
            sub.append(left)
        if r % 2 == 0:
            sub.append(right)
        self.track[l:r] = sub

    def queryRange(self, left: int, right: int) -> bool:
        l = bisect.bisect_right(self.track, left)
        r = bisect.bisect_left(self.track, right)
        return l % 2 == 1 and l == r

    def removeRange(self, left: int, right: int) -> None:
        l = bisect.bisect_left(self.track, left)
        r = bisect.bisect_right(self.track, right)
        sub = []
        if l % 2 == 1:
            sub.append(left)
        if r % 2 == 1:
            sub.append(right)
        self.track[l:r] = sub

Complexity

Time: queryRange: $O(\log N)$. addRange, removeRange: $O(N)$ array slice.
Space: $O(N)$ — Boundary list.
