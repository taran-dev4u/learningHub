📋 The problem

Implement a trie (prefix tree) with insert, exact-word search, and startsWith prefix search.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

A trie (pronounced as "try") or prefix tree is a tree data structure used to efficiently store and retrieve keys in a dataset of strings.

Every TrieNode contains: 1. children: A map or 26-element array pointing to child TrieNodes corresponding to each character. 2. is_end: A boolean flag indicating whether a complete word terminates at this node.

🐢 Brute force vs optimal

Searching a hash set for prefix matches requires checking every string ($O(N \times L)$). A Trie searches prefixes in strictly $O(L)$ time where $L$ is the word length, completely independent of the total number of words $N$ in the dictionary!

💡 Key insight: Each tree node branches on character ch: node = node.children.setdefault(ch, TrieNode()). Prefixes share common ancestry paths.

✅ The solution

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        curr = self.root
        for ch in word:
            if ch not in curr.children:
                curr.children[ch] = TrieNode()
            curr = curr.children[ch]
        curr.is_end = True

    def search(self, word: str) -> bool:
        curr = self.root
        for ch in word:
            if ch not in curr.children:
                return False
            curr = curr.children[ch]
        return curr.is_end

    def startsWith(self, prefix: str) -> bool:
        curr = self.root
        for ch in prefix:
            if ch not in curr.children:
                return False
            curr = curr.children[ch]
        return True

Complexity

Time: $O(L)$ for insert, search, and startsWith where $L$ is word/prefix length.
Space: $O(N \times L)$ where $N$ is total words and $L$ is average length.
