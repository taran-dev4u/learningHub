📋 The problem

Given meeting intervals, decide whether one person can attend them all (no overlaps).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Meeting Rooms & Scheduling — Sort and compare current's end with the previous — counts overlaps or schedules.

💡 Key idea
Sort; any start before the previous end ⇒ can't attend.

Why this pattern?

  • "merge overlapping intervals" / "insert interval"
  • "minimum meeting rooms / platforms / arrows"
  • "remove fewest to make non-overlapping" (greedy by end)
  • bookings, calendars, seat/resource occupancy over time

Pattern template to adapt

# Merge intervals
intervals.sort(key=lambda iv: iv[0])
merged = []
for s, e in intervals:
    if merged and s <= merged[-1][1]:            # overlaps the last block
        merged[-1][1] = max(merged[-1][1], e)    # extend it
    else:
        merged.append([s, e])

# Sweep line: max concurrent intervals
events = []
for s, e in intervals:
    events.append((s, 1))          # interval opens
    events.append((e, -1))         # interval closes
events.sort()                      # ties: -1 before +1 ⇒ [1,2],[2,3] don't stack
cur = peak = 0
for _, delta in events:
    cur += delta
    peak = max(peak, cur)
