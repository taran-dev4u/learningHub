📋 The problem

Convert a string to a 32-bit signed integer the way atoi does: skip leading spaces, read an optional sign, read digits until a non-digit, and clamp to the 32-bit range.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

String to Integer (atoi) — Skip whitespace, capture sign, parse digits with overflow clamping.

💡 Key idea
State machine: skip spaces, optional sign, consume digits, clamp to 32-bit range.

Why this pattern?

  • "anagram", "permutation of", "rearrange"
  • "group the strings that…" → canonical key + dict
  • palindromes (two pointers or expand-from-center)
  • parse/normalize (spaces, signs, overflow) — careful state machines

def expand(s, l, r):
    while l >= 0 and r < len(s) and s[l] == s[r]:
        l -= 1; r += 1
    return s[l+1:r]               # overshoot by one on both sides
