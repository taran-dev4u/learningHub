📋 The problem

Compute the integer square root of a non-negative integer (the floor of √x) without using built-in power functions.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a non-negative integer x, compute and return the square root of x rounded down to the nearest integer. The returned integer should be non-negative as well. Do not use built-in exponent functions like pow(x, 0.5).

🐢 Brute force first

Try every integer i = 1, 2, 3... and check if i * i <= x. Stop when (i+1) * (i+1) > x. Time: O(sqrt(x)). For x = 2^31 - 1, sqrt(x) ≈ 46,340 iterations.

💡 Key insight: The function f(m) = m * m is monotonically increasing for m >= 0. This is a binary search on the range [0, x] (or [1, x // 2] for x >= 4). We seek the largest integer m such that m * m <= x.

🪜 The approach, step by step

  1. If x < 2, return x (handles 0 and 1).
  2. Set left = 1, right = x // 2.
  3. While left <= right:
  4. Compute mid = left + (right - left) // 2.
  5. Compute sq = mid * mid.
  6. If sq == x, return mid.
  7. If sq < x, mid is a valid candidate for floor(sqrt(x)), but a larger one might exist: ans = mid, left = mid + 1.
  8. Else (sq > x), mid is too large: right = mid - 1.
  9. Return ans.

🎞️ Visual dry run — x = 8

✅ The solution

def mySqrt(x):
    """
    Approach 1: Binary search on answer range [0, x // 2]
    """
    if x < 2:
        return x
        
    left, right = 1, x // 2
    ans = 1
    
    while left <= right:
        mid = left + (right - left) // 2
        if mid * mid <= x:
            ans = mid
            left = mid + 1
        else:
            right = mid - 1
            
    return ans

# Approach 2: Newton-Raphson method (super fast convergence)
def mySqrt_newton(x):
    if x < 2:
        return x
    r = x
    while r * r > x:
        r = (r + x // r) // 2
    return r

⏱️ Complexity

Time O(log x) for binary search (or O(log(log x)) for Newton's method). Space O(1).

⚠️ Edge cases

  • x = 0: returns 0.
  • x = 1: returns 1.
  • Large integers up to 2^31 - 1: avoid overflow in languages with fixed integer sizes by using mid <= x // mid.
