📋 The problem

Search a target in a matrix whose rows are sorted and where each row starts after the previous row ends, in O(log(m·n)).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an m x n integer matrix with two properties: each row is sorted in non-decreasing order, and the first integer of each row is greater than the last integer of the previous row. Determine if target exists in the matrix in O(log(m * n)) time.

🐢 Brute force first

Linear scan over all m * n cells → O(m * n). Or binary search each row independently → O(m log n). Suboptimal because the matrix is globally sorted end-to-end!

💡 Key insight: The entire matrix can be treated as a single flattened 1D sorted array of length m * n! Any 1D index idx maps directly to 2D coordinates: row = idx // n, col = idx % n. Run standard binary search on [0, m * n - 1].

🪜 The approach, step by step

  1. Let m = len(matrix), n = len(matrix[0]).
  2. Initialize left = 0, right = m * n - 1.
  3. While left <= right:
  4. Compute mid = left + (right - left) // 2.
  5. Convert mid to 2D coordinate: val = matrix[mid // n][mid % n].
  6. If val == target, return True.
  7. If val < target, left = mid + 1.
  8. Else right = mid - 1.
  9. If not found, return False.

✅ The solution

def searchMatrix(matrix, target):
    """
    Treat the m x n matrix as a single 1D virtual sorted array.
    """
    if not matrix or not matrix[0]:
        return False
        
    m, n = len(matrix), len(matrix[0])
    left, right = 0, m * n - 1
    
    while left <= right:
        mid = left + (right - left) // 2
        # Coordinate mapping from 1D index to 2D row and col
        val = matrix[mid // n][mid % n]
        
        if val == target:
            return True
        elif val < target:
            left = mid + 1
        else:
            right = mid - 1
            
    return False

⏱️ Complexity

Time O(log(m * n)) = O(log m + log n) — Performs binary search over m * n elements. Space O(1) — No flattened array created; coordinates computed via division/modulo on the fly.

⚠️ Edge cases

  • 1x1 matrix: single cell comparison.
  • Single row or single column matrix: properly mapped by mid // n and mid % n.
  • Target smaller than matrix minimum (top-left) or larger than matrix maximum (bottom-right).
