📋 The problem

Decide whether one string is an anagram of another.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given two strings s and t, return true if t is an anagram of s, and false otherwise.

If $ ext{len}(s) e ext{len}(t)$, they cannot be anagrams. Maintain a single frequency table of size 26: - Increment count for each character in $s$: table[ord(c) - 97] += 1. - Decrement count for each character in $t$: table[ord(c) - 97] -= 1. - If any count drops below 0, return False immediately!

🐢 Brute force vs optimal

Sorting both strings takes $O(n \log n)$ time and $O(n)$ space. A fixed 26-int frequency array runs in $O(n)$ time with $O(1)$ constant space.

💡 Key insight: Fixed 26-element integer array. One pass increments from $s$ and decrements from $t$. If all frequencies balance to 0, they are anagrams.

✅ The solution

Reveal the commented solution (attempt it first!) 
def isAnagram(s: str, t: str) -> bool:
    if len(s) != len(t):
        return False
        
    counts = [0] * 26
    for c1, c2 in zip(s, t):
        counts[ord(c1) - ord('a')] += 1
        counts[ord(c2) - ord('a')] -= 1
        
    return all(c == 0 for c in counts)

Complexity

Time: $O(n)$ — Single linear pass over length $n$.
Space: $O(1)$ — Exactly 26 integers allocated.
