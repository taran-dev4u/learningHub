📋 The problem

Design shuffle() returning a uniformly random permutation of an array, and reset() restoring the original.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Fisher-Yates Shuffle — Fisher-Yates shuffle — swap each index with a random later index for a uniform permutation.

💡 Key idea
Fisher-Yates: swap i with a uniform j ≤ i, from the back.

Why this pattern?

  • "shuffle" / "random pick" with uniformity required
  • stream or linked list of unknown length + "pick one uniformly"
  • pick index proportional to weight → prefix sums + bisect
  • O(1) getRandom in a set → array + swap-delete

# Fisher-Yates shuffle — uniform over all n! orders
for i in range(len(a) - 1, 0, -1):
    j = random.randint(0, i)          # j ∈ [0, i]  (inclusive!)
    a[i], a[j] = a[j], a[i]
