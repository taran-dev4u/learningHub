📋 The problem

Count the islands in a grid of '1' (land) and '0' (water); land connects horizontally and vertically.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an m x n 2D binary grid grid representing a map of '1's (land) and '0's (water), return the number of islands. An island is surrounded by water and is formed by connecting adjacent lands horizontally or vertically.

🐢 Brute force first

Checking every pair of land cells for path connectivity via pairwise BFS takes O((m*n)^2). Suboptimal because connected components can be traversed in a single pass.

💡 Key insight: Iterate over every cell in the grid. When you encounter an unvisited land cell '1', you have discovered a new island! Increment the island count, then immediately launch a DFS or BFS traversal from that cell to visit and "sink" (or mark visited) the entire connected component of land. Every cell is visited at most a constant number of times.

🪜 The approach, step by step

  1. Initialize islands = 0. Let m = len(grid), n = len(grid[0]).
  2. Iterate through row r from 0 to m-1 and col c from 0 to n-1:
  3. If grid[r][c] == '1':
    • Increment islands += 1.
    • Trigger dfs(r, c) to sink the island.
  4. In dfs(r, c):
    • Base case: if out of bounds (r < 0 or r >= m or c < 0 or c >= n) or grid[r][c] != '1', return.
    • Mark cell as visited: grid[r][c] = '0' (in-place modification avoids an extra visited set).
    • Recursively call dfs on 4 neighbors: (r+1, c), (r-1, c), (r, c+1), (r, c-1).
  5. Return islands.

✅ The solution

def numIslands(grid):
    """
    Connected components count via in-place DFS flood fill.
    """
    if not grid or not grid[0]:
        return 0
        
    m, n = len(grid), len(grid[0])
    islands = 0
    
    def dfs(r, c):
        if r < 0 or r >= m or c < 0 or c >= n or grid[r][c] != '1':
            return
            
        # Sink the land cell to mark as visited
        grid[r][c] = '0'
        
        # Explore 4 orthogonal directions
        dfs(r + 1, c)
        dfs(r - 1, c)
        dfs(r, c + 1)
        dfs(r, c - 1)
        
    for r in range(m):
        for c in range(n):
            if grid[r][c] == '1':
                islands += 1
                dfs(r, c)
                
    return islands

⏱️ Complexity

Time O(m * n) — Every cell is visited at most twice (once by nested loops, once by DFS). Space O(m * n) in worst-case recursion stack (e.g., grid full of land).

⚠️ Edge cases

  • Grid containing only water: returns 0.
  • Grid containing only land: returns 1 (sunk in first DFS).
  • 1x1 grid with '0' or '1'.
