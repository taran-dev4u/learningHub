Problem Overview

Implement a trie with insert, search, and startsWith methods. A trie (pronounced "try") or prefix tree is a tree data structure used to efficiently store and retrieve keys in a dataset of strings.

Key Insights

Each TrieNode contains:

  1. children: A dictionary or fixed-size array of size 26 mapping each character to its child TrieNode.
  2. is_end_of_word: A boolean flag indicating whether the path from root to this node constitutes a complete stored word.
  • insert(word): Traverse or create nodes character by character; mark final node as is_end = True.
  • search(word): Traverse characters; return True if path exists and final node has is_end == True.
  • startsWith(prefix): Traverse characters; return True if the entire prefix path exists (regardless of is_end).

Python 3 Solution (Click to Expand) 
class TrieNode:
    __slots__ = ('children', 'is_end')
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        curr = self.root
        for ch in word:
            if ch not in curr.children:
                curr.children[ch] = TrieNode()
            curr = curr.children[ch]
        curr.is_end = True

    def search(self, word: str) -> bool:
        curr = self.root
        for ch in word:
            if ch not in curr.children:
                return False
            curr = curr.children[ch]
        return curr.is_end

    def startsWith(self, prefix: str) -> bool:
        curr = self.root
        for ch in prefix:
            if ch not in curr.children:
                return False
            curr = curr.children[ch]
        return True

Complexity & Edge Cases

  • Time Complexity: $O(L)$ for all operations (insert, search, startsWith), where $L$ is the length of the string.
  • Space Complexity: $O(N imes L)$ total nodes where $N$ is number of inserted words and $L$ is average word length.
  • Edge Cases: Single character strings, prefixes identical to existing words.
