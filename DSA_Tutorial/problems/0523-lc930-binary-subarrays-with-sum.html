📋 The problem

Count the subarrays of a binary array that sum exactly to a goal.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a binary array nums and an integer goal, return the number of non-empty subarrays with a sum goal.

Because all elements are non-negative ($0$ or $1$), we can use: 1. Prefix Sum Hash Map: Identical to LC 560 in $O(n)$ time and $O(n)$ space. 2. Sliding Window (At Most Trick): $$ ext{Exact}(goal) = ext{AtMost}(goal) - ext{AtMost}(goal - 1)$$ The number of subarrays with sum $\le goal$ can be computed using a two-pointer sliding window in $O(n)$ time and $O(1)$ space!

🐢 Brute force vs optimal

Hash map takes $O(n)$ space. Two-pass sliding window achieves $O(n)$ time with $O(1)$ auxiliary space.

💡 Key insight: $ ext{Exact}(K) = ext{atMost}(K) - ext{atMost}(K - 1)$. Sliding window expands $r$, shrinks $l$ while sum exceeds target, adding $(r - l + 1)$ in $O(1)$ space.

✅ The solution

Reveal the commented solution (attempt it first!) 
def numSubarraysWithSum(nums: list[int], goal: int) -> int:
    def at_most(target):
        if target < 0:
            return 0
        l = 0
        curr_sum = 0
        count = 0
        for r in range(len(nums)):
            curr_sum += nums[r]
            while curr_sum > target:
                curr_sum -= nums[l]
                l += 1
            count += r - l + 1
        return count
        
    return at_most(goal) - at_most(goal - 1)

Complexity

Time: $O(n)$ — Two linear sliding window passes.
Space: $O(1)$ — Constant pointers.
