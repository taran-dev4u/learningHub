#38 Count and Say MediumLeetCode

📋 The problem

Build the count-and-say sequence: each term describes the previous one aloud (e.g. '21' → 'one 2, one 1' → '1211'); return the n-th term.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

The count-and-say sequence is a sequence of digit strings defined by the recursive formula: - countAndSay(1) = "1" - countAndSay(n) is the run-length encoding of countAndSay(n - 1).

For example, to generate term n = 4 from term n = 3 ("21"): - Read "2": one 2 $\to$ "12" - Read "1": one 1 $\to$ "11" - Result: "1211".

🐢 Brute force vs optimal

Iteratively apply two-pointer run-length encoding $n - 1$ times. Group identical consecutive characters with pointer $j$, append str(count) + char, and advance.

💡 Key insight: Two pointers group consecutive identical digits: count occurrences while s[j] == s[i], append f"{count}{s[i]}", and advance i = j.

✅ The solution

def countAndSay(n: int) -> str:
    curr = "1"
    for _ in range(n - 1):
        res = []
        i = 0
        while i < len(curr):
            j = i
            while j < len(curr) and curr[j] == curr[i]:
                j += 1
            res.append(str(j - i))
            res.append(curr[i])
            i = j
        curr = "".join(res)
    return curr

Complexity

Time: $O(n \times L)$ where $L$ is length of the generated string.
Space: $O(L)$ — Output buffer for the current string.
