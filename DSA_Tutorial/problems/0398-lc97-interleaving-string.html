📋 The problem

Decide whether string s3 can be formed by interleaving s1 and s2 while keeping each string's internal order.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given strings s1, s2, and s3, determine whether s3 is formed by an interleaving of s1 and s2.

First, check the lengths: if $\text{len}(s1) + \text{len}(s2) e \text{len}(s3)$, return False immediately. Let $dp[i][j]$ be a boolean indicating whether the prefix $s3[0 \dots i+j-1]$ can be formed by interleaving $s1[0 \dots i-1]$ and $s2[0 \dots j-1]$.

At position $(i, j)$ corresponding to character $s3[i + j - 1]$: 1. If $s1[i - 1] == s3[i + j - 1]$ and $dp[i - 1][j]$ is true, then $dp[i][j] = \text{True}$. 2. If $s2[j - 1] == s3[i + j - 1]$ and $dp[i][j - 1]$ is true, then $dp[i][j] = \text{True}$.

🐢 Brute force vs optimal

Naive recursion explores branching paths in $O(2^{m+n})$. Dynamic programming caches intermediate prefixes in an $(m+1) \times (n+1)$ table in $O(m \times n)$ time and can be compressed to $O(n)$ space.

💡 Key insight: Rolling 1D array of size $n+1$: dp[j] = (dp[j] and s1[i-1] == s3[i+j-1]) or (dp[j-1] and s2[j-1] == s3[i+j-1]).

def isInterleave(s1: str, s2: str, s3: str) -> bool:
    m, n, l = len(s1), len(s2), len(s3)
    if m + n != l:
        return False
        
    dp = [False] * (n + 1)
    dp[0] = True
    
    # Base row: using only s2
    for j in range(1, n + 1):
        dp[j] = dp[j - 1] and s2[j - 1] == s3[j - 1]
        
    for i in range(1, m + 1):
        dp[0] = dp[0] and s1[i - 1] == s3[i - 1]
        for j in range(1, n + 1):
            char_s3 = s3[i + j - 1]
            from_s1 = dp[j] and s1[i - 1] == char_s3
            from_s2 = dp[j - 1] and s2[j - 1] == char_s3
            dp[j] = from_s1 or from_s2
            
    return dp[n]

Complexity

Time: $O(m \times n)$ where $m = \text{len}(s1), n = \text{len}(s2)$.
Space: $O(n)$ — Rolling 1D boolean array.
