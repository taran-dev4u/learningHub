#1845 Seat Reservation Manager MediumLeetCode

 

Pattern: Heap (Priority Queue) Patterns › Subpattern 7.4: Scheduling / Minimum Cost with Priority Queue · Problem 229 of 699

📋 The problem

Design a seat manager handing out the smallest free seat number and accepting returns (min-heap of freed seats).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a system that manages n seats numbered 1 to n. reserve() fetches the smallest-numbered unreserved seat. unreserve(seatNumber) releases a seat back to available. A min-heap provides instant O(log n) access to the smallest available seat.

🐢 Brute force first

Boolean array of reserved flags. Linear scan for the first False on reserve() → O(n) per reservation.

💡 Key insight: initialize a min-heap with numbers 1..n. reserve() pops heappop(heap) in O(log n); unreserve(seat) pushes heappush(heap, seat) in O(log n).

🪜 The approach, step by step

  1. Initialize heap = list(range(1, n + 1)) and heapify.
  2. reserve(): return heappop(self.heap).
  3. unreserve(seatNumber): heappush(self.heap, seatNumber).

🎞️ Visual dry run — n = 5

Init heap: [1, 2, 3, 4, 5]
reserve()   → pops 1
reserve()   → pops 2
unreserve(2)→ pushes 2 → heap: [2, 3, 4, 5]
reserve()   → pops 2 (smallest available seat!)
reserve()   → pops 3 ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
import heapq

class SeatManager:
    def __init__(self, n: int):
        self.available = list(range(1, n + 1))
        heapq.heapify(self.available)

    def reserve(self) -> int:
        return heapq.heappop(self.available)

    def unreserve(self, seatNumber: int) -> None:
        heapq.heappush(self.available, seatNumber)

⏱️ Complexity

Time O(n) initialization; O(log n) per reserve() and unreserve() call. Space O(n) for the heap.

⚠️ Edge cases

  • Repeated reserves and unreserves: heap guarantees monotonic smallest-seat extraction.
