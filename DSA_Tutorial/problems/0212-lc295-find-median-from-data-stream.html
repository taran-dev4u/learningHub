📋 The problem

Design a structure that accepts a stream of numbers and can return the median of everything seen so far at any time.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

The median splits sorted numbers into two equal halves. Numbers arrive dynamically. We need fast access to the largest of the smaller half and the smallest of the larger half. This naturally calls for two heaps:

  • A max-heap small for the lower half.
  • A min-heap large for the upper half.

🐢 Brute force first

Insert each number into a sorted array via binary insertion (bisect.insort) in O(n) time per addition. Query median in O(1). Overall addition time is O(n^2) for n numbers.

💡 Key insight: balance two heaps such that len(small) == len(large) or len(small) == len(large) + 1, and every element in small <= every element in large. Median is either small[0] (odd total) or (small[0] + large[0]) / 2 (even total).

🪜 The approach, step by step

  1. Maintain max-heap small (stores negated values) and min-heap large.
  2. addNum(num): push num to small, then pop maximum of small and push to large (ensures ordering).
  3. If len(large) > len(small), pop minimum of large and push back to small (ensures small has >= elements).
  4. findMedian(): if total elements is odd, return -small[0]; if even, return (-small[0] + large[0]) / 2.0.

🎞️ Visual dry run — add(1), add(2), add(3)

add(1): small=[1], large=[] → median = 1
add(2): push 2 to small → move top to large → small=[1], large=[2] → median = (1+2)/2 = 1.5
add(3): push 3 to small → move top to large → large=[2,3], small=[1]
        balance: move 2 to small → small=[2,1], large=[3] → median = 2 ✓

✅ The solution

import heapq

class MedianFinder:
    def __init__(self):
        # small is a max-heap (negated values) for the lower half
        self.small = []
        # large is a min-heap for the upper half
        self.large = []

    def addNum(self, num: int) -> None:
        # Step 1: Always route through small to maintain ordering
        heapq.heappush(self.small, -num)
        heapq.heappush(self.large, -heapq.heappop(self.small))
        
        # Step 2: Keep small holding equal or 1 more element than large
        if len(self.large) > len(self.small):
            heapq.heappush(self.small, -heapq.heappop(self.large))

    def findMedian(self) -> float:
        if len(self.small) > len(self.large):
            return float(-self.small[0])
        return (-self.small[0] + self.large[0]) / 2.0

⏱️ Complexity

Time O(log n) for addNum(), O(1) for findMedian(). Space O(n) to store all stream elements.

⚠️ Edge cases

  • Stream with duplicate values: heaps handle duplicates transparently.
  • Single element: findMedian() returns that element directly.

🐛 Common mistakes

  • Pushing directly to small or large based on length rather than comparing values, violating the invariant that max(small) <= min(large).
  • Returning integer division instead of float division when length is even.
