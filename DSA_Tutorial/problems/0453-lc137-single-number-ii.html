📋 The problem

Every number appears exactly three times except one; find that one in O(n) time and O(1) extra space.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer array nums where every element appears three times except for one, which appears exactly once. Find the single element and return it.

Bit-Counting Modulo 3: Consider each of the 32 bit positions independently. For any bit position $i$, if every number appeared three times, the sum of bits at position $i$ across all numbers would be a multiple of 3 ($0 \pmod 3$). Because one number appears exactly once, if the sum of bits at position $i$ is not a multiple of 3, the unique number must have a 1 at bit $i$!

🐢 Brute force vs optimal

Counting bits position by position takes $32 \times n = O(n)$ time and $O(1)$ space. Alternatively, a two-register digital logic circuit using ones and twos tracks modulo-3 states in a single pass.

💡 Key insight: Digital logic state machine: ones = (ones ^ x) & ~twos and twos = (twos ^ x) & ~ones. Tracks bits appearing 1 or 2 times modulo 3 in $O(n)$ time and $O(1)$ space.

✅ The solution

Reveal the commented solution (attempt it first!) 
def singleNumber(nums: list[int]) -> int:
    ones, twos = 0, 0
    for x in nums:
        # ones holds bits that appeared 1st time (and not 2nd time)
        ones = (ones ^ x) & ~twos
        # twos holds bits that appeared 2nd time (and not 3rd time)
        twos = (twos ^ x) & ~ones
    return ones

Complexity

Time: $O(n)$ — Single pass through array.
Space: $O(1)$ — Two integer variables.
