#1863 Sum of All Subset XOR Totals EasyLeetCode

 

Pattern: Bit Manipulation Patterns › Subpattern 14.3: Bitwise DP / Counting Bits Optimization · Problem 461 of 699

📋 The problem

Return the sum of XOR totals over every subset of the array (each bit present in half the subsets: OR × 2^(n-1)).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

The XOR total of an array is the bitwise XOR of all its elements. Given an array nums, return the sum of all XOR totals for every subset of nums.

The Symmetry of Bits: Consider any bit position $b$. If at least one element in nums has bit $b$ set to 1, then exactly half of all $2^n$ subsets will have bit $b$ set in their subset XOR! Why? Because choosing or omitting that element flips bit $b$ from 0 to 1 or 1 to 0 across all subset combinations!

Therefore, if bit $b$ is present in bitwise OR of all elements, it will contribute to exactly $2^{n-1}$ subsets: $$ ext{Total Sum} = ( ext{OR of all elements in nums}) \times 2^{n - 1}$$

🐢 Brute force vs optimal

Backtracking through all $2^n$ subsets takes $O(2^n)$ time. The bitwise OR insight solves it in $O(n)$ linear time and $O(1)$ space!

💡 Key insight: Every bit set in reduce(OR, nums) appears in exactly $2^{n-1}$ subsets. Total sum $= ( ext{OR\_all}) \ll (n - 1)$!

✅ The solution

Reveal the commented solution (attempt it first!) 
def subsetXORSum(nums: list[int]) -> int:
    or_all = 0
    for x in nums:
        or_all |= x
    return or_all << (len(nums) - 1)

Complexity

Time: $O(n)$ — Single linear OR reduction.
Space: $O(1)$ — Constant memory.
