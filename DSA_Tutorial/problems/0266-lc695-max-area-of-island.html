📋 The problem

Return the area of the largest island (connected group of 1s) in a binary grid.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an m x n binary matrix grid. An island is a group of 1's connected 4-directionally. The area of an island is the number of cells with a value 1 in the island. Return the maximum area of an island in grid. If there is no island, return 0.

🐢 Brute force first

Run full BFS from every cell tracking set of reachable cells → O((m*n)^2). Instead, DFS with in-place sinking counts each island's size in O(m * n) total time.

💡 Key insight: Modify the island-sinking DFS to return an integer: 1 + dfs(up) + dfs(down) + dfs(left) + dfs(right). When a new unvisited land cell is found, sink it and take the max area seen across all connected components!

🪜 The approach, step by step

  1. Initialize max_area = 0.
  2. Define dfs(r, c):
    • If r, c out of bounds or grid[r][c] == 0, return 0.
    • Sink cell: grid[r][c] = 0.
    • Return 1 + dfs(r+1, c) + dfs(r-1, c) + dfs(r, c+1) + dfs(r, c-1).
  3. Iterate through every cell (r, c): if grid[r][c] == 1, max_area = max(max_area, dfs(r, c)).
  4. Return max_area.

🎞️ Visual dry run — grid:

0 1 1 0
0 1 0 0
0 0 0 1

Island 1 at (0,1):
  (0,1) -> sinks, adds 1
  (0,2) -> sinks, adds 1
  (1,1) -> sinks, adds 1
  Total area = 3. max_area = 3.

Island 2 at (2,3):
  (2,3) -> sinks, adds 1
  Total area = 1.

max_area = max(3, 1) = 3! ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
def maxAreaOfIsland(grid):
    m, n = len(grid), len(grid[0])
    max_area = 0
    
    def dfs(r, c):
        if r < 0 or r >= m or c < 0 or c >= n or grid[r][c] == 0:
            return 0
            
        grid[r][c] = 0  # sink to avoid revisits
        
        return (1 + dfs(r + 1, c) + 
                    dfs(r - 1, c) + 
                    dfs(r, c + 1) + 
                    dfs(r, c - 1))
                    
    for r in range(m):
        for c in range(n):
            if grid[r][c] == 1:
                max_area = max(max_area, dfs(r, c))
                
    return max_area

⏱️ Complexity

Time O(m * n) — Each cell is visited at most once by DFS. Space O(m * n) for recursion call stack in worst case.

⚠️ Edge cases

  • Grid with no land (all 0s): returns 0.
  • Grid completely filled with land: returns m * n.
