📋 The problem

Houses form a binary tree; robbing two directly linked houses trips the alarm — return the maximum loot.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Include/Exclude on Tree (Tree Robber) — Each node returns (include_me, exclude_me); parent picks max — works for House Robber on tree.

Why this pattern?

  • optimize a value over a TREE (max path, max loot, longest chain)
  • constraints between parent and child ("can't pick both")
  • "count/size/best of subtrees" feeding a global answer
  • the diameter shape: best-through-this-node vs best-for-parent differ

Pattern template to adapt

def dfs(node):
    if not node:
        return NEUTRAL                     # e.g. (0, 0)
    L = dfs(node.left)                     # children first (postorder)
    R = dfs(node.right)
    include = node.val + L[1] + R[1]       # take node → children excluded
    exclude = max(L) + max(R)              # skip node → children free
    # global-answer problems also do:  best = max(best, through_node)
    return (include, exclude)

ans = max(dfs(root))
