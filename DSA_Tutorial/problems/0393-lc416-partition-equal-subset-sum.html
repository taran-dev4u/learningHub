📋 The problem

Decide whether an array can be split into two subsets with equal sums.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer array nums, return true if you can partition the array into two subsets such that the sum of the elements in both subsets is equal or false otherwise.

💡 Key insight: 1. Total sum must be even! If sum(nums) % 2 != 0, return False. 2. Target sum is target = sum(nums) // 2. 3. This is pure 0-1 Knapsack Subset Sum: can we pick a subset of elements that sums exactly to target? 4. Space optimization: 1D boolean array dp[j]. Iterate j backwards from target down to num so that each number is used at most once!

✅ The solution

Reveal the commented solution (attempt it first!) 
def canPartition(nums: list[int]) -> bool:
    """
    Determines if array can be partitioned into two equal sum subsets via 0-1 Knapsack DP.
    """
    total = sum(nums)
    if total % 2 != 0:
        return False
        
    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True
    
    for num in nums:
        # Loop backwards to prevent reusing the same element
        for j in range(target, num - 1, -1):
            dp[j] = dp[j] or dp[j - num]
            
    return dp[target]

⚡ Complexity analysis

  • Time Complexity: O(N × Target) pseudo-polynomial time where Target = sum(nums) / 2.
  • Space Complexity: O(Target).
