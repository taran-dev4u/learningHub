#632 Smallest Range Covering Elements from K Lists HardLeetCode

 

Pattern: Heap (Priority Queue) Patterns › Subpattern 7.3: K-way Merge · Problem 217 of 699

📋 The problem

From k sorted lists, find the smallest range that includes at least one number from every list.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You have k sorted lists. Find the smallest range [a, b] that includes at least one number from each of the k lists. Similar to #23 Merge k Sorted Lists: keep one pointer in each of the k lists. At any time, the range is [min_val, max_val] of the current k pointers. To shrink the range, the only option is to advance the pointer pointing to min_val.

🐢 Brute force first

Check every possible pair [a, b] and verify membership across all k lists → exponential.

💡 Key insight: maintain a min-heap of size k containing (val, list_index, element_index) and track the current_max. The current range is [heap[0].val, current_max]. Pop the minimum, record if it is a smaller range, and push the next element from that list. Stop when any list is exhausted.

🪜 The approach, step by step

  1. Initialize min-heap with the first element of each list: (nums[i][0], i, 0).
  2. Track cur_max = max(nums[i][0] for i in range(k)).
  3. Initialize best range [-inf, inf].
  4. While len(heap) == k:
  5. Pop min_val, r, c = heappop(heap).
  6. If cur_max - min_val < best_end - best_start, update best range.
  7. If c + 1 < len(nums[r]): next value is next_val = nums[r][c+1], update cur_max = max(cur_max, next_val), push (next_val, r, c + 1).
  8. Else: list r is exhausted, break loop.
  9. Return [best_start, best_end].

✅ The solution

import heapq

def smallestRange(nums):
    heap = []
    cur_max = -float('inf')
    
    # Initialize heap with the first element from each list
    for r in range(len(nums)):
        val = nums[r][0]
        heapq.heappush(heap, (val, r, 0))
        cur_max = max(cur_max, val)
        
    best_range = [-float('inf'), float('inf')]
    
    while len(heap) == len(nums):
        min_val, r, c = heapq.heappop(heap)
        
        # Check if the current range [min_val, cur_max] is tighter
        if cur_max - min_val < best_range[1] - best_range[0]:
            best_range = [min_val, cur_max]
            
        # Push the next element from the list whose element was just popped
        if c + 1 < len(nums[r]):
            next_val = nums[r][c + 1]
            heapq.heappush(heap, (next_val, r, c + 1))
            cur_max = max(cur_max, next_val)
        else:
            break   # one list is exhausted; cannot form a valid range anymore
            
    return best_range

⏱️ Complexity

Time O(N log k) — where N is total elements across all lists and k is number of lists. Space O(k) — for the heap of size k.

⚠️ Edge cases

  • k = 1: returns [nums[0][0], nums[0][0]] (range of length 0).
  • Ties in range width: earlier range is preserved.
