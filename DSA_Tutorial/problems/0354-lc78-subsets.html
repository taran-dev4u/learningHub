📋 The problem

Return every possible subset (the power set) of an array of distinct integers.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer array nums of unique elements, return all possible subsets (the power set). The solution set must not contain duplicate subsets and can be returned in any order.

For an array of length n, every element has exactly two choices: either include it in the current subset, or exclude it. The total number of subsets is mathematically 2^n. A state-space tree where nodes represent candidate subsets is traversed using Backtracking.

🐢 Brute force vs optimal

Since the output itself requires O(N × 2^N) time to write 2^N subsets of average length N/2, any optimal algorithm must operate in O(N × 2^N) time.

💡 Key insight: At each level of the recursion tree, the current path is a valid subset! Add a copy of path to result immediately. Then iterate index i from start to n - 1:
  1. Choose: path.append(nums[i])
  2. Explore: backtrack(i + 1, path)
  3. Un-choose: path.pop()

🪜 The approach, step by step

  1. Initialize result = [].
  2. Define backtrack(start, path):
    • Append list(path) to result.
    • For i from start to len(nums) - 1:
      • path.append(nums[i])
      • backtrack(i + 1, path)
      • path.pop()
  3. Call backtrack(0, []). Return result.

✅ The solution

def subsets(nums: list[int]) -> list[list[int]]:
    """
    Generates all subsets (power set) of distinct integers via backtracking.
    """
    res = []
    path = []
    n = len(nums)
    
    def backtrack(start):
        # Every node in the recursion tree represents a valid subset
        res.append(list(path))
        
        for i in range(start, n):
            path.append(nums[i])      # Choose
            backtrack(i + 1)          # Explore
            path.pop()                # Un-choose (Backtrack)
            
    backtrack(0)
    return res

⚡ Complexity analysis

  • Time Complexity: O(N × 2^N). There are 2^N subsets, and copying each subset takes on average O(N) time.
  • Space Complexity: O(N) recursion stack depth and path storage (excluding output array).
