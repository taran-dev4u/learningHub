Pattern: String Manipulation Patterns › Subpattern 13.1: Palindrome Check / Two Pointers / Reverse · Problem 433 of 707

📋 The problem

Determine whether an integer reads the same forwards and backwards, without converting it to a string.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Palindrome Check / Two Pointers / Reverse — Two-pointer or reverse-and-compare to check palindromes; consider ignoring non-alphanumeric.

💡 Key idea
Reverse only half the number and compare halves — no string needed.

Why this pattern?

  • "anagram", "permutation of", "rearrange"
  • "group the strings that…" → canonical key + dict
  • palindromes (two pointers or expand-from-center)
  • parse/normalize (spaces, signs, overflow) — careful state machines

def expand(s, l, r):
    while l >= 0 and r < len(s) and s[l] == s[r]:
        l -= 1; r += 1
    return s[l+1:r]               # overshoot by one on both sides
