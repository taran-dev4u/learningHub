📋 The problem

Exactly two values appear once and everything else twice; find those two in O(n) time and O(1) space.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer array nums, in which exactly two elements appear once and all other elements appear twice. Find the two elements that appear only once.

Let the two unique numbers be $A$ and $B$. 1. XOR all numbers in nums: $$ ext{diff} = A \oplus B$$ Since $A e B$, $ ext{diff} e 0$. There must be at least one bit position where $A$ and $B$ differ (one has 1, the other has 0)! 2. Isolate lowest set bit: $$ ext{mask} = ext{diff} \;\&\; (- ext{diff})$$ 3. Partition into two groups: - Group 1: numbers where bit mask is 1 (contains $A$ and pairs). - Group 2: numbers where bit mask is 0 (contains $B$ and pairs). XORing each group independently isolates $A$ and $B$!

🐢 Brute force vs optimal

Hash map requires $O(n)$ auxiliary space. Two-pass XOR partitioning isolates both elements in $O(n)$ time and $O(1)$ memory.

💡 Key insight: diff = xor_all. Isolate lowest set bit diff & (-diff). Partition array into two buckets based on this bit; XOR each bucket to find the two unique numbers!

✅ The solution

def singleNumber(nums: list[int]) -> list[int]:
    diff = 0
    for x in nums:
        diff ^= x
        
    # Isolate lowest set bit
    mask = diff & (-diff)
    
    a, b = 0, 0
    for x in nums:
        if x & mask:
            a ^= x
        else:
            b ^= x
            
    return [a, b]

Complexity

Time: $O(n)$ — Two passes over array.
Space: $O(1)$ — Constant scalar variables.
