#1539 Kth Missing Positive Number EasyLeetCode

 

Pattern: Binary Search Patterns › Subpattern 8.1: On Sorted Array/List · Problem 241 of 699

📋 The problem

Return the k-th positive integer missing from a sorted array (binary search on missing-count = arr[i] − i − 1).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an array arr of positive integers sorted in strictly ascending order, and an integer k, return the k-th positive integer that is missing from this array.

🐢 Brute force first

Scan num = 1, 2, 3... using a pointer in arr. If num == arr[i], advance i; otherwise decrement k. When k == 0, return num. Time: O(n + k), Space: O(1).

💡 Key insight: At index i, how many positive integers should precede it if none were missing? Exactly arr[i] - (i + 1)! Because the array is sorted, this missing count arr[i] - (i + 1) is monotonically non-decreasing! We can binary search for the largest index where missing count < k.

🪜 The approach, step by step

  1. Set left = 0, right = len(arr) - 1.
  2. While left <= right:
  3. Compute mid = left + (right - left) // 2.
  4. Calculate missing before mid: missing = arr[mid] - (mid + 1).
  5. If missing < k, we need to search further right: left = mid + 1.
  6. Else, search left: right = mid - 1.
  7. When the loop terminates, left is the number of elements in arr that are smaller than the kth missing number. The answer is simply left + k!

🎞️ Visual dry run — arr = [2, 3, 4, 7, 11], k = 5

✅ The solution

Reveal the commented solution (attempt it first!) 
def findKthPositive(arr, k):
    """
    Binary search on the number of missing integers.
    arr[i] - (i + 1) gives missing count up to index i.
    """
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = left + (right - left) // 2
        missing = arr[mid] - (mid + 1)
        
        if missing < k:
            left = mid + 1
        else:
            right = mid - 1
            
    # At termination, missing count before index 'right' is < k.
    # The kth missing number = arr[right] + (k - missing_at_right)
    # = arr[right] + k - (arr[right] - (right + 1)) = right + 1 + k = left + k
    return left + k

⏱️ Complexity

Time O(log n) — Binary search over array length. Space O(1).

⚠️ Edge cases

  • All missing numbers before arr[0] (e.g. arr = [5, 6, 7], k = 2): left = 0, returns 0 + 2 = 2.
  • All missing numbers after array (e.g. arr = [1, 2, 3], k = 2): left = 3, returns 3 + 2 = 5.
