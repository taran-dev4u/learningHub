📋 The problem

Find the path from top-left to bottom-right of a grid of non-negative numbers (moving right or down) minimizing the sum of visited cells.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an m x n grid filled with non-negative numbers, find a path from top left to bottom right which minimizes the sum of all numbers along its path. You can only move down or right.

At cell $(i, j)$, you arrived from either $(i - 1, j)$ or $(i, j - 1)$: $$dp[i][j] = grid[i][j] + \min(dp[i - 1][j], \; dp[i][j - 1])$$

🐢 Brute force vs optimal

We can solve this with $O(n)$ extra space using a 1D array, or even $O(1)$ extra space by updating grid in place.

💡 Key insight: Maintain 1D array: dp[c] = grid[r][c] + min(dp[c], dp[c - 1]).

✅ The solution

Reveal the commented solution (attempt it first!) 
def minPathSum(grid: list[list[int]]) -> int:
    m, n = len(grid), len(grid[0])
    dp = [float('inf')] * n
    dp[0] = 0
    
    for r in range(m):
        dp[0] += grid[r][0]
        for c in range(1, n):
            dp[c] = grid[r][c] + min(dp[c], dp[c - 1])
            
    return dp[-1]

Complexity

Time: $O(m \times n)$ — Grid traversed cell by cell.
Space: $O(n)$ — 1D array of width $n$.
