Where this fits

Tree BFS - Level Order Traversal — BFS with a queue; process the entire current level before moving on — level lists, right view, zigzag.

Why this pattern?

  • "level", "depth", "nearest", "zigzag by rows" → BFS
  • "path sum", "ancestor", "validate", "diameter" → DFS
  • BST + "k-th smallest / sorted order" → inorder
  • "serialize / reconstruct" → preorder
