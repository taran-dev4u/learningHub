📋 The problem

Return the sum of Hamming distances (differing bit positions) over all pairs in an array.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

The Hamming distance between two integers is the number of positions at which the corresponding bits are different. Given an integer array nums, return the sum of Hamming distances between all pairs of integers in nums.

Instead of comparing pairs $(i, j)$ ($O(n^2)$ time), calculate the contribution of each bit position $0 \dots 31$ independently across all numbers! For any bit position $b$: - Let $k$ be the count of numbers in nums that have the $b$-th bit set to 1. - Then $n - k$ numbers have the $b$-th bit set to 0. Each pairing between a number with bit 1 and a number with bit 0 contributes exactly 1 to the Hamming distance! $$ ext{Hamming Contribution at bit } b = k \times (n - k)$$ Total Hamming distance is simply $\sum_{b=0}^{31} k_b \times (n - k_b)$!

🐢 Brute force vs optimal

Comparing all $n(n-1)/2$ pairs takes $O(n^2)$ time. Column-wise bit counting runs in $32 \times n = O(n)$ linear time and $O(1)$ space.

💡 Key insight: At bit $b$, if $k$ numbers have 1 and $n-k$ numbers have 0, they form $k \times (n - k)$ differing pairs. Sum over 32 bit positions!

✅ The solution

Reveal the commented solution (attempt it first!) 
def totalHammingDistance(nums: list[int]) -> int:
    n = len(nums)
    total = 0
    
    for b in range(32):
        ones = sum((x >> b) & 1 for x in nums)
        zeros = n - ones
        total += ones * zeros
        
    return total

Complexity

Time: $O(32 \times n) = O(n)$ — 32 passes over array.
Space: $O(1)$ — Constant scalar variables.
