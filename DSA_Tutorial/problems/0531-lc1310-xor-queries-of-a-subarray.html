#1310 XOR Queries of a Subarray MediumLeetCode

 

Pattern: Prefix Sum & Difference Array Patterns › Subpattern 17.4: Prefix XOR / Prefix Product · Problem 531 of 699

📋 The problem

Answer XOR-of-range queries on an array using prefix XORs.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an array arr of positive integers and an array queries where queries[i] = [left_i, right_i]. Return an array containing the XOR sum of all elements between $left_i$ and $right_i$ for each query.

Prefix XOR Array: Because XOR is its own inverse ($x \oplus x = 0$): $$ ext{XOR}(arr[l \dots r]) = ext{prefix_xor}[r + 1] \oplus ext{prefix_xor}[l]$$ Everything from index $0$ to $l - 1$ cancels itself out to 0, leaving strictly the XOR sum of $arr[l \dots r]$ in $O(1)$ time!

🐢 Brute force vs optimal

XORing each query interval takes $O(Q imes n)$. Prefix XOR array answers each query in instant $O(1)$ time.

💡 Key insight: Prefix XOR: pref[i] = pref[i-1] ^ arr[i-1]. Range XOR $[l, r]$ is pref[r + 1] ^ pref[l] in strict $O(1)$!

✅ The solution

Reveal the commented solution (attempt it first!) 
def xorQueries(arr: list[int], queries: list[list[int]]) -> list[int]:
    prefix = [0]
    for x in arr:
        prefix.append(prefix[-1] ^ x)
        
    return [prefix[r + 1] ^ prefix[l] for l, r in queries]

Complexity

Time: $O(n + Q)$ — $O(n)$ prefix build, $O(1)$ per query.
Space: $O(n)$ — Prefix XOR array.
