📋 The problem

Implement an iterator that flattens a 2-D vector, exposing next() and hasNext().

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design an iterator to flatten a 2D vector. It should support next() and hasNext() operations.

Do NOT flatten the entire 2D vector into a 1D array upfront in the constructor ($O(N)$ extra space)! Instead, maintain two lightweight coordinate pointers: - row: current row index in the outer list. - col: current column index in the current inner list.

The Lazy Advance Helper _advance_to_valid(): Because rows can be completely empty (e.g. [[], [1, 2], [], [3]]), we must advance row forward whenever col == len(vec[row]) until we either land on a non-empty row or reach the end of the outer list!

🐢 Brute force vs optimal

Copying into a 1D list takes $O(N)$ auxiliary space. Two-pointer pointer navigation takes $O(1)$ auxiliary space and $O(1)$ amortized time per operation.

💡 Key insight: Advance pointers lazily: while row < len(vec) and col == len(vec[row]): row += 1; col = 0. Consumes $O(1)$ auxiliary space!

✅ The solution

Reveal the commented solution (attempt it first!) 
class Vector2D:
    def __init__(self, vec: list[list[int]]):
        self.vec = vec
        self.row = 0
        self.col = 0

    def _advance_to_valid(self):
        while self.row < len(self.vec) and self.col == len(self.vec[self.row]):
            self.row += 1
            self.col = 0

    def next(self) -> int:
        self._advance_to_valid()
        val = self.vec[self.row][self.col]
        self.col += 1
        return val

    def hasNext(self) -> bool:
        self._advance_to_valid()
        return self.row < len(self.vec)

Complexity

Time: $O(1)$ amortized for both next() and hasNext().
Space: $O(1)$ auxiliary space (no array copying).
