#796 Rotate String EasyLeetCode

 

Pattern: String Manipulation Patterns › Subpattern 13.6: String Matching / Naive / KMP / Rabin-Karp · Problem 449 of 699

📋 The problem

Decide whether one string becomes another after some number of left rotations.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given two strings s and goal, return true if and only if s can become goal after some number of shifts on s. A shift on s consists of moving the leftmost character of s to the rightmost position.

The Concatenation Invariance: Any cyclic rotation of string s of length $n$ must be a substring of s + s! For example: s = "abcde" $\to$ s + s = "abcdeabcde". All rotations ("bcdea", "cdeab", "deabc", "eabcd") are present inside s + s!

Therefore, goal is a rotation of s if and only if: 1. $ ext{len}(s) == ext{len}(goal)$ 2. goal in (s + s)

🐢 Brute force vs optimal

Simulating all $n$ shifts takes $O(n^2)$. String containment check in s + s runs in $O(n)$ time with KMP.

💡 Key insight: Return len(s) == len(goal) and goal in (s + s). Every valid cyclic shift is a substring of the doubled string.

✅ The solution

Reveal the commented solution (attempt it first!) 
def rotateString(s: str, goal: str) -> bool:
    """
    Checks if goal is a rotation of s in O(n) time.
    """
    return len(s) == len(goal) and goal in (s + s)

Complexity

Time: $O(n)$ — Substring search in string of length $2n$.
Space: $O(n)$ — Concatenated string s + s.
