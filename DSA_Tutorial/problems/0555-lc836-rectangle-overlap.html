#836 Rectangle Overlap EasyLeetCode

📋 The problem

Decide whether two axis-aligned rectangles overlap with positive area.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

An axis-aligned rectangle is represented by [x1, y1, x2, y2]. Two rectangles overlap if the area of their intersection is positive. Return true if they overlap, else false.

Key Insights

Two 1D intervals {2, 3, 5}[x_1, x_2]{2, 3, 5} and {2, 3, 5}[x_3, x_4]{2, 3, 5} overlap if and only if: {2, 3, 5}{2, 3, 5}\max(x_1, x_3) < \min(x_2, x_4){2, 3, 5}{2, 3, 5} For 2D rectangles to have positive overlapping area, their projections onto BOTH the X-axis and Y-axis must overlap simultaneously.

Python 3 Solution (Click to Expand) 
from typing import List

class Solution:
    def isRectangleOverlap(self, rec1: List[int], rec2: List[int]) -> bool:
        # Check X-projection overlap and Y-projection overlap
        x_overlap = max(rec1[0], rec2[0]) < min(rec1[2], rec2[2])
        y_overlap = max(rec1[1], rec2[1]) < min(rec1[3], rec2[3])
        return x_overlap and y_overlap

Complexity & Edge Cases

  • Time Complexity: {2, 3, 5}O(1){2, 3, 5}.
  • Space Complexity: {2, 3, 5}O(1){2, 3, 5}.
  • Edge Cases: Line contact or point contact (perimeter touching is not positive area overlap, correctly handled by strict inequality <).
