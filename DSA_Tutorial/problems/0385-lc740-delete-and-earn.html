#740 Delete and Earn MediumLeetCode

 

Pattern: Dynamic Programming (DP) Patterns › Subpattern 12.1: 1D Array / Fibonacci Style · Problem 385 of 699

📋 The problem

Taking a value earns its total but deletes all values one less and one greater; maximize points (House Robber over values).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an integer array nums. You want to maximize points earned. If you pick nums[i], you earn nums[i] points, but must delete every element equal to nums[i] - 1 and nums[i] + 1.

Notice the conflict: picking value x deletes all instances of x - 1 and x + 1. But if you decide to take value x, you should take all occurrences of x, earning x * count[x] total points!

This transforms the problem exactly into House Robber (LC 198) over bucket values $0 \dots \max(nums)$. You cannot rob adjacent value buckets!

🐢 Brute force vs optimal

Trying all subsets of numbers is exponential. By aggregating total points per value into a frequency bucket array points[v] = v * count[v], the recurrence is: $$dp[v] = \max(dp[v - 1], \; dp[v - 2] + points[v])$$ which runs in $O(M)$ time where $M = \max(nums)$.

💡 Key insight: Pre-aggregate into value buckets: points[v] = v * frequency. Then run standard House Robber rob, skip = max(skip + points[v], rob), rob.

✅ The solution

from collections import Counter

def deleteAndEarn(nums: list[int]) -> int:
    if not nums:
        return 0
    counts = Counter(nums)
    max_val = max(nums)
    
    prev2 = 0
    prev1 = 0
    
    for v in range(max_val + 1):
        gain = v * counts.get(v, 0)
        curr = max(prev1, prev2 + gain)
        prev2 = prev1
        prev1 = curr
        
    return prev1

Complexity

Time: $O(n + M)$ where $n = \text{len}(nums)$ and $M = \max(nums)$.
Space: $O(n)$ for the frequency map, $O(1)$ DP registers.
