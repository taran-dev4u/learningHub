#1552 Magnetic Force Between Two Balls MediumLeetCode

 

Pattern: Binary Search Patterns › Subpattern 8.3: On Answer / Condition Function · Problem 255 of 699

📋 The problem

Place m balls in baskets at given positions maximizing the minimum distance between any two balls (binary search the distance).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

In the universe, there are n baskets at positions position[i]. We distribute m balls into the baskets such that the minimum magnetic force between any two balls is maximized. The magnetic force between two balls at x and y is |x - y|.

🐢 Brute force first

Generate all combinations of choosing m baskets from n baskets, find minimum distance for each, take the maximum. Combinatorial explosion O(C(n, m)).

💡 Key insight: Maximize the minimum! This is the signature pattern for Binary Search on Answer. If we can place m balls such that all pairwise distances are >= D, then we can also place them with any distance < D. Sort positions first, then greedily place the next ball at the first basket with distance >= D.

🪜 The approach, step by step

  1. Sort position array.
  2. Range for answer: left = 1 (minimum possible force), right = position[-1] - position[0] (maximum possible force).
  3. Helper canPlace(force):
    • Place 1st ball at position[0].
    • For subsequent baskets, if position[i] - last_pos >= force, place ball here, update last_pos = position[i], count += 1.
    • Return count >= m.
  4. Binary search to find MAXIMUM feasible force:
    • If canPlace(mid): ans = mid, left = mid + 1 (try larger force!).
    • Else: right = mid - 1.
  5. Return ans.

✅ The solution

def maxDistance(position, m):
    position.sort()
    
    def canPlace(force):
        count = 1
        last_pos = position[0]
        for p in position[1:]:
            if p - last_pos >= force:
                count += 1
                last_pos = p
                if count == m:
                    return True
        return False
        
    left, right = 1, position[-1] - position[0]
    ans = 1
    
    while left <= right:
        mid = left + (right - left) // 2
        if canPlace(mid):
            ans = mid
            left = mid + 1   # Try for larger distance
        else:
            right = mid - 1
            
    return ans

⏱️ Complexity

Time O(n log n + n * log(max_dist)) — Sorting takes O(n log n); each greedy check takes O(n). Space O(1) (in-place sort).

⚠️ Edge cases

  • m = 2: simply place at position[0] and position[-1], answer is position[-1] - position[0].
  • Consecutive positions [1, 2, 3, 4, 5]: handled smoothly.
