📋 The problem

Schedule tasks (each identical letter needs a cooldown of n slots between repeats); return the minimum total intervals including idles.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a characters array tasks representing the tasks a CPU needs to do, where each letter represents a different task. Tasks could be done in any order. Each task is done in one unit of time. For each unit of time, the CPU could complete either one task or be idle. However, there is a non-negative integer n that represents the cooldown period between two same tasks (must be at least n intervals apart). Return the least number of units of times that the CPU will take to finish all the given tasks.

🐢 Brute force vs optimal

Simulating cooling queues with a max-heap takes O(T log 26). The problem can be solved mathematically in O(T) time by analyzing the most frequent task!

💡 Key insight: The most frequent task dictates the minimum frame structure.

Let max_freq be the frequency of the most common task, and count_max be the number of tasks having this maximum frequency. These tasks create (max_freq - 1) chunks, each requiring (n + 1) slots, plus count_max tasks in the final chunk: $$ ext{min\_time} = ( ext{max\_freq} - 1) imes (n + 1) + ext{count\_max}$$ If there are enough other tasks to fill all idle slots without needing any idling, the total time is simply len(tasks)! Therefore, answer = max(len(tasks), (max_freq - 1) * (n + 1) + count_max).

🎞️ Visual dry run — tasks = ["A","A","A","B","B","B"], n = 2:

max_freq = 3 (A and B both appear 3 times). count_max = 2 (A and B).
Frame layout:
Chunk 1: A B (idle) -> length n + 1 = 3
Chunk 2: A B (idle) -> length n + 1 = 3
Last:    A B        -> length count_max = 2

Total slots = (3 - 1) * (2 + 1) + 2 = 2 * 3 + 2 = 8 slots:
[A, B, idle, A, B, idle, A, B]
Output: 8 ✓

✅ The solution

from collections import Counter

def leastInterval(tasks: list[str], n: int) -> int:
    """
    Computes minimum CPU intervals to execute tasks with cooling period n.
    """
    counts = Counter(tasks)
    max_freq = max(counts.values())
    count_max = sum(1 for val in counts.values() if val == max_freq)
    
    empty_slots_time = (max_freq - 1) * (n + 1) + count_max
    return max(len(tasks), empty_slots_time)

⚡ Complexity analysis

  • Time Complexity: O(T) where T = len(tasks) to count frequencies. The alphabet size is at most 26.
  • Space Complexity: O(1) space (at most 26 uppercase letters in hash map).
