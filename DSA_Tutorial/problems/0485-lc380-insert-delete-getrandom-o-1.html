📋 The problem

Design a set supporting insert, delete, and getRandom (uniform over current elements), each in O(1) average.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Implement the RandomizedSet class such that insert, remove, and getRandom all execute in strict $O(1)$ average time complexity.

Why can't we just use a Hash Set? A Hash Set provides $O(1)$ insert and $O(1)$ remove, but cannot provide true uniform $O(1)$ getRandom because elements are distributed sparsely across buckets! Why can't we just use an Array? An Array provides $O(1)$ random indexing (nums[random.randint(0, len-1)]), but remove(val) takes $O(n)$ time to search and shift elements!

The Swap-with-Last Deletion Trick: Combine an Array and a Hash Map: - nums (Array): stores values contiguously. - val_to_idx (Map): maps val -> index in nums.

To remove(val) in $O(1)$: 1. Find index of val: idx = val_to_idx[val]. 2. Overwrite nums[idx] with the last element in nums: last = nums[-1]; nums[idx] = last. 3. Update map: val_to_idx[last] = idx. 4. Pop the last element in $O(1)$ without any shifting: nums.pop() and del val_to_idx[val]!

🐢 Brute force vs optimal

Swapping with the last element eliminates all array shifting, achieving strict $O(1)$ for insert, delete, and random sampling.

💡 Key insight: To delete from an array in $O(1)$: swap the target element with the last element, update the index in the hash map, and pop() the tail!

✅ The solution

import random

class RandomizedSet:
    def __init__(self):
        self.nums = []
        self.val_to_idx = {}

    def insert(self, val: int) -> bool:
        if val in self.val_to_idx:
            return False
        self.val_to_idx[val] = len(self.nums)
        self.nums.append(val)
        return True

    def remove(self, val: int) -> bool:
        if val not in self.val_to_idx:
            return False
        # Swap with last element
        idx = self.val_to_idx[val]
        last_val = self.nums[-1]
        
        self.nums[idx] = last_val
        self.val_to_idx[last_val] = idx
        
        # Pop tail in O(1)
        self.nums.pop()
        del self.val_to_idx[val]
        return True

    def getRandom(self) -> int:
        return random.choice(self.nums)

Complexity

Time: $O(1)$ average for insert, remove, and getRandom.
Space: $O(n)$ — Dynamic array and hash map holding $n$ values.
