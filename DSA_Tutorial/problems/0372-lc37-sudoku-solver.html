📋 The problem

Fill a partially completed 9×9 Sudoku grid so every row, column, and 3×3 box contains the digits 1–9 exactly once.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Write a program to solve a Sudoku puzzle by filling the empty cells (represented by '.'). Each of the digits 1-9 must occur exactly once in each row, each column, and each of the nine 3x3 sub-boxes.

💡 Key insight: Iterate to find the next empty cell (r, c). Try placing digits '1' through '9'. If placing digit d is valid (not in row r, not in col c, not in sub-box), set board[r][c] = d and recurse. If the recursive call returns True, return True immediately! If no digit works, reset board[r][c] = '.' and return False.

✅ The solution

def solveSudoku(board: list[list[str]]) -> None:
    """
    Solves 9x9 Sudoku board in-place via backtracking.
    """
    def is_valid(r, c, ch):
        for i in range(9):
            if board[r][i] == ch:
                return False
            if board[i][c] == ch:
                return False
            # Check 3x3 sub-box
            br, bc = 3 * (r // 3) + i // 3, 3 * (c // 3) + i % 3
            if board[br][bc] == ch:
                return False
        return True
        
    def solve():
        for r in range(9):
            for c in range(9):
                if board[r][c] == '.':
                    for d in "123456789":
                        if is_valid(r, c, d):
                            board[r][c] = d
                            if solve():
                                return True
                            board[r][c] = '.'  # Backtrack
                    return False
        return True
        
    solve()

⚡ Complexity analysis

  • Time Complexity: O(9^(empty_cells)) bounded by O(9^81) = O(1) for a fixed 9x9 board.
  • Space Complexity: O(81) = O(1) recursion stack.
