📋 The problem

Design a mini-Twitter: post tweets, follow/unfollow, and fetch the 10 most recent tweets across a user's feed.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a simplified version of Twitter where users can post tweets, follow/unfollow another user, and see the 10 most recent tweets in their news feed.

Data Structures: 1. follows: defaultdict(set) mapping userId -> set of followeeIds. 2. tweets: defaultdict(list) mapping userId -> list of (timestamp, tweetId). 3. global_time: Decrementing counter tracking chronological order.

Feed Generation (Merge K Sorted Lists): A user's feed is composed of the recent tweets of themselves plus everyone they follow. Because each user's tweet list is already chronologically sorted, finding the 10 most recent tweets across all followees is the classic Merge K Sorted Lists (LC 23) using a Min-Heap of size at most $K$ (number of followees)!

🐢 Brute force vs optimal

Pulling and sorting all tweets takes $O(T \log T)$. Merging with a heap inspects only the latest tweets from each followee in $O(K \log F)$ time.

💡 Key insight: Fan-out-on-read: merge the latest tweets of all followees using a Max-Heap / Priority Queue up to 10 elements.

✅ The solution

from collections import defaultdict
import heapq

class Twitter:
    def __init__(self):
        self.time = 0
        self.follows = defaultdict(set)
        self.tweets = defaultdict(list)

    def postTweet(self, userId: int, tweetId: int) -> None:
        self.time += 1
        # Store as (timestamp, tweetId)
        self.tweets[userId].append((self.time, tweetId))

    def getNewsFeed(self, userId: int) -> list[int]:
        # User follows themselves for feed inclusion
        followees = self.follows[userId] | {userId}
        
        # Max-heap to merge latest tweets from each followee
        # Elements: (-timestamp, tweetId, followeeId, next_index_in_list)
        max_heap = []
        for f_id in followees:
            user_tweets = self.tweets[f_id]
            if user_tweets:
                idx = len(user_tweets) - 1
                t, tw_id = user_tweets[idx]
                max_heap.append((-t, tw_id, f_id, idx - 1))
                
        heapq.heapify(max_heap)
        feed = []
        while max_heap and len(feed) < 10:
            neg_t, tw_id, f_id, next_idx = heapq.heappop(max_heap)
            feed.append(tw_id)
            if next_idx >= 0:
                t, next_tw_id = self.tweets[f_id][next_idx]
                heapq.heappush(max_heap, (-t, next_tw_id, f_id, next_idx - 1))
                
        return feed

    def follow(self, followerId: int, followeeId: int) -> None:
        self.follows[followerId].add(followeeId)

    def unfollow(self, followerId: int, followeeId: int) -> None:
        self.follows[followerId].discard(followeeId)

Complexity

Time: postTweet, follow, unfollow: $O(1)$. getNewsFeed: $O(F + 10 \log F)$ where $F$ is number of followees.
Space: $O(U + T)$ — Users graph and tweets storage.
