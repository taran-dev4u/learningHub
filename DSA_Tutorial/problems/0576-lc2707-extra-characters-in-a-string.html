#2707 Extra Characters in a String MediumLeetCode

📋 The problem

Given a string and a dictionary, minimize the characters left uncovered when you carve out non-overlapping dictionary words (DP + trie).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given a 0-indexed string s and a dictionary of words dictionary, break s into one or more non-overlapping substrings such that each substring is in dictionary. Return the minimum number of extra characters left over.

Key Insights

1D Dynamic Programming: Let $dp[i]$ be the minimum extra characters for the prefix $s[:i]$. Base case: $dp[0] = 0$. For index $i$ from 1 to $n$:

  1. Default option: Treat $s[i-1]$ as an extra character: $dp[i] = dp[i-1] + 1$.
  2. Try matching any dictionary word ending at $i$: If $s[j:i] \in ext{dict}$, $dp[i] = \min(dp[i], dp[j])$.

Python 3 Solution (Click to Expand) 
from typing import List

class Solution:
    def minExtraChar(self, s: str, dictionary: List[str]) -> int:
        words = set(dictionary)
        n = len(s)
        dp = [0] * (n + 1)
        
        for i in range(1, n + 1):
            dp[i] = dp[i - 1] + 1
            for j in range(i):
                if s[j:i] in words:
                    dp[i] = min(dp[i], dp[j])
                    
        return dp[n]

Complexity & Edge Cases

  • Time Complexity: $O(n^2)$ time with HashSet lookups.
  • Space Complexity: $O(n + D imes L)$.
