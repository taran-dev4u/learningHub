📋 The problem

Given a reference to a node in a connected undirected graph, return a deep copy of the whole graph.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Graph - Deep Copy / Cloning — DFS/BFS with a hashmap mapping old node → new node — copy nodes and links once each.

💡 Key idea
BFS/DFS with a dict old-node → clone; create the clone on first sight, wire neighbors as you traverse.

Why this pattern?

  • "islands", "connected", "regions", "provinces" → component DFS/BFS
  • "minimum steps / moves / days to reach" → BFS
  • "prerequisites", "build order", "course schedule" → topological sort
  • states-and-moves puzzles (word ladder, locks) → BFS over implicit graph

# Topological sort (Kahn's)
indeg = defaultdict(int)
for u in graph:
    for v in graph[u]: indeg[v] += 1
q = deque([u for u in graph if indeg[u] == 0])
order = []
while q:
    u = q.popleft(); order.append(u)
    for v in graph[u]:
        indeg[v] -= 1
        if indeg[v] == 0: q.append(v)
# len(order) < number of nodes  ⇒  cycle exists
