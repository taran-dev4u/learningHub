📋 The problem

Connect all points at minimum total Manhattan-distance cost (MST — Prim's fits dense complete graphs).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an array points representing integer coordinates of n points on a 2D plane, where points[i] = [xi, yi]. The cost of connecting two points [xi, yi] and [xj, yj] is the Manhattan distance: |xi - xj| + |yi - yj|. Return the minimum cost to make all points connected such that there is exactly one simple path between any pair of points.

Connecting all n points with minimum total cost and zero cycles is the textbook definition of a Minimum Spanning Tree (MST). Because every pair of points can be connected, the graph is a dense complete graph with V = n vertices and E = n(n - 1) / 2 edges.

🐢 Brute force vs optimal

Testing all spanning trees is exponential. For finding an MST on a dense graph where E ≈ V^2:

  • Kruskal's Algorithm: Requires creating and sorting all O(V^2) edges → O(V^2 log V) time and O(V^2) memory.
  • Prim's Algorithm (Dense Array Variant): Maintains min_cost[i] for each node. At each step, finds the node outside the tree with smallest cost in O(V) time. Repeating V times takes O(V^2) time and only O(V) space!

💡 Key insight: Dense Prim's algorithm starts with point 0 in the tree. We maintain min_dist = [inf] * n. At each iteration, pick the unvisited node u with the smallest distance, mark it visited, add its distance to the total cost, and update all other unvisited nodes v: min_dist[v] = min(min_dist[v], manhattan_dist(u, v)). No heap needed! Runs in pure O(N^2) time with zero allocation overhead.

🪜 The approach, step by step (Dense Prim's)

  1. Let n = len(points). If n ≤ 1, return 0.
  2. Initialize min_dist = [float('inf')] * n with min_dist[0] = 0.
  3. Initialize visited = [False] * n, total_cost = 0.
  4. Loop n times (to add all n nodes to the tree):
    • Find unvisited node u with minimum min_dist[u].
    • Mark visited[u] = True.
    • Add total_cost += min_dist[u].
    • For every unvisited node v from 0 to n - 1:
      • Calculate Manhattan distance: d = abs(points[u][0] - points[v][0]) + abs(points[u][1] - points[v][1]).
      • Update min_dist[v] = min(min_dist[v], d).
  5. Return total_cost.

def minCostConnectPoints(points: list[list[int]]) -> int:
    """
    Computes Minimum Spanning Tree on complete Euclidean point graph using Dense Prim's.
    """
    n = len(points)
    if n <= 1:
        return 0
        
    min_dist = [float('inf')] * n
    min_dist[0] = 0
    visited = [False] * n
    total_cost = 0
    
    for _ in range(n):
        # 1. Pick unvisited vertex with smallest connecting distance
        curr = -1
        curr_dist = float('inf')
        for i in range(n):
            if not visited[i] and min_dist[i] < curr_dist:
                curr_dist = min_dist[i]
                curr = i
                
        # 2. Add vertex to tree
        visited[curr] = True
        total_cost += curr_dist
        x1, y1 = points[curr]
        
        # 3. Update minimum distance to remaining unvisited vertices
        for nxt in range(n):
            if not visited[nxt]:
                x2, y2 = points[nxt]
                dist = abs(x1 - x2) + abs(y1 - y2)
                if dist < min_dist[nxt]:
                    min_dist[nxt] = dist
                    
    return total_cost

⚡ Complexity analysis

  • Time Complexity: O(N^2). There are N outer iterations; each iteration scans N nodes to find the minimum and another N nodes to update distances. For a dense graph with N(N-1)/2 edges, O(N^2) is strictly optimal and beats heap Prim's / Kruskal's O(N^2 log N).
  • Space Complexity: O(N) to store min_dist and visited arrays. Zero storage needed for explicit edges!

🚨 Edge cases to watch out for

  • n = 1: Cost is 0 (a single point is already connected).
  • Coincident points: Distance is 0; correctly handled.
