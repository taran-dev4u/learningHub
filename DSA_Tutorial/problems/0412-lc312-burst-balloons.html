📋 The problem

Bursting a balloon earns left·self·right coins (adjacent survivors); pop all balloons in the order that maximizes coins.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given n balloons, indexed from 0 to n - 1. Each balloon is painted with a number on it represented by an array nums. You are asked to burst all the balloons. If you burst balloon i you will get nums[i - 1] * nums[i] * nums[i + 1] coins. Return the maximum coins you can collect.

Pad boundaries with virtual balloons: nums = [1] + nums + [1]. If you think about which balloon to burst first, the left and right subproblems become coupled and dependent because bursting a balloon changes the neighbors for subsequent pops!

The Reverse Trick: Think about which balloon is burst LAST in the interval $(left, right)$! If balloon $k$ ($left < k < right$) is the last balloon burst in interval $(left, right)$, then balloons $left$ and $right$ are guaranteed to still be present right next to $k$: $$dp[l][r] = \max_{l < k < r} (dp[l][k] + dp[k][r] + nums[l] \times nums[k] \times nums[r])$$ Now the two subproblems $(l, k)$ and $(k, r)$ are completely independent!

🐢 Brute force vs optimal

Thinking forward creates intractable dependencies. Thinking backwards (last balloon to pop) yields clean Interval DP with states $O(n^2)$ and transition $O(n)$, running in $O(n^3)$ time.

💡 Key insight: Reverse your thinking: choose the last balloon $k$ to burst in $(l, r)$. Coins gained $= nums[l] \times nums[k] \times nums[r] + dp[l][k] + dp[k][r]$.

✅ The solution

Reveal the commented solution (attempt it first!) 
def maxCoins(nums: list[int]) -> int:
    padded = [1] + nums + [1]
    n = len(padded)
    dp = [[0] * n for _ in range(n)]
    
    # length of interval from 2 (no balloons inside) to n - 1
    for length in range(2, n):
        for left in range(0, n - length):
            right = left + length
            for k in range(left + 1, right):
                coins = padded[left] * padded[k] * padded[right] + dp[left][k] + dp[k][right]
                if coins > dp[left][right]:
                    dp[left][right] = coins
                    
    return dp[0][n - 1]

Complexity

Time: $O(n^3)$ — Lengths $2 \dots n$, left bounds $O(n)$, split points $k \in (l, r)$.
Space: $O(n^2)$ — 2D table for interval $(left, right)$.
