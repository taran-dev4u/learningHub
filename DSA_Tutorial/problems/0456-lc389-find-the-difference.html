#389 Find the Difference EasyLeetCode

📋 The problem

String t is s shuffled plus one extra letter; find the added letter.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given two strings s and t. String t is generated by random shuffling string s and then adding one more letter at a random position. Return the letter that was added to t.

XOR all character codes in string $s$ and string $t$. Every character that appears in both $s$ and $t$ will cancel itself to 0. The single added character is left over!

🐢 Brute force vs optimal

Frequency map or sorting takes $O(n)$ or $O(n \log n)$ time with extra memory. Running XOR runs in $O(n)$ time with $O(1)$ space.

💡 Key insight: XOR character ASCII codes: res = 0; for c in s + t: res ^= ord(c). Return chr(res).

✅ The solution

Reveal the commented solution (attempt it first!) 
def findTheDifference(s: str, t: str) -> str:
    res = 0
    for c in s:
        res ^= ord(c)
    for c in t:
        res ^= ord(c)
    return chr(res)

Complexity

Time: $O(n)$ — Linear pass over strings.
Space: $O(1)$ — Constant integer register.
