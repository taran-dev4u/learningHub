#1044 Longest Duplicate Substring HardLeetCode

 

Pattern: Advanced String Algorithm Patterns › Subpattern 29.3: Rolling Hash Beyond Rabin-Karp · Problem 706 of 707

📋 The problem

Return the longest substring that appears at least twice in a string (binary search length + rolling hash).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Rolling Hash Beyond Rabin-Karp — Rolling hash for substring fingerprinting — find duplicate/longest repeated substrings in O(n log n).

Why this pattern?

  • find/count occurrences of a pattern in a long text
  • "shortest palindrome by prepending", "longest prefix = suffix" → failure function
  • many substring-equality checks → rolling hash
  • "repeated substring pattern" / string periodicity

Pattern template to adapt

Start from the Advanced String Algorithm master template and adapt the marked parts to this problem:

# KMP failure table: fail[i] = length of longest proper prefix of
# pat[0..i] that is also its suffix
def build_fail(pat):
    fail = [0] * len(pat)
    k = 0
    for i in range(1, len(pat)):
        while k and pat[i] != pat[k]:
            k = fail[k - 1]            # fall back to shorter border
        if pat[i] == pat[k]:
            k += 1
        fail[i] = k
    return fail

def kmp_search(text, pat):             # O(n + m)
    fail, k = build_fail(pat), 0
    for i, ch in enumerate(text):
        while k and ch != pat[k]:
            k = fail[k - 1]
        if ch == pat[k]:
            k += 1
        if k == len(pat):
            yield i - k + 1            # match start
            k = fail[k - 1]</code>
