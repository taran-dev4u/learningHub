📋 The problem

Design a calendar where book() returns the maximum overlap count (k-booking) after adding each event.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Implement the MyCalendarThree class. An event can always be added. Return an integer $k$ representing the largest integer such that there exists a $k$-booking in the calendar (the maximum number of concurrent overlapping events).

Key Insights

Boundary Event Map / Line Sweep: Each booking of $[start, end)$ introduces two timestamp events:

  • events[start] += 1
  • events[end] -= 1
Sweep through all events in chronological order, maintaining a running prefix sum of active concurrent events. The peak value reached is the answer $k$!

Python 3 Solution (Chronological Event Map) 
from collections import defaultdict

class MyCalendarThree:
    def __init__(self):
        self.events = defaultdict(int)

    def book(self, startTime: int, endTime: int) -> int:
        self.events[startTime] += 1
        self.events[endTime] -= 1
        
        max_k = curr = 0
        for t in sorted(self.events.keys()):
            curr += self.events[t]
            max_k = max(max_k, curr)
            
        return max_k

Complexity & Edge Cases

  • Time Complexity: $O(N \log N)$ sorting of event timestamps per booking.
  • Space Complexity: $O(N)$ event timestamps.
