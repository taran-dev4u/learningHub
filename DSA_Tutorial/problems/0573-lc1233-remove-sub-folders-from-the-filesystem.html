#1233 Remove Sub-Folders from the Filesystem MediumLeetCode

 

Pattern: Trie / Prefix Tree Patterns › Subpattern 20.4: Streaming / Autocomplete / Suffix Trie · Problem 573 of 699

📋 The problem

Remove every folder that lies inside another folder in the list; return what remains (sort, or trie of path segments).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given a list of folders, return the folders after removing all sub-folders in those folders. If a folder folder[i] is located within another folder[j], it is called a sub-folder of it.

Key Insights

Sort the folders lexicographically: folder.sort(). When sorted, any subfolder must appear immediately after its parent folder! We only need to track the last_added folder. If current folder starts with last_added + '/', it is a subfolder and we skip it. Otherwise, add it to result!

Python 3 Solution (Lexicographical Prefix Pruning) 
from typing import List

class Solution:
    def removeSubfolders(self, folder: List[str]) -> List[str]:
        folder.sort()
        res = []
        
        for f in folder:
            if not res or not f.startswith(res[-1] + '/'):
                res.append(f)
                
        return res

Complexity & Edge Cases

  • Time Complexity: $O(N \log N imes L)$ sorting + $O(N imes L)$ scan.
  • Space Complexity: $O(N imes L)$ for sorted list and results.
