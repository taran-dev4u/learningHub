📋 The problem

Meetings queue for n rooms, taking the lowest free room (or waiting for the earliest); return the room that hosts the most meetings (two heaps).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You have n rooms numbered 0 to n - 1. Meetings arrive with [start, end]. Each meeting gets the lowest-numbered unused room. If all rooms are busy, it waits for the earliest room to finish (preserving duration). Return the room that held the most meetings.

🐢 Brute force first

For each meeting, scan all n rooms to check availability; if none, find the room with minimal end time and delay → O(m * n).

💡 Key insight: use two min-heaps:

  • unused: contains available room numbers 0..n-1 (min-heap by room index).
  • busy: contains (endTime, roomNumber) (min-heap by end time).

For each meeting: free up all rooms whose endTime <= start by popping from busy and pushing to unused. If unused is empty, take the earliest from busy and advance its end time by the meeting's duration.

🪜 The approach, step by step

  1. Sort meetings by start time.
  2. Initialize unused = list(range(n)) (heapified) and busy = []. Track counts = [0] * n.
  3. For each start, end in meetings:
  4. While busy and busy[0][0] <= start: pop (_, room) and push room to unused.
  5. If unused: pop smallest room, push (end, room) to busy, increment counts[room].
  6. Else: pop earliest (earliest_end, room) from busy, push (earliest_end + (end - start), room), increment counts[room].
  7. Return the room index with maximum count (tiebreaker: smallest index).

✅ The solution

import heapq

def mostBooked(n, meetings):
    meetings.sort()
    
    unused = list(range(n))
    heapq.heapify(unused)
    
    busy = []   # (end_time, room_index)
    count = [0] * n
    
    for start, end in meetings:
        # Free rooms that finished before or at current start time
        while busy and busy[0][0] <= start:
            _, room = heapq.heappop(busy)
            heapq.heappush(unused, room)
            
        duration = end - start
        if unused:
            room = heapq.heappop(unused)
            heapq.heappush(busy, (end, room))
        else:
            # Wait for the earliest room to become free
            earliest_end, room = heapq.heappop(busy)
            heapq.heappush(busy, (earliest_end + duration, room))
            
        count[room] += 1
        
    return count.index(max(count))

⏱️ Complexity

Time O(m log m + m log n) — where m is number of meetings. Sorting takes O(m log m); each meeting performs O(log n) heap operations. Space O(n) — for the two heaps.

⚠️ Edge cases

  • Duration overflow if meeting delayed across large time spans: Python handles arbitrarily large integers.
  • Tiebreaker when multiple rooms have the exact same maximum count: count.index(max(count)) naturally returns the smallest index.
