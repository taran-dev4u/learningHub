📋 The problem

Rearrange an array of numbers into the lexicographically next greater permutation in place; if none exists, sort ascending.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

A permutation of an array of integers is an arrangement of its members into a sequence or linear order. The next permutation is the next lexicographically greater permutation. Rearrange nums into the lexicographically next greater permutation of numbers in-place with O(1) extra memory. If no greater permutation is possible, rearrange it to the lowest possible order (sorted ascending).

🐢 Brute force vs optimal

Generating all permutations takes O(N!). The single-pass greedy scan operates in O(N) time and O(1) space!

💡 Key insight: 4-step algorithm:
  1. Find Pivot: Scan from right to left to find the first decreasing element: nums[i] < nums[i + 1]. The suffix nums[i + 1:] is descending.
  2. Find Successor: If such index i exists, scan from right to left to find the smallest number greater than nums[i]: nums[j] > nums[i].
  3. Swap: Swap nums[i] and nums[j].
  4. Reverse Suffix: Reverse the suffix nums[i + 1:] to turn it into ascending order (smallest possible value).

🎞️ Visual dry run — nums = [1, 2, 7, 4, 3, 1]:

1. Suffix 7, 4, 3, 1 is descending. First decreasing element from right is 2 (index 1).
2. Smallest element in suffix larger than 2 is 3 (index 4).
3. Swap 2 and 3 -> [1, 3, 7, 4, 2, 1].
4. Reverse suffix [7, 4, 2, 1] -> [1, 2, 4, 7].
Result: [1, 3, 1, 2, 4, 7] ✓

def nextPermutation(nums: list[int]) -> None:
    """
    Rearranges numbers into lexicographically next greater permutation in-place.
    """
    n = len(nums)
    i = n - 2
    
    # 1. Find first index i from right where nums[i] < nums[i + 1]
    while i >= 0 and nums[i] >= nums[i + 1]:
        i -= 1
        
    if i >= 0:
        # 2. Find index j from right where nums[j] > nums[i]
        j = n - 1
        while nums[j] <= nums[i]:
            j -= 1
        # 3. Swap
        nums[i], nums[j] = nums[j], nums[i]
        
    # 4. Reverse suffix from i + 1 to end
    left, right = i + 1, n - 1
    while left < right:
        nums[left], nums[right] = nums[right], nums[left]
        left += 1
        right -= 1

⚡ Complexity analysis

  • Time Complexity: O(N). Two linear scans from right and one reverse.
  • Space Complexity: O(1) strictly in-place.
