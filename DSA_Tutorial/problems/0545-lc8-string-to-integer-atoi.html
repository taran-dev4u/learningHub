📋 The problem

Convert a string to a 32-bit signed integer the way atoi does: skip leading spaces, read an optional sign, read digits until a non-digit, and clamp to the 32-bit range.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Implement the myAtoi(string s) function, which converts a string to a 32-bit signed integer. Must parse leading whitespace, handle optional sign '+' or '-', read digits until a non-digit character, and clamp values to the 32-bit signed range {2, 3, 5}[-2^{31}, 2^{31} - 1]{2, 3, 5}.

Key Insights

State machine traversal:

  1. Skip leading spaces with index pointer.
  2. Check optional sign at current pointer.
  3. Accumulate digits: val = val * 10 + digit. Check for 32-bit overflow before multiplication.
  4. Clamp to {2, 3, 5}-2^{31} = -2147483648{2, 3, 5} and {2, 3, 5}2^{31} - 1 = 2147483647{2, 3, 5}.

Python 3 Solution (Deterministic Parsing) 
class Solution:
    def myAtoi(self, s: str) -> int:
        INT_MAX = 2**31 - 1
        INT_MIN = -2**31
        
        i, n = 0, len(s)
        while i < n and s[i] == ' ':
            i += 1
            
        if i == n:
            return 0
            
        sign = 1
        if s[i] == '+':
            i += 1
        elif s[i] == '-':
            sign = -1
            i += 1
            
        val = 0
        while i < n and s[i].isdigit():
            digit = ord(s[i]) - ord('0')
            val = val * 10 + digit
            if sign * val > INT_MAX:
                return INT_MAX
            if sign * val < INT_MIN:
                return INT_MIN
            i += 1
            
        return sign * val

Complexity & Edge Cases

  • Time Complexity: {2, 3, 5}O(N){2, 3, 5} single pass over characters.
  • Space Complexity: {2, 3, 5}O(1){2, 3, 5}.
  • Edge Cases: Whitespace only, sign without digits ("+"), words preceding numbers ("words and 987" returns 0), numbers exceeding 64 bits.
