📋 The problem

Given n, generate every string of n pairs of parentheses that is well-formed.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given n pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

💡 Key insight: Maintain open_count and close_count:
  • Can add '(' if open_count < n.
  • Can add ')' if close_count < open_count.
Base case: when len(path) == 2 * n, append "".join(path)!

✅ The solution

Reveal the commented solution (attempt it first!) 
def generateParenthesis(n: int) -> list[str]:
    """
    Generates well-formed parentheses strings via open/close bounded backtracking.
    """
    res = []
    path = []
    
    def backtrack(open_count, close_count):
        if len(path) == 2 * n:
            res.append("".join(path))
            return
            
        if open_count < n:
            path.append('(')
            backtrack(open_count + 1, close_count)
            path.pop()
            
        if close_count < open_count:
            path.append(')')
            backtrack(open_count, close_count + 1)
            path.pop()
            
    backtrack(0, 0)
    return res

⚡ Complexity analysis

  • Time Complexity: O(4^N / sqrt(N)) governed by the n-th Catalan number $C_n = rac{1}{n+1}inom{2n}{n}$.
  • Space Complexity: O(N) stack depth.
