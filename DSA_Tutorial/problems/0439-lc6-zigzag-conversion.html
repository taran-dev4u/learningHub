#6 Zigzag Conversion MediumLeetCode

📋 The problem

Write a string in a zigzag over a given number of rows, then read it row by row and return the result.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

The string "PAYPALISHIRING" is written in a zigzag pattern on a given number of rows like this: 

P   A   H   N
A P L S I I G
Y   I   R
And then read line by line: "PAHNAPLSIIGYIR".

Track the current row curr_row and direction step = 1 (moving down) or step = -1 (moving up diagonally). - Whenever curr_row == 0, set step = 1. - Whenever curr_row == numRows - 1, set step = -1.

🐢 Brute force vs optimal

Instead of creating an entire 2D matrix with empty spaces, maintain a list of numRows string buffers! Append each character to rows[curr_row], then join all rows at the end.

💡 Key insight: Bouncing pointer: curr_row += step. Reverse step direction (step = -step) when hitting row 0 or row numRows - 1.

✅ The solution

Reveal the commented solution (attempt it first!) 
def convert(s: str, numRows: int) -> str:
    if numRows == 1 or numRows >= len(s):
        return s
        
    rows = [[] for _ in range(numRows)]
    curr_row = 0
    step = -1
    
    for ch in s:
        rows[curr_row].append(ch)
        if curr_row == 0 or curr_row == numRows - 1:
            step = -step
        curr_row += step
        
    return "".join("".join(row) for row in rows)

Complexity

Time: $O(n)$ — Single pass over string $s$.
Space: $O(n)$ — String buffers holding characters.
