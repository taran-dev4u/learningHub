📋 The problem

A 4-wheel lock starts at 0000; each move turns one wheel one notch, avoiding dead-end codes; return the fewest moves to the target.

Where this fits

Graph - BFS on State Space — BFS where states are not graph nodes but encoded situations — word transformations, lock combinations.

Why this pattern?

  • "islands", "connected", "regions", "provinces" → component DFS/BFS
  • "minimum steps / moves / days to reach" → BFS
  • "prerequisites", "build order", "course schedule" → topological sort
  • states-and-moves puzzles (word ladder, locks) → BFS over implicit graph

q, seen = deque([(start, 0)]), {start}
while q:
    node, d = q.popleft()
    if node == goal: return d
    for nb in neighbors(node):
        if nb not in seen:
            seen.add(nb)                 # mark on ENQUEUE
            q.append((nb, d + 1))

# Topological sort (Kahn's)
indeg = defaultdict(int)
for u in graph:
    for v in graph[u]: indeg[v] += 1
q = deque([u for u in graph if indeg[u] == 0])
order = []
while q:
    u = q.popleft(); order.append(u)
    for v in graph[u]:
        indeg[v] -= 1
        if indeg[v] == 0: q.append(v)
# len(order) < number of nodes  ⇒  cycle exists
