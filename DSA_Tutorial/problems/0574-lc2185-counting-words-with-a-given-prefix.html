#2185 Counting Words With a Given Prefix EasyLeetCode

 

Pattern: Trie / Prefix Tree Patterns › Subpattern 20.4: Streaming / Autocomplete / Suffix Trie · Problem 574 of 699

📋 The problem

Count the words in a list that start with a given prefix.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an array of strings words and a string pref, return the number of strings in words that contain pref as a prefix.

Key Insights

Iterate through words and count how many start with pref using Python's str.startswith(pref).

Python 3 Solution (Click to Expand) 
from typing import List

class Solution:
    def prefixCount(self, words: List[str], pref: str) -> int:
        return sum(1 for w in words if w.startswith(pref))

Complexity & Edge Cases

  • Time Complexity: $O(N imes L)$ where $L = ext{len}(pref)$.
  • Space Complexity: $O(1)$.
