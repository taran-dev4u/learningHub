Pattern: Advanced Dynamic Programming Patterns › Subpattern 23.1: Bitmask / Subset DP / TSP-style · Problem 611 of 707

📋 The problem

Decide whether matchsticks of given lengths can form a square using every stick exactly once.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Bitmask / Subset DP / TSP-style — dp[mask] over subsets of n elements (n ≤ 20); iterate over submasks for partition/TSP problems.

Why this pattern?

  • two strings/sequences compared → 2-D prefix DP
  • pick items under a budget → knapsack (0/1 vs unbounded!)
  • "longest increasing …" → LIS (O(n log n) with patience trick)
  • operations on ranges "burst/merge/remove" → interval DP over lengths

        if a[i-1] == b[j-1]:
            dp[i][j] = dp[i-1][j-1]         # free match
        else:
            dp[i][j] = 1 + min(dp[i-1][j],      # delete
                               dp[i][j-1],      # insert
                               dp[i-1][j-1])    # replace

# 0/1 knapsack, 1-D
