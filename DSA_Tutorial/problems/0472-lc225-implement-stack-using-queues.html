📋 The problem

Implement a LIFO stack using only queue operations.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Implement a last-in-first-out (LIFO) stack using only standard FIFO queues (only push to back, peek/pop from front, size, and is empty operations).

The Single-Queue Rotation Trick: When pushing element $x$ to the queue: 1. Append $x$ to the back of the queue. 2. For all previous $size - 1$ elements in the queue, dequeue from front and enqueue back to rear! This inverts the order so that the newly added element $x$ is now sitting at the front of the queue, ready to be popped in $O(1)$!

🐢 Brute force vs optimal

By spending $O(n)$ time during push, all reads (pop and top) execute in instant $O(1)$ time using only 1 queue!

💡 Key insight: After enqueuing $x$, rotate the queue by size - 1: q.append(q.popleft()). The newest element is now at the front!

✅ The solution

Reveal the commented solution (attempt it first!) 
from collections import deque

class MyStack:
    def __init__(self):
        self.q = deque()

    def push(self, x: int) -> None:
        self.q.append(x)
        # Rotate all previous elements behind the newly added x
        for _ in range(len(self.q) - 1):
            self.q.append(self.q.popleft())

    def pop(self) -> int:
        return self.q.popleft()

    def top(self) -> int:
        return self.q[0]

    def empty(self) -> bool:
        return len(self.q) == 0

Complexity

Time: push: $O(n)$ rotation. pop, top, empty: $O(1)$.
Space: $O(n)$ — Single queue buffer.
