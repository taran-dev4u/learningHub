📋 The problem

Return the n-th 'ugly number' — the n-th positive integer whose prime factors are limited to 2, 3, and 5.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an integer {2, 3, 5}n{2, 3, 5}, return the {2, 3, 5}n^{ ext{th}}{2, 3, 5} ugly number. Ugly numbers are positive integers whose prime factors are limited to 2, 3, and 5.

Key Insights

Every ugly number after 1 must be formed by multiplying a previously generated ugly number by 2, 3, or 5. We maintain three pointers {2, 3, 5}p_2, p_3, p_5{2, 3, 5}, each pointing to the candidate index in the sorted list of ugly numbers: {2, 3, 5}{2, 3, 5}next_ugly = \min(ugly[p_2] imes 2, ugly[p_3] imes 3, ugly[p_5] imes 5){2, 3, 5}{2, 3, 5} Whenever the chosen candidate matches {2, 3, 5}ugly[p_k] imes k{2, 3, 5}, advance {2, 3, 5}p_k{2, 3, 5}. (Handling duplicates like {2, 3, 5}2 imes 3 = 6{2, 3, 5} and {2, 3, 5}3 imes 2 = 6{2, 3, 5} naturally by advancing both pointers).

Python 3 Solution (Three-Pointer DP - O(N)) 
class Solution:
    def nthUglyNumber(self, n: int) -> int:
        ugly = [1] * n
        p2 = p3 = p5 = 0
        
        for i in range(1, n):
            c2, c3, c5 = ugly[p2] * 2, ugly[p3] * 3, ugly[p5] * 5
            nxt = min(c2, c3, c5)
            ugly[i] = nxt
            
            if nxt == c2:
                p2 += 1
            if nxt == c3:
                p3 += 1
            if nxt == c5:
                p5 += 1
                
        return ugly[-1]

Complexity & Edge Cases

  • Time Complexity: {2, 3, 5}O(n){2, 3, 5} strictly linear time.
  • Space Complexity: {2, 3, 5}O(n){2, 3, 5} array to store {2, 3, 5}n{2, 3, 5} ugly numbers.
