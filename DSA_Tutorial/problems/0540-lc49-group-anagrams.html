📋 The problem

Group a list of words so that words that are anagrams of each other end up in the same group.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Grouping / Frequency — Hashmap groups elements by a canonical key (sorted string, character signature, etc.).

💡 Key idea
Group by canonical key: tuple(sorted(word)) or the 26-count tuple.

Why this pattern?

  • "O(1) average for every operation"
  • eviction by recency/frequency, capacity limits
  • time-versioned lookups (get value at timestamp)
  • two-way mappings, consistent grouping

def get_val(k, t):
    arr = store[k]

    return arr[i-1][1] if i else ""
