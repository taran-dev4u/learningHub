#900 RLE Iterator MediumLeetCode

 

Pattern: Design Patterns › Subpattern 15.1: General / Specific Data Structure Design · Problem 495 of 699

📋 The problem

Iterate over a run-length encoded sequence: next(n) consumes n elements and returns the last one consumed (-1 past the end).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

We can use run-length encoding (RLE) to encode a sequence of integers. Design an iterator that iterates through a run-length encoded sequence given by encoding where even indices are counts and odd indices are values.

Maintain: - idx: pointer to current count in encoding. - During next(n): While idx < len(encoding) and n > 0: - If encoding[idx] >= n: decrement encoding[idx] -= n and return encoding[idx + 1] (the value!). - If encoding[idx] < n: exhaust this entire run: n -= encoding[idx]; idx += 2. If we run out of elements, return -1!

🐢 Brute force vs optimal

Decompressing the entire sequence takes $O( ext{Total Counts})$ memory which exceeds 32-bit limits. The pointer consumes $O(1)$ auxiliary space and skips entire runs in $O(1)$!

💡 Key insight: Decrement counts directly in-place: subtract $n$ from encoding[idx]. If exhausted, advance idx += 2. Runs in $O(1)$ space!

✅ The solution

Reveal the commented solution (attempt it first!) 
class RLEIterator:
    def __init__(self, encoding: list[int]):
        self.enc = encoding
        self.idx = 0

    def next(self, n: int) -> int:
        while self.idx < len(self.enc):
            if self.enc[self.idx] >= n:
                self.enc[self.idx] -= n
                return self.enc[self.idx + 1]
            else:
                n -= self.enc[self.idx]
                self.idx += 2
        return -1

Complexity

Time: $O(1)$ amortized per next() call.
Space: $O(1)$ auxiliary memory.
