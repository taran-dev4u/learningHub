#1352 Product of the Last K Numbers MediumLeetCode

 

Pattern: Design Patterns › Subpattern 15.1: General / Specific Data Structure Design · Problem 499 of 699

📋 The problem

Design a stream where add appends a number and getProduct(k) returns the product of the last k (prefix products, reset on zero).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design an algorithm that accepts a stream of integers and retrieves the product of the last k integers of the stream in $O(1)$ time complexity!

Prefix Product Array: Let $prefix[i]$ be the cumulative product of all numbers up to index $i$. The product of the last $k$ numbers is simply: $$ ext{Product} = \frac{prefix[-1]}{prefix[-1 - k]}$$

The Zero Reset Problem: If a 0 is added to the stream: Any product that includes that 0 will be 0! Any product that does NOT include that 0 will only look at numbers added after the 0! Therefore, whenever num == 0: Clear the prefix product array completely and reset prefix = [1]! If a query requests $k \ge ext{len}(prefix)$, it means the product spans across the zero, so return 0 immediately!

🐢 Brute force vs optimal

Multiplying last $k$ numbers takes $O(k)$ time. Prefix products calculate the quotient in strict $O(1)$ time.

💡 Key insight: Prefix products: prefix.append(prefix[-1] * num). If $num == 0$, reset prefix = [1]. Product of last $k$ is prefix[-1] // prefix[-1 - k] in $O(1)$!

✅ The solution

Reveal the commented solution (attempt it first!) 
class ProductOfNumbers:
    def __init__(self):
        self.prefix = [1]

    def add(self, num: int) -> None:
        if num == 0:
            # A zero invalidates all previous products
            self.prefix = [1]
        else:
            self.prefix.append(self.prefix[-1] * num)

    def getProduct(self, k: int) -> int:
        if k >= len(self.prefix):
            return 0
        return self.prefix[-1] // self.prefix[-1 - k]

Complexity

Time: $O(1)$ for both add and getProduct.
Space: $O(N)$ — Prefix product buffer.
