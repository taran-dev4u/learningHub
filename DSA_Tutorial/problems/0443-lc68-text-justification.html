#68 Text Justification HardLeetCode

📋 The problem

Greedily pack words into lines of exactly maxWidth characters, distributing spaces as evenly as possible (left-justify the last line).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an array of strings words and a width maxWidth, format the text such that each line has exactly maxWidth characters and is fully (left and right) justified.

Rules to handle: 1. Pack as many words as possible: a line can hold words if $\sum ext{len}(w) + (k - 1) \le ext{maxWidth}$. 2. Evenly distribute extra spaces: - Let total_spaces = maxWidth - sum_len_words. - If line has $k > 1$ words, there are $k - 1$ slots. - Base spaces per slot: base = total_spaces // (k - 1). - Extra spaces assigned to leftmost slots: extra = total_spaces % (k - 1). 3. Edge cases (Single word line OR Last line): - Left-justify! Words separated by exactly single space " ", and pad remaining spaces to the right until maxWidth.

🐢 Brute force vs optimal

Single linear pass over words collecting lines greedily, then applying formatting rules in $O(N)$ time.

💡 Key insight: Greedily pack words per line. If $k=1$ or last line: left justify (join with " " and ljust(maxWidth)). Otherwise: distribute total_spaces // (k-1) with total_spaces % (k-1) extra to left slots.

def fullJustify(words: list[str], maxWidth: int) -> list[str]:
    res = []
    i = 0
    n = len(words)
    
    while i < n:
        # 1. Determine which words fit on current line
        line_words = [words[i]]
        line_len = len(words[i])
        j = i + 1
        while j < n and line_len + 1 + len(words[j]) <= maxWidth:
            line_words.append(words[j])
            line_len += 1 + len(words[j])
            j += 1
            
        k = len(line_words)
        total_word_len = sum(len(w) for w in line_words)
        total_spaces = maxWidth - total_word_len
        
        # 2. Case: Last line OR single word line -> Left justify
        if j == n or k == 1:
            line = " ".join(line_words).ljust(maxWidth)
        else:
            # 3. Fully justify
            base_spaces = total_spaces // (k - 1)
            extra_spaces = total_spaces % (k - 1)
            line_parts = []
            for idx in range(k - 1):
                line_parts.append(line_words[idx])
                spaces = base_spaces + (1 if idx < extra_spaces else 0)
                line_parts.append(" " * spaces)
            line_parts.append(line_words[-1])
            line = "".join(line_parts)
            
        res.append(line)
        i = j
        
    return res

Complexity

Time: $O(N)$ where $N$ is total length of all characters.
Space: $O(N)$ — Justified text result array.
