#115 Distinct Subsequences HardLeetCode

📋 The problem

Count how many distinct subsequences of string s equal string t.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given two strings s and t, return the number of distinct subsequences of s which equals t.

Let $dp[i][j]$ be the number of distinct subsequences of $s[0 \dots i-1]$ that equal $t[0 \dots j-1]$. - If $s[i - 1] == t[j - 1]$, we have two choices: 1. Match this character: add $dp[i - 1][j - 1]$ (match $s[i-1]$ with $t[j-1]$). 2. Skip this character: add $dp[i - 1][j]$ (look for $t[0 \dots j-1]$ earlier in $s$). $$dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]$$ - If $s[i - 1] e t[j - 1]$, we cannot match, so: $$dp[i][j] = dp[i - 1][j]$$

🐢 Brute force vs optimal

Generating all $2^{|s|}$ subsequences is impossibly slow. 2D DP computes the answer in $O(|s| \times |t|)$ time. Traversing j backwards optimizes space to $O(|t|)$!

💡 Key insight: 1D array backwards: if $s[i-1] == t[j-1]$, dp[j] += dp[j - 1] with base case dp[0] = 1 (empty string $t$ has 1 subsequence in any prefix of $s$).

✅ The solution

Reveal the commented solution (attempt it first!) 
def numDistinct(s: str, t: str) -> int:
    m, n = len(s), len(t)
    if m < n:
        return 0
        
    dp = [0] * (n + 1)
    dp[0] = 1
    
    for char_s in s:
        for j in range(n, 0, -1):
            if char_s == t[j - 1]:
                dp[j] += dp[j - 1]
                
    return dp[n]

Complexity

Time: $O(m \times n)$ — Nested string traversal.
Space: $O(n)$ — 1D space traversing right-to-left.
