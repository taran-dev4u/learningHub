📋 The problem

Design an LFU cache: evict the least frequently used key (ties: least recently used), all operations O(1).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design and implement a data structure for a Least Frequently Used (LFU) cache. When the capacity is reached, evict the least frequently used key. If there is a tie, evict the least recently used key among them.

Core Challenge: Both get and put must run in $O(1)$ time!

The Doubly-Linked-List per Frequency Architecture: We maintain: 1. vals: key -> (value, freq) 2. freq_lists: freq -> DoublyLinkedList (each frequency has its own Doubly Linked List storing keys in LRU order!) 3. min_freq: integer tracking the current global minimum frequency in the cache.

When a key's frequency increments ($f o f + 1$): 1. Remove key from freq_lists[f]. 2. If freq_lists[f] becomes empty and min_freq == f, increment min_freq += 1! 3. Insert key into freq_lists[f + 1].

When evicting at full capacity: Remove the LRU node from freq_lists[min_freq].tail.prev in $O(1)$!

🐢 Brute force vs optimal

Using a heap or priority queue takes $O(\log n)$ per access. A frequency-to-doubly-linked-list mapping achieves strict $O(1)$ operations.

💡 Key insight: Map each frequency to its own Doubly Linked List. Track min_freq. When evicting, remove the oldest element from freq_lists[min_freq] in $O(1)$!

from collections import defaultdict

class Node:
    def __init__(self, key=0, val=0):
        self.key = key
        self.val = val
        self.freq = 1
        self.prev = None
        self.next = None

class DLinkedList:
    def __init__(self):
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head
        self.size = 0

    def add_to_head(self, node: Node):
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node
        self.size += 1

    def remove(self, node: Node):
        node.prev.next = node.next
        node.next.prev = node.prev
        self.size -= 1

    def remove_tail(self) -> Node:
        if self.size == 0:
            return None
        lru = self.tail.prev
        self.remove(lru)
        return lru

class LFUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.nodes = {} # key -> Node
        self.freq_lists = defaultdict(DLinkedList) # freq -> DLinkedList
        self.min_freq = 0

    def _update_freq(self, node: Node):
        f = node.freq
        self.freq_lists[f].remove(node)
        if self.freq_lists[f].size == 0 and self.min_freq == f:
            self.min_freq += 1
            
        node.freq += 1
        self.freq_lists[node.freq].add_to_head(node)

    def get(self, key: int) -> int:
        if key not in self.nodes:
            return -1
        node = self.nodes[key]
        self._update_freq(node)
        return node.val

    def put(self, key: int, value: int) -> None:
        if self.capacity == 0:
            return
            
        if key in self.nodes:
            node = self.nodes[key]
            node.val = value
            self._update_freq(node)
        else:
            if len(self.nodes) >= self.capacity:
                lfu_node = self.freq_lists[self.min_freq].remove_tail()
                del self.nodes[lfu_node.key]
                
            new_node = Node(key, value)
            self.nodes[key] = new_node
            self.freq_lists[1].add_to_head(new_node)
            self.min_freq = 1

Complexity

Time: $O(1)$ for both get and put.
Space: $O( ext{capacity})$ — Hash map and nodes partitioned across frequency lists.
