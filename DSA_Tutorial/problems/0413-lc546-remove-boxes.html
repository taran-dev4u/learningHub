#546 Remove Boxes HardLeetCode

 

Pattern: Dynamic Programming (DP) Patterns › Subpattern 12.9: Interval DP · Problem 413 of 699

📋 The problem

Remove boxes in groups of equal-colored consecutive boxes, earning k² per group of k; maximize total points.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given several boxes with different colors represented by positive integers boxes. You may experience several rounds to remove boxes until there is no box left. Each time you can choose some continuous boxes with the same color (i.e. length k >= 1), remove them and get k * k points. Return the maximum points you can get.

This is one of the most famous 3D Interval DP problems in competitive programming! A standard 2D interval $dp[l][r]$ is insufficient because boxes to the left of $l$ with the same color as $boxes[l]$ can be accumulated and merged together after clearing intermediate boxes!

3D State Formulation: Let $dp[l][r][k]$ be the maximum score for subarray $boxes[l \dots r]$ given that there are already $k$ boxes adjacent to $boxes[l]$ on the left with the same color $boxes[l]$! 1. Option 1: Remove $boxes[l]$ together with the $k$ accumulated identical boxes: $$\text{gain} = (k + 1)^2 + dp[l + 1][r][0]$$ 2. Option 2: Keep $boxes[l]$ and the $k$ boxes, find another box $m \in [l+1, r]$ where $boxes[m] == boxes[l]$, clear the intermediate segment $boxes[l+1 \dots m-1]$, and merge: $$\text{gain} = dp[l + 1][m - 1][0] + dp[m][r][k + 1]$$

🐢 Brute force vs optimal

Brute force search is factorial. 3D memoization bounds distinct subproblems to $O(n^4)$ states and transitions, executing smoothly within typical constraints ($n \le 100$).

💡 Key insight: State includes $k$: dfs(l, r, k) = max score on boxes[l..r] with $k$ matching boxes attached to boxes[l] from the left.

✅ The solution

from functools import lru_cache

def removeBoxes(boxes: list[int]) -> int:
    @lru_cache(maxsize=None)
    def dfs(l: int, r: int, k: int) -> int:
        if l > r:
            return 0
            
        # Optimization: group consecutive matching boxes at the start
        while l + 1 <= r and boxes[l] == boxes[l + 1]:
            l += 1
            k += 1
            
        # Option 1: burst boxes[l] and the k accumulated identical boxes
        res = (k + 1) * (k + 1) + dfs(l + 1, r, 0)
        
        # Option 2: find another matching box m in (l+1..r)
        for m in range(l + 1, r + 1):
            if boxes[m] == boxes[l]:
                res = max(res, dfs(l + 1, m - 1, 0) + dfs(m, r, k + 1))
                
        return res
        
    return dfs(0, len(boxes) - 1, 0)

Complexity

Time: $O(n^4)$ — $n^3$ states, each taking $O(n)$ transition scan.
Space: $O(n^3)$ — 3D memoization cache.
