📋 The problem

Return every subset of an array that may contain duplicates, without producing duplicate subsets.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer array nums that may contain duplicates, return all possible subsets (the power set). The solution set must not contain duplicate subsets.

🐢 Brute force vs optimal

Generating all subsets and converting to a set(tuple(x)) wastes computation on duplicate branches. By sorting the input and pruning identical sibling choices at the same recursion depth, we generate only unique subsets in O(N × 2^N) time.

💡 Key insight: Sort nums. In the loop for i in range(start, n): If i > start and nums[i] == nums[i - 1]: continue!

Why i > start? Because if i == start, this is the first time we are picking this duplicate element for the current position (e.g. picking the second '2' to make [2, 2]). But if i > start, we have already explored all subsets starting with an identical element at this level—picking it again would generate a duplicate branch!

🪜 The approach, step by step

  1. Sort nums.sort().
  2. Initialize res = [], path = [].
  3. In backtrack(start):
    • Append list(path) to res.
    • For i from start to len(nums) - 1:
      • If i > start and nums[i] == nums[i - 1]: continue (prune duplicate sibling!).
      • path.append(nums[i])
      • backtrack(i + 1)
      • path.pop()

✅ The solution

def subsetsWithDup(nums: list[int]) -> list[list[int]]:
    """
    Generates all unique subsets from array with duplicates using sorting and sibling pruning.
    """
    nums.sort()
    res = []
    path = []
    n = len(nums)
    
    def backtrack(start):
        res.append(list(path))
        
        for i in range(start, n):
            # Prune duplicate choices at the same recursion depth
            if i > start and nums[i] == nums[i - 1]:
                continue
                
            path.append(nums[i])
            backtrack(i + 1)
            path.pop()
            
    backtrack(0)
    return res

⚡ Complexity analysis

  • Time Complexity: O(N × 2^N). Sorting takes O(N log N).
  • Space Complexity: O(N) recursion stack.
