📋 The problem

Return the length of the longest subsequence common to two strings.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given two strings text1 and text2, return the length of their longest common subsequence. If there is no common subsequence, return 0.

💡 Key insight: 2D Dynamic Programming table dp[i][j] representing LCS of prefixes text1[:i] and text2[:j]:
  • If text1[i - 1] == text2[j - 1]: characters match! dp[i][j] = 1 + dp[i - 1][j - 1].
  • Else: characters differ! Skip one character from either string: dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]).

✅ The solution

def longestCommonSubsequence(text1: str, text2: str) -> int:
    """
    Computes length of LCS between two strings in O(M * N) time.
    """
    m, n = len(text1), len(text2)
    # dp[i][j] stores LCS length of text1[:i] and text2[:j]
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = 1 + dp[i - 1][j - 1]
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
                
    return dp[m][n]

⚡ Complexity analysis

  • Time Complexity: O(M × N) where M = len(text1), N = len(text2).
  • Space Complexity: O(M × N) (can be optimized to O(min(M, N)) using a 1D rolling array).
