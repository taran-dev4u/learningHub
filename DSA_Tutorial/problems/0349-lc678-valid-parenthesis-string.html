📋 The problem

With '(' ')' and '*' (wildcard: '(' or ')' or empty), decide whether a string can be a valid parentheses string.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a string s containing only three types of characters: '(', ')', and '*', return true if s is valid. An '*' could be treated as a single right parenthesis ')' or a single left parenthesis '(' or an empty string "".

🐢 Brute force vs optimal

Because each '*' has 3 choices, branching recursion takes O(3^N). Dynamic programming takes O(N^2). The Greedy approach tracks the range of possible open parentheses count [cmin, cmax] in O(N) time and O(1) space!

💡 Key insight: Maintain cmin (minimum possible unclosed open parentheses) and cmax (maximum possible unclosed open parentheses):
  • '(': cmin += 1, cmax += 1.
  • ')': cmin -= 1, cmax -= 1.
  • '*': Can act as ')' (decrement), '(' (increment), or "" (unchanged) → cmin -= 1, cmax += 1.
If cmax < 0, we have more ')' than could ever be matched → return False. Clamp cmin = max(cmin, 0) (an '*' never forces open count below 0). At the end, return cmin == 0!

✅ The solution

Reveal the commented solution (attempt it first!) 
def checkValidString(s: str) -> bool:
    """
    Validates parenthesis string with wildcards by tracking open count range [cmin, cmax].
    """
    cmin = 0  # Min possible open brackets
    cmax = 0  # Max possible open brackets
    
    for ch in s:
        if ch == '(':
            cmin += 1
            cmax += 1
        elif ch == ')':
            cmin -= 1
            cmax -= 1
        else:  # ch == '*'
            cmin -= 1
            cmax += 1
            
        if cmax < 0:
            return False  # Too many closing parentheses
        cmin = max(cmin, 0)
        
    return cmin == 0

⚡ Complexity analysis

  • Time Complexity: O(N). Single pass.
  • Space Complexity: O(1). Two integer counters.
