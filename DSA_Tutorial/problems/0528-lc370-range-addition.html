📋 The problem

Apply many (start, end, value) range additions to a zero array and return the final array.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an integer length and an array updates where updates[i] = [startIdx, endIdx, inc]. Apply all updates to an initially zeroed array and return the final array.

The Difference Array Technique: Instead of modifying all elements from $start$ to $end$ ($O(length)$ per update): Apply changes only at the boundaries in $O(1)$ time! - diff[start] += inc: indicates values from $start$ onward increase by $inc$. - diff[end + 1] -= inc: stops the increase from extending past $end$!

After all updates are recorded in $O(1)$ each, compute the running prefix sum of diff to reconstruct the final array in a single $O(n)$ pass!

🐢 Brute force vs optimal

Updating intervals directly takes $O(U imes N)$ time. Difference array executes updates in $O(1)$ and rebuilds in $O(N)$ time.

💡 Key insight: Difference array: diff[start] += inc; diff[end + 1] -= inc. Final array is the running cumulative prefix sum of diff. $O(U + N)$ total time!

✅ The solution

Reveal the commented solution (attempt it first!) 
def getModifiedArray(length: int, updates: list[list[int]]) -> list[int]:
    diff = [0] * (length + 1)
    
    # 1. Apply boundary markers in O(1)
    for start, end, inc in updates:
        diff[start] += inc
        diff[end + 1] -= inc
        
    # 2. Cumulative prefix sum in O(length)
    res = [0] * length
    curr = 0
    for i in range(length):
        curr += diff[i]
        res[i] = curr
        
    return res

Complexity

Time: $O(U + N)$ where $U = ext{len}(updates)$ and $N = length$.
Space: $O(N)$ — Difference buffer.
