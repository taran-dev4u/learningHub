#241 Different Ways to Add Parentheses MediumLeetCode

📋 The problem

Given an expression of numbers and operators, return every result obtainable by fully parenthesizing it differently.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a string expression of numbers and operators, return all possible results from computing all the different possible ways to group numbers and operators (with parentheses).

This is divide and conquer / Catalan structure: Every operator (+, -, *) splits the expression into a left subexpression and a right subexpression: $$\text{diffWaysToCompute}(\text{left}) \quad \text{op} \quad \text{diffWaysToCompute}(\text{right})$$ Evaluate Cartesian product of all results from left and right operands.

🐢 Brute force vs optimal

Memoizing on the string slice memo[expression] prevents re-evaluating identical subexpressions.

💡 Key insight: For each operator at index $i$: split into expr[:i] and expr[i+1:], recurse with memoization, and combine pairwise results.

✅ The solution

def diffWaysToCompute(expression: str) -> list[int]:
    memo = {}
    
    def dfs(expr: str) -> list[int]:
        if expr in memo:
            return memo[expr]
            
        res = []
        for i, ch in enumerate(expr):
            if ch in '+-*':
                left_results = dfs(expr[:i])
                right_results = dfs(expr[i + 1:])
                
                for l in left_results:
                    for r in right_results:
                        if ch == '+':
                            res.append(l + r)
                        elif ch == '-':
                            res.append(l - r)
                        elif ch == '*':
                            res.append(l * r)
                            
        # Base case: pure number
        if not res:
            res.append(int(expr))
            
        memo[expr] = res
        return res
        
    return dfs(expression)

Complexity

Time: $O(4^n / \sqrt{n})$ — Bound by Catalan number of parenthesizations.
Space: $O(4^n / \sqrt{n})$ — Memoization dictionary storing all subexpression evaluation lists.
