#1032 Stream of Characters HardLeetCode

📋 The problem

Design a stream reader that reports, after each character, whether some suffix of the stream matches a dictionary word (suffix trie of reversed words).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Design an algorithm that accepts a stream of characters and checks if a suffix of these characters is a string of a given array of words.

Key Insights

A forward Trie requires maintaining a set of all active search pointers for every character in history, which explodes in size. Reversed Word Trie: Insert all dictionary words in reverse order into the Trie! Keep a running stream history array history. When query(letter) is called, append letter to history, then walk backward from the end of history through the reversed Trie! If we hit node.is_end == True at any point, a valid suffix match is found in $O(L)$ time.

Python 3 Solution (Reversed Suffix Trie) 
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class StreamChecker:
    def __init__(self, words: List[str]):
        self.root = TrieNode()
        self.history = []
        self.max_len = 0
        
        for w in words:
            self.max_len = max(self.max_len, len(w))
            curr = self.root
            for ch in reversed(w):
                if ch not in curr.children:
                    curr.children[ch] = TrieNode()
                curr = curr.children[ch]
            curr.is_end = True

    def query(self, letter: str) -> bool:
        self.history.append(letter)
        curr = self.root
        
        # Walk backward through history
        for i in range(len(self.history) - 1, -1, -1):
            ch = self.history[i]
            if ch not in curr.children:
                return False
            curr = curr.children[ch]
            if curr.is_end:
                return True
            if len(self.history) - i > self.max_len:
                break
                
        return False

Complexity & Edge Cases

  • Time Complexity: $O(L)$ per query, where $L$ is max word length.
  • Space Complexity: $O(N imes L)$ nodes.
