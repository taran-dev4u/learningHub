#325 Maximum Size Subarray Sum Equals k MediumLeetCode

 

Pattern: Prefix Sum & Difference Array Patterns › Subpattern 17.1: Subarray Sum with Hashmap · Problem 519 of 699

📋 The problem

Return the length of the longest subarray whose elements sum exactly to k.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer array nums and an integer k, return the maximum length of a subarray that sums to k. If there isn't one, return 0 instead.

Let $prefix[i]$ be the cumulative running sum up to index $i$. A subarray from $j + 1$ to $i$ has sum $prefix[i] - prefix[j] = k$. Rearranging: $$prefix[j] = prefix[i] - k$$ To maximize the length $i - j$, we want index $j$ to be as small (as early) as possible! Therefore, maintain a hash map first_seen[sum] -> index: - Only record the index the first time a prefix sum is encountered (never overwrite it)! - Base case: first_seen[0] = -1 (to handle subarrays starting at index 0).

🐢 Brute force vs optimal

Checking all $O(n^2)$ subarrays takes $O(n^2)$ time. Hash map of earliest prefix occurrences finds the maximum length in a single linear pass $O(n)$ with $O(n)$ space.

💡 Key insight: Store earliest index of each prefix sum: if curr_sum not in first_seen: first_seen[curr_sum] = i. If curr_sum - k in map, update max_len = max(max_len, i - first_seen[curr_sum - k]).

✅ The solution

Reveal the commented solution (attempt it first!) 
def maxSubArrayLen(nums: list[int], k: int) -> int:
    first_seen = {0: -1}
    curr_sum = 0
    max_len = 0
    
    for i, x in enumerate(nums):
        curr_sum += x
        if curr_sum - k in first_seen:
            max_len = max(max_len, i - first_seen[curr_sum - k])
        if curr_sum not in first_seen:
            first_seen[curr_sum] = i
            
    return max_len

Complexity

Time: $O(n)$ — Single pass through array.
Space: $O(n)$ — Hash map storing prefix sums.
