📋 The problem

Return the maximum sum of any path in a binary tree; a path connects nodes parent-to-child and may not fork (it can pass through a node's two children only at its highest point).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Tree Max Path Sum / Tilt — Each node returns max-gain-as-leaf; while recursing, update the global max-path-sum answer.

💡 Key idea
At each node: best downward gain per child (clamped at 0); path through node = val + leftGain + rightGain updates the global.

Why this pattern?

  • optimize a value over a TREE (max path, max loot, longest chain)
  • constraints between parent and child ("can't pick both")
  • "count/size/best of subtrees" feeding a global answer
  • the diameter shape: best-through-this-node vs best-for-parent differ

def dfs(node):
    if not node:
        return NEUTRAL                     # e.g. (0, 0)
    L = dfs(node.left)                     # children first (postorder)
    R = dfs(node.right)
    include = node.val + L[1] + R[1]       # take node → children excluded
    exclude = max(L) + max(R)              # skip node → children free
    # global-answer problems also do:  best = max(best, through_node)
    return (include, exclude)
