#130 Surrounded Regions MediumLeetCode

📋 The problem

In a grid of X and O, flip every O region that is completely surrounded by X (regions touching the border survive).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an m x n matrix board containing 'X' and 'O', capture all regions that are 4-directionally surrounded by 'X'. A region is captured by flipping all 'O's into 'X's in that surrounded region.

🐢 Brute force first

Checking each 'O' to see if it can reach the boundary takes O((m*n)^2). Invert the perspective: which 'O's CANNOT be captured?

💡 Key insight: Any 'O' on the border (or connected to a border 'O') can NEVER be surrounded! Therefore, reverse the logic: 1. Start DFS from all 'O's located on the 4 borders of the matrix. Mark them and all connected 'O's with a temporary marker (e.g. 'E' for Escaped). 2. Now, all remaining 'O's are completely surrounded! Flip them to 'X'. 3. Finally, restore the escaped 'E' cells back to 'O'.

🪜 The approach, step by step

  1. Identify all boundary cells: first row, last row, first col, last col.
  2. For each boundary cell where board[r][c] == 'O', run DFS to mark all connected 'O's as 'E'.
  3. Iterate through the entire board:
    • If board[r][c] == 'O': flip to 'X' (it was truly surrounded).
    • If board[r][c] == 'E': restore to 'O' (it was connected to border).

✅ The solution

def solve(board):
    """
    Do not return anything, modify board in-place instead.
    """
    if not board or not board[0]:
        return
        
    m, n = len(board), len(board[0])
    
    def dfs(r, c):
        if r < 0 or r >= m or c < 0 or c >= n or board[r][c] != 'O':
            return
        board[r][c] = 'E'  # Mark as escaped / border-connected
        dfs(r + 1, c)
        dfs(r - 1, c)
        dfs(r, c + 1)
        dfs(r, c - 1)
        
    # Step 1: Run DFS from all border 'O's
    for r in range(m):
        for c in (0, n - 1):
            if board[r][c] == 'O':
                dfs(r, c)
    for c in range(n):
        for r in (0, m - 1):
            if board[r][c] == 'O':
                dfs(r, c)
                
    # Step 2: Flip captured 'O' -> 'X', and restore 'E' -> 'O'
    for r in range(m):
        for c in range(n):
            if board[r][c] == 'O':
                board[r][c] = 'X'
            elif board[r][c] == 'E':
                board[r][c] = 'O'

⏱️ Complexity

Time O(m * n). Space O(m * n) recursion stack.

⚠️ Edge cases

  • Grid of size <= 2: no inner cell can be surrounded; all cells are on the border.
  • Board containing only 'X' or only 'O'.
