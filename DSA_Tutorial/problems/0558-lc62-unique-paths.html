📋 The problem

Count the paths a robot can take from the top-left to the bottom-right of an m×n grid moving only right or down.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

A robot is located at the top-left corner of an {2, 3, 5}m imes n{2, 3, 5} grid. The robot can only move either down or right at any point. How many possible unique paths are there to reach the bottom-right corner?

Key Insights

To reach cell {2, 3, 5}(m-1, n-1){2, 3, 5} from {2, 3, 5}(0, 0){2, 3, 5}, the robot must make exactly:

  • {2, 3, 5}m - 1{2, 3, 5} steps Down
  • {2, 3, 5}n - 1{2, 3, 5} steps Right
Total steps = {2, 3, 5}(m - 1) + (n - 1) = m + n - 2{2, 3, 5}. Any path is determined by choosing which {2, 3, 5}m - 1{2, 3, 5} steps are Down out of the total {2, 3, 5}m + n - 2{2, 3, 5} steps. This is a closed-form combinatorics formula: {2, 3, 5}{2, 3, 5}\binom{m + n - 2}{m - 1} = \frac{(m + n - 2)!}{(m - 1)! \cdot (n - 1)!}{2, 3, 5}{2, 3, 5}

Python 3 Solution (Combinatorics - O(min(m, n))) 
import math

class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        # Combination: C(m + n - 2, min(m - 1, n - 1))
        return math.comb(m + n - 2, m - 1)

Complexity & Edge Cases

  • Time Complexity: {2, 3, 5}O(\min(m, n)){2, 3, 5} multiplicative steps.
  • Space Complexity: {2, 3, 5}O(1){2, 3, 5}.
  • Edge Cases: {2, 3, 5}m = 1{2, 3, 5} or {2, 3, 5}n = 1{2, 3, 5} (returns 1).
