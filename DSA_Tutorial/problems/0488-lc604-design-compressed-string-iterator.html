#604 Design Compressed String Iterator EasyLeetCode

 

Pattern: Design Patterns › Subpattern 15.1: General / Specific Data Structure Design · Problem 488 of 699

📋 The problem

Design an iterator over a compressed string like 'a2b3' that yields a, a, b, b, b.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design and implement a data structure for a compressed string iterator. The given compressed string represents the original uncompressed string of characters followed by their frequencies (e.g. "L1e2t1c1o1d1e1" representing "Leetcode").

Maintain: - s: compressed string. - ptr: cursor index in s. - curr_char: active character being emitted. - curr_count: remaining repeat count of curr_char.

During next(): If curr_count == 0, read the next character and parse the entire multidigit number following it! Decrement curr_count -= 1 and return curr_char.

🐢 Brute force vs optimal

Expanding the entire string in memory takes $O( ext{Total Length})$ which can explode if count is $10^9$. Reading on the fly takes $O(1)$ extra space.

💡 Key insight: Parse on the fly: when curr_count == 0, extract next character and read multidigit integer. Avoids unpacking giant strings.

✅ The solution

Reveal the commented solution (attempt it first!) 
class StringIterator:
    def __init__(self, compressedString: str):
        self.s = compressedString
        self.ptr = 0
        self.curr_char = ' '
        self.curr_count = 0

    def next(self) -> str:
        if not self.hasNext():
            return ' '
        if self.curr_count == 0:
            self.curr_char = self.s[self.ptr]
            self.ptr += 1
            # Parse multi-digit number
            num = 0
            while self.ptr < len(self.s) and self.s[self.ptr].isdigit():
                num = num * 10 + int(self.s[self.ptr])
                self.ptr += 1
            self.curr_count = num
            
        self.curr_count -= 1
        return self.curr_char

    def hasNext(self) -> bool:
        return self.curr_count > 0 or self.ptr < len(self.s)

Complexity

Time: $O(1)$ amortized per next() call.
Space: $O(1)$ auxiliary space.
