#87 Scramble String HardLeetCode

 

Pattern: Dynamic Programming (DP) Patterns › Subpattern 12.6: 2D Array / Longest Common Subsequence (LCS) · Problem 397 of 699

📋 The problem

Decide whether one string is a 'scramble' of another, where scrambling recursively splits a string in two and may swap the halves.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

We can scramble a string s to get a string t using the following algorithm: 1. If the length of the string is 1, stop. 2. Split string into two non-empty substrings at any index. 3. Randomly choose whether to swap the two substrings or leave them as is. 4. Apply the algorithm recursively on each substring.

Given s1 and s2 of length $n$, can s2 be formed by scrambling s1?

For any split index $k \in [1, n-1]$: 1. Without Swap: $s1[0 \dots k]$ scrambles to $s2[0 \dots k]$ AND $s1[k \dots n]$ scrambles to $s2[k \dots n]$. 2. With Swap: $s1[0 \dots k]$ scrambles to $s2[n-k \dots n]$ AND $s1[k \dots n]$ scrambles to $s2[0 \dots n-k]$.

🐢 Brute force vs optimal

Top-down memoized recursion with a frequency character pruning check. If sorted(s1) != sorted(s2), return False immediately without branching!

💡 Key insight: Memoize (s1, s2). Prune early using Counter(s1) != Counter(s2). For each split $k$, check (no_swap) or (swap).

✅ The solution

from collections import Counter
from functools import lru_cache

def isScramble(s1: str, s2: str) -> bool:
    @lru_cache(maxsize=None)
    def dfs(a: str, b: str) -> bool:
        if a == b:
            return True
        if Counter(a) != Counter(b):
            return False
            
        n = len(a)
        for k in range(1, n):
            # Case 1: no swap
            if dfs(a[:k], b[:k]) and dfs(a[k:], b[k:]):
                return True
            # Case 2: swapped
            if dfs(a[:k], b[n - k:]) and dfs(a[k:], b[:n - k]):
                return True
                
        return False
        
    return dfs(s1, s2)

Complexity

Time: $O(n^4)$ states with memoization.
Space: $O(n^3)$ memoization cache and recursion stack.
