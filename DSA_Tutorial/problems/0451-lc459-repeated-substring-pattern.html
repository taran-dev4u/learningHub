#459 Repeated Substring Pattern EasyLeetCode

 

Pattern: String Manipulation Patterns › Subpattern 13.7: Repeated Substring Pattern Detection · Problem 451 of 699

📋 The problem

Decide whether a string equals some substring of itself repeated multiple times.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a string s, check if it can be constructed by taking a substring of it and appending one or more copies of the substring together.

Approach 1: The Doubled String Theorem: If a string $s$ is composed of repeated sub-patterns, then shifting $s$ cyclically will produce $s$ again! Therefore, $s$ is periodic if and only if $s$ appears as a substring inside $(s + s)[1:-1]$ (stripping the first and last character so we don't match the original copies at indices $0$ and $n$).

Approach 2: KMP LPS Property: Let $L = lps[-1]$ be the longest prefix that is also a suffix of $s$. The remaining characters $P = n - L$ represent the length of the candidate repeating unit! If $L > 0$ and $n \pmod{n - L} == 0$, then $s$ is periodically constructed from the prefix of length $n - L$!

🐢 Brute force vs optimal

Both the Doubled String trick s in (s + s)[1:-1] and KMP LPS check run in $O(n)$ time.

💡 Key insight: KMP LPS: let $L = lps[-1]$. If $L > 0$ and $n \% (n - L) == 0$, $s$ is periodic! Or simply return s in (s + s)[1:-1].

✅ The solution

Reveal the commented solution (attempt it first!) 
def repeatedSubstringPattern(s: str) -> bool:
    """
    Checks if string is periodic in O(n) time.
    """
    return s in (s + s)[1:-1]

Complexity

Time: $O(n)$ — Linear substring search in string of length $2n - 2$.
Space: $O(n)$ — Sliced string buffer.
