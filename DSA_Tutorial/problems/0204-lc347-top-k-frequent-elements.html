📋 The problem

Return the k most frequent elements of an array.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer array, return the k most frequent elements. First, count frequencies using a hash map. Then we need the k largest counts. We can either use a min-heap of size k (O(n log k)) or bucket sort based on frequencies (O(n)).

🐢 Brute force first

Count frequencies with a hash map, sort the items by frequency descending, and take the first k elements.

from collections import Counter
def topKFrequent(nums, k):
    counts = Counter(nums)
    sorted_items = sorted(counts.items(), key=lambda x: x[1], reverse=True)
    return [item[0] for item in sorted_items[:k]]

Time O(m log m) where m is the number of distinct elements (up to n). Space O(m).

💡 Key insight: frequency of any element cannot exceed n. We can use Bucket Sort: an array of lists where index i holds elements with frequency i. Scanning backwards from index n yields the top k frequent elements in O(n) linear time.

🪜 The approach, step by step

  1. Count occurrences of each number using Counter(nums).
  2. Create buckets of size len(nums) + 1, where buckets[f] is a list of numbers appearing f times.
  3. Populate buckets by mapping each (num, count) into buckets[count].append(num).
  4. Iterate backwards from frequency len(nums) down to 1, collecting numbers into result until len(result) == k.

✅ The solution

Reveal the commented solution (attempt it first!) 
from collections import Counter

def topKFrequent(nums, k):
    count = Counter(nums)
    # Bucket index = frequency, value = list of numbers with that frequency
    buckets = [[] for _ in range(len(nums) + 1)]
    for num, freq in count.items():
        buckets[freq].append(num)
        
    res = []
    # Collect from highest frequency bucket down to 1
    for freq in range(len(nums), 0, -1):
        for num in buckets[freq]:
            res.append(num)
            if len(res) == k:
                return res
    return res

⏱️ Complexity

Time O(n) — O(n) to count frequencies, O(n) to populate buckets, and O(n) to gather top k. Space O(n) — for the hash map and the bucket array.

⚠️ Edge cases

  • k = len(set(nums)): all distinct elements returned.
  • All elements have frequency 1: any k elements are valid.
  • Array with a single unique element: returned immediately.

🐛 Common mistakes

  • Using bucket size n instead of n + 1, resulting in an IndexError when an element appears n times.
  • Using O(n log n) sorting when interviewers specifically ask for better than O(n log n).
