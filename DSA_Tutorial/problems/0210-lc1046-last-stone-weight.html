#1046 Last Stone Weight Easy★NC★GLeetCode

 

Pattern: Heap (Priority Queue) Patterns › Subpattern 7.1: Top K Elements / Selection / Frequency · Problem 210 of 699

📋 The problem

Repeatedly smash the two heaviest stones (equal → both vanish; else the difference survives); return the last stone's weight (0 if none).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

We are given stone weights. Each turn, pick the two heaviest stones x and y (with x <= y). If x == y, both are destroyed; if x != y, stone x is destroyed and stone y has new weight y - x. Repeat until at most one stone remains. We need repeated maximum retrieval, which is the definition of a max-heap.

🐢 Brute force first

Sort the array descending every time after smashing two stones → O(n^2 log n).

💡 Key insight: invert all values to negative numbers and use Python's heapq as a max-heap. Popping twice gives the two largest stones in O(log n); pushing the difference back takes O(log n).

🪜 The approach, step by step

  1. Negate all elements in stones and heapify in O(n).
  2. While len(heap) > 1:
  3. Pop the largest stone y = -heappop(heap).
  4. Pop the second largest stone x = -heappop(heap).
  5. If y > x, push -(y - x) back onto the heap.
  6. Return -heap[0] if heap is non-empty else 0.

🎞️ Visual dry run — stones = [2, 7, 4, 1, 8, 1]

✅ The solution

import heapq

def lastStoneWeight(stones):
    # Python heapq is a min-heap; negate weights to simulate a max-heap
    heap = [-s for s in stones]
    heapq.heapify(heap)
    
    while len(heap) > 1:
        y = -heapq.heappop(heap)   # heaviest stone
        x = -heapq.heappop(heap)   # second heaviest stone
        if y != x:
            heapq.heappush(heap, -(y - x))
            
    return -heap[0] if heap else 0

⏱️ Complexity

Time O(n log n) — at most n-1 smashes, each doing O(log n) heap operations. Space O(n) — for the heap.

⚠️ Edge cases

  • Single stone: immediately returned.
  • All stones pairwise equal: heap becomes empty, returns 0.
