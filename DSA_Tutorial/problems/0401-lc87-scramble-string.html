#87 Scramble String HardLeetCode

 

Pattern: Dynamic Programming (DP) Patterns › Subpattern 12.6: 2D Array / Longest Common Subsequence (LCS) · Problem 401 of 707

📋 The problem

Decide whether one string is a 'scramble' of another, where scrambling recursively splits a string in two and may swap the halves.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

2D Array / Longest Common Subsequence (LCS) — dp[i][j] = LCS length of prefixes; +1 on match, max otherwise.

Why this pattern?

  • "count the number of ways…"
  • "minimum/maximum cost/value to reach…"
  • choices at each step + overlapping futures (take/skip an item)
  • "longest/shortest subsequence" (non-contiguous!)
