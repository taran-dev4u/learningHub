📋 The problem

Count the prime numbers strictly less than n.

Problem Overview

Given an integer {2, 3, 5}n{2, 3, 5}, return the number of prime numbers strictly less than {2, 3, 5}n{2, 3, 5}.

Key Insights

Checking each number up to {2, 3, 5}n{2, 3, 5} individually with trial division takes {2, 3, 5}O(n \sqrt{n}){2, 3, 5} time, which will TLE for {2, 3, 5}n = 5 imes 10^6{2, 3, 5}.

The optimal algorithm is the Sieve of Eratosthenes:

  1. Initialize a boolean array is_prime of size {2, 3, 5}n{2, 3, 5} with True. Set indices 0 and 1 to False.
  2. For each {2, 3, 5}i{2, 3, 5} from 2 up to {2, 3, 5}\lfloor \sqrt{n} floor{2, 3, 5}:
    • If is_prime[i] is true, mark all multiples of {2, 3, 5}i{2, 3, 5} starting from {2, 3, 5}i^2{2, 3, 5} (step size {2, 3, 5}i{2, 3, 5}) as False.
  3. Return sum(is_prime).

Python 3 Solution (Sieve of Eratosthenes - O(N log log N)) 
class Solution:
    def countPrimes(self, n: int) -> int:
        if n < 3:
            return 0
            
        is_prime = [True] * n
        is_prime[0] = is_prime[1] = False
        
        limit = int(n**0.5)
        for i in range(2, limit + 1):
            if is_prime[i]:
                # Mark multiples starting from i*i
                is_prime[i*i:n:i] = [False] * len(is_prime[i*i:n:i])
                
        return sum(is_prime)

Complexity & Edge Cases

  • Time Complexity: {2, 3, 5}O(n \log \log n){2, 3, 5} by the Prime Number Theorem.
  • Space Complexity: {2, 3, 5}O(n){2, 3, 5} boolean array.
  • Edge Cases: {2, 3, 5}n = 0, 1, 2{2, 3, 5} (returns 0).
