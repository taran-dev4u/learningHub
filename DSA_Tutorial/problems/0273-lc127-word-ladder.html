📋 The problem

Given start and end words and a dictionary, return the length of the shortest sequence of one-letter changes (each intermediate word must be in the dictionary).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Graph BFS - Connected Components / Island Counting — BFS variant of the above — preferred when you also need shortest path or you want to avoid recursion depth.

💡 Key idea
BFS over words where neighbors differ by one letter; generate neighbors by mutating 26 letters per position.

Why this pattern?

  • "islands", "connected", "regions", "provinces" → component DFS/BFS
  • "minimum steps / moves / days to reach" → BFS
  • "prerequisites", "build order", "course schedule" → topological sort
  • states-and-moves puzzles (word ladder, locks) → BFS over implicit graph

# Topological sort (Kahn's)
indeg = defaultdict(int)
for u in graph:
    for v in graph[u]: indeg[v] += 1
q = deque([u for u in graph if indeg[u] == 0])
order = []
while q:
    u = q.popleft(); order.append(u)
    for v in graph[u]:
        indeg[v] -= 1
        if indeg[v] == 0: q.append(v)
# len(order) < number of nodes  ⇒  cycle exists
