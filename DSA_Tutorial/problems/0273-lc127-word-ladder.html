📋 The problem

Given start and end words and a dictionary, return the length of the shortest sequence of one-letter changes (each intermediate word must be in the dictionary).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

A transformation sequence from beginWord to endWord using a dictionary wordList is a sequence of words where every adjacent pair of words differs by exactly one letter, and every word in the sequence exists in wordList. Given beginWord, endWord, and wordList, return the number of words in the shortest transformation sequence from beginWord to endWord, or 0 if no such sequence exists.

🐢 Brute force first

Testing all pairs of words for 1-letter difference takes O(N^2 * L) to build an adjacency graph. When N = 5,000, N^2 = 25,000,000 operations.

💡 Key insight: Treat each word as a graph node. An edge exists between words that differ by 1 letter. To find the shortest path, use BFS! Instead of comparing word-to-word (O(N)), generate all 26 * L possible single-character mutations of the current word and check set membership in O(1)! Even faster: Bidirectional BFS, expanding from both beginWord and endWord simultaneously, reducing the search space from $b^d$ to $2 imes b^{d/2}$!

🪜 The approach, step by step

  1. Convert wordList into a hash set for O(1) lookups. If endWord not in wordList, return 0.
  2. Initialize two sets: begin_set = {beginWord}, end_set = {endWord}.
  3. step = 1.
  4. While begin_set and end_set are non-empty:
    • Always expand the smaller set to minimize branching factor: if len(begin_set) > len(end_set), swap them.
    • next_set = set().
    • For each word in begin_set:
    • Try all 26 character substitutions at each of the L positions.
    • If mutated word is in end_set: return step + 1 (search frontiers met!).
    • If mutated word in word_set: add to next_set, remove from word_set to prevent cycles.
    • begin_set = next_set; step += 1.
  5. Return 0.

🎞️ Visual dry run — beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]

  Expand "hit" -> "hot" (valid).
  next_set = {"hot"}. step = 2.

Step 2: begin_set = {"hot"} (len 1), end_set = {"cog"} (len 1).
  Expand "hot" -> "dot", "lot".
  next_set = {"dot", "lot"}. step = 3.

Step 3: Swap so begin_set = {"cog"} (len 1), end_set = {"dot", "lot"} (len 2).
  Expand "cog" -> "dog", "log".
  next_set = {"dog", "log"}. step = 4.

Step 4: Expand "dog" -> matches "dot" in end_set!
Frontiers meet! Return step + 1 = 4 + 1 = 5 words!

✅ The solution

def ladderLength(beginWord, endWord, wordList):
    word_set = set(wordList)
    if endWord not in word_set:
        return 0
        
    begin_set = {beginWord}
    end_set = {endWord}
    step = 1
    L = len(beginWord)
    
    while begin_set and end_set:
        # Always expand the smaller frontier
        if len(begin_set) > len(end_set):
            begin_set, end_set = end_set, begin_set
            
        next_set = set()
        for word in begin_set:
            word_chars = list(word)
            for i in range(L):
                orig_char = word_chars[i]
                for c in 'abcdefghijklmnopqrstuvwxyz':
                    if c == orig_char:
                        continue
                    word_chars[i] = c
                    mutated = ''.join(word_chars)
                    
                    if mutated in end_set:
                        return step + 1
                    if mutated in word_set:
                        next_set.add(mutated)
                        word_set.remove(mutated)  # Mark visited
                word_chars[i] = orig_char
                
        begin_set = next_set
        step += 1
        
    return 0

⏱️ Complexity

Time O(M * N * 26) = O(M * N) where M is length of words and N is total words in dictionary. Space O(N) for word sets.

⚠️ Edge cases

  • endWord not in wordList: returns 0 immediately.
  • No valid transformation path exists.
