📋 The problem

Return the shortest palindrome obtainable by adding characters in front of the given string.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given a string s. You can convert s to a palindrome by adding characters in front of it. Return the shortest palindrome you can find by performing this transformation.

To minimize characters added to the front, we must find the longest palindromic prefix of s! Once we find the longest palindromic prefix of length $L$, the remaining suffix $s[L:]$ reversed and prepended to $s$ forms the shortest palindrome: $$ ext{Result} = ext{reverse}(s[L:]) + s$$

The KMP Prefix Function Trick: Form a combined string $T = s + ext{"#"} + ext{reverse}(s)$. The value of $LPS[-1]$ (longest prefix of $T$ that is also suffix) is exactly the length of the longest palindromic prefix of $s$!

🐢 Brute force vs optimal

Checking palindromes from $n$ down to 1 takes $O(n^2)$. KMP LPS table computes the longest palindromic prefix in $O(n)$ linear time!

💡 Key insight: Build $T = s + ext{'#'} + ext{reverse}(s)$. Run KMP failure function. $l = LPS[-1]$ is the longest palindromic prefix! Prepend $s[l:][::-1]$.

✅ The solution

def shortestPalindrome(s: str) -> str:
    if not s:
        return ""
        
    rev_s = s[::-1]
    temp = s + "#" + rev_s
    
    # Compute KMP LPS table
    lps = [0] * len(temp)
    prev = 0
    i = 1
    while i < len(temp):
        if temp[i] == temp[prev]:
            prev += 1
            lps[i] = prev
            i += 1
        elif prev > 0:
            prev = lps[prev - 1]
        else:
            lps[i] = 0
            i += 1
            
    # Length of longest palindromic prefix in s
    pal_len = lps[-1]
    
    # Suffix not included in palindrome must be reversed and prepended
    add_on = rev_s[:len(s) - pal_len]
    return add_on + s

Complexity

Time: $O(n)$ — Linear KMP LPS computation on string of length $2n + 1$.
Space: $O(n)$ — LPS array and concatenated string.
