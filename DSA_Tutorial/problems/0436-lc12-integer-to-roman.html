#12 Integer to Roman MediumLeetCode

📋 The problem

Convert an integer (1 to 3999) into its Roman numeral representation.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Seven different symbols represent Roman numerals. Given an integer num, convert it to a Roman numeral.

We greedily subtract the largest possible Roman symbol value! To handle the subtraction cases (like 4 = IV, 9 = IX, 40 = XL, 900 = CM), we simply treat those six subtraction combinations as their own distinct denominations in our lookup table!

🐢 Brute force vs optimal

Greedy subtraction from 1000 down to 1. Because integers are bounded ($1 \le num \le 3999$), loop runs at most 13 steps.

💡 Key insight: Ordered denominations list including subtraction pairs: [(1000, "M"), (900, "CM"), (500, "D"), (400, "CD"), (100, "C"), (90, "XC"), (50, "L"), (40, "XL"), (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I")]. Greedily append!

✅ The solution

Reveal the commented solution (attempt it first!) 
def intToRoman(num: int) -> str:
    denominations = [
        (1000, "M"), (900, "CM"), (500, "D"), (400, "CD"),
        (100, "C"), (90, "XC"), (50, "L"), (40, "XL"),
        (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I")
    ]
    res = []
    for val, sym in denominations:
        if num == 0:
            break
        count, num = divmod(num, val)
        res.append(sym * count)
        
    return "".join(res)

Complexity

Time: $O(1)$ — Finite number of denominations (at most 13 operations).
Space: $O(1)$ — Constant output string buffer.
