📋 The problem

Return the length of the longest subarray with an equal number of 0s and 1s.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a binary array nums, return the maximum length of a contiguous subarray with an equal number of 0 and 1.

Transform 0 to -1 Trick: If we treat 0 as -1 and 1 as +1: An equal number of 0s and 1s means the transformed subarray sums to 0! This reduces directly to LC 325 (Maximum Size Subarray Sum Equals 0)! Maintain first_seen[sum] -> index with base case first_seen[0] = -1.

🐢 Brute force vs optimal

Counting 0s and 1s across all subarrays takes $O(n^2)$. Prefix transformation solves it in $O(n)$ time and $O(n)$ space.

💡 Key insight: Replace 0 with -1: count += 1 if x == 1 else -1. If count was seen before at index $j$, subarray from $j+1$ to $i$ has equal 0s and 1s!

✅ The solution

Reveal the commented solution (attempt it first!) 
def findMaxLength(nums: list[int]) -> int:
    first_seen = {0: -1}
    curr_sum = 0
    max_len = 0
    
    for i, x in enumerate(nums):
        curr_sum += 1 if x == 1 else -1
        if curr_sum in first_seen:
            max_len = max(max_len, i - first_seen[curr_sum])
        else:
            first_seen[curr_sum] = i
            
    return max_len

Complexity

Time: $O(n)$ — Linear pass over array.
Space: $O(n)$ — Hash map storing running balance.
