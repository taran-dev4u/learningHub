#35 Search Insert Position EasyLeetCode

 

Pattern: Binary Search Patterns › Subpattern 8.1: On Sorted Array/List · Problem 233 of 699

📋 The problem

Given a sorted array and a target, return the index where the target is found or where it would be inserted to keep order.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a sorted array of distinct integers and a target value, return the index if the target is found. If not, return the index where it would be if it were inserted in order. The requirement is an algorithm with O(log n) runtime complexity.

🐢 Brute force first

Linear scan until finding an element >= target. Return that index, or n if target is greater than all elements. Time: O(n).

💡 Key insight: This is finding the lower bound (first element >= target). When the standard binary search terminates with left > right, left is exactly the insertion point where the target belongs!

🪜 The approach, step by step

  1. Initialize left = 0, right = len(nums) - 1.
  2. While left <= right:
  3. Compute mid = left + (right - left) // 2.
  4. If nums[mid] == target, target already exists, return mid.
  5. If nums[mid] < target, target belongs to the right, so left = mid + 1.
  6. Else, target belongs to the left or at mid, so right = mid - 1.
  7. When the loop exits, left points precisely to the correct insertion position. Return left.

🎞️ Visual dry run — nums = [1, 3, 5, 6], target = 2

Initial: left = 0, right = 3
Iter 1: mid = 1, nums[1] = 3 > 2 → right = mid - 1 = 0
Iter 2: left = 0, right = 0
        mid = 0, nums[0] = 1 < 2 → left = mid + 1 = 1
Loop ends because left (1) > right (0).
Return left = 1.
Insert 2 at index 1 → [1, 2, 3, 5, 6] (sorted!). ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
def searchInsert(nums, target):
    """
    Binary search lower bound: finds first index with nums[i] >= target.
    """
    left, right = 0, len(nums) - 1
    
    while left <= right:
        mid = left + (right - left) // 2
        
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
            
    # When loop ends, left points to insertion index
    return left

⏱️ Complexity

Time O(log n) — Binary search divides search space by 2 each step. Space O(1) — In-place pointer manipulation.

⚠️ Edge cases

  • Target smaller than nums[0]: left ends at 0.
  • Target greater than nums[-1]: left ends at len(nums).
  • Single element array matching target or not matching.
