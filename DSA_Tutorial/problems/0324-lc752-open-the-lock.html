📋 The problem

A 4-wheel lock starts at 0000; each move turns one wheel one notch, avoiding dead-end codes; return the fewest moves to the target.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You have a 4-wheel lock starting at "0000". Each wheel has digits '0' through '9' and can rotate forward (9 → 0) or backward (0 → 9). You are given a list of deadends: if the lock displays any deadend combination, the wheels lock and you cannot turn them anymore. Return the minimum number of total turns required to reach target, or -1 if impossible.

Every combination is a vertex in an unweighted graph. Each combination has 8 neighbors (4 wheels × 2 rotation directions). Since each move has unit cost 1, the shortest path from "0000" to target is solved using Breadth-First Search (BFS).

🐢 Brute force vs optimal

Standard BFS explores level by level. To make it blaze fast, Bidirectional BFS searches from both "0000" and target simultaneously, meeting in the middle!

💡 Key insight: Bidirectional BFS reduces branching volume. If search tree has branching factor b = 8 and depth d, single-ended BFS explores O(bd) states, whereas bidirectional BFS explores 2 × O(bd/2) states—a massive speedup! Always expand the smaller frontier set at each step.

🪜 The approach, step by step

  1. Deadend check: if "0000" in deadends or target in deadends, return -1 immediately.
  2. Initialize two frontier sets: begin_set = {"0000"} and end_set = {target}.
  3. Initialize visited = set(deadends) and turns = 0.
  4. While begin_set and end_set:
    • Always expand the smaller set: if len(begin_set) > len(end_set), swap them.
    • Create next_level = set().
    • For each code in begin_set:
      • For each digit position i ∈ [0, 3]:
        • Try turning forward ((d + 1) % 10) and backward ((d - 1) % 10).
        • If neighbor in end_set: return turns + 1 (the two frontiers met!).
        • If neighbor not in visited: add to visited and next_level.
    • begin_set = next_level, turns += 1.
  5. Return -1.

✅ The solution

Python 3 — Bidirectional BFS 
def openLock(deadends: list[str], target: str) -> int:
    """
    Finds minimum turns to open lock avoiding deadends using Bidirectional BFS.
    """
    dead_set = set(deadends)
    if "0000" in dead_set or target in dead_set:
        return -1
    if target == "0000":
        return 0
        
    begin_set = {"0000"}
    end_set = {target}
    visited = set(deadends)
    visited.add("0000")
    visited.add(target)
    turns = 0
    
    while begin_set and end_set:
        # Always expand the smaller frontier set
        if len(begin_set) > len(end_set):
            begin_set, end_set = end_set, begin_set
            
        next_level = set()
        for code in begin_set:
            for i in range(4):
                digit = int(code[i])
                # Generate 2 turns: +1 and -1
                for diff in (-1, 1):
                    new_digit = (digit + diff) % 10
                    neighbor = code[:i] + str(new_digit) + code[i+1:]
                    
                    if neighbor in end_set:
                        return turns + 1
                    if neighbor not in visited:
                        visited.add(neighbor)
                        next_level.add(neighbor)
                        
        turns += 1
        begin_set = next_level
        
    return -1

⚡ Complexity analysis

  • Time Complexity: O(8 × 104) = O(1). The state space is bounded by 10,000 combinations (0000 to 9999), and each state has 8 transitions.
  • Space Complexity: O(104) = O(1) for sets and visited storage.

🚨 Edge cases to watch out for

  • "0000" is in deadends: Returns -1.
  • target == "0000": Returns 0 immediately.
