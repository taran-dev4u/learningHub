#1277 Count Square Submatrices with All Ones MediumLeetCode

 

Pattern: Dynamic Programming (DP) Patterns › Subpattern 12.8: 2D Array / Unique Paths on Grid · Problem 411 of 699

📋 The problem

Count the square submatrices of all 1s in a binary matrix (DP: largest square ending at each cell, summed).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a m * n matrix of ones and zeros, return how many square submatrices have all ones.

Recall Maximal Square (LC 221): if $dp[i][j] = k$, it means the largest square ending at $(i, j)$ has side length $k$. That automatically implies there are squares of side length $1, 2, \dots, k$ all sharing $(i, j)$ as their bottom-right corner! Therefore, the number of square submatrices with bottom-right corner at $(i, j)$ is exactly $dp[i][j]$!

$$\text{Total Squares} = \sum_{i, j} dp[i][j]$$

🐢 Brute force vs optimal

Iterating all submatrices takes $O(m \cdot n \cdot \min(m, n))$. With DP, each cell is $O(1)$, so total time is $O(m \cdot n)$!

💡 Key insight: dp[i][j] is both the maximum side length AND the exact count of squares whose bottom-right corner is at $(i, j)$. Simply sum all dp[i][j]!

✅ The solution

Reveal the commented solution (attempt it first!) 
def countSquares(matrix: list[list[int]]) -> int:
    m, n = len(matrix), len(matrix[0])
    total = 0
    
    for r in range(m):
        for c in range(n):
            if matrix[r][c] == 1:
                if r > 0 and c > 0:
                    matrix[r][c] = 1 + min(matrix[r - 1][c], matrix[r][c - 1], matrix[r - 1][c - 1])
                total += matrix[r][c]
                
    return total

Complexity

Time: $O(m \times n)$ — Single pass in place.
Space: $O(1)$ — Modified in place (or $O(n)$ if matrix immutable).
