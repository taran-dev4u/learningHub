📋 The problem

Design a structure that adds points and counts axis-aligned squares completable with a query point (dict of point counts, iterate diagonal partners).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Implement the DetectSquares class to add 2D points from a stream and count the number of ways to choose three existing points that, together with a query point, form an axis-aligned square with positive area.

Key Insights

An axis-aligned square has four vertices: query point {2, 3, 5}(qx, qy){2, 3, 5}, diagonal point {2, 3, 5}(x, y){2, 3, 5}, and two anti-diagonal points {2, 3, 5}(qx, y){2, 3, 5} and {2, 3, 5}(x, qy){2, 3, 5}. A point {2, 3, 5}(x, y){2, 3, 5} can form a square with {2, 3, 5}(qx, qy){2, 3, 5} if and only if: {2, 3, 5}{2, 3, 5}|x - qx| == |y - qy| > 0{2, 3, 5}{2, 3, 5} Once a valid diagonal point {2, 3, 5}(x, y){2, 3, 5} is found, the number of valid squares formed is: {2, 3, 5}{2, 3, 5} ext{count}(x, y) imes ext{count}(qx, y) imes ext{count}(x, qy){2, 3, 5}{2, 3, 5} We store point frequencies in a hash map point_counts[(x, y)] and iterate over distinct points.

from typing import List
from collections import defaultdict

class DetectSquares:
    def __init__(self):
        self.pts = defaultdict(int)

    def add(self, point: List[int]) -> None:
        self.pts[tuple(point)] += 1

    def count(self, point: List[int]) -> int:
        qx, qy = point
        total = 0
        
        # Iterate over all registered points as candidate diagonal points
        for (x, y), count_diag in self.pts.items():
            dx = abs(x - qx)
            dy = abs(y - qy)
            if dx > 0 and dx == dy:
                # Valid square diagonal candidate
                c1 = self.pts.get((qx, y), 0)
                c2 = self.pts.get((x, qy), 0)
                total += count_diag * c1 * c2
                
        return total

Complexity & Edge Cases

  • Time Complexity: add is {2, 3, 5}O(1){2, 3, 5}; count is {2, 3, 5}O(P){2, 3, 5} where {2, 3, 5}P{2, 3, 5} is the number of distinct points added.
  • Space Complexity: {2, 3, 5}O(P){2, 3, 5} hash map entries.
  • Edge Cases: Duplicate points at same coordinate (handled by multiplicative counting), points with same coordinate as query point ({2, 3, 5}dx = 0{2, 3, 5}, ignored).
