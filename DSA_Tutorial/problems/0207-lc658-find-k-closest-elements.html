📋 The problem

Return the k elements of a sorted array closest to x, in ascending order.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a sorted integer array arr, find the k closest integers to x. Closeness is determined by |a - x| < |b - x| (tiebreaker: smaller value). Since arr is sorted, the k closest elements form a contiguous subarray. We can use a max-heap of size k, or binary search for the left boundary of the window.

🐢 Brute force first

Compute |num - x| for all numbers, sort by distance, slice first k, sort again → O(n log n).

💡 Key insight: the k closest elements in a sorted array must be a contiguous subarray arr[left:left+k]. Binary search for the starting index left between 0 and len(arr) - k by comparing distances at x - arr[mid] and arr[mid + k] - x.

🪜 The approach, step by step

  1. Binary search range: low = 0, high = len(arr) - k.
  2. While low < high:
  3. mid = (low + high) // 2.
  4. If x - arr[mid] > arr[mid + k] - x, arr[mid + k] is closer than arr[mid], so search right: low = mid + 1.
  5. Else, arr[mid] is closer or tied, so search left: high = mid.
  6. Return arr[low:low + k].

🎞️ Visual dry run — arr = [1, 2, 3, 4, 5], k = 4, x = 3

Search range: low = 0, high = 5 - 4 = 1
mid = 0: compare x - arr[0] (3 - 1 = 2) vs arr[0 + 4] - x (5 - 3 = 2)
Distances equal (2 == 2) → tiebreaker prefers smaller value (left side) → high = 0
Exit loop: low = 0
Slice arr[0:4] = [1, 2, 3, 4] ✓

✅ The solution

def findClosestElements(arr, k, x):
    # Binary search for the left boundary of the k-length window
    low, high = 0, len(arr) - k
    
    while low < high:
        mid = (low + high) // 2
        # Compare distance of candidate left element vs candidate element right after the window
        if x - arr[mid] > arr[mid + k] - x:
            low = mid + 1    # right side is strictly closer
        else:
            high = mid       # left side is closer or tied
            
    return arr[low:low + k]

⏱️ Complexity

Time O(log(n - k) + k) — binary search takes O(log(n - k)) and slicing takes O(k). Space O(1) extra space.

⚠️ Edge cases

  • x <= arr[0]: returns the first k elements.
  • x >= arr[-1]: returns the last k elements.
  • k == len(arr): returns the entire array.
