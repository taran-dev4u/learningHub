📋 The problem

Meetings queue for n rooms, taking the lowest free room (or waiting for the earliest); return the room that hosts the most meetings (two heaps).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

You are given an integer $n$ (rooms numbered $0$ to $n - 1$) and a 2D integer array meetings. Meetings are allocated to the lowest numbered unused room. If all rooms are busy, the meeting is delayed until a room becomes free. Return the number of the room that held the most meetings.

Key Insights

Two Priority Queues:

  1. available_rooms: Min-heap storing available room IDs (lowest ID on top). Initially contains $0, 1, \dots, n - 1$.
  2. busy_rooms: Min-heap storing tuples (end_time, room_id).
Sort meetings by start time. For each meeting $(start, end)$:
  1. Free any rooms whose end_time <= start, returning them to available_rooms.
  2. If an available room exists, pop lowest room ID, assign meeting until $end$.
  3. If all rooms are busy, pop room with earliest end_time: The meeting starts at that room's free_time and runs for $duration = end - start$. Push back to busy_rooms with new end time free_time + duration.

Python 3 Solution (Double Min-Heap Simulation) 
from typing import List
import heapq

class Solution:
    def mostBooked(self, n: int, meetings: List[List[int]]) -> int:
        meetings.sort(key=lambda x: x[0])
        
        available = list(range(n))
        heapq.heapify(available)
        busy = []  # (end_time, room_id)
        
        room_counts = [0] * n
        
        for start, end in meetings:
            duration = end - start
            # Free rooms
            while busy and busy[0][0] <= start:
                _, room = heapq.heappop(busy)
                heapq.heappush(available, room)
                
            if available:
                room = heapq.heappop(available)
                heapq.heappush(busy, (end, room))
            else:
                earliest_end, room = heapq.heappop(busy)
                heapq.heappush(busy, (earliest_end + duration, room))
                
            room_counts[room] += 1
            
        max_meetings = max(room_counts)
        return room_counts.index(max_meetings)

Complexity & Edge Cases

  • Time Complexity: $O(M \log M + M \log n)$ where $M$ is number of meetings.
  • Space Complexity: $O(n)$ for room heaps.
