📋 The problem

Given an expression of numbers and operators, return every result obtainable by fully parenthesizing it differently.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Catalan Numbers — Sum dp[k]·dp[n-1-k] for k = 0..n-1 — counts binary trees, parenthesizations, polygon triangulations.

Why this pattern?

  • "count the number of ways…"
  • "minimum/maximum cost/value to reach…"
  • choices at each step + overlapping futures (take/skip an item)
  • "longest/shortest subsequence" (non-contiguous!)
