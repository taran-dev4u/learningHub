📋 The problem

Design a calendar where book() returns the maximum overlap count (k-booking) after adding each event.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

A $k$-booking happens when $k$ events have some non-empty intersection. Implement MyCalendarThree which returns the largest integer $k$ such that there exists a $k$-booking in the calendar.

Line Sweep with Coordinate Delta Map: Use a sorted difference map (or dictionary of boundary points): - When an event starts at $start$: increment active events: delta[start] += 1. - When an event ends at $end$: decrement active events: delta[end] -= 1.

To find the maximum concurrent overlapping events: Iterate through all boundary timestamps in sorted order, maintaining a running sum: $$ ext{curr\_active} += ext{delta}[t]$$ $$ ext{max\_k} = \max( ext{max\_k}, \; ext{curr\_active})$$

🐢 Brute force vs optimal

Sorted coordinate delta map computes the global maximum overlap in $O(N)$ per booking.

💡 Key insight: Line sweep: delta[start] += 1; delta[end] -= 1. Sweep through sorted timestamps accumulating active events; track global max!

✅ The solution

Reveal the commented solution (attempt it first!) 
from collections import defaultdict

class MyCalendarThree:
    def __init__(self):
        self.delta = defaultdict(int)

    def book(self, startTime: int, endTime: int) -> int:
        self.delta[startTime] += 1
        self.delta[endTime] -= 1
        
        curr_active = 0
        max_k = 0
        for t in sorted(self.delta.keys()):
            curr_active += self.delta[t]
            if curr_active > max_k:
                max_k = curr_active
                
        return max_k

Complexity

Time: $O(N \log N)$ per booking to sort unique timestamps.
Space: $O(N)$ — Timestamp dictionary.
