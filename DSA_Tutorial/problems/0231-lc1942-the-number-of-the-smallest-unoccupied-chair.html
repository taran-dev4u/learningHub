📋 The problem

Friends arrive/leave; each takes the smallest free chair — return the chair number the targetFriend gets (two heaps over events).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Scheduling / Minimum Cost with Priority Queue — Heap selects the highest-cost/highest-priority task at each step — task scheduling, IPO, sticks.

Why this pattern?

  • "k largest / k closest / k most frequent / k-th …"
  • merge k sorted lists/streams
  • "median of a stream" / balance two halves → two heaps
  • scheduling: always take the earliest end / most frequent / cheapest next

# Top-k largest: min-heap of size k
h = []
for x in nums:
    heapq.heappush(h, x)
    if len(h) > k:
        heapq.heappop(h)                 # evict the smallest of the k+1
