#1942 The Number of the Smallest Unoccupied Chair MediumLeetCode

 

Pattern: Heap (Priority Queue) Patterns › Subpattern 7.4: Scheduling / Minimum Cost with Priority Queue · Problem 231 of 699

📋 The problem

Friends arrive/leave; each takes the smallest free chair — return the chair number the targetFriend gets (two heaps over events).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Friends arrive and leave at distinct times [arrival, leaving]. When a friend arrives, they sit in the smallest unoccupied chair (chairs numbered 0, 1, 2...). Find which chair targetFriend sits on. We need to track available chairs (min-heap) and busy friends (min-heap by leaving time).

🐢 Brute force first

Simulate each second, linear scan for empty chair → O(max_time * n).

💡 Key insight: tag each friend with their index: (arr, leave, i) and sort by arrival time. Use two min-heaps: free_chairs (chair numbers 0..n-1) and busy (leaving_time, chair). When friend arrives, free all chairs of friends who left, and take the smallest available chair.

🪜 The approach, step by step

  1. Tag friends with indices and sort by arrival: events = sorted([(times[i][0], times[i][1], i) for i in range(len(times))]).
  2. Initialize free_chairs = list(range(len(times))) and heapify.
  3. Initialize busy = [] (min-heap of (leaving_time, chair)).
  4. For each arr, leave, idx:
  5. While busy and busy[0][0] <= arr: pop (_, chair) and push chair to free_chairs.
  6. Pop smallest chair = heappop(free_chairs).
  7. If idx == targetFriend: return chair.
  8. Push (leave, chair) to busy.

✅ The solution

import heapq

def smallestChair(times, targetFriend):
    target_arrival = times[targetFriend][0]
    # Sort friends by arrival time
    events = sorted([(arr, leave, i) for i, (arr, leave) in enumerate(times)])
    
    free_chairs = list(range(len(times)))
    heapq.heapify(free_chairs)
    
    busy = []   # (leaving_time, chair)
    
    for arr, leave, i in events:
        # Free chairs of friends who have departed
        while busy and busy[0][0] <= arr:
            _, chair = heapq.heappop(busy)
            heapq.heappush(free_chairs, chair)
            
        chair = heapq.heappop(free_chairs)
        if i == targetFriend:
            return chair
            
        heapq.heappush(busy, (leave, chair))
        
    return -1

⏱️ Complexity

Time O(n log n) — sorting events takes O(n log n); each friend performs O(log n) heap operations. Space O(n) for the heaps.

⚠️ Edge cases

  • Target friend is the first to arrive: returns chair 0.
  • Departure and arrival at the same time: departure happens first, so the chair is immediately available for the arriving friend.
