📋 The problem

Classify each MST edge as critical (in every MST) or pseudo-critical (in some MST) — Kruskal with forced inclusion/exclusion.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Graph - Minimum Spanning Tree — Kruskal (sort edges + Union-Find) or Prim (heap-based expansion) for minimum spanning tree.

Why this pattern?

  • "islands", "connected", "regions", "provinces" → component DFS/BFS
  • "minimum steps / moves / days to reach" → BFS
  • "prerequisites", "build order", "course schedule" → topological sort
  • states-and-moves puzzles (word ladder, locks) → BFS over implicit graph

# Topological sort (Kahn's)
indeg = defaultdict(int)
for u in graph:
    for v in graph[u]: indeg[v] += 1
q = deque([u for u in graph if indeg[u] == 0])
order = []
while q:
    u = q.popleft(); order.append(u)
    for v in graph[u]:
        indeg[v] -= 1
        if indeg[v] == 0: q.append(v)
# len(order) < number of nodes  ⇒  cycle exists
