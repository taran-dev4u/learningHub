📋 The problem

Reorder string s so its characters follow the relative order given by string 'order' (unlisted chars anywhere).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given two strings order and s. All the characters of order are unique and were sorted in some custom order previously. Permute the characters of s so that they match the order that order was sorted.

Count frequencies of all characters in $s$ using a frequency map / Counter. 1. Iterate through characters $c$ in order in their specified sequence. If $c \in s$, append $c \times count[c]$ to result and delete from map. 2. Append all remaining characters not mentioned in order at the end (their order does not matter!).

🐢 Brute force vs optimal

Custom sorting with comparator takes $O(n \log n)$. Frequency counting (bucket sort) runs in $O(|order| + |s|)$ linear time with $O(1)$ space (26 lowercase letters).

💡 Key insight: Bucket sort: count frequencies in $s$. Append characters in sequence of order, then dump remaining unlisted characters. Runs in $O(n)$ time!

✅ The solution

from collections import Counter

def customSortString(order: str, s: str) -> str:
    counts = Counter(s)
    res = []
    
    # 1. Append characters in custom order
    for ch in order:
        if ch in counts:
            res.append(ch * counts[ch])
            del counts[ch]
            
    # 2. Append all remaining characters
    for ch, count in counts.items():
        res.append(ch * count)
        
    return "".join(res)

Complexity

Time: $O(|order| + |s|)$ — Linear traversal.
Space: $O(1)$ — 26 lowercase English letters frequency map.
