📋 The problem

Group a list of words so that words that are anagrams of each other end up in the same group.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an array of strings strs, group the anagrams together in any order. An anagram is a word formed by rearranging the letters of a different word, using all the original letters exactly once.

Key Insights

Two strings are anagrams if and only if their sorted versions are identical, or equivalently, their character frequency counts across the 26 lowercase English letters are identical. We can use a hash map where the key is the canonical representation of an anagram class and the value is a list of strings belonging to that class.

Sorted String as Key$O(N \cdot K \log K)$$O(N \cdot K)$Simple to write; slower for long words.

Step-by-Step Algorithm (Optimal 26-Count Tuple)

  1. Initialize groups = collections.defaultdict(list).
  2. For each word in strs:
    • Initialize a count array of size 26 with zeros.
    • For each character $c$ in the word, increment count[ord(c) - ord('a')].
    • Convert the mutable list count into an immutable tuple tuple(count) to use as a hashable dictionary key.
    • Append the original word to groups[tuple(count)].
  3. Return list(groups.values()).

from typing import List
from collections import defaultdict

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = defaultdict(list)
        
        for s in strs:
            count = [0] * 26
            for ch in s:
                count[ord(ch) - ord('a')] += 1
            # Tuples are hashable in Python
            groups[tuple(count)].append(s)
            
        return list(groups.values())

Complexity & Edge Cases

  • Time Complexity: $O(N \cdot K)$ where $N$ is the number of strings and $K$ is the maximum length of a string. Counting frequencies takes $O(K)$, and hashing a 26-element tuple is $O(26) = O(1)$.
  • Space Complexity: $O(N \cdot K)$ to store the grouped strings in the hash map.
  • Edge Cases: Single character words, empty strings [""], words with identical letters (e.g. "aaaa").
