📋 The problem

A signal starts at node k in a weighted directed graph; return the time for all nodes to receive it (-1 if some never do).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You have a network of n nodes labeled 1 to n, and a list of directed edges times[i] = (u, v, w) where w is the signal travel time from u to v. A signal is sent from source node k. Return the minimum time for all nodes to receive the signal. If it is impossible for all nodes to receive it, return -1.

Because all edge weights are non-negative (w ≥ 0), this is the classic Single-Source Shortest Path (SSSP) problem, solved optimally by Dijkstra's Algorithm. Once we find the shortest travel time from k to every node, the network delay is simply the maximum time among all reached nodes (since signals propagate concurrently).

🐢 Brute force vs optimal

Bellman-Ford relaxes all edges V - 1 times, taking O(V × E). Floyd-Warshall computes all-pairs in O(V3). Dijkstra with a min-priority queue computes the optimal distances in O((V + E) log V), which is standard for interview graphs.

💡 Key insight: Dijkstra greedily processes nodes in increasing order of their accumulated distance from source k. Because all weights are non-negative, once a node is popped from the min-heap, its shortest distance is finalized and will never be improved. When the min-heap empties, if we have visited all n nodes, the answer is max(distances.values()); otherwise some node was unreachable, so return -1.

🪜 The approach, step by step

  1. Build graph adjacency list: graph = defaultdict(list) mapping u → (v, w).
  2. Initialize Dijkstra state:
    • Min-heap pq = [(0, k)] storing pairs of (distance_so_far, node).
    • Visited/shortest distance hash map dist = {}.
  3. Extract-min loop:
    • Pop (d, u) from pq.
    • If u is already in dist, skip it (a stale, longer path was pushed earlier).
    • Record dist[u] = d.
    • If len(dist) == n, we can stop early—all nodes have their shortest paths!
    • For each outgoing neighbor (v, weight) of u: if v not in dist, push (d + weight, v) into pq.
  4. Evaluate result: If len(dist) == n, return max(dist.values()); otherwise return -1.

✅ The solution

Python 3 — Clean Dijkstra with Min-Heap 
import heapq
from collections import defaultdict

def networkDelayTime(times: list[list[int]], n: int, k: int) -> int:
    """
    Finds maximum time for signal to reach all n nodes from source k using Dijkstra's Algorithm.
    """
    # 1. Build adjacency list: u -> list of (v, weight)
    graph = defaultdict(list)
    for u, v, w in times:
        graph[u].append((v, w))
        
    # 2. Priority queue: stores (distance, node). Start at k with dist 0.
    pq = [(0, k)]
    dist = {}
    
    # 3. Dijkstra relaxation loop
    while pq:
        d, u = heapq.heappop(pq)
        
        # If node u already finalized, ignore duplicate queue entry
        if u in dist:
            continue
            
        dist[u] = d
        if len(dist) == n:
            break
            
        for v, weight in graph[u]:
            if v not in dist:
                heapq.heappush(pq, (d + weight, v))
                
    # 4. Check if all n nodes received the signal
    return max(dist.values()) if len(dist) == n else -1

⚡ Complexity analysis

  • Time Complexity: O(E log V). In the worst case, every directed edge is pushed into the priority queue once. Inserting into and extracting from a binary heap of size up to E takes O(log E) = O(log V) time.
  • Space Complexity: O(V + E) to store the adjacency list graph and up to O(E) elements in the priority queue.

🚨 Edge cases to watch out for

  • Unreachable nodes / Disconnected graph: If a component has no incoming edges from k, len(dist) < n; must return -1.
  • Graph with cycles: The if u in dist: continue check prevents infinite loops in cyclic graphs.
  • Single node graph (n=1): Loop pops source, len(dist) == 1 == n, returns 0 immediately.

🧗 Follow-ups & variations

  • Path with Maximum Probability (#1514): Negate probabilities or use max-heap with multiplicative weights.
  • Cheapest Flights Within K Stops (#787): Constrained shortest paths where edge count is bounded; use Bellman-Ford or BFS with step tracking.
