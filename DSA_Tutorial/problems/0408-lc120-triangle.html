📋 The problem

Given a triangle of numbers, find the minimum path sum from top to bottom, moving to an adjacent index each row down.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a triangle array, return the minimum path sum from top to bottom. For each step, you may move to an adjacent number on the row below (i.e. from index i on current row to index i or i + 1 on the next row).

Top-down DP requires handling boundary conditions. Bottom-up DP starting from the base of the triangle is vastly cleaner and eliminates all edge cases!

$$dp[j] = \text{triangle}[r][j] + \min(dp[j], \; dp[j + 1])$$

🐢 Brute force vs optimal

Starting from the bottom row, collapse upwards row by row. At the top, dp[0] contains the global minimum path sum!

💡 Key insight: Initialize dp = triangle[-1][:]. Iterate from row $n-2$ down to 0, updating dp[c] = triangle[r][c] + min(dp[c], dp[c + 1]).

✅ The solution

Reveal the commented solution (attempt it first!) 
def minimumTotal(triangle: list[list[int]]) -> int:
    dp = triangle[-1][:]
    
    for r in range(len(triangle) - 2, -1, -1):
        for c in range(len(triangle[r])):
            dp[c] = triangle[r][c] + min(dp[c], dp[c + 1])
            
    return dp[0]

Complexity

Time: $O(N)$ where $N$ is total number of cells in triangle ($n(n+1)/2$).
Space: $O(n)$ — 1D buffer the length of the bottom row.
