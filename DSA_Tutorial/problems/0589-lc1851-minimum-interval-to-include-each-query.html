📋 The problem

For each query point, return the length of the smallest interval containing it (-1 if none) — offline sort + heap.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given a 2D integer array intervals and an integer array queries, the size of interval $[l, r]$ is $r - l + 1$. For each query $q_j$, find the minimum size of an interval such that $l_i \le q_j \le r_i$. If no such interval exists, return -1.

Key Insights

Offline Queries + Min-Heap: Sort intervals by start time. Sort queries in ascending order while keeping their original indices: sorted_q = sorted(enumerate(queries), key=lambda x: x[1]). For each query $q$:

  1. Push all intervals with $start \le q$ into a min-heap ordered by interval size $(r - l + 1, r)$.
  2. Pop any intervals from heap top whose $r < q$ (they cannot cover $q$ or any future larger query).
  3. The top of the heap is the minimum size interval covering $q$!

Python 3 Solution (Offline Sorting + Min-Heap) 
from typing import List
import heapq

class Solution:
    def minInterval(self, intervals: List[List[int]], queries: List[int]) -> List[int]:
        intervals.sort(key=lambda x: x[0])
        q_sorted = sorted(enumerate(queries), key=lambda x: x[1])
        
        heap = []  # (size, right)
        ans = [-1] * len(queries)
        i = 0
        n = len(intervals)
        
        for orig_idx, q in q_sorted:
            # Add all intervals that start <= q
            while i < n and intervals[i][0] <= q:
                l, r = intervals[i]
                heapq.heappush(heap, (r - l + 1, r))
                i += 1
                
            # Discard intervals that end < q
            while heap and heap[0][1] < q:
                heapq.heappop(heap)
                
            if heap:
                ans[orig_idx] = heap[0][0]
                
        return ans

Complexity & Edge Cases

  • Time Complexity: $O(N \log N + Q \log Q)$. Each interval is pushed and popped at most once.
  • Space Complexity: $O(N + Q)$.
