📋 The problem

Design a calendar that allows double bookings but rejects any event causing a triple booking.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Implement the MyCalendarTwo class such that no triple booking happens (three events have some non-empty intersection).

Key Insights

Maintain two lists:

  1. bookings: All successfully booked single events $[s, e)$.
  2. overlaps: All double-booked interval segments $[\max(s_1, s_2), \min(e_1, e_2))$.
When trying to book a new interval $[start, end)$:
  1. Check if $[start, end)$ overlaps with ANY interval in overlaps. If yes, it would cause a triple booking! Return False immediately.
  2. Otherwise, find all overlaps between $[start, end)$ and existing bookings, adding them to overlaps.
  3. Add $[start, end)$ to bookings and return True!

Python 3 Solution (Double Booking Tracker) 
class MyCalendarTwo:
    def __init__(self):
        self.bookings = []
        self.overlaps = []

    def book(self, start: int, end: int) -> bool:
        # 1. Check if it causes triple booking
        for s, e in self.overlaps:
            if max(start, s) < min(end, e):
                return False
                
        # 2. Record new double-booked overlaps
        for s, e in self.bookings:
            os = max(start, s)
            oe = min(end, e)
            if os < oe:
                self.overlaps.append((os, oe))
                
        self.bookings.append((start, end))
        return True

Complexity & Edge Cases

  • Time Complexity: $O(N)$ per booking call.
  • Space Complexity: $O(N)$ intervals stored.
