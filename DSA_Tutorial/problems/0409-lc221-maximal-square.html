📋 The problem

In a binary matrix, find the area of the largest square containing only 1s.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an m x n binary matrix filled with '0's and '1's, find the largest square containing only '1's and return its area.

Let $dp[i][j]$ be the side length of the largest square whose bottom-right corner is at $(i, j)$. If matrix[i][j] == '1', $(i, j)$ can extend a square only if its top, left, and top-left diagonal neighbors can also form squares: $$dp[i][j] = 1 + \min(dp[i - 1][j], \; dp[i][j - 1], \; dp[i - 1][j - 1])$$ If matrix[i][j] == '0', $dp[i][j] = 0$.

🐢 Brute force vs optimal

Checking every possible square of size $k \times k$ takes $O(m \times n \times \min(m, n)^2)$ which is $O((m \cdot n)^2)$. DP reduces this to a single pass $O(m \cdot n)$ with $O(n)$ space.

💡 Key insight: The bottom-right corner of a square of size $k$ requires size $k-1$ from top, left, and top-left diagonal simultaneously.

✅ The solution

def maximalSquare(matrix: list[list[str]]) -> int:
    if not matrix:
        return 0
    m, n = len(matrix), len(matrix[0])
    dp = [0] * (n + 1)
    max_side = 0
    prev_diag = 0
    
    for r in range(m):
        prev_diag = 0
        for c in range(n):
            temp = dp[c + 1]
            if matrix[r][c] == '1':
                dp[c + 1] = 1 + min(dp[c], dp[c + 1], prev_diag)
                max_side = max(max_side, dp[c + 1])
            else:
                dp[c + 1] = 0
            prev_diag = temp
            
    return max_side * max_side

Complexity

Time: $O(m \times n)$ — Each cell visited once.
Space: $O(n)$ — Single 1D row array.
