📋 The problem

Decide whether an integer is a power of four, without loops.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer n, return true if it is a power of four. Otherwise, return false.

Powers of four ($4^0=1, 4^1=4, 4^2=16, 4^3=64$) must satisfy two properties: 1. Must be a power of two: $n > 0$ and $(n \;\&\; (n - 1)) == 0$. 2. The single set bit must be at an even bit position (0, 2, 4, 6...): In 32-bit binary, the mask with bits at all even positions is 0x55555555 (binary 01010101010101010101010101010101)! $$n \;\&\; ext{0x55555555} e 0$$ Alternatively: $n \pmod 3 == 1$!

🐢 Brute force vs optimal

Bitmask check runs in $O(1)$ time with zero loops.

💡 Key insight: Must be power of 2 AND single bit must be at even index: n > 0 and (n & (n - 1)) == 0 and (n & 0x55555555) != 0.

✅ The solution

Reveal the commented solution (attempt it first!) 
def isPowerOfFour(n: int) -> bool:
    return n > 0 and (n & (n - 1)) == 0 and (n & 0x55555555) != 0

Complexity

Time: $O(1)$ — Instant bitmask verification.
Space: $O(1)$ — Constant memory.
