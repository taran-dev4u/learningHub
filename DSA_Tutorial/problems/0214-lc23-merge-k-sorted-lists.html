📋 The problem

Merge k sorted linked lists into one sorted linked list.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You have k sorted linked lists and want to merge them into one sorted list. At any step, the next node in the merged list must be the smallest current head among the k lists. A min-heap containing the current head of each list gives us the minimum in O(log k) time.

🐢 Brute force first

Traverse all nodes into an array, sort the array, and reconstruct a linked list → O(N log N) where N is total nodes. Doesn't leverage that lists are already sorted.

💡 Key insight: initialize a min-heap of size at most k with the head of each non-empty list. Repeatedly pop the smallest node, attach it to the result, and if that node has a .next, push node.next into the heap.

🪜 The approach, step by step

  1. Create a dummy head dummy = ListNode(0) and curr = dummy.
  2. Push a tuple (node.val, i, node) for each non-empty list head into the min-heap. (The index i acts as a unique tie-breaker to prevent Python from comparing ListNode objects).
  3. While heap is non-empty:
  4. Pop (val, i, node). Attach curr.next = node, advance curr.
  5. If node.next exists, push (node.next.val, i, node.next).
  6. Return dummy.next.

✅ The solution

import heapq

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def mergeKLists(lists):
    heap = []
    # Push (val, index, node) - index breaks ties when values are equal
    for i, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.val, i, node))
            
    dummy = ListNode(0)
    curr = dummy
    
    while heap:
        val, i, node = heapq.heappop(heap)
        curr.next = node
        curr = curr.next
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))
            
    return dummy.next

⏱️ Complexity

Time O(N log k) — where N is the total number of nodes across all k lists. Each of the N nodes is pushed and popped from a heap of size at most k. Space O(k) — for the heap of size k.

⚠️ Edge cases

  • lists = []: returns None.
  • lists = [[]]: list contains empty heads, returns None.
  • k = 1: returns the single list directly.

🐛 Common mistakes

  • Pushing (node.val, node) without a tiebreaker — Python throws TypeError: '<' not supported between instances of 'ListNode' when two nodes have equal values.

🔁 Variations & follow-ups

  • Divide and Conquer approach: merge pairs of lists iteratively in O(N log k) time with O(1) extra space.
