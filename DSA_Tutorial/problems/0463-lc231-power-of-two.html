#231 Power of Two EasyLeetCode

 

Pattern: Bit Manipulation Patterns › Subpattern 14.4: Bitwise Operations / Power of Two or Four Check · Problem 463 of 699

📋 The problem

Decide whether an integer is a power of two, ideally without loops.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer n, return true if it is a power of two. Otherwise, return false.

A power of two in binary has exactly one set bit (e.g. $1=2^0=1_2, 2=2^1=10_2, 4=2^2=100_2, 8=2^3=1000_2$). Recall Brian Kernighan's bit trick: $$n \;\&\; (n - 1)$$ clears the lowest set bit! If $n$ has only one set bit, clearing it leaves 0: $$n > 0 \quad ext{and} \quad (n \;\&\; (n - 1)) == 0$$

🐢 Brute force vs optimal

Repeated division by 2 takes $O(\log n)$. The single bitwise check runs in $O(1)$ constant time.

💡 Key insight: Power of two check: n > 0 and (n & (n - 1)) == 0. Executes in a single CPU cycle!

✅ The solution

Reveal the commented solution (attempt it first!) 
def isPowerOfTwo(n: int) -> bool:
    """
    Checks power of two in O(1) time and space.
    """
    return n > 0 and (n & (n - 1)) == 0

Complexity

Time: $O(1)$ — Single bitwise operation.
Space: $O(1)$ — No memory allocated.
