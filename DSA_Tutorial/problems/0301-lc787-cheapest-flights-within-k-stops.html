📋 The problem

Return the cheapest flight price from src to dst using at most k intermediate stops (-1 if impossible).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There are n cities connected by flights with prices. Given src, dst, and an integer k, return the cheapest price from src to dst with at most k stops (i.e. at most k + 1 flight legs). If no such route exists, return -1.

Because the number of edges is explicitly bounded by k + 1, standard Dijkstra's algorithm fails if it greedily explores a cheap path that consumes too many stops. Instead, this problem is custom-built for Bellman-Ford Algorithm run for exactly k + 1 rounds, or BFS level-by-level.

🐢 Brute force vs optimal

DFS backtracking is exponential. Bellman-Ford runs in O((K + 1) × E) time and takes O(V) auxiliary space.

💡 Key insight: In Bellman-Ford, iteration i calculates the shortest distance to all vertices using at most i edges!

CRITICAL TRICK: At the start of each iteration, copy prices to temp_prices. Relax edges using values from the previous iteration: temp_prices[v] = min(temp_prices[v], prices[u] + weight). This ensures an iteration uses at most ONE additional flight and prevents a single iteration from cascading through multiple flights!

🪜 The approach, step by step

  1. Initialize prices = [float('inf')] * n. Set prices[src] = 0.
  2. Loop k + 1 times (allowing at most k + 1 flights):
    • Create a copy: temp = list(prices).
    • For each flight (u, v, cost) in flights:
      • If prices[u] != float('inf') and prices[u] + cost < temp[v]: temp[v] = prices[u] + cost.
    • Update prices = temp.
  3. Return prices[dst] if prices[dst] != float('inf') else -1.

🎞️ Visual dry run — n=3, flights=[(0,1,100),(1,2,100),(0,2,500)], src=0, dst=2, k=1:

✅ The solution

Python 3 — Bellman-Ford with Copy Array 
def findCheapestPrice(n: int, flights: list[list[int]], src: int, dst: int, k: int) -> int:
    """
    Computes cheapest flight price from src to dst with at most k stops using Bellman-Ford.
    """
    prices = [float('inf')] * n
    prices[src] = 0
    
    # Run Bellman-Ford for at most k + 1 flights
    for _ in range(k + 1):
        temp = list(prices)
        for u, v, cost in flights:
            if prices[u] != float('inf') and prices[u] + cost < temp[v]:
                temp[v] = prices[u] + cost
        prices = temp
        
    return prices[dst] if prices[dst] != float('inf') else -1

⚡ Complexity analysis

  • Time Complexity: O((K + 1) × E). There are k + 1 rounds, and each round scans all E flights.
  • Space Complexity: O(V) to store the prices and temp arrays.

🚨 Edge cases to watch out for

  • src == dst: Cost is 0.
  • Destination unreachable within k stops: Returns -1 correctly.
  • Direct flight exists but is more expensive: The algorithm correctly considers the multi-hop cheaper route if within k stops.
