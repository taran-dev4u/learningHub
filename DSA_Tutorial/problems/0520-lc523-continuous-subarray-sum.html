📋 The problem

Decide whether the array has a subarray of length ≥ 2 whose sum is a multiple of k.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer array nums and an integer k, return true if nums has a continuous subarray of size at least two whose elements sum up to a multiple of k.

Modulo Arithmetic on Prefix Sums: If two prefix sums have the same remainder modulo $k$: $$prefix[i] \equiv prefix[j] \pmod k \implies (prefix[i] - prefix[j]) \equiv 0 \pmod k$$ which means the subarray sum between $j$ and $i$ is divisible by $k$! Maintain first_seen[remainder] -> index: - Base case: first_seen[0] = -1. - If curr_sum % k has been seen before at index $j$ and $i - j \ge 2$, return True!

🐢 Brute force vs optimal

Checking all subarrays takes $O(n^2)$. Modulo prefix map detects matching remainders in $O(n)$ time and $O(\min(n, k))$ space.

💡 Key insight: Subarray sum is divisible by $k$ if two prefix sums share the same remainder: rem = curr_sum % k. Check if seen previously with index distance $\ge 2$.

✅ The solution

Reveal the commented solution (attempt it first!) 
def checkSubarraySum(nums: list[int], k: int) -> bool:
    first_seen = {0: -1}
    curr_sum = 0
    
    for i, x in enumerate(nums):
        curr_sum += x
        rem = curr_sum % k
        if rem in first_seen:
            if i - first_seen[rem] >= 2:
                return True
        else:
            first_seen[rem] = i
            
    return False

Complexity

Time: $O(n)$ — Single pass.
Space: $O(\min(n, k))$ — Hash map storing remainders.
