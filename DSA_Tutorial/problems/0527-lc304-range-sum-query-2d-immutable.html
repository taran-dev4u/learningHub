#304 Range Sum Query 2D - Immutable MediumLeetCode

 

Pattern: Prefix Sum & Difference Array Patterns › Subpattern 17.2: Range Sum Query (Static) · Problem 527 of 699

📋 The problem

Precompute over an immutable matrix so any rectangle-sum query answers in O(1).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a 2D matrix matrix, handle multiple queries of calculating the sum of elements inside the rectangle defined by top-left $(row1, col1)$ and bottom-right $(row2, col2)$.

2D Prefix Sum Formula (Inclusion-Exclusion): Let $dp[r+1][c+1]$ be the sum of the submatrix from $(0, 0)$ to $(r, c)$: $$dp[r+1][c+1] = matrix[r][c] + dp[r][c+1] + dp[r+1][c] - dp[r][c]$$ To query rectangle from $(r_1, c_1)$ to $(r_2, c_2)$: $$ ext{Sum} = dp[r_2+1][c_2+1] - dp[r_1][c_2+1] - dp[r_2+1][c_1] + dp[r_1][c_1]$$

🐢 Brute force vs optimal

Traversing rectangle cells takes $O(m imes n)$ per query. 2D prefix sum answers queries in strictly $O(1)$ time!

💡 Key insight: 2D inclusion-exclusion: subtract top and left submatrices, add back the double-subtracted top-left overlap. Answers any rectangle in $O(1)$!

✅ The solution

Reveal the commented solution (attempt it first!) 
class NumMatrix:
    def __init__(self, matrix: list[list[int]]):
        if not matrix or not matrix[0]:
            return
        m, n = len(matrix), len(matrix[0])
        self.dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for r in range(m):
            for c in range(n):
                self.dp[r + 1][c + 1] = (matrix[r][c] 
                                       + self.dp[r][c + 1] 
                                       + self.dp[r + 1][c] 
                                       - self.dp[r][c])

    def sumRegion(self, r1: int, c1: int, r2: int, c2: int) -> int:
        return (self.dp[r2 + 1][c2 + 1] 
              - self.dp[r1][c2 + 1] 
              - self.dp[r2 + 1][c1] 
              + self.dp[r1][c1])

Complexity

Time: Constructor: $O(m imes n)$. sumRegion: $O(1)$ arithmetic.
Space: $O(m imes n)$ — 2D prefix table.
