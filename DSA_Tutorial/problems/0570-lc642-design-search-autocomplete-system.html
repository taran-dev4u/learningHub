📋 The problem

Design search autocomplete: given typed prefixes ('#' ends a sentence), return the top 3 historical sentences by frequency.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Design a search autocomplete system for a search engine. Users enter sentences character by character ending with '#'. Return the top 3 historical hot sentences that have prefix equal to the typed sentence so far, sorted by frequency descending, then lexicographical order ascending.

Key Insights

Each TrieNode stores a dictionary of sentence frequencies: counts = defaultdict(int). When typing character $c$:

  • If c == '#': Insert/increment full typed query in the trie, reset search pointer to root.
  • If c != '#': Walk to child node. The node directly contains all candidate sentences passing through it! Sort candidates with custom key (-freq, sentence) and return top 3.

from typing import List
from collections import defaultdict
import heapq

class TrieNode:
    def __init__(self):
        self.children = {}
        self.counts = defaultdict(int)

class AutocompleteSystem:
    def __init__(self, sentences: List[str], times: List[int]):
        self.root = TrieNode()
        self.curr_node = self.root
        self.curr_input = []
        self.dead_end = False
        
        for s, t in zip(sentences, times):
            self._add(s, t)

    def _add(self, sentence: str, count: int) -> None:
        curr = self.root
        for ch in sentence:
            if ch not in curr.children:
                curr.children[ch] = TrieNode()
            curr = curr.children[ch]
            curr.counts[sentence] += count

    def input(self, c: str) -> List[str]:
        if c == '#':
            sentence = "".join(self.curr_input)
            self._add(sentence, 1)
            self.curr_node = self.root
            self.curr_input = []
            self.dead_end = False
            return []
            
        self.curr_input.append(c)
        if self.dead_end or c not in self.curr_node.children:
            self.dead_end = True
            return []
            
        self.curr_node = self.curr_node.children[c]
        # Extract top 3 candidates
        candidates = sorted(self.curr_node.counts.items(), key=lambda x: (-x[1], x[0]))
        return [sent for sent, _ in candidates[:3]]

Complexity & Edge Cases

  • Time Complexity: $O(K \log K)$ where $K$ is number of candidate sentences sharing the prefix.
  • Space Complexity: $O(N imes L)$ nodes and inverted index entries.
