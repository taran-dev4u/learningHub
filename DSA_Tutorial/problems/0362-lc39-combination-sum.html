📋 The problem

Given distinct candidate numbers and a target, list all unique combinations (numbers reusable any times) that sum to the target.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an array of distinct integers candidates and a target integer, return a list of all unique combinations of candidates where the chosen numbers sum to target. The same number may be chosen from candidates an unlimited number of times.

💡 Key insight: Sort candidates. At index i, if candidates[i] > remaining_target, break immediately (pruning!). When exploring, pass index i (NOT i + 1) to allow reusing the current candidate.

✅ The solution

def combinationSum(candidates: list[int], target: int) -> list[list[int]]:
    """
    Finds combinations summing to target with unlimited element reuse.
    """
    candidates.sort()
    res = []
    path = []
    n = len(candidates)
    
    def backtrack(start, remain):
        if remain == 0:
            res.append(list(path))
            return
            
        for i in range(start, n):
            if candidates[i] > remain:
                break  # Pruning: all subsequent candidates are larger!
                
            path.append(candidates[i])
            backtrack(i, remain - candidates[i])  # Reuse candidate by passing i
            path.pop()
            
    backtrack(0, target)
    return res

⚡ Complexity analysis

  • Time Complexity: O(N^(T/M)) where T = target and M = min(candidates).
  • Space Complexity: O(T/M) for maximum recursion tree depth.
