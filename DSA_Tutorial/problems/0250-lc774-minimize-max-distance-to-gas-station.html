#774 Minimize Max Distance to Gas Station HardLeetCode

 

Pattern: Binary Search Patterns › Subpattern 8.3: On Answer / Condition Function · Problem 250 of 699

📋 The problem

Add k gas stations along existing ones to minimize the maximum distance between adjacent stations; return that minimized distance.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an integer array stations that represents the positions of gas stations on the x-axis in sorted order. You are also given an integer k. You should add k new gas stations such that the maximum distance between adjacent gas stations is minimized. Return the smallest possible value of D (answer within 10^-6 of actual value).

🐢 Brute force first

Greedily place one station at a time into the currently largest interval using a max heap: O(k log n). When k = 10^6, heap operations timeout. Continuous binary search handles any k!

💡 Key insight: Can we achieve adjacent distance at most D? For an interval of length diff = stations[i+1] - stations[i], we need floor(diff / D) additional stations! If the sum of stations needed <= k, then D is achievable! Use floating-point binary search.

🪜 The approach, step by step

  1. Floating binary search: left = 0.0, right = stations[-1] - stations[0].
  2. Loop while right - left > 1e-6 (or fixed 60 iterations):
  3. mid = (left + right) / 2.0.
  4. Count stations needed: sum(int((stations[i+1] - stations[i]) / mid) for i in range(len(stations)-1)).
  5. If count <= k: right = mid (can achieve this max distance, try smaller).
  6. Else: left = mid.
  7. Return left.

✅ The solution

Reveal the commented solution (attempt it first!) 
def minmaxGasDist(stations, k):
    left, right = 0.0, float(stations[-1] - stations[0])
    
    # 60 iterations gives precision (right - left) / 2^60 < 10^-10
    for _ in range(60):
        mid = (left + right) / 2.0
        needed = sum(int((stations[i+1] - stations[i]) / mid) for i in range(len(stations) - 1))
        
        if needed <= k:
            right = mid
        else:
            left = mid
            
    return left

⏱️ Complexity

Time O(n * log((max_gap) / eps)) ≈ 60 * O(n). Space O(1).

⚠️ Edge cases

  • Stations with uneven initial spacings.
  • Floating-point termination: running a fixed 60 or 70 iterations completely avoids infinite loops from precision loss.
