📋 The problem

Among all permutations of 1..n in sorted order, return the k-th one directly (without generating them all).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Permutations — Swap each index with subsequent indices to generate all n! orderings.

Why this pattern?

  • "all combinations / permutations / subsets / partitions"
  • "generate all valid …" (parentheses, palindromes)
  • board search: N-Queens, Sudoku, word paths in a grid
  • n is small (≤ ~20) — exponential output is expected

def backtrack(start, path):
    if is_complete(path):                 # base: record a snapshot
        res.append(path[:])               # COPY — path keeps mutating!
        return
    for i in range(start, len(choices)):
        if not valid(choices[i]):         # prune early
            continue
        path.append(choices[i])           # choose
        backtrack(i + 1, path)            # explore  (i+1: combinations;
        path.pop()                        # un-choose      i: reuse allowed)
