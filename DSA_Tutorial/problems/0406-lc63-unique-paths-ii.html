📋 The problem

Same right/down robot walk, but some grid cells contain obstacles that cannot be entered; count the paths.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an m x n integer array obstacleGrid. A 1 represents an obstacle and 0 represents an empty space. A robot starts at the top-left corner and moves only down or right. Return the number of unique paths to the bottom-right corner.

Transition rule: - If obstacleGrid[i][j] == 1, $dp[i][j] = 0$ (impassable!). - If obstacleGrid[i][j] == 0, $dp[i][j] = dp[i - 1][j] + dp[i][j - 1]$.

🐢 Brute force vs optimal

Instead of an $m \times n$ 2D matrix, we only need the current row and the row above. We can reduce space to $O(n)$ using a 1D rolling array!

💡 Key insight: 1D DP: dp[j] represents paths to cell $(i, j)$. If cell has obstacle, set dp[j] = 0. Otherwise add left neighbor: dp[j] += dp[j - 1].

✅ The solution

def uniquePathsWithObstacles(obstacleGrid: list[list[int]]) -> int:
    if not obstacleGrid or obstacleGrid[0][0] == 1:
        return 0
        
    m, n = len(obstacleGrid), len(obstacleGrid[0])
    dp = [0] * n
    dp[0] = 1
    
    for r in range(m):
        for c in range(n):
            if obstacleGrid[r][c] == 1:
                dp[c] = 0
            elif c > 0:
                dp[c] += dp[c - 1]
                
    return dp[n - 1]

Complexity

Time: $O(m \times n)$ — Every cell evaluated once.
Space: $O(n)$ — Single 1D array of width $n$.
