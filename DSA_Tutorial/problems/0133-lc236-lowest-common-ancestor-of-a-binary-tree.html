📋 The problem

In a general binary tree, return the lowest common ancestor of two given nodes.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Tree - Lowest Common Ancestor (LCA) Finding — Find the deepest node that has both target nodes in its subtree — recursive or with parent pointers.

💡 Key idea
Postorder: a node returning non-null from both sides is the LCA; otherwise forward the non-null side.

Why this pattern?

  • "level", "depth", "nearest", "zigzag by rows" → BFS
  • "path sum", "ancestor", "validate", "diameter" → DFS
  • BST + "k-th smallest / sorted order" → inorder
  • "serialize / reconstruct" → preorder
