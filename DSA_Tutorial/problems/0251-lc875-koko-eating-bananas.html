📋 The problem

Koko eats bananas at speed k per hour, one pile per hour; find the slowest k that finishes all piles within h hours.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Koko loves to eat bananas. There are n piles of bananas, where the i-th pile has piles[i] bananas. The guards will return in h hours. Koko can decide her eating speed k (bananas-per-hour). Each hour, she chooses a pile and eats k bananas from it. If the pile has less than k bananas, she eats all of them and will not eat any more bananas during this hour. Return the minimum integer k such that she can eat all bananas within h hours.

🐢 Brute force first

Test speeds k = 1, 2, 3... max(piles). For each speed, calculate total hours needed: sum(math.ceil(pile / k)). The first speed where total hours <= h is the answer. Time: O(max(piles) * n). When max(piles) = 10^9, this TLEs immediately.

💡 Key insight: Notice the monotonicity! If Koko can finish all bananas at speed k, she can certainly finish them at any speed > k. If she cannot finish at speed k, she cannot finish at any speed < k. This monotonic feasibility predicate canFinish(k) -> bool enables Binary Search on Answer in range [1, max(piles)]!

🪜 The approach, step by step

  1. Set search range: left = 1 (minimum possible eating speed) and right = max(piles) (maximum needed eating speed).
  2. Define helper canFinish(k): calculates total hours spent across all piles: sum((pile + k - 1) // k) (integer ceil). Returns True if total hours <= h.
  3. While left < right:
  4. Compute mid = left + (right - left) // 2.
  5. If canFinish(mid) is True: mid might be the minimum speed or a smaller speed might work → right = mid.
  6. Else: mid is too slow → left = mid + 1.
  7. When left == right, return left.

✅ The solution

Reveal the commented solution (attempt it first!) 
import math

def minEatingSpeed(piles, h):
    """
    Binary search on answer range [1, max(piles)].
    """
    def canFinish(k):
        # (pile + k - 1) // k is fast integer ceiling for pile / k
        return sum((p + k - 1) // k for p in piles) <= h
        
    left, right = 1, max(piles)
    
    while left < right:
        mid = left + (right - left) // 2
        if canFinish(mid):
            right = mid
        else:
            left = mid + 1
            
    return left

⏱️ Complexity

Time O(n * log(max(piles))) — Each binary search step takes O(n) to sum hours across all piles, and the search range shrinks by 2 each step. Space O(1).

⚠️ Edge cases

  • len(piles) == h: Koko must eat each pile in 1 hour, so answer is max(piles).
  • h very large: answer will be 1.
  • Very large pile sizes up to 10^9: binary search completes in ~30 iterations.
