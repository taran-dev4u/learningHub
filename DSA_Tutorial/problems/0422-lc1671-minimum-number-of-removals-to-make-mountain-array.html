#1671 Minimum Number of Removals to Make Mountain Array HardLeetCode

 

Pattern: Dynamic Programming (DP) Patterns › Subpattern 12.11: Longest Increasing Subsequence (LIS) · Problem 422 of 699

📋 The problem

Return the minimum removals so the array becomes a strict mountain (LIS from the left + LDS from the right, combined at peaks).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You may recall that an array arr is a mountain array if and only if: - $\text{len}(arr) \ge 3$ - There exists some index $i$ ($0 < i < \text{len}(arr) - 1$) such that $arr[0] < arr[1] < \dots < arr[i]$ and $arr[i] > arr[i+1] > \dots > arr[-1]$.

Given an integer array nums, return the minimum number of elements to remove to make nums a mountain array.

Minimizing removals is equivalent to maximizing the length of the mountain array! For every valid peak index $i$: $$\text{Mountain Length} = LIS_{left}[i] + LIS_{right}[i] - 1$$ where: - $LIS_{left}[i]$ is the Longest Increasing Subsequence in $nums[0 \dots i]$ ending at $i$. - $LIS_{right}[i]$ is the Longest Decreasing Subsequence starting at $i$ (i.e. LIS in reversed array ending at $i$).

A peak is valid only if $LIS_{left}[i] \ge 2$ and $LIS_{right}[i] \ge 2$ (must have at least one element strictly climbing up and one climbing down!).

🐢 Brute force vs optimal

Compute $LIS_{left}$ and $LIS_{right}$ using $O(n \log n)$ Patience Sorting. Maximize valid mountain length in $O(n \log n)$ time total!

💡 Key insight: Compute forward LIS and backward LIS in $O(n \log n)$. For every peak with $left \ge 2$ and $right \ge 2$, removals $= n - (left + right - 1)$.

✅ The solution

import bisect

def minimumMountainRemovals(nums: list[int]) -> int:
    n = len(nums)
    
    # 1. Forward LIS ending at i
    lis_left = [1] * n
    tails = []
    for i in range(n):
        idx = bisect.bisect_left(tails, nums[i])
        if idx == len(tails):
            tails.append(nums[i])
        else:
            tails[idx] = nums[i]
        lis_left[i] = idx + 1
        
    # 2. Backward LIS starting at i
    lis_right = [1] * n
    tails = []
    for i in range(n - 1, -1, -1):
        idx = bisect.bisect_left(tails, nums[i])
        if idx == len(tails):
            tails.append(nums[i])
        else:
            tails[idx] = nums[i]
        lis_right[i] = idx + 1
        
    # 3. Find max mountain length
    max_mountain = 0
    for i in range(1, n - 1):
        if lis_left[i] >= 2 and lis_right[i] >= 2:
            max_mountain = max(max_mountain, lis_left[i] + lis_right[i] - 1)
            
    return n - max_mountain

Complexity

Time: $O(n \log n)$ — Two binary search LIS passes.
Space: $O(n)$ — Arrays storing lis_left and lis_right.
