#852 Peak Index in a Mountain Array MediumLeetCode

 

Pattern: Binary Search Patterns › Subpattern 8.2: Find Min/Max in Rotated Sorted Array · Problem 246 of 699

📋 The problem

An array increases then decreases (a mountain); find the peak index in O(log n).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

An array arr is a mountain if it increases to a single peak and then decreases. Given a mountain array, return the index i such that arr[0] < arr[1] < ... arr[i-1] < arr[i] > arr[i+1] > ... > arr[arr.length - 1]. Must be O(log(arr.length)).

🐢 Brute force first

Scan linearly until arr[i] > arr[i+1]. Return i. Time O(n).

💡 Key insight: The mountain array has two distinct phases: ascending (arr[i] < arr[i+1]) and descending (arr[i] > arr[i+1]). The peak is the unique transition point. Binary search easily identifies which slope mid lies on.

🪜 The approach, step by step

  1. Initialize left = 0, right = len(arr) - 1.
  2. While left < right:
  3. Compute mid = left + (right - left) // 2.
  4. If arr[mid] < arr[mid + 1], we are ascending: left = mid + 1.
  5. Else, we are descending or at the peak: right = mid.
  6. Return left when left == right.

🎞️ Visual dry run — arr = [0, 10, 5, 2]

Iter 1: left = 0, right = 3 → mid = 1
        arr[1] = 10 > arr[2] = 5 → descending slope!
        right = mid = 1
Iter 2: left = 0, right = 1 → mid = 0
        arr[0] = 0 < arr[1] = 10 → ascending slope!
        left = mid + 1 = 1
left == right == 1.
Peak is at index 1 (val = 10). ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
def peakIndexInMountainArray(arr):
    left, right = 0, len(arr) - 1
    
    while left < right:
        mid = left + (right - left) // 2
        if arr[mid] < arr[mid + 1]:
            left = mid + 1
        else:
            right = mid
            
    return left

⏱️ Complexity

Time O(log n). Space O(1).

⚠️ Edge cases

  • Guaranteed to be a mountain array of length at least 3, so peak is never at index 0 or index n-1.
