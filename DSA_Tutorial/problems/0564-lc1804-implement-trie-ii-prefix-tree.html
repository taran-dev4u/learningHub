#1804 Implement Trie II (Prefix Tree) MediumLeetCode

📋 The problem

A trie that also counts how many inserted words equal, and how many start with, a query string.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Extend the standard Trie to support:

  • insert(word): Insert string word into trie.
  • countWordsEqualTo(word): Return number of instances of word in trie.
  • countWordsStartingWith(prefix): Return number of words that have prefix as prefix.
  • erase(word): Erase one instance of word from trie.

Key Insights

Each node maintains two counters:

  1. pass_count: Incremented when inserting, decremented when erasing. Tells how many words pass through this node.
  2. end_count: Incremented at the final character node when inserting, decremented when erasing. Tells how many exact words end here.

Python 3 Solution (Click to Expand) 
class TrieNode:
    def __init__(self):
        self.children = {}
        self.pass_count = 0
        self.end_count = 0

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        curr = self.root
        curr.pass_count += 1
        for ch in word:
            if ch not in curr.children:
                curr.children[ch] = TrieNode()
            curr = curr.children[ch]
            curr.pass_count += 1
        curr.end_count += 1

    def countWordsEqualTo(self, word: str) -> int:
        curr = self.root
        for ch in word:
            if ch not in curr.children:
                return 0
            curr = curr.children[ch]
        return curr.end_count

    def countWordsStartingWith(self, prefix: str) -> int:
        curr = self.root
        for ch in prefix:
            if ch not in curr.children:
                return 0
            curr = curr.children[ch]
        return curr.pass_count

    def erase(self, word: str) -> None:
        curr = self.root
        curr.pass_count -= 1
        for ch in word:
            curr = curr.children[ch]
            curr.pass_count -= 1
        curr.end_count -= 1

Complexity & Edge Cases

  • Time Complexity: $O(L)$ for all four operations.
  • Space Complexity: $O(N imes L)$.
