📋 The problem

Design a structure that adds words and searches them where '.' in the query matches any single letter.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Trie with Wildcards — Extend search to handle '.' or '*' wildcards via DFS branching.

💡 Key idea
Trie search where '.' recursively tries every child.

Why this pattern?

  • "startsWith", autocomplete, longest common prefix over many strings
  • wildcard search ('.' matches anything) → branch at the dot
  • find many words in a letter grid simultaneously
  • XOR maximization → binary trie over bits

Pattern template to adapt

Start from the Trie / Prefix Tree master template and adapt the marked parts to this problem:

class TrieNode:
    __slots__ = ('kids', 'end')
    def __init__(self):
        self.kids = {}                 # char → TrieNode
        self.end = False               # a word ends here

root = TrieNode()
def insert(word):                      # O(len)
    node = root
    for ch in word:
        node = node.kids.setdefault(ch, TrieNode())
    node.end = True

def search(word, node=None, i=0):      # supports '.' wildcard
    node = node or root
    for j in range(i, len(word)):
        ch = word[j]
        if ch == '.':
            return any(search(word, kid, j+1) for kid in node.kids.values())
        if ch not in node.kids: return False
        node = node.kids[ch]
    return node.end
