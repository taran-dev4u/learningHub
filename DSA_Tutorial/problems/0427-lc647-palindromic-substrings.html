📋 The problem

Count the palindromic substrings of a string (each occurrence counts).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a string s, return the number of palindromic substrings in it.

A substring is a palindrome if it reads the same forward and backward. Like LC 5, every palindromic substring must have a center. Expanding around each of the $2n - 1$ centers, every successful match $s[l] == s[r]$ contributes exactly one valid palindrome!

🐢 Brute force vs optimal

Brute force generation of all substrings takes $O(n^3)$. Expand-around-center checks all centers in $O(n^2)$ time and $O(1)$ auxiliary space.

💡 Key insight: As you expand from center $(l, r)$, increment count += 1 on every matching step s[l] == s[r].

✅ The solution

Reveal the commented solution (attempt it first!) 
def countSubstrings(s: str) -> int:
    n = len(s)
    total = 0
    
    def count_palindromes(l: int, r: int) -> int:
        c = 0
        while l >= 0 and r < n and s[l] == s[r]:
            c += 1
            l -= 1
            r += 1
        return c
        
    for i in range(n):
        total += count_palindromes(i, i)     # Odd centers
        total += count_palindromes(i, i + 1) # Even centers
        
    return total

Complexity

Time: $O(n^2)$ — Each expansion runs at most $O(n)$.
Space: $O(1)$ — Only count accumulators.
