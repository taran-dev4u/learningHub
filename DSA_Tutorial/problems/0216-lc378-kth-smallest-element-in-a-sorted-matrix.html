📋 The problem

Return the k-th smallest element of a matrix whose rows and columns are sorted ascending.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an n x n matrix where each row and column is sorted in ascending order, find the kth smallest element. Two optimal ways:

  1. Min-Heap: treat each row as a sorted list, k-way merge until k elements popped (O(k log n)).
  2. Binary Search on Value Range: search between matrix[0][0] and matrix[n-1][n-1], counting elements <= mid in O(n) time (O(n log(max - min))).

🐢 Brute force first

Flatten the matrix into a 1D array, sort it, and return index k - 1 → O(n^2 log(n^2)).

💡 Key insight (Heap): push the first element of each row (matrix[r][0], r, 0) into a min-heap. Pop the minimum k-1 times, pushing the next element from that row. The kth popped element is the answer.

🪜 The approach, step by step

  1. Push (matrix[r][0], r, 0) for r in 0..min(n, k) - 1.
  2. Loop k - 1 times: pop (val, r, c). If c + 1 < n, push (matrix[r][c + 1], r, c + 1).
  3. The next popped element's value is the kth smallest.

✅ The solution

Reveal the commented solution (attempt it first!) 
import heapq

def kthSmallest(matrix, k):
    n = len(matrix)
    # Min-heap of size at most min(n, k)
    heap = []
    for r in range(min(n, k)):
        heapq.heappush(heap, (matrix[r][0], r, 0))
        
    val = 0
    for _ in range(k):
        val, r, c = heapq.heappop(heap)
        if c + 1 < n:
            heapq.heappush(heap, (matrix[r][c + 1], r, c + 1))
            
    return val

⏱️ Complexity

Time O(k log n) using Min-Heap (or O(n log(max - min)) using Binary Search). Space O(n) for the heap.

⚠️ Edge cases

  • k = 1: returns matrix[0][0].
  • k = n * n: returns matrix[n-1][n-1].
  • 1x1 matrix.
