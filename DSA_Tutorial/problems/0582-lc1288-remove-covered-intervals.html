📋 The problem

Remove intervals fully covered by another interval; return how many remain (sort by start asc, end desc).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an array intervals where intervals[i] = [li, ri], remove all intervals that are covered by another interval in the list. An interval $[a, b)$ is covered by $[c, d)$ if and only if $c \le a$ and $b \le d$. Return the number of remaining intervals.

Key Insights

Sort intervals by start ascending, and on tie by end descending: intervals.sort(key=lambda x: (x[0], -x[1])) With this sorting order: Whenever an interval has $x[0] == prev[0]$, the wider one appears first! We maintain max_end seen so far. For each interval $[s, e]$:

  • If $e \le max_end$: It is completely covered by an earlier interval with a smaller or equal start and larger end! We don't count it.
  • If $e > max_end$: It is uncovered! Increment count and update $max_end = e$.

Python 3 Solution (Click to Expand) 
from typing import List

class Solution:
    def removeCoveredIntervals(self, intervals: List[List[int]]) -> int:
        # Start ascending, end descending
        intervals.sort(key=lambda x: (x[0], -x[1]))
        
        count = 0
        max_end = 0
        
        for start, end in intervals:
            if end > max_end:
                count += 1
                max_end = end
                
        return count

Complexity & Edge Cases

  • Time Complexity: $O(N \log N)$ sorting + $O(N)$ scan.
  • Space Complexity: $O(1)$ extra space.
