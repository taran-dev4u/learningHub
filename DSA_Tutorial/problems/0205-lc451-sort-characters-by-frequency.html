📋 The problem

Sort a string's characters by decreasing frequency.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Sort characters in a string by decreasing frequency. Similar to #347, count each character's occurrences and sort or bucket-sort characters by frequency, then reconstruct the string multiplying each character by its frequency.

🐢 Brute force first

Count character frequencies with a dictionary, sort the unique characters by frequency descending, and build the string.

from collections import Counter
def frequencySort(s):
    count = Counter(s)
    chars = sorted(count.keys(), key=lambda c: count[c], reverse=True)
    return "".join(c * count[c] for c in chars)

Time O(n + k log k) where k is the number of distinct characters (at most 52 for ASCII letters, 128 for full ASCII). Space O(n).

💡 Key insight: since maximum frequency is n = len(s), bucket sort groups characters by frequency in O(n) time and O(n) space without any comparison sorting.

🪜 The approach, step by step

  1. Count character frequencies using Counter(s).
  2. Create bucket array of length len(s) + 1.
  3. For each character and count, append character to buckets[count].
  4. Traverse buckets from len(s) down to 1, appending c * count to the result string.

✅ The solution

Reveal the commented solution (attempt it first!) 
from collections import Counter

def frequencySort(s):
    count = Counter(s)
    buckets = [[] for _ in range(len(s) + 1)]
    for char, freq in count.items():
        buckets[freq].append(char)
        
    res = []
    for freq in range(len(s), 0, -1):
        for char in buckets[freq]:
            res.append(char * freq)
    return "".join(res)

⏱️ Complexity

Time O(n) — linear scan to count, bucket, and assemble. Space O(n) — for the buckets and reconstructed string.

⚠️ Edge cases

  • All characters unique (e.g. "abc"): any permutation is valid.
  • All characters identical (e.g. "aaaa"): string returned unchanged.
  • Case sensitivity: 'A' and 'a' are treated as distinct characters.

🐛 Common mistakes

  • Concatenating strings inside a loop with += (O(n^2) in some languages) instead of joining a list of string chunks.
