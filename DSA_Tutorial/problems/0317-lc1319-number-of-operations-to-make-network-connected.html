📋 The problem

Given network cables between computers, return the minimum re-plugs to connect everything (components − 1 if enough cables; else -1).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There are n computers numbered from 0 to n - 1 connected by ethernet cables connections. You can extract redundant cables from connected computers and reconnect them to unconnected computers. Return the minimum number of times you need to do this to make all computers connected. If it is impossible, return -1.

To connect n nodes into a single connected component, we mathematically need at least n - 1 cables.

  • If len(connections) < n - 1: Impossible! Even if we rearrange every cable optimally, there simply aren't enough edges. Return -1.
  • If len(connections) >= n - 1: By Graph Theory, any connected graph with C separate components can be linked together into a single component using exactly C - 1 edges! Since we know there are surplus redundant edges, the answer is simply components - 1!

🐢 Brute force vs optimal

We only need to count the number of connected components in the graph using Disjoint Set Union (DSU) or DFS in O(V + E) time!

💡 Key insight: Check len(connections) < n - 1 first. Then count the number of disjoint components components. Every successful union reduces component count. The answer is components - 1!

🪜 The approach, step by step

  1. If len(connections) < n - 1, return -1.
  2. Initialize parent = list(range(n)), components = n.
  3. Define find(x) with path compression.
  4. For each u, v in connections:
    • ru, rv = find(u), find(v).
    • If ru != rv: parent[ru] = rv, components -= 1.
  5. Return components - 1.

🎞️ Visual dry run — n=4, connections=[[0,1],[0,2],[1,2]]:

1. len(connections) = 3 >= 4 - 1 = 3. Possible!
2. Initial components = 4: {0}, {1}, {2}, {3}
3. Edge (0, 1): components = 3 ({0, 1}, {2}, {3})
4. Edge (0, 2): components = 2 ({0, 1, 2}, {3})
5. Edge (1, 2): find(1)==find(2). Redundant edge! components stays 2.
Final components = 2.
Operations needed = components - 1 = 2 - 1 = 1 ✓

✅ The solution

def makeConnected(n: int, connections: list[list[int]]) -> int:
    """
    Computes minimum cable rewirings to connect all computers via DSU.
    """
    if len(connections) < n - 1:
        return -1
        
    parent = list(range(n))
    components = n
    
    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]
        
    for u, v in connections:
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            components -= 1
            
    return components - 1

⚡ Complexity analysis

  • Time Complexity: O(N + E × α(N)) ≈ O(N + E). Initial check is O(1), and DSU runs in near-linear time.
  • Space Complexity: O(N) for the parent array.

🚨 Edge cases to watch out for

  • len(connections) < n - 1: Returns -1 immediately.
  • n = 1: components = 1, returns 0 (already connected).
