📋 The problem

Convert a string to a 32-bit signed integer the way atoi does: skip leading spaces, read an optional sign, read digits until a non-digit, and clamp to the 32-bit range.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Implement the myAtoi(string s) function, which converts a string to a 32-bit signed integer (similar to C/C++'s atoi function).

The 4-step state machine: 1. Whitespace: Discard leading whitespace (s.lstrip()). 2. Sign: Check if next character is '+' or '-'. Set sign = -1 or 1. 3. Digits: Read consecutive digits until a non-digit character or end of string. 4. Clamping: Clamp integer into 32-bit signed range: $[-2^{31}, 2^{31} - 1]$.

🐢 Brute force vs optimal

Linear scan with arithmetic overflow clamping. Prevents 64-bit integer overflow if in languages without arbitrary precision.

💡 Key insight: Accumulate num = num * 10 + digit. Clamp with max(-2**31, min(2**31 - 1, sign * num)).

✅ The solution

def myAtoi(s: str) -> int:
    s = s.lstrip()
    if not s:
        return 0
        
    sign = 1
    idx = 0
    if s[0] == '-':
        sign = -1
        idx = 1
    elif s[0] == '+':
        idx = 1
        
    res = 0
    INT_MAX = 2**31 - 1
    INT_MIN = -2**31
    
    while idx < len(s) and s[idx].isdigit():
        digit = int(s[idx])
        # Check overflow
        if res > (INT_MAX - digit) // 10:
            return INT_MAX if sign == 1 else INT_MIN
        res = res * 10 + digit
        idx += 1
        
    res *= sign
    return max(INT_MIN, min(INT_MAX, res))

Complexity

Time: $O(n)$ — Single linear pass.
Space: $O(1)$ — Scalar variables only.
