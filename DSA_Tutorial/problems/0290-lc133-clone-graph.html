📋 The problem

Given a reference to a node in a connected undirected graph, return a deep copy of the whole graph.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a reference of a node in a connected undirected graph, return a deep copy (clone) of the graph. Each node in the graph contains a value (int) and a list of its neighbors (List[Node]).

🐢 Brute force first

Traversing without tracking visited clones causes an infinite loop because undirected graphs contain bidirectional cycles!

💡 Key insight: Use a hash map cloned = {original_node: new_cloned_node}. When visiting node: 1. If node is already in cloned, return cloned[node]. 2. Create clone: copy = Node(node.val) and store in cloned[node] = copy. 3. For each neighbor in node.neighbors: recursively clone it and append to copy.neighbors.

🪜 The approach, step by step

  1. If node is None, return None.
  2. cloned = {}.
  3. Define dfs(curr):
    • If curr in cloned, return cloned[curr].
    • copy = Node(curr.val); cloned[curr] = copy.
    • For neighbor in curr.neighbors: copy.neighbors.append(dfs(neighbor)).
    • Return copy.
  4. Return dfs(node).

✅ The solution

def cloneGraph(node):
    if not node:
        return None
        
    cloned = {}
    
    def dfs(curr):
        if curr in cloned:
            return cloned[curr]
            
        copy = Node(curr.val)
        cloned[curr] = copy
        
        for neighbor in curr.neighbors:
            copy.neighbors.append(dfs(neighbor))
            
        return copy
        
    return dfs(node)

⏱️ Complexity

Time O(V + E) — Visits each node and edge once. Space O(V) for hash map and recursion stack.

⚠️ Edge cases

  • node is None: returns None.
  • Single node with no neighbors: returns copy with empty neighbors list.
