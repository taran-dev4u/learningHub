#2064 Minimized Maximum of Products Distributed to Any Store MediumLeetCode

 

Pattern: Binary Search Patterns › Subpattern 8.3: On Answer / Condition Function · Problem 257 of 699

📋 The problem

Distribute product quantities to n stores, one product type per store, minimizing the largest store load (binary search the answer).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an integer n denoting the number of specialty retail stores, and an integer array quantities where quantities[i] represents the amount of the i-th product type. Distribute all products to stores such that each store receives at most one product type, but any amount of it. Minimize the maximum number of products given to any store.

🐢 Brute force first

Linear search through possible max store quantities from 1 to max(quantities). O(n * max(quantities)) TLE.

💡 Key insight: If each store receives at most x items, product quantities[i] needs ceil(quantities[i] / x) stores. If the sum of required stores <= n, distribution x is feasible! Binary search on x in [1, max(quantities)].

🪜 The approach, step by step

  1. left = 1, right = max(quantities).
  2. While left < right:
  3. mid = left + (right - left) // 2.
  4. Stores needed: sum((q + mid - 1) // mid for q in quantities).
  5. If stores <= n: right = mid.
  6. Else: left = mid + 1.
  7. Return left.

🎞️ Visual dry run — n = 6, quantities = [11, 6]

Range: [1, 11]
Iter 1: mid = 6 → stores = ceil(11/6) + ceil(6/6) = 2 + 1 = 3 <= 6 → right = 6
Iter 2: left = 1, right = 6 → mid = 3 → stores = ceil(11/3) + ceil(6/3) = 4 + 2 = 6 <= 6 → right = 3
Iter 3: left = 1, right = 3 → mid = 2 → stores = ceil(11/2) + ceil(6/2) = 6 + 3 = 9 > 6 → left = 3
left == right == 3. Return 3! ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
def minimizedMaximum(n, quantities):
    left, right = 1, max(quantities)
    
    while left < right:
        mid = left + (right - left) // 2
        stores = sum((q + mid - 1) // mid for q in quantities)
        
        if stores <= n:
            right = mid
        else:
            left = mid + 1
            
    return left

⏱️ Complexity

Time O(m * log(max(quantities))) where m = len(quantities). Space O(1).

⚠️ Edge cases

  • n == len(quantities): each store gets exactly one product type, answer is max(quantities).
