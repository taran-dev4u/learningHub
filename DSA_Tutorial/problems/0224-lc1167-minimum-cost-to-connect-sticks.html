📋 The problem

Connect sticks by paying the sum of the two joined each time; return the minimum total cost (always join the two smallest — heap).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Connect sticks of lengths sticks into one. Cost to connect two sticks of lengths x and y is x + y. We want the minimum total cost. Notice that sticks connected earlier contribute repeatedly to future connection costs. Therefore, we should greedily connect the two smallest sticks first (classic Huffman Coding algorithm).

🐢 Brute force first

Try all possible pairing orders → exponential.

💡 Key insight: use a min-heap. Repeatedly pop the two smallest sticks a and b, add a + b to total cost, and push a + b back into the heap until one stick remains.

🪜 The approach, step by step

  1. Heapify sticks in O(n).
  2. Initialize total_cost = 0.
  3. While len(sticks) > 1:
  4. a = heappop(sticks), b = heappop(sticks).
  5. cost = a + b, total_cost += cost.
  6. heappush(sticks, cost).
  7. Return total_cost.

✅ The solution

Reveal the commented solution (attempt it first!) 
import heapq

def connectSticks(sticks):
    heapq.heapify(sticks)
    total_cost = 0
    
    while len(sticks) > 1:
        first = heapq.heappop(sticks)
        second = heapq.heappop(sticks)
        cost = first + second
        total_cost += cost
        heapq.heappush(sticks, cost)
        
    return total_cost

⏱️ Complexity

Time O(n log n) — n - 1 connections, each performing O(log n) heap operations. Space O(1) auxiliary if heapified in-place.

⚠️ Edge cases

  • Single stick: already connected, cost = 0.
  • All sticks equal length: pairs merge symmetrically.
