#310 Minimum Height Trees MediumLeetCode

📋 The problem

For a tree given as an edge list, return the root(s) that minimize the tree's height (there are at most two).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

A tree is an undirected graph in which any two vertices are connected by exactly one path. The height of a rooted tree is the number of edges on the longest downward path between the root and a leaf. Given n nodes labeled 0 to n - 1 and a tree of n - 1 edges, find all nodes that, when chosen as root, produce a tree with minimum height. Return a list of all such roots (Minimum Height Trees, or MHTs).

🐢 Brute force vs optimal

Running BFS from every single node to compute its height takes O(N × (V + E)) = O(N^2), which TLEs on n = 20,000.

💡 Key insight: The roots that minimize tree height are the centroids of the tree! In graph theory, any tree has either 1 or 2 centroids.

Think of this like peeling an onion from the outside in: repeatedly trim all current leaf nodes (nodes with degree == 1) layer by layer. The last remaining 1 or 2 nodes in the core are guaranteed to be the centroids!

🪜 The approach, step by step

  1. Base cases: if n ≤ 2, all nodes are already MHT roots; return list(range(n)).
  2. Build adjacency sets: adj = defaultdict(set).
  3. Find all initial leaves: leaves = [i for i in range(n) if len(adj[i]) == 1].
  4. Maintain remaining node count: remaining_nodes = n.
  5. While remaining_nodes > 2:
    • Subtract current leaves: remaining_nodes -= len(leaves).
    • New leaves list new_leaves = [].
    • For each leaf in leaves:
      • Find its only neighbor: neighbor = adj[leaf].pop().
      • Remove leaf from neighbor: adj[neighbor].remove(leaf).
      • If neighbor now has len(adj[neighbor]) == 1: append neighbor to new_leaves.
    • leaves = new_leaves.
  6. Return leaves (contains either 1 or 2 nodes).

✅ The solution

Python 3 — Leaf Trimming (Topological Onion Peeling) 
from collections import defaultdict

def findMinHeightTrees(n: int, edges: list[list[int]]) -> list[int]:
    """
    Finds centroids of tree by iteratively trimming leaf nodes layer by layer.
    """
    if n <= 2:
        return list(range(n))
        
    # 1. Build adjacency list using sets for O(1) edge removal
    adj = defaultdict(set)
    for u, v in edges:
        adj[u].add(v)
        adj[v].add(u)
        
    # 2. Collect initial leaves
    leaves = [i for i in range(n) if len(adj[i]) == 1]
    
    # 3. Trim leaves until 1 or 2 centroids remain
    remaining_nodes = n
    while remaining_nodes > 2:
        remaining_nodes -= len(leaves)
        new_leaves = []
        for leaf in leaves:
            # The only neighbor of this leaf
            neighbor = adj[leaf].pop()
            adj[neighbor].remove(leaf)
            if len(adj[neighbor]) == 1:
                new_leaves.append(neighbor)
        leaves = new_leaves
        
    return leaves

⚡ Complexity analysis

  • Time Complexity: O(N). Each node and edge is examined and removed at most once during the leaf-trimming process.
  • Space Complexity: O(N) to store the adjacency sets and leaf lists.

🚨 Edge cases to watch out for

  • n = 1: Returns [0] immediately.
  • n = 2: Returns [0, 1].
  • Linear line graph: Centroids are the exact middle node (if odd length) or middle two nodes (if even length).
