#132 Palindrome Partitioning II HardLeetCode

📋 The problem

Return the minimum number of cuts needed to split a string so every piece is a palindrome.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a string s, partition s such that every substring of the partition is a palindrome. Return the minimum cuts needed for a palindrome partitioning of s.

Let $cuts[i]$ be the minimum cuts needed for prefix $s[0 \dots i]$. To find $cuts[i]$, consider all possible palindromic suffixes $s[j \dots i]$ ($0 \le j \le i$): - If $s[0 \dots i]$ is already a palindrome ($j = 0$), then $cuts[i] = 0$. - If $s[j \dots i]$ is a palindrome for $j > 0$, then $cuts[i] = \min(cuts[i], \; cuts[j - 1] + 1)$.

🐢 Brute force vs optimal

Precomputing or simultaneously updating palindrome intervals with expand-around-center optimizes the solution to $O(n^2)$ time and $O(n)$ space.

💡 Key insight: Maintain cuts[i] = i (worst case: cut every char). While expanding palindrome $(l, r)$, transition cuts[r] = min(cuts[r], (cuts[l - 1] + 1) if l > 0 else 0).

✅ The solution

def minCut(s: str) -> int:
    n = len(s)
    cuts = list(range(n)) # cuts[i] initialized to i (max possible cuts)
    
    for mid in range(n):
        # Odd-length palindromes centered at mid
        l, r = mid, mid
        while l >= 0 and r < n and s[l] == s[r]:
            new_cut = 0 if l == 0 else cuts[l - 1] + 1
            cuts[r] = min(cuts[r], new_cut)
            l -= 1
            r += 1
            
        # Even-length palindromes centered between mid and mid + 1
        l, r = mid, mid + 1
        while l >= 0 and r < n and s[l] == s[r]:
            new_cut = 0 if l == 0 else cuts[l - 1] + 1
            cuts[r] = min(cuts[r], new_cut)
            l -= 1
            r += 1
            
    return cuts[-1]

Complexity

Time: $O(n^2)$ — Each character center expanded in $O(n)$ time.
Space: $O(n)$ — 1D cuts array of length $n$.
