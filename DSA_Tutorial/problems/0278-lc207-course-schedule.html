📋 The problem

Given course prerequisite pairs, decide whether all courses can be finished (i.e., the prerequisite graph has no cycle).

Where this fits

Graph DFS - Cycle Detection (Directed Graph) — DFS with three colors (white/gray/black) detects back edges in directed graphs.

💡 Key idea
Cycle detection: Kahn's topological sort finishes all nodes iff no cycle.

Why this pattern?

  • "islands", "connected", "regions", "provinces" → component DFS/BFS
  • "minimum steps / moves / days to reach" → BFS
  • "prerequisites", "build order", "course schedule" → topological sort
  • states-and-moves puzzles (word ladder, locks) → BFS over implicit graph

# Topological sort (Kahn's)
indeg = defaultdict(int)
for u in graph:
    for v in graph[u]: indeg[v] += 1
q = deque([u for u in graph if indeg[u] == 0])
order = []
while q:
    u = q.popleft(); order.append(u)
    for v in graph[u]:
        indeg[v] -= 1
        if indeg[v] == 0: q.append(v)
# len(order) < number of nodes  ⇒  cycle exists
