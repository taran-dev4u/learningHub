📋 The problem

Given course prerequisite pairs, decide whether all courses can be finished (i.e., the prerequisite graph has no cycle).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There are a total of numCourses courses you have to take, labeled from 0 to numCourses - 1. You are given an array prerequisites where prerequisites[i] = [a_i, b_i] indicates that you must take course b_i first if you want to take course a_i. Return true if you can finish all courses, or false otherwise.

🐢 Brute force first

Attempting all permutations of course orders is factorial O(n!).

💡 Key insight: Can you complete all courses? Only if there is NO CYCLE in the directed prerequisite graph! A directed graph without cycles is a DAG (Directed Acyclic Graph). We can detect cycles using either: 1. Kahn's Algorithm (BFS with In-degrees): Count in-degrees (prerequisites needed). Courses with 0 in-degrees can be taken immediately. Decrement in-degrees of their dependent courses. If total taken courses == numCourses, no cycle exists! 2. DFS 3-State Coloring: 0 = unvisited, 1 = visiting (in current recursion stack), 2 = visited. If a neighbor is in state 1, a back-edge (cycle) exists!

🪜 The approach, step by step (Kahn's Algorithm)

  1. Build adjacency list graph = {i: []} and compute in_degree = [0] * numCourses.
  2. For dest, src in prerequisites: graph[src].append(dest), in_degree[dest] += 1.
  3. Add all courses with in_degree[i] == 0 to a queue (courses with no prerequisites).
  4. taken = 0.
  5. While queue:
    • course = queue.popleft(); taken += 1.
    • For neighbor in graph[course]:
      • in_degree[neighbor] -= 1.
      • If in_degree[neighbor] == 0: queue.append(neighbor).
  6. Return taken == numCourses.

🎞️ Visual dry run — prerequisites = [[1, 0], [0, 1]] (Cycle!)

in_degrees: 0: 1, 1: 1

Loop terminates immediately.

✅ The solution

from collections import deque, defaultdict

def canFinish(numCourses, prerequisites):
    """
    Kahn's Algorithm for Topological Sort / Cycle Detection.
    """
    graph = defaultdict(list)
    in_degree = [0] * numCourses
    
    for dest, src in prerequisites:
        graph[src].append(dest)
        in_degree[dest] += 1
        
    queue = deque([i for i in range(numCourses) if in_degree[i] == 0])
    taken = 0
    
    while queue:
        course = queue.popleft()
        taken += 1
        
        for neighbor in graph[course]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)
                
    return taken == numCourses

⏱️ Complexity

Time O(V + E) where V = numCourses and E = len(prerequisites). Space O(V + E) for graph and queue.

⚠️ Edge cases

  • No prerequisites: all courses have in-degree 0, returns True.
  • Self-dependency [0, 0]: in-degree never reaches 0, returns False.
