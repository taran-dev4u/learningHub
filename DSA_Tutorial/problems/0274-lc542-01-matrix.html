📋 The problem

For every cell of a binary matrix, compute the distance to the nearest 0.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an m x n binary matrix mat, return the distance of the nearest 0 for each cell. The distance between two adjacent cells is 1.

🐢 Brute force first

For every 1, run BFS to find the closest 0: O((m*n)^2). Reverse the thinking: run multi-source BFS starting from all 0s simultaneously!

💡 Key insight: Multi-Source BFS from all 0s! 1. Initialize distance matrix dist with -1. 2. Enqueue all cells containing 0 with distance 0. 3. As BFS expands outwards, the first time you reach a cell (nr, nc), the distance dist[r][c] + 1 is guaranteed to be its shortest distance to ANY 0!

🪜 The approach, step by step

  1. Initialize dist = [[-1]*n for _ in range(m)] and queue = deque().
  2. Add all (r, c) where mat[r][c] == 0 to queue, setting dist[r][c] = 0.
  3. While queue:
    • r, c = queue.popleft().
    • For 4 neighbors: if in bounds and dist[nr][nc] == -1: dist[nr][nc] = dist[r][c] + 1, queue.append((nr, nc)).
  4. Return dist.

✅ The solution

from collections import deque

def updateMatrix(mat):
    m, n = len(mat), len(mat[0])
    dist = [[-1] * n for _ in range(m)]
    queue = deque()
    
    # Enqueue all 0s as multi-source origins
    for r in range(m):
        for c in range(n):
            if mat[r][c] == 0:
                dist[r][c] = 0
                queue.append((r, c))
                
    while queue:
        r, c = queue.popleft()
        for dr, dc in [(1, 0), (-1, 0), (0, 1), (0, -1)]:
            nr, nc = r + dr, c + dc
            if 0 <= nr < m and 0 <= nc < n and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1
                queue.append((nr, nc))
                
    return dist

⏱️ Complexity

Time O(m * n) — Each cell is queued and dequeued exactly once. Space O(m * n) for distance matrix and queue.

⚠️ Edge cases

  • All 0s: returns all 0s.
  • Single 0 in corner.
