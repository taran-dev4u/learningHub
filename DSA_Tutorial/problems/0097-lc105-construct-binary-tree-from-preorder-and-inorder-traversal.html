📋 The problem

Rebuild a binary tree from its preorder and inorder traversals (all values distinct).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Tree DFS - Recursive Preorder Traversal — Visit root, then left subtree, then right — used for tree cloning, serialization, path building.

💡 Key idea
Preorder's first element is the root; find it in inorder to split left/right subtrees; recurse with index math.

Why this pattern?

  • "level", "depth", "nearest", "zigzag by rows" → BFS
  • "path sum", "ancestor", "validate", "diameter" → DFS
  • BST + "k-th smallest / sorted order" → inorder
  • "serialize / reconstruct" → preorder
