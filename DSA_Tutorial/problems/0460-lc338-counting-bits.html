📋 The problem

For every i from 0 to n, output how many 1-bits i has, ideally in O(n) total.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer n, return an array ans of length n + 1 such that for each i ($0 \le i \le n$), ans[i] is the number of 1's in the binary representation of i.

Bit DP Recurrence: Notice that shifting right by 1 (i >> 1) divides $i$ by 2 and drops the lowest bit: $$dp[i] = dp[i >> 1] + (i \;\&\; 1)$$ Alternatively, using Brian Kernighan's lowest bit clear: $$dp[i] = dp[i \;\&\; (i - 1)] + 1$$ Both relations allow computing $dp[i]$ in $O(1)$ time using previously computed entries!

🐢 Brute force vs optimal

Counting bits independently for each number takes $O(n \log n)$. Bit DP computes the entire array in $O(n)$ linear time.

💡 Key insight: dp[i] = dp[i >> 1] + (i & 1). The bit count of $i$ is the bit count of $i // 2$ plus the lowest bit!

✅ The solution

Reveal the commented solution (attempt it first!) 
def countBits(n: int) -> list[int]:
    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        dp[i] = dp[i >> 1] + (i & 1)
    return dp

Complexity

Time: $O(n)$ — Single pass from 1 to $n$.
Space: $O(n)$ — Output array of size $n+1$.
