#648 Replace Words MediumLeetCode

📋 The problem

Replace each word in a sentence with its shortest dictionary root that prefixes it (if any).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given a dictionary of root words and a sentence, replace all derivative words in the sentence with their shortest matching root word in the dictionary.

Key Insights

Store all roots in a Trie. For each word in the sentence: Walk through its characters in the Trie. As soon as we encounter a node with is_end == True, we have found the shortest root prefix! Replace the word with this prefix immediately. If path terminates without finding an end, keep the original word.

Python 3 Solution (Click to Expand) 
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Solution:
    def replaceWords(self, dictionary: List[str], sentence: str) -> str:
        root = TrieNode()
        for word in dictionary:
            curr = root
            for ch in word:
                if ch not in curr.children:
                    curr.children[ch] = TrieNode()
                curr = curr.children[ch]
            curr.is_end = True
            
        def find_root(w: str) -> str:
            curr = root
            for i, ch in enumerate(w):
                if ch not in curr.children:
                    return w
                curr = curr.children[ch]
                if curr.is_end:
                    return w[:i + 1]
            return w
            
        return " ".join(find_root(w) for w in sentence.split())

Complexity & Edge Cases

  • Time Complexity: $O(D imes L + S imes L)$ where $D$ is dictionary size, $S$ is number of sentence words.
  • Space Complexity: $O(D imes L)$ for Trie.
