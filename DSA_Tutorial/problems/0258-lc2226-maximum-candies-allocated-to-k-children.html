#2226 Maximum Candies Allocated to K Children MediumLeetCode

 

Pattern: Binary Search Patterns › Subpattern 8.3: On Answer / Condition Function · Problem 258 of 699

📋 The problem

Split candy piles into sub-piles (no merging) so k children get equal amounts; maximize that amount (binary search).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an integer array candies where each element is the number of candies in a pile. You are also given an integer k. You can divide each pile into any number of sub-piles, but you cannot merge two piles together. You want to allocate candies to k children such that each child gets the same number of candies. Find the maximum number of candies each child can get.

🐢 Brute force first

Total sum of candies must be >= k, otherwise answer is 0. Try candy amounts c = 1, 2, ... max(candies). For each c, count children satisfied: sum(candy // c). Stop when count < k.

💡 Key insight: Maximize candies per child! Monotonic feasibility: if each child can get c candies, they can also get any amount < c. Binary search in range [1, max(candies)]. Notice we want the MAXIMUM feasible value!

🪜 The approach, step by step

  1. If sum(candies) < k, return 0.
  2. left = 1, right = max(candies). ans = 0.
  3. While left <= right:
  4. mid = left + (right - left) // 2.
  5. Children served: sum(c // mid for c in candies).
  6. If served >= k: this amount is possible! Record ans = mid, search for larger: left = mid + 1.
  7. Else: right = mid - 1.
  8. Return ans.

✅ The solution

Reveal the commented solution (attempt it first!) 
def maximumCandies(candies, k):
    left, right = 1, max(candies)
    ans = 0
    
    while left <= right:
        mid = left + (right - left) // 2
        children = sum(c // mid for c in candies)
        
        if children >= k:
            ans = mid
            left = mid + 1   # Try for even more candies
        else:
            right = mid - 1
            
    return ans

⏱️ Complexity

Time O(n * log(max(candies))). Space O(1).

⚠️ Edge cases

  • sum(candies) < k: returns 0.
  • k = 1: returns max(candies).
