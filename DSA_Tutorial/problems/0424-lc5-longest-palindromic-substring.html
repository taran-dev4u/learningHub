📋 The problem

Given a string, return its longest substring that reads the same forwards and backwards.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a string s, return the longest palindromic substring in s.

Every palindrome mirrors around its center. A string of length $n$ has exactly $2n - 1$ potential centers: 1. $n$ odd-length centers: centered at character $s[i]$ ($i \in [0, n-1]$). 2. $n - 1$ even-length centers: centered between $s[i]$ and $s[i+1]$ ($i \in [0, n-2]$).

Expanding outward from each center until characters mismatch finds the longest palindrome in $O(n^2)$ time with $O(1)$ space. For $O(n)$ linear time, Manacher's Algorithm mirrors palindromic lengths using previously computed boundaries.

🐢 Brute force vs optimal

Testing all $O(n^2)$ substrings for palindromicity takes $O(n^3)$ time. Expand-around-center reduces time to $O(n^2)$ and space to $O(1)$ without allocating any DP table!

💡 Key insight: Expand outward from $2n-1$ centers. For center $(l, r)$, decrement $l$ and increment $r$ while $s[l] == s[r]$. Track the maximum $(r - l - 1)$ interval.

✅ The solution

def longestPalindrome(s: str) -> str:
    if not s or len(s) == 1:
        return s
        
    start, max_len = 0, 1
    
    def expand(l: int, r: int):
        nonlocal start, max_len
        while l >= 0 and r < len(s) and s[l] == s[r]:
            curr_len = r - l + 1
            if curr_len > max_len:
                max_len = curr_len
                start = l
            l -= 1
            r += 1
            
    for i in range(len(s)):
        expand(i, i)       # Odd length palindrome
        expand(i, i + 1)   # Even length palindrome
        
    return s[start : start + max_len]

Complexity

Time: $O(n^2)$ — $2n - 1$ centers, expanding at most $n$ times.
Space: $O(1)$ — Constant scalar variables (pointers).
