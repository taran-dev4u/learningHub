📋 The problem

Balloons occupy x-ranges; an arrow shot at x pops every balloon whose range contains x. Return the fewest arrows to pop all.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There are spherical balloons taped to a flat wall. Each balloon is represented by a 2D integer array points where points[i] = [x_start, x_end]. An arrow shot vertically from x bursts all balloons with x_start ≤ x ≤ x_end. Find the minimum number of arrows that must be shot to burst all balloons.

Every arrow should burst as many overlapping balloons as possible. Like interval scheduling, we want to shoot our arrow at the earliest end coordinate among remaining balloons.

🐢 Brute force vs optimal

Sorting by x_end coordinates lets us greedily place an arrow at x_end of the first unburst balloon, guaranteeing that every balloon overlapping that coordinate is burst in O(N log N) time.

💡 Key insight: Sort by x_end. Shoot the first arrow at points[0][1]. For each subsequent balloon, if its start <= arrow_pos, it is already burst by the current arrow! If its start > arrow_pos, the current arrow cannot reach it → increment arrows by 1 and shoot a new arrow at this balloon's end!

🪜 The approach, step by step

  1. If not points, return 0.
  2. Sort points by end coordinate: points.sort(key=lambda x: x[1]).
  3. Initialize arrows = 1, arrow_pos = points[0][1].
  4. For each start, end in points[1:]:
    • If start > arrow_pos: arrows += 1; arrow_pos = end.
  5. Return arrows.

✅ The solution

def findMinArrowShots(points: list[list[int]]) -> int:
    """
    Finds minimum arrows to burst all balloons by sorting by end coordinate.
    """
    if not points:
        return 0
        
    points.sort(key=lambda x: x[1])
    arrows = 1
    arrow_pos = points[0][1]
    
    for start, end in points[1:]:
        if start > arrow_pos:
            arrows += 1
            arrow_pos = end
            
    return arrows

⚡ Complexity analysis

  • Time Complexity: O(N log N) for sorting.
  • Space Complexity: O(1) auxiliary space.
