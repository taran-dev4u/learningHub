#3008 Find Beautiful Indices in the Given Array II HardLeetCode

📋 The problem

Find indices where pattern a occurs within distance k of an occurrence of pattern b (KMP both, two-pointer over match lists).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given a 0-indexed string s, two strings a and b, and an integer k. An index $i$ is beautiful if: 1. $0 \le i \le ext{len}(s) - ext{len}(a)$ and $s[i \dots i + ext{len}(a) - 1] == a$. 2. There exists some index $j$ such that $0 \le j \le ext{len}(s) - ext{len}(b)$ and $s[j \dots j + ext{len}(b) - 1] == b$ with $|j - i| \le k$.

3-Step Efficient Pipeline: 1. Find all match indices of $a$ in $s$: Run KMP algorithm to find all starting indices indices_a in $O(n)$ time. 2. Find all match indices of $b$ in $s$: Run KMP algorithm to find all starting indices indices_b in $O(n)$ time. 3. Filter with Binary Search: For each index $i \in indices\_a$, we need to check if there is any $j \in indices\_b$ such that $i - k \le j \le i + k$. Use bisect_left(indices_b, i - k). If the found index has $j \le i + k$, then $i$ is beautiful!

🐢 Brute force vs optimal

Pairwise check takes $O(|indices\_a| \times |indices\_b|)$. KMP pattern matching + binary search runs in $O(|s| + |indices\_a| \log |indices\_b|)$.

💡 Key insight: KMP finds all match positions of $a$ and $b$ in $O(n)$. Binary search (bisect_left) on indices_b verifies $|j - i| \le k$ in $O(\log |b\_matches|)$ per candidate!

✅ The solution

import bisect

def beautifulIndices(s: str, a: str, b: str, k: int) -> list[int]:
    def kmp_search(pattern: str) -> list[int]:
        m = len(pattern)
        if m == 0 or m > len(s):
            return []
            
        # LPS
        lps = [0] * m
        prev, i = 0, 1
        while i < m:
            if pattern[i] == pattern[prev]:
                prev += 1
                lps[i] = prev
                i += 1
            elif prev > 0:
                prev = lps[prev - 1]
            else:
                lps[i] = 0
                i += 1
                
        matches = []
        i, j = 0, 0
        while i < len(s):
            if s[i] == pattern[j]:
                i += 1
                j += 1
                if j == m:
                    matches.append(i - m)
                    j = lps[j - 1]
            elif j > 0:
                j = lps[j - 1]
            else:
                i += 1
        return matches

    indices_a = kmp_search(a)
    indices_b = kmp_search(b)
    
    res = []
    for i in indices_a:
        idx = bisect.bisect_left(indices_b, i - k)
        if idx < len(indices_b) and indices_b[idx] <= i + k:
            res.append(i)
            
    return res

Complexity

Time: $O(|s| + |indices\_a| \log |indices\_b|)$ — Linear KMP matchings followed by binary search.
Space: $O(|s|)$ — Arrays of matching index coordinates.
