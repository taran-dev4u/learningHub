Instead, we use Binary Exponentiation (Fast Powering): {2, 3, 5}{2, 3, 5}x^n = \begin{cases} (x^2)^{n / 2} & ext{if } n ext{ is even} \ x \cdot (x^2)^{(n - 1) / 2} & ext{if } n ext{ is odd} \end{cases}{2, 3, 5}{2, 3, 5} This cuts the exponent in half at each step, reducing time complexity to {2, 3, 5}O(\log n){2, 3, 5}.

Python 3 Solution (Iterative Binary Exponentiation) 
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n == 0:
            return 1.0
        if n < 0:
            x = 1.0 / x
            n = -n
            
        res = 1.0
        curr_power = x
        
        while n > 0:
            if n & 1:
                res *= curr_power
            curr_power *= curr_power
            n >>= 1
            
        return res

Complexity & Edge Cases

  • Time Complexity: {2, 3, 5}O(\log n){2, 3, 5} because {2, 3, 5}n{2, 3, 5} is halved at every bit shift.
  • Space Complexity: {2, 3, 5}O(1){2, 3, 5} iterative memory.
  • Edge Cases: {2, 3, 5}n = -2^{31}{2, 3, 5} (in 32-bit systems, taking {2, 3, 5}-n{2, 3, 5} overflows if not handled with 64-bit/Python arbitrary precision), {2, 3, 5}x = 0{2, 3, 5}, {2, 3, 5}n = 0{2, 3, 5}.
