📋 The problem

Given every employee's sorted working intervals, return the common free-time intervals (finite gaps everyone shares).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given a list schedule of employees, which represents the working time for each employee, return the list of finite intervals representing common, positive-length free time for all employees, sorted in order of time.

Key Insights

Flatten all employees' work intervals into a single global list. Sort all intervals by start time. Merge overlapping intervals just like LC 56! Any gap between adjacent merged working intervals constitutes a common free time interval: $$ ext{Gap} = [merged[i-1].end, merged[i].start]$$

Python 3 Solution (Interval Merging + Gap Extraction) 
# Definition for an Interval:
# class Interval:
#     def __init__(self, start: int = None, end: int = None):
#         self.start = start
#         self.end = end

class Solution:
    def employeeFreeTime(self, schedule: '[[Interval]]') -> '[Interval]':
        all_intervals = []
        for emp in schedule:
            for iv in emp:
                all_intervals.append([iv.start, iv.end])
                
        all_intervals.sort(key=lambda x: x[0])
        
        merged = []
        for start, end in all_intervals:
            if not merged or start > merged[-1][1]:
                merged.append([start, end])
            else:
                merged[-1][1] = max(merged[-1][1], end)
                
        # Gaps between merged working intervals
        free_time = []
        for i in range(1, len(merged)):
            free_time.append(Interval(merged[i - 1][1], merged[i][0]))
            
        return free_time

Complexity & Edge Cases

  • Time Complexity: $O(N \log N)$ where $N$ is total intervals across all employees.
  • Space Complexity: $O(N)$.
