📋 The problem

Decide whether a graph is bipartite: its nodes can be 2-colored so every edge joins different colors.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

An undirected graph is bipartite if we can split its set of nodes into two independent subsets A and B such that every edge in the graph connects a node in A and a node in B.

In graph theory, this is identical to 2-Coloring: can we color every vertex with one of two colors (e.g. Red and Blue, or 1 and -1) such that no two adjacent vertices have the same color?

🐢 Brute force vs optimal

Trying all 2^n coloring combinations is exponential. BFS or DFS 2-coloring checks the graph in O(V + E) time.

💡 Key insight: An undirected graph is bipartite if and only if it contains NO odd-length cycles.

Iterate through all nodes 0 to n - 1. If a node is uncolored, start a BFS/DFS from it with color 1. For every neighbor:
  • If uncolored: assign it -color and recurse.
  • If already colored: it MUST have color -color. If it has the SAME color, a conflict (odd cycle) is detected → return False!

🪜 The approach, step by step

  1. Initialize color = {}.
  2. For each node i from 0 to n - 1:
    • If i not in color:
      • Launch bfs(i): queue q = deque([i]), set color[i] = 1.
      • While q:
        • Pop u.
        • For neighbor v in graph[u]:
          • If v not in color: set color[v] = -color[u], push v.
          • Else if color[v] == color[u]: return False!
  3. Return True.

🎞️ Visual dry run:

Graph: 0 -- 1

1. color[0] = 1 (Blue)
2. Neighbors of 0: 1 and 3 -> color[1] = -1 (Red), color[3] = -1 (Red)
3. Neighbor of 1: 2 -> color[2] = 1 (Blue)
4. Check 3's neighbor 2: color[3]=-1 != color[2]=1. Valid!
Result: True (Bipartite) ✓

Odd cycle counterexample: Triangle 0-1-2
0 (Blue) -> 1 (Red) -> 2 (Blue)
Edge 2-0 connects Blue to Blue! Conflict! Output: False ✓

✅ The solution

Python 3 — BFS 2-Coloring 
from collections import deque

def isBipartite(graph: list[list[int]]) -> bool:
    """
    Determines if graph is 2-colorable using BFS traversal across all components.
    """
    n = len(graph)
    color = {}  # node -> 1 or -1
    
    for i in range(n):
        if i not in color:
            color[i] = 1
            q = deque([i])
            
            while q:
                u = q.popleft()
                for v in graph[u]:
                    if v not in color:
                        color[v] = -color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        return False  # Odd cycle found
                        
    return True

⚡ Complexity analysis

  • Time Complexity: O(V + E). Each node is colored once and each edge is inspected twice.
  • Space Complexity: O(V) for the color dictionary and BFS queue.
