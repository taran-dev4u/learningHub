📋 The problem

Design a metro card system: record checkins/checkouts and answer average travel time between station pairs.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

An underground railway system is keeping track of customer travel times between stations. Design a system to support checkIn(id, stationName, t), checkOut(id, stationName, t), and getAverageTime(startStation, endStation).

Maintain two hash maps: 1. check_ins: userId -> (startStation, checkInTime). 2. routes: (startStation, endStation) -> [total_travel_time, trip_count].

- On checkIn: record passenger entry in check_ins[id]. - On checkOut: retrieve start info, compute duration $t - t_{in}$, add to routes[(start, end)], and remove passenger from check_ins. - On getAverageTime: return total_time / trip_count in $O(1)$!

🐢 Brute force vs optimal

Both check-ins and average queries execute in constant $O(1)$ time with zero historical trip scanning.

💡 Key insight: Two maps: active passenger states in check_ins[id]; accumulated route metrics in routes[(start, end)] = [total_time, count]. $O(1)$ throughout.

✅ The solution

Reveal the commented solution (attempt it first!) 
class UndergroundSystem:
    def __init__(self):
        # id -> (station, time)
        self.check_ins = {}
        # (start, end) -> [total_time, count]
        self.routes = {}

    def checkIn(self, id: int, stationName: str, t: int) -> None:
        self.check_ins[id] = (stationName, t)

    def checkOut(self, id: int, stationName: str, t: int) -> None:
        start_station, start_time = self.check_ins.pop(id)
        route_key = (start_station, stationName)
        duration = t - start_time
        
        if route_key not in self.routes:
            self.routes[route_key] = [duration, 1]
        else:
            self.routes[route_key][0] += duration
            self.routes[route_key][1] += 1

    def getAverageTime(self, startStation: str, endStation: str) -> float:
        total_time, count = self.routes[(startStation, endStation)]
        return total_time / count

Complexity

Time: $O(1)$ for checkIn, checkOut, and getAverageTime.
Space: $O(P + S^2)$ where $P$ is active passengers and $S$ is number of stations.
