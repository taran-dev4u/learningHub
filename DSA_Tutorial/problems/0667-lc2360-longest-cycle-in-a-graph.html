Pattern: Advanced Graph Algorithm Patterns › Subpattern 24.9: Functional Graph / Safe-State Analysis · Problem 667 of 707

📋 The problem

Every node has at most one outgoing edge; return the length of the longest cycle (timestamped walk per component).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Functional Graph / Safe-State Analysis — Functional graph / safe-state analysis: detect nodes whose out-paths all terminate in a sink.

Why this pattern?

  • "cheapest / fastest path" with weights → Dijkstra (non-negative)
  • negative weights or "at most k stops" → Bellman-Ford / k-round relaxation
  • "minimum cost to connect all" → MST (Kruskal + DSU, or Prim)
  • "critical connection" whose removal disconnects → bridges (Tarjan)
