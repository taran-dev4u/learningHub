#373 Find K Pairs with Smallest Sums MediumLeetCode

 

Pattern: Heap (Priority Queue) Patterns › Subpattern 7.3: K-way Merge · Problem 215 of 699

📋 The problem

From two sorted arrays, return the k pairs (one element from each) with the smallest sums.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given two sorted arrays nums1 and nums2, find the k pairs (u, v) with the smallest sums. Think of this as a matrix where cell (i, j) has sum nums1[i] + nums2[j]. Since both arrays are sorted, each row and column is sorted. This is identical to #23 Merge k Sorted Lists.

🐢 Brute force first

Generate all pairs, sort by sum, return the first k → O(n1 * n2 log(n1 * n2)). Infeasible when n1, n2 = 10^5.

💡 Key insight: start by pushing the first element of each row: (nums1[i] + nums2[0], i, 0) for i < min(k, len(nums1)) into a min-heap. When popping (i, j), the next smallest candidate in that row is (i, j + 1).

🪜 The approach, step by step

  1. Initialize min-heap with (nums1[i] + nums2[0], i, 0) for i up to min(k, len(nums1)).
  2. While heap is not empty and len(res) < k:
  3. Pop (sum, i, j), append [nums1[i], nums2[j]] to result.
  4. If j + 1 < len(nums2), push (nums1[i] + nums2[j+1], i, j + 1).
  5. Return res.

✅ The solution

import heapq

def kSmallestPairs(nums1, nums2, k):
    if not nums1 or not nums2 or k <= 0:
        return []
        
    heap = []
    # Seed the heap with the first column (at most k rows)
    for i in range(min(k, len(nums1))):
        heapq.heappush(heap, (nums1[i] + nums2[0], i, 0))
        
    res = []
    while heap and len(res) < k:
        _, i, j = heapq.heappop(heap)
        res.append([nums1[i], nums2[j]])
        # Push the next element in the same row
        if j + 1 < len(nums2):
            heapq.heappush(heap, (nums1[i] + nums2[j + 1], i, j + 1))
            
    return res

⏱️ Complexity

Time O(k log(min(n1, k))) — at most k elements popped and pushed from a heap of size at most min(n1, k). Space O(min(n1, k)) — for the heap.

⚠️ Edge cases

  • k > n1 * n2: returns all possible pairs.
  • Arrays with single elements.
