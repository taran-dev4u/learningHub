📋 The problem

Implement a HashMap from scratch: put, get, remove — no built-in hash structures.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a HashMap without using any built-in hash table libraries.

Similar to MyHashSet (LC 705), maintain $B = 769$ bucket lists storing (key, value) pairs. - put(key, value): hash to bucket. If key already exists in bucket, overwrite value. Otherwise, append [key, value]. - get(key): search bucket for key. Return value if found, else -1. - remove(key): remove [key, value] pair from bucket if present.

🐢 Brute force vs optimal

Separate chaining gives $O(1)$ amortized operations.

💡 Key insight: Bucket array storing [key, val] pairs: idx = key % 769. Overwrite on duplicate key, append on new key.

✅ The solution

class MyHashMap:
    def __init__(self):
        self.size = 769
        self.buckets = [[] for _ in range(self.size)]

    def _hash(self, key: int) -> int:
        return key % self.size

    def put(self, key: int, value: int) -> None:
        bucket = self.buckets[self._hash(key)]
        for i, (k, v) in enumerate(bucket):
            if k == key:
                bucket[i] = (key, value)
                return
        bucket.append((key, value))

    def get(self, key: int) -> int:
        bucket = self.buckets[self._hash(key)]
        for k, v in bucket:
            if k == key:
                return v
        return -1

    def remove(self, key: int) -> None:
        bucket = self.buckets[self._hash(key)]
        for i, (k, v) in enumerate(bucket):
            if k == key:
                del bucket[i]
                return

Complexity

Time: $O(1)$ average for put, get, and remove.
Space: $O(N + B)$ where $N$ is total pairs and $B = 769$.
