#2407 Longest Increasing Subsequence II HardLeetCode

 

Pattern: Dynamic Programming (DP) Patterns › Subpattern 12.11: Longest Increasing Subsequence (LIS) · Problem 423 of 699

📋 The problem

Longest strictly increasing subsequence where adjacent chosen values differ by at most k (DP over values with a max-segment-tree).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an integer array nums and an integer k. Find the longest subsequence of nums that meets the following requirements: 1. The subsequence is strictly increasing. 2. The difference between adjacent elements in the subsequence is at most k (i.e. $nums[i+1] - nums[i] \le k$).

For each number $x \in nums$, we can extend any previous subsequence ending at value $v \in [\max(1, x - k), x - 1]$. $$dp[x] = 1 + \max_{v \in [\max(1, x - k), x - 1]} dp[v]$$ This requires a dynamic point-update and range-maximum query over the value domain $[1, \max(nums)]$! A Segment Tree or Fenwick Tree over the value range executes both query and update in $O(\log M)$ time!

🐢 Brute force vs optimal

Checking all previous values takes $O(n \times k)$ or $O(n^2)$. Using a Segment Tree on value range $M = \max(nums)$ solves it in $O(n \log M)$ time!

💡 Key insight: Segment tree over value domain $[1, M]$: query range $\max$ on $[\max(1, x-k), x-1]$, add 1, and update point $x$ with new max length.

class SegmentTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (4 * size)
        
    def query(self, node, start, end, l, r):
        if r < start or end < l:
            return 0
        if l <= start and end <= r:
            return self.tree[node]
        mid = (start + end) // 2
        p1 = self.query(2 * node, start, mid, l, r)
        p2 = self.query(2 * node + 1, mid + 1, end, l, r)
        return max(p1, p2)
        
    def update(self, node, start, end, idx, val):
        if start == end:
            self.tree[node] = max(self.tree[node], val)
            return
        mid = (start + end) // 2
        if idx <= mid:
            self.update(2 * node, start, mid, idx, val)
        else:
            self.update(2 * node + 1, mid + 1, end, idx, val)
        self.tree[node] = max(self.tree[2 * node], self.tree[2 * node + 1])

def lengthOfLIS(nums: list[int], k: int) -> int:
    max_val = max(nums)
    st = SegmentTree(max_val)
    
    for x in nums:
        left_bound = max(1, x - k)
        right_bound = x - 1
        best_prev = 0
        if left_bound <= right_bound:
            best_prev = st.query(1, 1, max_val, left_bound, right_bound)
        st.update(1, 1, max_val, x, best_prev + 1)
        
    return st.tree[1]

Complexity

Time: $O(n \log M)$ where $M = \max(nums)$. $n$ range queries and point updates.
Space: $O(M)$ — Segment tree nodes for value domain.
