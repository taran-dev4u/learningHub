📋 The problem

Split a string into as many parts as possible so no letter appears in two parts; return the part sizes.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given a string s. We want to partition the string into as many parts as possible so that each letter appears in at most one part. Return a list of integers representing the size of these parts.

🐢 Brute force vs optimal

In a pre-pass, find the last occurrence index of each character. Then scan the string from left to right, maintaining an expanding boundary end. When our scan index reaches end, every character encountered so far will never appear again → close the partition!

💡 Key insight: 1. last = {c: i for i, c in enumerate(s)}. 2. Maintain start = 0 and end = 0. 3. For index i, c: update end = max(end, last[c]). 4. If i == end: partition complete! Size is end - start + 1. Update start = i + 1.

🎞️ Visual dry run — s = "ababcbacadefegdehijhklij":

Chars in first block: 'a', 'b', 'c'.
Last index of 'a' is 8, 'b' is 5, 'c' is 7 -> max end = 8.
At index 8: i == end (8==8)!
Partition 1 size = 8 - 0 + 1 = 9 ("ababcbaca"). start = 9.

Next block: 'd', 'e', 'f', 'g'.
Last of 'd' is 14, 'e' is 15 -> max end = 15.
At index 15: i == end (15==15)!
Partition 2 size = 15 - 9 + 1 = 7 ("defegde"). start = 16.

Final block: 'h'..'j'.
Partition 3 size = 8 ("hijhklij").
Output: [9, 7, 8] ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
def partitionLabels(s: str) -> list[int]:
    """
    Partitions string such that each letter appears in at most one partition.
    """
    last = {c: i for i, c in enumerate(s)}
    res = []
    start = 0
    end = 0
    
    for i, c in enumerate(s):
        end = max(end, last[c])
        if i == end:
            res.append(end - start + 1)
            start = i + 1
            
    return res

⚡ Complexity analysis

  • Time Complexity: O(N). Two linear passes over string.
  • Space Complexity: O(1) space (at most 26 alphabet characters in hash map).
