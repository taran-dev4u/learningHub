#506 Relative Ranks EasyLeetCode

📋 The problem

Given scores, assign ranks with Gold/Silver/Bronze medals for the top three and numbers below.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given athlete scores, assign ranks: 1st is 'Gold Medal', 2nd is 'Silver Medal', 3rd is 'Bronze Medal', and 4th onwards are placement numbers ('4', '5'...). We need athletes sorted by score descending while placing ranks at their original indices. A max-heap of (-score, originalIndex) gives the top athletes in order.

🐢 Brute force first

Sort a copy of the array descending, look up the rank of each score using score_copy.index(score) + 1 → O(n^2).

💡 Key insight: push (-score[i], i) to a max-heap (or sort pairs in O(n log n)). Pop one by one: the 1st gets 'Gold Medal', 2nd 'Silver Medal', 3rd 'Bronze Medal', and remaining get str(rank) placed directly at result[i].

🪜 The approach, step by step

  1. Create result array res = [""] * len(score).
  2. Push (-score[i], i) into heap for each index.
  3. Pop in order: track rank = 1, 2, ....
  4. Assign 'Gold Medal', 'Silver Medal', 'Bronze Medal', or str(rank) to res[i].
  5. Return res.

🎞️ Visual dry run — score = [10, 3, 8, 9, 4]

Heap: [(-10, 0), (-9, 3), (-8, 2), (-4, 4), (-3, 1)]
Rank 1: score 10 (idx 0) → res[0] = "Gold Medal"
Rank 2: score 9 (idx 3)  → res[3] = "Silver Medal"
Rank 3: score 8 (idx 2)  → res[2] = "Bronze Medal"
Rank 4: score 4 (idx 4)  → res[4] = "4"
Rank 5: score 3 (idx 1)  → res[1] = "5"
Result: ["Gold Medal", "5", "Bronze Medal", "Silver Medal", "4"] ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
import heapq

def findRelativeRanks(score):
    n = len(score)
    res = [""] * n
    heap = [(-s, i) for i, s in enumerate(score)]
    heapq.heapify(heap)
    
    medals = {1: "Gold Medal", 2: "Silver Medal", 3: "Bronze Medal"}
    rank = 1
    
    while heap:
        _, idx = heapq.heappop(heap)
        res[idx] = medals.get(rank, str(rank))
        rank += 1
        
    return res

⏱️ Complexity

Time O(n log n) to heapify and pop all n elements. Space O(n) for the heap and result list.

⚠️ Edge cases

  • len(score) < 3: only available medals are assigned.
  • Single athlete: returns ["Gold Medal"].
