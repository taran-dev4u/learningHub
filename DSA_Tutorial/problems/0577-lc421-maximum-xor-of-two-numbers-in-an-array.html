#421 Maximum XOR of Two Numbers in an Array MediumLeetCode

 

Pattern: Trie / Prefix Tree Patterns › Subpattern 20.5: XOR Trie / Binary Trie · Problem 577 of 699

📋 The problem

Return the maximum XOR obtainable from any two numbers in an array, faster than O(n²).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an integer array nums, return the maximum result of nums[i] XOR nums[j] where $0 \le i \le j < n$. Must run in $O(n)$ time.

Key Insights

A Binary Bitwise Trie: Each number has 31 bits ($0 \dots 30$). Insert all numbers into a Trie where branches are only $0$ and $1$. To maximize $x \oplus y$, for each bit of $x$ (from most significant bit 30 down to 0): We greedily want the opposite bit $1 - bit$ to exist in the Trie! If $1 - bit$ exists, we move to that branch and set the corresponding bit in XOR sum to 1. Otherwise, we are forced to take the matching bit.

Python 3 Solution (Binary Trie - O(31 * N)) 
from typing import List

class TrieNode:
    __slots__ = ('children',)
    def __init__(self):
        self.children = [None, None]

class Solution:
    def findMaximumXOR(self, nums: List[int]) -> int:
        root = TrieNode()
        
        # 1. Insert all numbers into 31-bit Trie
        for num in nums:
            curr = root
            for bit_pos in range(30, -1, -1):
                bit = (num >> bit_pos) & 1
                if not curr.children[bit]:
                    curr.children[bit] = TrieNode()
                curr = curr.children[bit]
                
        # 2. Greedily find max XOR partner
        max_xor = 0
        for num in nums:
            curr = root
            curr_xor = 0
            for bit_pos in range(30, -1, -1):
                bit = (num >> bit_pos) & 1
                opp_bit = 1 - bit
                if curr.children[opp_bit]:
                    curr_xor |= (1 << bit_pos)
                    curr = curr.children[opp_bit]
                else:
                    curr = curr.children[bit]
            max_xor = max(max_xor, curr_xor)
            
        return max_xor

Complexity & Edge Cases

  • Time Complexity: $O(31 imes N) = O(N)$ strictly linear time.
  • Space Complexity: $O(31 imes N)$ nodes.
