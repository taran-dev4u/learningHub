📋 The problem

Return the k-th largest element in an unsorted array (not the k-th distinct).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You need the kth largest element in an unsorted array. Sorting the entire array is O(n log n), which wastes work sorting the remaining n - k elements. Instead, think: what data structure can maintain the top k candidates dynamically? A min-heap of size k: the smallest of the top-k sits at the root. Any number bigger than the root replaces it.

🐢 Brute force first

Sort the array in descending order and return the element at index k - 1.

def findKthLargest(nums, k):
    nums.sort(reverse=True)
    return nums[k - 1]

Time O(n log n), Space O(1) or O(n) depending on sort implementation.

💡 Key insight: keep a min-heap of size k. As you scan, push each element; when the heap size exceeds k, pop the minimum. After processing all n elements, the heap contains the k largest elements, and the root is the kth largest. Alternatively, Quickselect achieves O(n) average time.

🪜 The approach, step by step

  1. Initialize an empty min-heap h = [].
  2. Iterate through each number x in nums:
  3. Push x onto h. If len(h) > k, pop the smallest element via heappop(h).
  4. At the end, return h[0] (the root of the min-heap).

🎞️ Visual dry run — nums = [3, 2, 1, 5, 6, 4], k = 2

x=3  → heap [3] (size 1 <= 2)
x=2  → heap [2, 3] (size 2 <= 2)
x=1  → push 1 → [1, 3, 2], size 3 > 2 → pop 1 → heap [2, 3]
x=5  → push 5 → [2, 3, 5], size 3 > 2 → pop 2 → heap [3, 5]
x=6  → push 6 → [3, 5, 6], size 3 > 2 → pop 3 → heap [5, 6]
x=4  → push 4 → [4, 6, 5], size 3 > 2 → pop 4 → heap [5, 6]
Result: h[0] = 5 ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
import heapq

def findKthLargest(nums, k):
    # Maintain a min-heap of the k largest elements seen so far
    heap = []
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:
            heapq.heappop(heap)   # discard the smallest among the top k+1
    return heap[0]                # the root is the kth largest element

⏱️ Complexity

Time O(n log k) — processing n elements with heap operations of size at most k+1. Space O(k) — to store k elements in the heap.

⚠️ Edge cases

  • k = 1: returns the maximum element.
  • k = len(nums): returns the minimum element.
  • Duplicate elements: handled naturally since the heap allows duplicates.
  • Negative numbers: heap comparison operates directly on integer values.

🐛 Common mistakes

  • Using a max-heap of size n instead of a min-heap of size k, which uses O(n) space and O(n + k log n) time.
  • Popping when len(heap) == k instead of after pushing the (k+1)th element.

🔁 Variations & follow-ups

  • Kth Smallest Element: maintain a max-heap of size k (or invert values in Python).
  • Streaming Kth Largest (#703): where numbers arrive one by one.
  • Quickselect approach: partition around a pivot for O(n) average time complexity.
