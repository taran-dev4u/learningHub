📋 The problem

Classic binary search: find a target's index in a sorted array, or -1, in O(log n).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an array of integers nums sorted in ascending order and a target value, find whether the target exists. If it exists, return its index; otherwise return -1. Because the array is sorted, comparing the middle element with the target immediately eliminates half the remaining search space.

🐢 Brute force first

Scan linearly from index 0 to n-1 with a simple loop. Time: O(n), Space: O(1). Suboptimal because it ignores the sorted order property entirely.

💡 Key insight: Maintain a search window [left, right]. Compute mid mid = left + (right - left) // 2. If nums[mid] == target, we're done. If nums[mid] < target, target must lie in the right half, so left = mid + 1. If nums[mid] > target, target must lie in the left half, so right = mid - 1. Loop terminates when left > right.

🪜 The approach, step by step

  1. Initialize left = 0 and right = len(nums) - 1.
  2. While left <= right:
  3. Compute safe midpoint: mid = left + (right - left) // 2 (avoids 32-bit integer overflow in languages like C++/Java).
  4. If nums[mid] == target, return mid.
  5. If nums[mid] < target, eliminate left half: left = mid + 1.
  6. Else, eliminate right half: right = mid - 1.
  7. If the loop terminates without finding target, return -1.

🎞️ Visual dry run — nums = [-1, 0, 3, 5, 9, 12], target = 9

        mid = 3 + (5 - 3) // 2 = 4 → nums[4] = 9

✅ The solution

Reveal the commented solution (attempt it first!) 
def search(nums, target):
    """
    Classic iterative binary search with closed interval [left, right].
    """
    left, right = 0, len(nums) - 1
    
    while left <= right:
        mid = left + (right - left) // 2
        
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
            
    return -1

⏱️ Complexity

Time O(log n) — The search space is halved every iteration. Space O(1) — Iterative implementation uses only two boundary pointers.

⚠️ Edge cases

  • Array of size 1: target present or absent.
  • Target smaller than all elements or larger than all elements.
  • Negative values and zeros handled naturally without type casting.
