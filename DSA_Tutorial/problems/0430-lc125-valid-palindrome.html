📋 The problem

Decide whether a string is a palindrome when you keep only letters and digits and ignore case.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

A phrase is a palindrome if, after converting all uppercase letters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward.

Use two pointers: left = 0 and right = len(s) - 1. Advance left past non-alphanumeric characters (not s[left].isalnum()). Advance right past non-alphanumeric characters (not s[right].isalnum()). Compare lowercased characters: if s[left].lower() != s[right].lower(), return False immediately. Repeat until pointers cross!

🐢 Brute force vs optimal

Creating a cleaned filtered string takes $O(n)$ extra memory. Converging two pointers runs in-place with $O(1)$ auxiliary space.

💡 Key insight: Converge two pointers skipping non-alphanumerics via isalnum(). Compare s[l].lower() == s[r].lower() in $O(1)$ space.

✅ The solution

Reveal the commented solution (attempt it first!) 
def isPalindrome(s: str) -> bool:
    l, r = 0, len(s) - 1
    
    while l < r:
        while l < r and not s[l].isalnum():
            l += 1
        while l < r and not s[r].isalnum():
            r -= 1
            
        if s[l].lower() != s[r].lower():
            return False
            
        l += 1
        r -= 1
        
    return True

Complexity

Time: $O(n)$ — Single pass inward.
Space: $O(1)$ — Two integer index pointers.
