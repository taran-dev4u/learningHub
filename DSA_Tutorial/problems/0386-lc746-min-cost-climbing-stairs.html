#746 Min Cost Climbing Stairs Easy★NCLeetCode

📋 The problem

Each stair has a cost; you may start at step 0 or 1 and climb 1–2 steps; reach the top with minimum total cost.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an integer array cost where cost[i] is the cost of i-th step on a staircase. Once you pay the cost, you can either climb one or two steps. You can start from step 0 or step 1. Return the minimum cost to reach the top floor (index n).

To stand on step i, you must have stepped from either i - 1 or i - 2. Therefore, the cost to reach step i is: $$dp[i] = \min(dp[i - 1] + cost[i - 1], \; dp[i - 2] + cost[i - 2])$$

🐢 Brute force vs optimal

Exploring both 1-step and 2-step choices recursively yields an $O(2^n)$ recurrence tree. Since subproblems overlap, we memoize or tabulate. Moreover, step i only depends on dp[i - 1] and dp[i - 2], so two variables suffice for $O(1)$ auxiliary space.

💡 Key insight: Define dp1 and dp2 as the minimum cost to arrive at the current and previous steps. At each index, transition via curr = min(dp1 + cost[i - 1], dp2 + cost[i - 2]).

✅ The solution

Reveal the commented solution (attempt it first!) 
def minCostClimbingStairs(cost: list[int]) -> int:
    """
    Computes min cost to reach top floor using rolling DP.
    """
    # dp1: cost to reach step 1, dp2: cost to reach step 0
    dp2, dp1 = 0, 0
    for i in range(2, len(cost) + 1):
        curr = min(dp1 + cost[i - 1], dp2 + cost[i - 2])
        dp2, dp1 = dp1, curr
    return dp1

Complexity

Time: $O(n)$ — Single pass through the array.
Space: $O(1)$ — Only two rolling variables.
