📋 The problem

Given prerequisites, return any valid order to take all courses, or an empty list if impossible.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given numCourses and array prerequisites, return the ordering of courses you should take to finish all courses. If there are many valid answers, return any of them. If it is impossible to finish all courses, return an empty array.

🐢 Brute force first

Kahn's algorithm produces the exact valid topological ordering as courses are dequeued!

💡 Key insight: Extend Kahn's algorithm: as each course with in_degree == 0 is popped from the queue, append it to an order list. If len(order) == numCourses, return order; otherwise a cycle exists, return []!

🪜 The approach, step by step

  1. Construct graph and in_degree array.
  2. Enqueue all nodes with in_degree == 0.
  3. Initialize order = [].
  4. While queue:
    • u = queue.popleft().
    • order.append(u).
    • For v in graph[u]: in_degree[v] -= 1; if in_degree[v] == 0, queue.append(v).
  5. Return order if len(order) == numCourses else [].

✅ The solution

from collections import deque, defaultdict

def findOrder(numCourses, prerequisites):
    graph = defaultdict(list)
    in_degree = [0] * numCourses
    
    for dest, src in prerequisites:
        graph[src].append(dest)
        in_degree[dest] += 1
        
    queue = deque([i for i in range(numCourses) if in_degree[i] == 0])
    order = []
    
    while queue:
        course = queue.popleft()
        order.append(course)
        
        for neighbor in graph[course]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)
                
    return order if len(order) == numCourses else []

⏱️ Complexity

Time O(V + E). Space O(V + E).

⚠️ Edge cases

  • Cycle exists: returns empty list [].
  • Disconnected components: processes all independent subgraphs correctly.
