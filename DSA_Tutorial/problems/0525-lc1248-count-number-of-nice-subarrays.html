📋 The problem

Count the subarrays containing exactly k odd numbers ('nice' subarrays).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an array of integers nums and an integer k. A continuous subarray is called nice if there are k odd numbers on it. Return the number of nice sub-arrays.

Map each number to: - 1 if odd (x % 2 == 1). - 0 if even (x % 2 == 0). The problem transforms identically to Binary Subarrays With Sum (LC 930) with goal = k! $$ ext{Exact}(k) = ext{atMost}(k) - ext{atMost}(k - 1)$$

🐢 Brute force vs optimal

Sliding window with "at most" reduction executes in $O(n)$ time and $O(1)$ space.

💡 Key insight: Replace odd numbers with 1 and evens with 0. Subarrays with exactly $k$ odds $= ext{atMost}(k) - ext{atMost}(k - 1)$ in $O(1)$ space!

✅ The solution

Reveal the commented solution (attempt it first!) 
def numberOfSubarrays(nums: list[int], k: int) -> int:
    def at_most(target):
        if target < 0:
            return 0
        l = 0
        odds = 0
        count = 0
        for r in range(len(nums)):
            odds += nums[r] % 2
            while odds > target:
                odds -= nums[l] % 2
                l += 1
            count += r - l + 1
        return count
        
    return at_most(k) - at_most(k - 1)

Complexity

Time: $O(n)$ — Two linear scans.
Space: $O(1)$ — Only pointer variables.
