📋 The problem

Versions after the first bad one are all bad; using an isBadVersion API, find the first bad version with minimal calls.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Suppose you have n versions [1, 2, ..., n] and you want to find out the first bad one, which causes all following ones to be bad. You are given an API isBadVersion(version) which returns whether version is bad. Minimize calls to the API.

🐢 Brute force first

Call isBadVersion(i) for i = 1, 2, ... n. First one returning True is the answer. Takes O(n) API calls.

💡 Key insight: The versions form a monotonic predicate sequence: [False, False, ..., False, True, True, ..., True]. We need to find the boundary index where isBadVersion turns from False to True. This is a classic binary search on a condition function!

🪜 The approach, step by step

  1. Initialize left = 1, right = n.
  2. While left < right:
  3. Compute mid = left + (right - left) // 2.
  4. If isBadVersion(mid) == True: mid could be the first bad version or a later bad version. The first bad version must be at mid or to its left: right = mid.
  5. Else (False): mid and all versions before it are good: left = mid + 1.
  6. When left == right, the search space has converged to the exact first bad version. Return left.

🎞️ Visual dry run — n = 5, bad = 4

Versions: [1:F, 2:F, 3:F, 4:T, 5:T]
Iter 1: left = 1, right = 5 → mid = 3 → isBad(3) = False → left = 4
Iter 2: left = 4, right = 5 → mid = 4 → isBad(4) = True → right = 4
left == right == 4. Loop terminates.
Return 4. (Only 2 API calls instead of 4). ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
def firstBadVersion(n):
    """
    Binary search for transition boundary: False -> True.
    Note the loop condition left < right and right = mid.
    """
    left, right = 1, n
    
    while left < right:
        mid = left + (right - left) // 2
        if isBadVersion(mid):
            right = mid      # mid could be first bad version
        else:
            left = mid + 1   # mid is definitely good
            
    return left

⏱️ Complexity

Time O(log n) — Halves the remaining versions each step. Space O(1).

⚠️ Edge cases

  • n = 1: loop terminates immediately, returns 1 with 0 API calls.
  • First version is bad (bad = 1): right collapses down to 1.
  • Last version is bad (bad = n): left advances up to n.
