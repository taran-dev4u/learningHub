📋 The problem

Pick at most k engineers maximizing (sum of speeds) × (minimum efficiency) — sort by efficiency, min-heap of speeds.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given n engineers with speeds and efficiencies, choose at most k engineers to maximize performance: sum(speed) * min(efficiency). Since performance is bounded by the minimum efficiency, if we fix an engineer as the bottleneck efficiency, we should greedily pick the fastest engineers whose efficiencies are >= this bottleneck.

🐢 Brute force first

Examine all subsets of size up to k → combinatorial explosion.

💡 Key insight: sort engineers by efficiency descending. For each engineer, consider them as the minimum efficiency. Maintain a min-heap of speeds of size at most k. If heap exceeds k, pop the smallest speed. Track the maximum speed_sum * efficiency.

🪜 The approach, step by step

  1. Sort engineers by efficiency descending: engineers = sorted(zip(efficiency, speed), reverse=True).
  2. Initialize min-heap speed_heap = [], speed_sum = 0, max_perf = 0.
  3. For each eff, spd in engineers:
  4. Push spd to heap, add spd to speed_sum.
  5. If len(speed_heap) > k: speed_sum -= heappop(speed_heap).
  6. Update max_perf = max(max_perf, speed_sum * eff).
  7. Return max_perf % (10^9 + 7).

✅ The solution

import heapq

def maxPerformance(n, speed, efficiency, k):
    # Sort engineers by efficiency descending
    engineers = sorted(zip(efficiency, speed), reverse=True)
    
    speed_heap = []   # min-heap storing speeds of chosen engineers
    speed_sum = 0
    max_perf = 0
    MOD = 10**9 + 7
    
    for eff, spd in engineers:
        heapq.heappush(speed_heap, spd)
        speed_sum += spd
        
        # Keep at most k engineers (discard the slowest)
        if len(speed_heap) > k:
            speed_sum -= heapq.heappop(speed_heap)
            
        max_perf = max(max_perf, speed_sum * eff)
        
    return max_perf % MOD

⏱️ Complexity

Time O(n log n) — sorting takes O(n log n), plus n heap operations of size k (O(n log k)). Space O(n) for sorted engineers and heap.

⚠️ Edge cases

  • k = 1: simply finds max speed[i] * efficiency[i].
  • Modulo arithmetic: apply modulo only at the very end to prevent intermediate precision comparison bugs.
