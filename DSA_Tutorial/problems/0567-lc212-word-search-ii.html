📋 The problem

Given a letter grid and a word list, return every word that can be traced through adjacent cells without reusing a cell.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an $m imes n$ board of characters and a list of strings words, return all words on the board. Each word must be constructed from letters of sequentially adjacent cells (horizontally or vertically neighboring). The same letter cell may not be used more than once in a word.

Key Insights

Running individual DFS for each word from every cell takes $O(W imes M imes N imes 4^L)$, which will TLE.

Optimal Trie + Simultaneous DFS Backtracking:

  1. Build a Trie containing all words. Store the entire word string node.word = word at the terminal node for $O(1)$ result collection.
  2. Start DFS from every cell $(r, c)$. As we walk the grid, walk the Trie simultaneously!
  3. Pruning (Crucial optimization): When a word is found, set node.word = None so it is not added again. If a node has no remaining children, prune it from its parent's children dict to prevent re-traversing dead branches!

Python 3 Solution (Trie + In-Place Backtracking + Pruning) 
from typing import List

class TrieNode:
    def __init__(self):
        self.children = {}
        self.word = None

class Solution:
    def findWords(self, board: List[List[str]], words: List[str]) -> List[str]:
        root = TrieNode()
        for w in words:
            curr = root
            for ch in w:
                if ch not in curr.children:
                    curr.children[ch] = TrieNode()
                curr = curr.children[ch]
            curr.word = w

        R, C = len(board), len(board[0])
        result = []

        def dfs(r: int, c: int, parent: TrieNode):
            ch = board[r][c]
            curr = parent.children.get(ch)
            if not curr:
                return

            if curr.word:
                result.append(curr.word)
                curr.word = None  # Avoid duplicates

            # Backtrack marker
            board[r][c] = '#'
            for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < R and 0 <= nc < C and board[nr][nc] != '#':
                    dfs(nr, nc, curr)
            board[r][c] = ch

            # Trie leaf pruning
            if not curr.children:
                del parent.children[ch]

        for r in range(R):
            for c in range(C):
                if board[r][c] in root.children:
                    dfs(r, c, root)

        return result

Complexity & Edge Cases

  • Time Complexity: $O(M imes N imes 4^L)$ bounded heavily by Trie pruning.
  • Space Complexity: $O(\sum |w|)$ for Trie nodes.
