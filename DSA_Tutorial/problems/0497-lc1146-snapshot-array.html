📋 The problem

Design an array supporting set, snap (snapshot), and get(index, snap_id) — value at a past snapshot (per-index history + bisect).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Implement a SnapshotArray that supports pre-allocating an array of length length, taking snap() which returns snapshot id, set(index, val), and get(index, snap_id).

Do NOT copy the entire array of size 50,000 on every snapshot ($O(N \times S)$ would memory limit exceed!). Instead, maintain history per index: history[index] = [(snap_id, val)]

- snap(): simply increments a global integer counter curr_snap_id += 1 in $O(1)$! - set(index, val): append (curr_snap_id, val) to history[index]. - get(index, snap_id): run binary search (bisect_right) on history[index] to find the latest value recorded at or before snap_id in $O(\log S)$!

🐢 Brute force vs optimal

Copying the array on snapshot takes $O(N)$ time and space per snapshot. Per-index version lists take $O(1)$ for snap and $O(\log S)$ for get.

💡 Key insight: Version history per cell: history[idx].append((snap_id, val)). Binary search finds state at any past snapshot in $O(\log S)$ time.

✅ The solution

import bisect

class SnapshotArray:
    def __init__(self, length: int):
        self.snap_id = 0
        # For each index: list of (snap_id, val)
        self.history = [[(0, 0)] for _ in range(length)]

    def set(self, index: int, val: int) -> None:
        if self.history[index][-1][0] == self.snap_id:
            # Overwrite value in current active snapshot
            self.history[index][-1] = (self.snap_id, val)
        else:
            self.history[index].append((self.snap_id, val))

    def snap(self) -> int:
        self.snap_id += 1
        return self.snap_id - 1

    def get(self, index: int, snap_id: int) -> int:
        hist = self.history[index]
        # Binary search for rightmost entry with recorded_snap <= query snap_id
        idx = bisect.bisect_right(hist, (snap_id, float('inf'))) - 1
        return hist[idx][1]

Complexity

Time: set: $O(1)$. snap: $O(1)$. get: $O(\log S)$ where $S$ is mutations per index.
Space: $O(N + ext{Total Sets})$ — Only modified cells consume memory.
