📋 The problem

Given a list of words sorted by an unknown alphabet, recover a valid letter ordering of that alphabet (or report contradiction).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There is a new alien language that uses the English alphabet. However, the order of the letters is unknown to you. You are given a list of strings words from the alien language dictionary, where the words are claimed to be sorted lexicographically by the rules of this language. Derive the order of letters in this language. If the order is invalid, return "". If there are multiple valid orders, return any of them.

This is the definitive interview problem for Topological Sort on a Directed Acyclic Graph (DAG) using Kahn's Algorithm.

🐢 Brute force vs optimal

Each pair of adjacent words provides a relative ordering constraint between two characters. Comparing every word with every other word takes O(W^2), but because the dictionary is already sorted, we only need to compare adjacent words words[i] and words[i+1] in O(W × L) where L is maximum word length.

💡 Key insight:
  1. Edge Extraction: For adjacent words w1 and w2: find the first index j where w1[j] != w2[j]. This tells us w1[j] must come before w2[j] → directed edge w1[j] → w2[j], and increment in_degree[w2[j]] += 1.
  2. Prefix Invalidity Trap: If len(w1) > len(w2) and w1.startswith(w2) (e.g. ["apple", "app"]), the dictionary is invalid! In any valid lexicographical order, a prefix must come before its longer version. Return "" immediately!
  3. Topological BFS: Push all characters with in_degree == 0 into a queue. Pop and append to result string, decrementing neighbors' in-degrees. If the final string length equals the number of unique characters, return it; otherwise a cycle exists (e.g. a → b → a), so return "".

🪜 The approach, step by step

  1. Initialize adj = {c: set() for word in words for c in word} and in_degree = {c: 0 for c in adj}.
  2. For i from 0 to len(words) - 2:
    • w1, w2 = words[i], words[i+1].
    • If len(w1) > len(w2) and w1.startswith(w2): return "".
    • Find first differing index j:
      • If w2[j] not in adj[w1[j]]: add w2[j] to adj[w1[j]] and increment in_degree[w2[j]] += 1.
      • Break (subsequent characters give no ordering information).
  3. Queue q = deque([c for c, deg in in_degree.items() if deg == 0]).
  4. While q:
    • Pop c, append to order.
    • For neighbor nxt in adj[c]:
      • in_degree[nxt] -= 1.
      • If in_degree[nxt] == 0: push nxt to q.
  5. Return "".join(order) if len(order) == len(in_degree) else "".

✅ The solution

Python 3 — Kahn's Algorithm (Topological Sort) 
from collections import deque

def alienOrder(words: list[str]) -> str:
    """
    Derives alien alphabet ordering using Kahn's topological sort algorithm.
    """
    # 1. Initialize graph and in-degree maps for all unique characters
    adj = {c: set() for word in words for c in word}
    in_degree = {c: 0 for c in adj}
    
    # 2. Build graph from adjacent word comparisons
    for i in range(len(words) - 1):
        w1, w2 = words[i], words[i + 1]
        min_len = min(len(w1), len(w2))
        
        # Check invalid prefix case: e.g. ["apple", "app"]
        if len(w1) > len(w2) and w1[:min_len] == w2[:min_len]:
            return ""
            
        for j in range(min_len):
            if w1[j] != w2[j]:
                if w2[j] not in adj[w1[j]]:
                    adj[w1[j]].add(w2[j])
                    in_degree[w2[j]] += 1
                break  # Only first differing character determines order
                
    # 3. BFS with queue of characters with in-degree == 0
    q = deque([c for c, deg in in_degree.items() if deg == 0])
    order = []
    
    while q:
        c = q.popleft()
        order.append(c)
        for neighbor in adj[c]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                q.append(neighbor)
                
    # 4. If order length equals unique characters, valid DAG; else cycle exists
    return "".join(order) if len(order) == len(in_degree) else ""

⚡ Complexity analysis

  • Time Complexity: O(C) where C is the total length of all words in the input. Extracting edges examines each character at most once. Topological sort visits at most 26 vertices and edges.
  • Space Complexity: O(1) or O(U + min(U^2, N)) where U ≤ 26 is the alphabet size. Storage is bounded by at most 26 nodes.

🚨 Edge cases to watch out for

  • Prefix anomaly: ["abc", "ab"] → must return "".
  • Cycles: ["z", "x", "z"] → z → x and x → z → cycle detected, returns "".
  • Single character or single word: Returns the character(s) in any valid order.
