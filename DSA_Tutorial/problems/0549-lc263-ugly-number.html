📋 The problem

Decide whether a number's only prime factors are 2, 3, and 5.

Problem Overview

An ugly number is a positive integer whose prime factors are limited to 2, 3, and 5. Given an integer {2, 3, 5}n{2, 3, 5}, return true if {2, 3, 5}n{2, 3, 5} is an ugly number, and false otherwise.

Key Insights

If {2, 3, 5}n \le 0{2, 3, 5}, it cannot be ugly (ugly numbers are positive by definition). Repeatedly divide {2, 3, 5}n{2, 3, 5} by 2, 3, and 5 while it is divisible. If the resulting value is 1, all prime factors were in {2, 3, 5}{2, 3, 5}{2, 3, 5}.

Python 3 Solution (Click to Expand) 
class Solution:
    def isUgly(self, n: int) -> bool:
        if n <= 0:
            return False
            
        for factor in (2, 3, 5):
            while n % factor == 0:
                n //= factor
                
        return n == 1

Complexity & Edge Cases

  • Time Complexity: {2, 3, 5}O(\log n){2, 3, 5}.
  • Space Complexity: {2, 3, 5}O(1){2, 3, 5}.
  • Edge Cases: {2, 3, 5}n \le 0{2, 3, 5} (negative and zero return False), {2, 3, 5}n = 1{2, 3, 5} (returns True).
