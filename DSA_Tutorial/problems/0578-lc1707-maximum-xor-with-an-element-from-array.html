#1707 Maximum XOR With an Element From Array HardLeetCode

📋 The problem

For each query (x, m), return the maximum x XOR element among array values ≤ m (offline sort + bit trie).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an array nums and queries where queries[i] = [xi, mi], the answer is the maximum bitwise XOR of $x_i$ with any element in nums that is $\le m_i$. If no such element exists, answer is -1.

Key Insights

Offline Query Processing + Binary Trie: Sort nums ascending. Sort queries by $m_i$ ascending while preserving original query indices: queries_sorted = sorted(enumerate(queries), key=lambda q: q[1][1]). As we process queries in increasing order of $m_i$, insert elements from nums that are $\le m_i$ into the Binary Trie incrementally! Query the Trie greedily using the standard $O(31)$ max XOR lookup.

Python 3 Solution (Offline Queries + Binary Trie) 
from typing import List

class TrieNode:
    __slots__ = ('children',)
    def __init__(self):
        self.children = [None, None]

class Solution:
    def maximizeXor(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        nums.sort()
        # queries with original index: (orig_idx, x, m)
        q_sorted = sorted([(i, q[0], q[1]) for i, q in enumerate(queries)], key=lambda item: item[2])
        
        root = TrieNode()
        ans = [-1] * len(queries)
        num_idx = 0
        n = len(nums)
        
        def insert(val: int):
            curr = root
            for bit_pos in range(30, -1, -1):
                bit = (val >> bit_pos) & 1
                if not curr.children[bit]:
                    curr.children[bit] = TrieNode()
                curr = curr.children[bit]
                
        def query_max_xor(x: int) -> int:
            if not root.children[0] and not root.children[1]:
                return -1
            curr = root
            res = 0
            for bit_pos in range(30, -1, -1):
                bit = (x >> bit_pos) & 1
                opp_bit = 1 - bit
                if curr.children[opp_bit]:
                    res |= (1 << bit_pos)
                    curr = curr.children[opp_bit]
                else:
                    curr = curr.children[bit]
            return res

        for orig_idx, x, m in q_sorted:
            while num_idx < n and nums[num_idx] <= m:
                insert(nums[num_idx])
                num_idx += 1
            ans[orig_idx] = query_max_xor(x)
            
        return ans

Complexity & Edge Cases

  • Time Complexity: $O(N \log N + Q \log Q + 31 imes (N + Q))$.
  • Space Complexity: $O(31 imes N)$ Trie nodes + $O(Q)$ results.
  • Edge Cases: No elements $\le m_i$ in nums (returns -1).
