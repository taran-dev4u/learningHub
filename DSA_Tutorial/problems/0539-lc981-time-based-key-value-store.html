📋 The problem

Design a key-value store where set stamps a timestamp and get(key, t) returns the value set at the latest time ≤ t.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Design a time-based key-value data structure that can store multiple values for the same key at different time stamps and retrieve the key's value at a certain timestamp.

  • set(key, value, timestamp): Stores the key and value along with the given timestamp. Timestamps are strictly increasing.
  • get(key, timestamp): Returns a value such that set was called previously with timestamp_prev <= timestamp. If multiple, return the largest timestamp; if none, return "".

Key Insights

Because timestamps for each key are added in strictly increasing order, the list of (timestamp, value) pairs for any key is already sorted! We can use Binary Search (bisect_right) to find the rightmost timestamp $\le$ the requested query timestamp in $O(\log N)$ time.

Python 3 Solution (Click to Expand) 
from collections import defaultdict
import bisect

class TimeMap:
    def __init__(self):
        # key -> list of (timestamp, value)
        self.store = defaultdict(list)

    def set(self, key: str, value: str, timestamp: int) -> None:
        self.store[key].append((timestamp, value))

    def get(self, key: str, timestamp: int) -> str:
        if key not in self.store:
            return ""
        entries = self.store[key]
        # Binary search for rightmost entry with entry[0] <= timestamp
        idx = bisect.bisect_right(entries, (timestamp, chr(127)))
        if idx == 0:
            return ""
        return entries[idx - 1][1]

Complexity & Edge Cases

  • Time Complexity:
    • set: $O(1)$ append.
    • get: $O(\log M)$ where $M$ is the number of timestamps for the given key.
  • Space Complexity: $O(N)$ total elements stored across all keys.
  • Edge Cases: Query timestamp smaller than any stored timestamp for the key (returns "").
