📋 The problem

Partition intervals into the fewest groups so no group has overlaps (sweep line peak = answer).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an array intervals, divide the intervals into one or more groups such that each interval is in exactly one group, and no two intervals in the same group intersect. Return the minimum number of groups required.

Key Insights

By Dilworth's theorem and interval scheduling theory, the minimum number of non-overlapping groups required is equal to the maximum number of mutually overlapping intervals at any point in time! This is mathematically identical to Meeting Rooms II (LC 253), except here intervals are inclusive $[left, right]$, so an interval ending at $t$ overlaps with one starting at $t$. Events: $(start, +1)$ and $(end + 1, -1)$. Sort events and track running prefix sum!

Python 3 Solution (Line Sweep with Event Deltas) 
from typing import List
from collections import defaultdict

class Solution:
    def minGroups(self, intervals: List[List[int]]) -> int:
        events = defaultdict(int)
        for s, e in intervals:
            events[s] += 1
            events[e + 1] -= 1  # end is inclusive, freed at e + 1
            
        max_groups = curr = 0
        for t in sorted(events.keys()):
            curr += events[t]
            max_groups = max(max_groups, curr)
            
        return max_groups

Complexity & Edge Cases

  • Time Complexity: $O(N \log N)$ event sorting.
  • Space Complexity: $O(N)$ event map.
