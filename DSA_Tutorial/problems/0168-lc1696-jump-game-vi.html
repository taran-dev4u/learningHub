Pattern: Sliding Window Patterns › Subpattern 5.3: Monotonic Queue for Max/Min · Problem 168 of 707

📋 The problem

Jump forward up to k steps, scoring each landing value; maximize the score reaching the end (DP + sliding-window max).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Monotonic Queue for Max/Min — A deque of indices keeps candidates in monotonic order — answers 'max in window' in O(n).

Why this pattern?

  • "contiguous subarray / substring" + longest/shortest/max/min/count
  • fixed size k ("every window of size k")
  • a constraint to maintain: "at most k distinct", "no repeats", "sum ≥ target"
  • strings + character frequency ("anagram of", "contains all chars of")

Pattern template to adapt

Start from the Sliding Window master template and adapt the marked parts to this problem:

# Variable-size window (the general form)
state = {}                              # counts / sum — whatever the constraint needs
left = 0
best = 0
for right in range(len(s)):
    add(s[right], state)                # 1) window grows
    while invalid(state):               # 2) shrink until constraint holds again
        remove(s[left], state)
        left += 1
    best = max(best, right - left + 1)  # 3) window is valid here
