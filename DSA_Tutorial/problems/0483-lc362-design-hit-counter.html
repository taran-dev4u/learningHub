📋 The problem

Design a hit counter that records hits and reports how many occurred in the past 5 minutes.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a hit counter which counts the number of hits received in the past 5 minutes (300 seconds).

The Circular Array / Bucketing Pattern (Fixed Memory): Instead of keeping a growing list or queue of all raw hits ($O(N)$ space if millions of hits occur in 5 minutes): Maintain a fixed circular array of size 300! - times = [0] * 300: stores the timestamp mod 300. - hits = [0] * 300: stores the hit count for that specific second.

When hit(timestamp) is called: Let idx = timestamp % 300. - If times[idx] != timestamp: reset times[idx] = timestamp and hits[idx] = 1. - Else: increment hits[idx] += 1.

When getHits(timestamp) is called: Iterate through all 300 buckets. If timestamp - times[i] < 300, sum hits[i]!

🐢 Brute force vs optimal

Storing all timestamps in a queue can explode memory under high QPS. The 300-bucket circular array consumes fixed $O(1)$ memory and executes in $O(1)$ time!

💡 Key insight: Circular buffer of 300 buckets: idx = timestamp % 300. Memory is strictly bounded to 300 integers regardless of whether there are 10 hits or 10 billion hits!

✅ The solution

Reveal the commented solution (attempt it first!) 
class HitCounter:
    def __init__(self):
        # 300 seconds in 5 minutes
        self.times = [0] * 300
        self.hits = [0] * 300

    def hit(self, timestamp: int) -> None:
        idx = timestamp % 300
        if self.times[idx] != timestamp:
            self.times[idx] = timestamp
            self.hits[idx] = 1
        else:
            self.hits[idx] += 1

    def getHits(self, timestamp: int) -> int:
        total = 0
        for i in range(300):
            if timestamp - self.times[i] < 300:
                total += self.hits[i]
        return total

Complexity

Time: hit: $O(1)$. getHits: $O(300) = O(1)$ fixed loop.
Space: $O(1)$ — Exactly 600 integers allocated permanently.
