📋 The problem

Given building rectangles on a skyline, return the key points that outline their combined silhouette.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

A city's skyline is the outer contour of the silhouette formed by all the buildings. Given buildings = [left, right, height], output the key points that characterize the skyline.

The Event-Driven Line Sweep Pattern: Every building creates two discrete events: 1. Start of building at $x = left$: pushes height $h$ into active buildings. 2. End of building at $x = right$: removes height $h$ from active buildings.

Sort all event boundaries along the x-axis: - For equal $x$ coordinates: - If both are starts: higher building comes first (process height descending). - If both are ends: lower building comes first (process height ascending). - If one is start and one is end: start comes first!

Maintain a Max-Heap of active heights (with lazy deletion). At each event $x$: - If current max height changes from previous max height: $$(x, \; ext{new\_max\_height})$$ is a critical key point on the skyline!

🐢 Brute force vs optimal

Evaluating height at every integer coordinate takes $O(W \times N)$ where $W$ is width. Line sweep with max-heap evaluates in $O(N \log N)$ time and $O(N)$ space.

💡 Key insight: Sweep vertical line left to right. Maintain active building heights in a Max-Heap with lazy deletion. Whenever the maximum height changes, record a keypoint $(x, max\_h)$!

import heapq
from collections import defaultdict

def getSkyline(buildings: list[list[int]]) -> list[list[int]]:
    # Events: (x, -height) for start, (x, height) for end
    events = []
    for l, r, h in buildings:
        events.append((l, -h, r)) # start event (stores end time r)
        events.append((r, 0, 0))   # end boundary trigger
        
    events.sort()
    
    # max_heap stores (-height, end_x)
    max_heap = [(0, float('inf'))]
    res = []
    prev_max_h = 0
    
    for x, neg_h, r in events:
        if neg_h < 0:
            heapq.heappush(max_heap, (neg_h, r))
            
        # Lazy garbage collection: pop buildings whose right boundary <= current x
        while max_heap and max_heap[0][1] <= x:
            heapq.heappop(max_heap)
            
        curr_max_h = -max_heap[0][0]
        if curr_max_h != prev_max_h:
            res.append([x, curr_max_h])
            prev_max_h = curr_max_h
            
    return res

Complexity

Time: $O(N \log N)$ — Sorting events and heap operations.
Space: $O(N)$ — Events list and max heap.
