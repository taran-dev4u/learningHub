📋 The problem

Insert a new interval into a sorted list of non-overlapping intervals, merging where needed.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

You are given an array of non-overlapping intervals sorted in ascending order by start time, and a new interval newInterval = [start, end]. Insert newInterval into intervals such that the list is still sorted in ascending order and non-overlapping (merge if necessary).

Key Insights

Because the input is already sorted, a three-phase linear scan solves it in $O(n)$ time:

  1. Phase 1 (Before): Append all intervals that end strictly before newInterval.start ($end_i < newInterval.start$).
  2. Phase 2 (Overlap & Merge): For all intervals that overlap with newInterval ($start_i \le newInterval.end$): $$newInterval.start = \min(newInterval.start, start_i)$$ $$newInterval.end = \max(newInterval.end, end_i)$$
  3. Phase 3 (After): Append the merged newInterval, then append all remaining intervals that start after newInterval.end.

Python 3 Solution (Three-Phase Linear Scan - O(N)) 
from typing import List

class Solution:
    def insert(self, intervals: List[List[int]], newInterval: List[int]) -> List[List[int]]:
        res = []
        i, n = 0, len(intervals)
        s, e = newInterval
        
        # 1. Add all intervals completely before newInterval
        while i < n and intervals[i][1] < s:
            res.append(intervals[i])
            i += 1
            
        # 2. Merge all overlapping intervals
        while i < n and intervals[i][0] <= e:
            s = min(s, intervals[i][0])
            e = max(e, intervals[i][1])
            i += 1
        res.append([s, e])
        
        # 3. Add all remaining intervals after newInterval
        while i < n:
            res.append(intervals[i])
            i += 1
            
        return res

Complexity & Edge Cases

  • Time Complexity: $O(n)$ single linear scan.
  • Space Complexity: $O(n)$ for output array.
  • Edge Cases: Empty intervals list (returns [newInterval]), newInterval placed at very beginning or very end without overlap.
