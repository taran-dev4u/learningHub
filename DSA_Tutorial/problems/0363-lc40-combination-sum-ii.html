📋 The problem

Given candidates that may repeat and a target, list all unique combinations summing to the target where each candidate is used at most once.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a collection of candidate numbers candidates (which may contain duplicates) and a target, find all unique combinations where candidate numbers sum to target. Each number in candidates may only be used once in the combination.

💡 Key insight: Sort candidates. Pass i + 1 into recursive call (each number used once). Prune duplicate sibling branches: if i > start and candidates[i] == candidates[i - 1]: continue.

def combinationSum2(candidates: list[int], target: int) -> list[list[int]]:
    """
    Finds unique combinations summing to target with single-use candidates and duplicates.
    """
    candidates.sort()
    res = []
    path = []
    n = len(candidates)
    
    def backtrack(start, remain):
        if remain == 0:
            res.append(list(path))
            return
            
        for i in range(start, n):
            if candidates[i] > remain:
                break
            if i > start and candidates[i] == candidates[i - 1]:
                continue  # Skip duplicate elements at same depth
                
            path.append(candidates[i])
            backtrack(i + 1, remain - candidates[i])
            path.pop()
            
    backtrack(0, target)
    return res

⚡ Complexity analysis

  • Time Complexity: O(2^N) in worst case.
  • Space Complexity: O(N).
