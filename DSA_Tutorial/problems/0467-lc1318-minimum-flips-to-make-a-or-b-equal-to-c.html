#1318 Minimum Flips to Make a OR b Equal to c MediumLeetCode

 

Pattern: Bit Manipulation Patterns › Subpattern 14.4: Bitwise Operations / Power of Two or Four Check · Problem 467 of 699

📋 The problem

Return the minimum bit flips in a and/or b so that a OR b equals c (per-bit case analysis).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given 3 positives numbers a, b and c. Return the minimum flips to make (a OR b == c). In one flip, you can change any single bit (from 1 to 0, or 0 to 1) in a or b.

Inspect bit by bit from $0$ to $31$: - Let $bit_a = (a >> i) \& 1$, $bit_b = (b >> i) \& 1$, $bit_c = (c >> i) \& 1$. - Case 1 ($bit_c == 1$): We need $(bit_a \lor bit_b) == 1$. If both $bit_a == 0$ and $bit_b == 0$, we need 1 flip (flip either $a$ or $b$ to 1). - Case 2 ($bit_c == 0$): We need $(bit_a \lor bit_b) == 0$. Both bits must be 0! If $bit_a == 1$, add 1 flip. If $bit_b == 1$, add 1 flip (up to 2 flips).

🐢 Brute force vs optimal

Loop runs exactly 32 times ($O(1)$ time and space).

💡 Key insight: If $c_i = 1$: flip $= 1$ only if both $a_i=0$ and $b_i=0$. If $c_i = 0$: flip $= a_i + b_i$ (both must be turned off).

✅ The solution

Reveal the commented solution (attempt it first!) 
def minFlips(a: int, b: int, c: int) -> int:
    flips = 0
    for i in range(32):
        bit_a = (a >> i) & 1
        bit_b = (b >> i) & 1
        bit_c = (c >> i) & 1
        
        if bit_c == 1:
            if bit_a == 0 and bit_b == 0:
                flips += 1
        else:
            flips += bit_a + bit_b
            
    return flips

Complexity

Time: $O(1)$ — 32 bit comparisons.
Space: $O(1)$ — Scalar counter.
