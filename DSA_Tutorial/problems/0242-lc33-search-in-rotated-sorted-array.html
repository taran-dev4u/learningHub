📋 The problem

A sorted array was rotated at an unknown pivot. Find the index of a target value in O(log n), or -1.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There is an integer array nums sorted in ascending order (with distinct values) that has been rotated at an unknown pivot index. Given the rotated array and a target, return its index if found, or -1 if not. Must be O(log n) time.

🐢 Brute force first

Linear scan over all elements takes O(n). To achieve O(log n), we must identify which half of the array is sorted at any given step.

💡 Key insight: If you divide a rotated sorted array in half at mid, at least one half is always strictly sorted! Check if nums[left] <= nums[mid]. If yes, the left half is sorted; otherwise the right half is sorted. Once you know which half is sorted, you can check if target falls inside its range in O(1) and discard the other half!

🪜 The approach, step by step

  1. Set left = 0, right = len(nums) - 1.
  2. While left <= right:
  3. Compute mid = left + (right - left) // 2.
  4. If nums[mid] == target, return mid.
  5. Check if left half is sorted: nums[left] <= nums[mid]:
  6.   If nums[left] <= target < nums[mid]: target is in the left half, so right = mid - 1.
  7.   Else: target must be in the right half, so left = mid + 1.
  8. Else (right half is sorted):
  9.   If nums[mid] < target <= nums[right]: target is in the right half, so left = mid + 1.
  10.   Else: target must be in the left half, so right = mid - 1.
  11. If not found, return -1.

🎞️ Visual dry run — nums = [4, 5, 6, 7, 0, 1, 2], target = 0

        Is 4 <= target(0) < 7? No!

        Is 0 <= target(0) < 1? Yes!
        Target is in left half → right = mid - 1 = 4

Iter 3: left = 4, right = 4 → mid = 4, nums[mid] = 0 == target!
        Match! Return 4. ✓

✅ The solution

def search(nums, target):
    """
    Binary search in rotated sorted array.
    Determine sorted half and check if target is within bounds.
    """
    left, right = 0, len(nums) - 1
    
    while left <= right:
        mid = left + (right - left) // 2
        
        if nums[mid] == target:
            return mid
            
        # Left half is sorted
        if nums[left] <= nums[mid]:
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        # Right half is sorted
        else:
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
                
    return -1

⏱️ Complexity

Time O(log n) — Search space halved at each step. Space O(1).

⚠️ Edge cases

  • Array not rotated (standard sorted array): handled identically.
  • Array of size 1 or 2.
  • Target at rotation pivot boundary.
