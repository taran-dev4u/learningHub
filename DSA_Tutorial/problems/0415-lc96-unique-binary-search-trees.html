📋 The problem

Count how many structurally unique binary search trees can store values 1..n.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer n, return the number of structurally unique BST's (binary search trees) which has exactly n nodes of unique values from 1 to n.

Let $G(n)$ be the number of unique BSTs for sequence of length $n$. For each root $i \in [1, n]$, there are $i - 1$ nodes in the left subtree and $n - i$ nodes in the right subtree: $$G(n) = \sum_{i=1}^n G(i - 1) \times G(n - i)$$ with base cases $G(0) = 1, G(1) = 1$. This is the mathematical recurrence for Catalan Numbers!

🐢 Brute force vs optimal

1D DP tabulates $G(0) \dots G(n)$ in $O(n^2)$ time. Alternatively, Catalan closed form $C_n = \frac{1}{n+1}\binom{2n}{n} = \frac{(2n)!}{(n+1)!n!}$ computes in $O(n)$ time and $O(1)$ space.

💡 Key insight: Closed-form iterative Catalan computation: $C_{i} = C_{i-1} \times \frac{2(2i - 1)}{i + 1}$ computes the exact answer in $O(n)$ time!

✅ The solution

Reveal the commented solution (attempt it first!) 
def numTrees(n: int) -> int:
    """
    Computes nth Catalan number in O(n) time and O(1) space.
    """
    c = 1
    for i in range(1, n + 1):
        c = c * 2 * (2 * i - 1) // (i + 1)
    return c

Complexity

Time: $O(n)$ — Single linear mathematical iteration.
Space: $O(1)$ — Single scalar accumulator.
