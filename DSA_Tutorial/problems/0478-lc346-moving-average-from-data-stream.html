📋 The problem

Design a class that returns the moving average of the last k values of a stream.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a stream of integers and a window size, calculate the moving average of all integers in the sliding window.

Maintain: - A FIFO circular queue or deque of maximum capacity $size$. - A running scalar total_sum.

When a new number $val$ arrives: 1. If the queue is at capacity, subtract the oldest element from total_sum and dequeue it: total_sum -= q.popleft(). 2. Add $val$ to total_sum and append to queue: total_sum += val; q.append(val). 3. Return total_sum / len(q) in $O(1)$!

🐢 Brute force vs optimal

Summing the window from scratch takes $O(k)$ time. Running accumulator updates in $O(1)$ time and $O(k)$ memory.

💡 Key insight: Sliding window accumulator: window_sum += val - (q.popleft() if full else 0). Average computes in $O(1)$ time.

✅ The solution

Reveal the commented solution (attempt it first!) 
from collections import deque

class MovingAverage:
    def __init__(self, size: int):
        self.size = size
        self.queue = deque()
        self.window_sum = 0

    def next(self, val: int) -> float:
        if len(self.queue) == self.size:
            self.window_sum -= self.queue.popleft()
            
        self.queue.append(val)
        self.window_sum += val
        return self.window_sum / len(self.queue)

Complexity

Time: $O(1)$ for each next() invocation.
Space: $O(k)$ where $k$ is the window size.
