📋 The problem

In a height grid, water flows to lower-or-equal neighbors; return cells from which water can reach both the top-left (Pacific) and bottom-right (Atlantic) borders.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There is an m x n rectangular island bordered by the Pacific Ocean (top and left edges) and the Atlantic Ocean (bottom and right edges). Water flows from cell to neighbor if the neighbor's height is less than or equal to the current cell's height. Find all grid coordinates where rain water can flow to both the Pacific and Atlantic oceans.

🐢 Brute force first

Run DFS from every cell to see if it can reach both oceans: O((m*n)^2). Flowing downhill from every cell causes massive duplicate work.

💡 Key insight: Reverse the flow! Instead of simulating water flowing downhill from every internal cell to the oceans, simulate water flowing uphill from the oceans into the island! 1. Start BFS/DFS from all Pacific boundary cells moving to neighbors with height >= current_height. Mark reachable in pacific set. 2. Start BFS/DFS from all Atlantic boundary cells moving uphill. Mark in atlantic set. 3. The intersection pacific & atlantic is the exact set of coordinates that can reach both oceans!

🪜 The approach, step by step

  1. Create two boolean sets: pacific = set() and atlantic = set().
  2. Helper dfs(r, c, visited):
    • Add (r, c) to visited.
    • For 4 neighbors (nr, nc): if in bounds, not in visited, and heights[nr][nc] >= heights[r][c] (uphill!), recurse dfs(nr, nc, visited).
  3. Run DFS for all Pacific border cells: top row r=0 and left col c=0.
  4. Run DFS for all Atlantic border cells: bottom row r=m-1 and right col c=n-1.
  5. Return list(pacific & atlantic).

✅ The solution

def pacificAtlantic(heights):
    if not heights or not heights[0]:
        return []
        
    m, n = len(heights), len(heights[0])
    pacific = set()
    atlantic = set()
    
    def dfs(r, c, visited):
        visited.add((r, c))
        for dr, dc in [(1, 0), (-1, 0), (0, 1), (0, -1)]:
            nr, nc = r + dr, c + dc
            if 0 <= nr < m and 0 <= nc < n and (nr, nc) not in visited:
                # Water flows uphill: neighbor must be >= current cell
                if heights[nr][nc] >= heights[r][c]:
                    dfs(nr, nc, visited)
                    
    # Pacific border: row 0 and col 0
    for r in range(m):
        dfs(r, 0, pacific)
    for c in range(n):
        dfs(0, c, pacific)
        
    # Atlantic border: row m-1 and col n-1
    for r in range(m):
        dfs(r, n - 1, atlantic)
    for c in range(n):
        dfs(m - 1, c, atlantic)
        
    return [list(coord) for coord in (pacific & atlantic)]

⏱️ Complexity

Time O(m * n) — Each cell is visited at most twice per ocean. Space O(m * n) for the two visited sets.

⚠️ Edge cases

  • 1x1 grid: cell touches both Pacific and Atlantic, returns [[0, 0]].
  • All cells equal height: every cell can reach both oceans.
