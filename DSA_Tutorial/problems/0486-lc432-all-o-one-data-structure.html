#432 All O`one Data Structure HardLeetCode

 

Pattern: Design Patterns › Subpattern 15.1: General / Specific Data Structure Design · Problem 486 of 699

This problem also appears under: Hash Map & Cache Design — same problem, different lens.

📋 The problem

Design a structure with inc(key), dec(key), getMaxKey(), getMinKey() — all O(1).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a data structure to store the strings' count with the ability to return the strings with minimum and maximum counts in $O(1)$ time complexity for all operations: inc, dec, getMaxKey, and getMinKey!

Doubly Linked List of Buckets + Hash Maps: 1. Each BucketNode represents a distinct count value (e.g. count = 1, 2, 5...) and holds: - count: integer value. - keys: a hash set of strings that currently have this exact count. - prev and next: pointers linking to the adjacent count bucket. 2. key_to_node (Hash Map): maps each string key -> BucketNode. 3. Sentinel head and tail nodes keep track of minimum count (first bucket after head) and maximum count (last bucket before tail)!

Transitions: - inc(key): Move key from bucket $C$ to bucket $C + 1$ (create bucket $C + 1$ if it doesn't exist). Remove key from bucket $C$; delete bucket $C$ if empty! - dec(key): Move key from bucket $C$ to bucket $C - 1$ (or delete key if $C == 1$). Delete bucket $C$ if empty! - getMaxKey(): Return any key from tail.prev.keys in $O(1)$! - getMinKey(): Return any key from head.next.keys in $O(1)$!

🐢 Brute force vs optimal

Heap or balanced tree requires $O(\log n)$ per update. Doubly linked list of frequency buckets achieves strict $O(1)$ for all operations.

💡 Key insight: Doubly linked list where each node is a bucket holding a set of keys with identical counts. Head neighbor is min; tail neighbor is max. Strict $O(1)$!

class Bucket:
    def __init__(self, count=0):
        self.count = count
        self.keys = set()
        self.prev = None
        self.next = None

class AllOne:
    def __init__(self):
        self.head = Bucket(0) # Dummy head
        self.tail = Bucket(0) # Dummy tail
        self.head.next = self.tail
        self.tail.prev = self.head
        self.key_to_bucket = {} # key -> Bucket

    def _insert_after(self, target: Bucket, new_bucket: Bucket):
        new_bucket.next = target.next
        new_bucket.prev = target
        target.next.prev = new_bucket
        target.next = new_bucket

    def _remove_bucket(self, bucket: Bucket):
        bucket.prev.next = bucket.next
        bucket.next.prev = bucket.prev

    def inc(self, key: str) -> None:
        if key not in self.key_to_bucket:
            # Target count is 1
            if self.head.next.count == 1:
                b = self.head.next
            else:
                b = Bucket(1)
                self._insert_after(self.head, b)
            b.keys.add(key)
            self.key_to_bucket[key] = b
        else:
            curr_b = self.key_to_bucket[key]
            next_count = curr_b.count + 1
            if curr_b.next.count == next_count:
                next_b = curr_b.next
            else:
                next_b = Bucket(next_count)
                self._insert_after(curr_b, next_b)
            next_b.keys.add(key)
            self.key_to_bucket[key] = next_b
            curr_b.keys.remove(key)
            if not curr_b.keys:
                self._remove_bucket(curr_b)

    def dec(self, key: str) -> None:
        curr_b = self.key_to_bucket[key]
        curr_b.keys.remove(key)
        if curr_b.count == 1:
            del self.key_to_bucket[key]
        else:
            prev_count = curr_b.count - 1
            if curr_b.prev.count == prev_count:
                prev_b = curr_b.prev
            else:
                prev_b = Bucket(prev_count)
                self._insert_after(curr_b.prev, prev_b)
            prev_b.keys.add(key)
            self.key_to_bucket[key] = prev_b
        if not curr_b.keys:
            self._remove_bucket(curr_b)

    def getMaxKey(self) -> str:
        if self.tail.prev == self.head:
            return ""
        return next(iter(self.tail.prev.keys))

    def getMinKey(self) -> str:
        if self.head.next == self.tail:
            return ""
        return next(iter(self.head.next.keys))

Complexity

Time: $O(1)$ for inc, dec, getMaxKey, and getMinKey.
Space: $O(K)$ where $K$ is the number of distinct keys stored.
