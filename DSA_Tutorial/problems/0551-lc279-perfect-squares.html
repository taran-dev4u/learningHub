📋 The problem

Return the fewest perfect square numbers that sum to n.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an integer {2, 3, 5}n{2, 3, 5}, return the least number of perfect square numbers that sum to {2, 3, 5}n{2, 3, 5}.

Key Insights

By Lagrange's Four-Square Theorem, every natural number can be represented as the sum of at most four integer squares! Furthermore, by Legendre's Three-Square Theorem, a number can be expressed as the sum of three squares if and only if it is not of the form {2, 3, 5}4^k(8m + 7){2, 3, 5}. Hence, the answer is always strictly 1, 2, 3, or 4:

  1. Answer 1: If {2, 3, 5}n{2, 3, 5} is a perfect square ({2, 3, 5}s^2 == n{2, 3, 5}).
  2. Answer 4: While {2, 3, 5}n % 4 == 0{2, 3, 5}, {2, 3, 5}n //= 4{2, 3, 5}. If {2, 3, 5}n % 8 == 7{2, 3, 5}, answer is 4.
  3. Answer 2: Check if {2, 3, 5}n = a^2 + b^2{2, 3, 5} for some integer {2, 3, 5}a{2, 3, 5}.
  4. Answer 3: Otherwise, the answer is 3.

Python 3 Solution (Number Theoretic O(sqrt(N))) 
class Solution:
    def numSquares(self, n: int) -> int:
        def is_square(x: int) -> bool:
            s = int(x**0.5)
            return s * s == x
            
        if is_square(n):
            return 1
            
        # Check Legendre's 4-square condition: 4^k * (8m + 7)
        temp = n
        while temp % 4 == 0:
            temp //= 4
        if temp % 8 == 7:
            return 4
            
        # Check if sum of two squares: n = a^2 + b^2
        for a in range(1, int(n**0.5) + 1):
            if is_square(n - a * a):
                return 2
                
        return 3

Complexity & Edge Cases

  • Time Complexity: {2, 3, 5}O(\sqrt{n}){2, 3, 5} time due to the 2-square search loop. Drastically faster than DP ({2, 3, 5}O(n \sqrt{n}){2, 3, 5}).
  • Space Complexity: {2, 3, 5}O(1){2, 3, 5}.
