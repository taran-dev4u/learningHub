📋 The problem

Given n nodes and an edge list, decide whether they form a valid tree (connected and acyclic).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You have a graph of n nodes labeled from 0 to n - 1 and a list of undirected edges. Determine if these edges form a valid tree.

By mathematical definition, an undirected graph of n nodes is a tree if and only if:

  1. It contains no cycles.
  2. It is fully connected (all nodes belong to a single connected component).
  3. It has exactly n - 1 edges.

🐢 Brute force vs optimal

If len(edges) != n - 1, it cannot possibly be a tree!

  • If len(edges) < n - 1, the graph is disconnected.
  • If len(edges) > n - 1, by the Pigeonhole Principle the graph must contain at least one cycle.
Thus, we can instantly return False if len(edges) != n - 1. Then, we only need to verify either connectivity or cycle freedom using Disjoint Set Union (DSU) or BFS/DFS.

💡 Key insight: Using Disjoint Set Union (Union-Find) with path compression: Start with n disjoint components. For each edge (u, v): find the representatives of u and v. If find(u) == find(v), they are already connected, so adding this edge creates a cycle → return False! Otherwise union them and decrement component count. At the end, must have exactly 1 component!

🪜 The approach, step by step (DSU)

  1. Check base condition: if len(edges) != n - 1, return False immediately.
  2. Initialize parent = list(range(n)) and rank = [1] * n.
  3. Define find(i) with recursive path compression: parent[i] = find(parent[i]).
  4. Define union(u, v):
    • Find roots root_u = find(u) and root_v = find(v).
    • If root_u == root_v, return False (cycle detected!).
    • Attach smaller rank tree under larger rank tree. Return True.
  5. Iterate through every edge: if not union(u, v), return False.
  6. Return True (since len(edges) == n - 1 and no cycles were found, it must be connected).

🎞️ Visual dry run — n=5, edges=[(0,1), (0,2), (0,3), (1,4)]:

✅ The solution

Python 3 — Union-Find with Path Compression & Rank 
def validTree(n: int, edges: list[list[int]]) -> bool:
    """
    Checks if n nodes and undirected edges form a single acyclic connected tree.
    """
    # A valid tree with n nodes must have exactly n - 1 edges
    if len(edges) != n - 1:
        return False
        
    parent = list(range(n))
    rank = [1] * n
    
    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])  # Path compression
        return parent[x]
        
    def union(x, y):
        rx, ry = find(x), find(y)
        if rx == ry:
            return False  # Cycle detected: x and y already in same component!
            
        # Union by rank
        if rank[rx] < rank[ry]:
            parent[rx] = ry
        elif rank[rx] > rank[ry]:
            parent[ry] = rx
        else:
            parent[ry] = rx
            rank[rx] += 1
        return True
        
    for u, v in edges:
        if not union(u, v):
            return False
            
    return True

⚡ Complexity analysis

  • Time Complexity: O(N × α(N)) ≈ O(N), where α is the Inverse Ackermann function (less than 5 for all practical input sizes). Checking edge count is O(1), and processing n - 1 edges with path compression runs in near-linear time.
  • Space Complexity: O(N) for the parent and rank arrays.

🚨 Edge cases to watch out for

  • n = 1, edges = []: len(edges) == 0 == n - 1, returns True. A single isolated node is a valid tree.
  • Disconnected components with cycle: e.g. a triangle of 3 nodes and 2 isolated nodes with 4 edges total. Handled because DSU catches the triangle cycle.
