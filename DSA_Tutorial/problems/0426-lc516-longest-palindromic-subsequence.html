📋 The problem

Return the length of the longest palindromic subsequence of a string.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a string s, find the longest palindromic subsequence's length in s. A subsequence is a sequence that can be derived from another sequence by deleting some or no elements without changing the order of the remaining elements.

💡 Key insight: Two equivalent approaches: 1. LCS with Reverse: The Longest Palindromic Subsequence of s is mathematically identical to the Longest Common Subsequence of s and its reverse s[::-1]! 2. Interval DP: Let dp[i][j] be LPS length in substring s[i..j]: - If s[i] == s[j]: dp[i][j] = 2 + dp[i + 1][j - 1]. - Else: dp[i][j] = max(dp[i + 1][j], dp[i][j - 1]).

✅ The solution

def longestPalindromeSubseq(s: str) -> int:
    """
    Computes LPS length via Interval DP in O(N^2) time and O(N) space.
    """
    n = len(s)
    # dp[j] stores LPS length for substring ending at j
    dp = [0] * n
    
    for i in range(n - 1, -1, -1):
        new_dp = [0] * n
        new_dp[i] = 1  # Single character palindrome
        for j in range(i + 1, n):
            if s[i] == s[j]:
                new_dp[j] = 2 + dp[j - 1]
            else:
                new_dp[j] = max(dp[j], new_dp[j - 1])
        dp = new_dp
        
    return dp[n - 1]

⚡ Complexity analysis

  • Time Complexity: O(N^2).
  • Space Complexity: O(N) rolling array space.
