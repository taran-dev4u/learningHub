📋 The problem

An array holds n distinct numbers from 0..n; return the one number missing from the range.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Cyclic Sort — Place each value at index value-1 by swapping — finds missing/duplicate numbers in O(n) O(1).

💡 Key idea
XOR all indices 0..n and all values — everything pairs off except the missing number.

Why this pattern?

  • "rotate / transpose / flip" a matrix or array
  • "in place" / "O(1) extra space" on a grid problem
  • traverse in an unusual order (spiral, diagonal, zigzag)
  • mark/erase cells based on other cells (use the cells themselves as flags)

# Rotate matrix 90° clockwise, in place
n = len(matrix)
for r in range(n):                     # 1) transpose (swap across diagonal)
    for c in range(r + 1, n):
        matrix[r][c], matrix[c][r] = matrix[c][r], matrix[r][c]
for row in matrix:                     # 2) reverse each row
    row.reverse()

# Spiral walk: shrink four boundaries
top, bottom, left, right = 0, rows - 1, 0, cols - 1
while top <= bottom and left <= right:
    ...walk top row, right col, bottom row, left col...
    top += 1; bottom -= 1; left += 1; right -= 1
