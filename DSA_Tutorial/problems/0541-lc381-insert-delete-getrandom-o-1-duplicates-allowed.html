Problem Overview

Implement the RandomizedCollection class with support for duplicate elements, such that insert, remove, and getRandom operate in $O(1)$ average time.

Key Insights

Because duplicates are allowed, a value can appear at multiple indices in the array. Therefore, the hash map must map each value to a set of indices: val_to_indices = defaultdict(set).

When removing val:

  1. Take any index remove_idx from val_to_indices[val].
  2. Let last_idx = len(nums) - 1 and last_val = nums[-1].
  3. Overwrite nums[remove_idx] = last_val.
  4. Update val_to_indices[last_val]: remove last_idx and add remove_idx.
  5. Remove remove_idx from val_to_indices[val].
  6. Pop from nums in $O(1)$.
Careful with the edge case where remove_idx == last_idx: perform set modifications appropriately so indices remain consistent!

from collections import defaultdict
import random

class RandomizedCollection:
    def __init__(self):
        self.nums = []
        self.indices = defaultdict(set)

    def insert(self, val: int) -> bool:
        has_val = len(self.indices[val]) > 0
        self.indices[val].add(len(self.nums))
        self.nums.append(val)
        return not has_val

    def remove(self, val: int) -> bool:
        if not self.indices[val]:
            return False
        
        # Pick any index of val to remove
        remove_idx = self.indices[val].pop()
        last_idx = len(self.nums) - 1
        last_val = self.nums[-1]
        
        if remove_idx != last_idx:
            self.nums[remove_idx] = last_val
            self.indices[last_val].remove(last_idx)
            self.indices[last_val].add(remove_idx)
            
        self.nums.pop()
        return True

    def getRandom(self) -> int:
        return random.choice(self.nums)

Complexity & Invariants

  • Time Complexity: $O(1)$ average for insert, remove, and getRandom. Set operations on integer indices run in $O(1)$.
  • Space Complexity: $O(N)$ for array and set of indices.
  • Edge Cases: Removing the very last element in the array (remove_idx == last_idx).
