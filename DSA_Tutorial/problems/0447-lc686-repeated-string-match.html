📋 The problem

Return the minimum number of times to repeat string a so that b is a substring of it (-1 if never).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given two strings a and b, return the minimum number of times you should repeat string a so that string b is a substring of it. If it is impossible, return -1.

How many repetitions could possibly be required? To even have length $\ge ext{len}(b)$, we need at least $k = \lceil ext{len}(b) / ext{len}(a) \rceil$ repetitions. Because $b$ could start near the end of the first copy of $a$ and spill over, it might require at most one extra copy: $k + 1$! Any repetitions beyond $k + 1$ are completely redundant: if $b$ is not in $a \times k$ and not in $a \times (k + 1)$, it will never be in $a \times (k + 2)$!

🐢 Brute force vs optimal

Test $a \times k$; if $b$ is inside, return $k$. Else test $a \times (k + 1)$; if $b$ is inside, return $k + 1$. Otherwise, return -1! Can use KMP or Rabin-Karp substring search.

💡 Key insight: Lower bound repetitions $k = -(- ext{len}(b) // ext{len}(a))$. Only test $k$ and $k + 1$; if neither contains $b$, return -1.

✅ The solution

Reveal the commented solution (attempt it first!) 
def repeatedStringMatch(a: str, b: str) -> int:
    # Ceiling division for minimum repeats
    k = -(-len(b) // len(a))
    
    repeated = a * k
    if b in repeated:
        return k
    if b in (repeated + a):
        return k + 1
        
    return -1

Complexity

Time: $O(|a| + |b|)$ with KMP or built-in Boyer-Moore-Horspool search.
Space: $O(|a| \times k)$ — Buffer for repeated string.
