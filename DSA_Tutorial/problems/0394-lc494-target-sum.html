📋 The problem

Assign + or - to every number so the expression sums to a target; count the ways.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an integer array nums and an integer target. Build an expression by adding + or - before each integer in nums. Return the number of different expressions that evaluate to target.

Divide nums into two disjoint subsets: $P$ (elements assigned +) and $N$ (elements assigned -). $$\sum P - \sum N = \text{target}$$ Adding $\sum P + \sum N = \text{total\_sum}$ to both sides: $$2 \times \sum P = \text{target} + \text{total\_sum} \implies \sum P = \frac{\text{target} + \text{total\_sum}}{2}$$

This transforms Target Sum into finding the number of subsets with sum $S = (\text{target} + \text{total\_sum}) / 2$ — standard 0-1 Knapsack Subset Sum!

🐢 Brute force vs optimal

Trying all $2^n$ sign assignments is $O(2^n)$. The subset sum reduction solves it in $O(n \times S)$ time with 1D space rolling backwards!

💡 Key insight: Check parity: if target + total_sum is odd or abs(target) > total_sum, return 0. Otherwise, count subsets with target sum $S$ traversing backward to prevent reusing elements.

✅ The solution

def findTargetSumWays(nums: list[int], target: int) -> int:
    total = sum(nums)
    if (target + total) % 2 != 0 or abs(target) > total:
        return 0
        
    s = (target + total) // 2
    dp = [0] * (s + 1)
    dp[0] = 1
    
    for num in nums:
        for j in range(s, num - 1, -1):
            dp[j] += dp[j - num]
            
    return dp[s]

Complexity

Time: $O(n \times S)$ where $S = (\text{target} + \text{total}) / 2$.
Space: $O(S)$ — 1D space optimized backward traversal.
