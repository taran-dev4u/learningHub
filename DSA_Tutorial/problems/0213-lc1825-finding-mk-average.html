#1825 Finding MK Average HardLeetCode

 

Pattern: Heap (Priority Queue) Patterns › Subpattern 7.2: Two Heaps for Median Finding · Problem 213 of 699

📋 The problem

Design MKAverage: over the last m stream values, drop the k smallest and k largest and report the mean of the rest (three balanced buckets).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Maintain a stream of numbers. On request, compute the average of the last m elements after removing the k smallest and k largest. The window has size m. We need to split the window into three dynamically balanced groups: left (k smallest), mid (m - 2k middle elements), and right (k largest). We maintain a running sum of elements in mid for O(1) average computation.

🐢 Brute force first

Sort the last m elements, drop first k and last k, and compute average → O(m log m) per query.

💡 Key insight: use a balanced data structure (like SortedList from sortedcontainers or dual/triple heaps with lazy deletion). Keep mid_sum updated as elements migrate between left, mid, and right partitions. Average is mid_sum // (m - 2k).

🪜 The approach, step by step

  1. Use a queue to track the last m incoming elements.
  2. Maintain three sorted sets: left (size k), mid (size m - 2k), and right (size k).
  3. Maintain mid_sum for all elements in mid.
  4. On addElement(num): insert into appropriate set, rebalance sizes, and update mid_sum. When queue size exceeds m, remove the oldest element.
  5. On calculateMKAverage(): if queue length < m, return -1; else return mid_sum // (m - 2*k).

✅ The solution

from collections import deque
from bisect import insort, bisect_left

class MKAverage:
    def __init__(self, m: int, k: int):
        self.m = m
        self.k = k
        self.q = deque()
        self.sl = []          # sorted list of the m elements
        self.mid_sum = 0

    def addElement(self, num: int) -> None:
        self.q.append(num)
        insort(self.sl, num)
        
        # If queue has reached window size m + 1, evict oldest
        if len(self.q) > self.m:
            oldest = self.q.popleft()
            idx = bisect_left(self.sl, oldest)
            self.sl.pop(idx)
            
        # Recompute mid_sum when window is exactly m
        if len(self.q) == self.m:
            self.mid_sum = sum(self.sl[self.k : self.m - self.k])

    def calculateMKAverage(self) -> int:
        if len(self.q) < self.m:
            return -1
        return self.mid_sum // (self.m - 2 * self.k)

⏱️ Complexity

Time O(m) insertion with bisect (or O(log m) with balanced Fenwick tree / B-Tree). O(1) for calculateMKAverage(). Space O(m) to store window elements.

⚠️ Edge cases

  • Fewer than m elements in the stream: returns -1.
  • Duplicate elements: binary search bisect finds correct occurrence.
