#931 Minimum Falling Path Sum MediumLeetCode

📋 The problem

Falling through a square matrix choosing down / down-left / down-right each row, minimize the path sum.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an n x n array of integers matrix, return the minimum sum of any falling path through matrix. A falling path starts at any element in the first row and chooses the element in the next row that is either directly below or diagonally left/right.

$$dp[r][c] = matrix[r][c] + \min(dp[r - 1][c - 1], \; dp[r - 1][c], \; dp[r - 1][c + 1])$$

🐢 Brute force vs optimal

Branching factor 3 at each row yields $O(3^n)$ recursion. Standard DP computes row by row in $O(n^2)$ time and $O(n)$ memory.

💡 Key insight: Rolling 1D array: dp[c] = matrix[r][c] + min(prev[max(0, c-1) : min(n, c+2)]).

✅ The solution

Reveal the commented solution (attempt it first!) 
def minFallingPathSum(matrix: list[list[int]]) -> int:
    n = len(matrix)
    dp = matrix[0][:]
    
    for r in range(1, n):
        new_dp = [0] * n
        for c in range(n):
            best_prev = dp[c]
            if c > 0:
                best_prev = min(best_prev, dp[c - 1])
            if c < n - 1:
                best_prev = min(best_prev, dp[c + 1])
            new_dp[c] = matrix[r][c] + best_prev
        dp = new_dp
        
    return min(dp)

Complexity

Time: $O(n^2)$ — $n \times n$ matrix cells.
Space: $O(n)$ — Single row of size $n$.
