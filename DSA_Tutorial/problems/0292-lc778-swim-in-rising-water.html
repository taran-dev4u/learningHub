📋 The problem

Water rises over a height grid; return the earliest time you can swim from the top-left to the bottom-right (path cells ≤ time).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an n x n integer matrix grid where each value represents the elevation at (i, j). At time t, water level everywhere is t. You can swim from cell to adjacent cell if the elevation of both cells is at most t. Return the minimum time t until you can reach (n - 1, n - 1) starting from (0, 0).

This is a shortest path problem on a grid where the cost to enter any cell (r, c) along a path is max(time_so_far, grid[r][c]). We want to find a path that minimizes the peak elevation encountered.

🐢 Brute force vs optimal

Backtracking is exponential. Binary searching the answer t ∈ [0, n^2 - 1] with BFS reachability takes O(n^2 log n). Modified Dijkstra with a min-heap directly finds the optimal path in O(n^2 log n) with less code.

💡 Key insight: Min-priority queue stores (current_time, r, c). At each step, pop the cell with the smallest water level needed to reach it. When we pop (n-1, n-1), that water level is guaranteed to be the minimum time required!

🪜 The approach, step by step

  1. Initialize min-heap pq = [(grid[0][0], 0, 0)] and a 2D boolean visited array.
  2. Mark visited[0][0] = True.
  3. While pq is not empty:
    • Pop (t, r, c).
    • If r == n - 1 and c == n - 1, return t!
    • For each of the 4 neighbors (nr, nc):
      • If inside grid and not visited:
      • Mark visited[nr][nc] = True.
      • Push (max(t, grid[nr][nc]), nr, nc) into pq.

✅ The solution

Python 3 — Dijkstra via Min-Heap 
import heapq

def swimInWater(grid: list[list[int]]) -> int:
    """
    Returns minimum time to swim from (0,0) to (n-1, n-1) using modified Dijkstra.
    """
    n = len(grid)
    visited = [[False] * n for _ in range(n)]
    visited[0][0] = True
    
    # Priority queue stores (time_required, row, col)
    pq = [(grid[0][0], 0, 0)]
    dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]
    
    while pq:
        t, r, c = heapq.heappop(pq)
        
        if r == n - 1 and c == n - 1:
            return t
            
        for dr, dc in dirs:
            nr, nc = r + dr, c + dc
            if 0 <= nr < n and 0 <= nc < n and not visited[nr][nc]:
                visited[nr][nc] = True
                heapq.heappush(pq, (max(t, grid[nr][nc]), nr, nc))
                
    return 0

⚡ Complexity analysis

  • Time Complexity: O(n2 log n). Each cell is pushed and popped from the priority queue at most once. Priority queue contains at most n^2 elements, making heap operations O(log n^2) = O(log n).
  • Space Complexity: O(n2) for the visited matrix and priority queue.

🚨 Edge cases to watch out for

  • 1×1 grid: Returns grid[0][0] directly on first pop.
  • Start cell elevation high: If grid[0][0] is large, time must be at least grid[0][0] because you must wait for water to cover the start cell before you can even begin swimming!
