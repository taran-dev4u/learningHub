#14 Longest Common Prefix EasyLeetCode

📋 The problem

Given an array of strings, return the longest prefix shared by all of them (empty string if none).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Write a function to find the longest common prefix string amongst an array of strings. If there is no common prefix, return an empty string "".

Vertical Scanning: Look at index i across all strings simultaneously. If index i exceeds any string's length or strs[j][i] != strs[0][i], the common prefix ends right before index i!

🐢 Brute force vs optimal

Vertical scanning stops at the earliest mismatch point. Worst-case time is $O(S)$ where $S$ is total characters across all strings; best case takes only $O(n \times ext{min\_len})$ operations.

💡 Key insight: Vertical scanning: check character at column $i$ for all strings. Stop at the very first mismatch or end-of-string.

✅ The solution

Reveal the commented solution (attempt it first!) 
def longestCommonPrefix(strs: list[str]) -> str:
    if not strs:
        return ""
        
    for i in range(len(strs[0])):
        ch = strs[0][i]
        for s in strs[1:]:
            if i >= len(s) or s[i] != ch:
                return strs[0][:i]
                
    return strs[0]

Complexity

Time: $O(S)$ where $S$ is sum of all characters in all strings.
Space: $O(1)$ — No extra space allocated.
