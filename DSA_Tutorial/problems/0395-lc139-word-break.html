📋 The problem

Decide whether a string can be segmented into a sequence of words from a given dictionary (words reusable).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a string s and a dictionary of strings wordDict, return true if s can be segmented into a space-separated sequence of one or more dictionary words.

💡 Key insight: Let dp[i] be True if prefix s[:i] can be segmented into dictionary words. dp[0] = True (empty string is always valid). For i from 1 to n: For j from 0 to i: If dp[j] == True and substring s[j:i] is in word_set → set dp[i] = True and break!

✅ The solution

Reveal the commented solution (attempt it first!) 
def wordBreak(s: str, wordDict: list[str]) -> bool:
    """
    Validates if string can be segmented into dictionary words via 1D boolean DP.
    """
    word_set = set(wordDict)
    n = len(s)
    dp = [False] * (n + 1)
    dp[0] = True
    
    for i in range(1, n + 1):
        for j in range(i):
            if dp[j] and s[j:i] in word_set:
                dp[i] = True
                break
                
    return dp[n]

⚡ Complexity analysis

  • Time Complexity: O(N^2 × K) where K is average word length for string slicing and hashing.
  • Space Complexity: O(N) for the DP array.
