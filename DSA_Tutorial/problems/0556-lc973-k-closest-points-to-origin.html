📋 The problem

Return the k points closest to the origin.

Problem Overview

Given an array of points where points[i] = [xi, yi] represents a point on the X-Y plane and an integer {2, 3, 5}k{2, 3, 5}, return the {2, 3, 5}k{2, 3, 5} closest points to the origin {2, 3, 5}(0, 0){2, 3, 5}.

Key Insights

Squared Euclidean distance: {2, 3, 5}dist^2 = x^2 + y^2{2, 3, 5}. Because square root is monotonic, comparing {2, 3, 5}x^2 + y^2{2, 3, 5} preserves order without floating-point computations. Two optimal strategies:

  1. Max-Heap of size {2, 3, 5}k{2, 3, 5}: Maintain the {2, 3, 5}k{2, 3, 5} closest points. If a new point is closer than the heap root, pop and push: {2, 3, 5}O(n \log k){2, 3, 5} time, {2, 3, 5}O(k){2, 3, 5} space.
  2. QuickSelect (Optimal): Average {2, 3, 5}O(n){2, 3, 5} time, partitioning in-place around pivot distances.

Python 3 Solution (Max-Heap - O(N log K)) 
from typing import List
import heapq

class Solution:
    def kClosest(self, points: List[List[int]], k: int) -> List[List[int]]:
        # Max-heap storing (-dist_sq, x, y)
        heap = []
        for x, y in points:
            dist_sq = x * x + y * y
            if len(heap) < k:
                heapq.heappush(heap, (-dist_sq, x, y))
            else:
                if dist_sq < -heap[0][0]:
                    heapq.heapreplace(heap, (-dist_sq, x, y))
                    
        return [[x, y] for _, x, y in heap]

Complexity & Edge Cases

  • Time Complexity: {2, 3, 5}O(n \log k){2, 3, 5}.
  • Space Complexity: {2, 3, 5}O(k){2, 3, 5} to store the heap.
  • Edge Cases: {2, 3, 5}k == n{2, 3, 5}, multiple points having identical distances.
