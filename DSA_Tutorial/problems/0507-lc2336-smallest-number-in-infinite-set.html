#2336 Smallest Number in Infinite Set MediumLeetCode

 

Pattern: Design Patterns › Subpattern 15.1: General / Specific Data Structure Design · Problem 507 of 699

📋 The problem

Design a set pre-filled with all positive integers: popSmallest and addBack(num) (heap + set for returned numbers, counter for the frontier).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You have a set which contains all positive integers [1, 2, 3, 4, 5, ...]. Implement the SmallestInfiniteSet class: - popSmallest(): Removes and returns the smallest integer. - addBack(num): Adds positive integer back into set if not already present.

You cannot store an infinite set in memory! Instead, notice that all integers from $1$ to $\infty$ are naturally present in increasing order. Maintain: 1. curr_smallest = 1: pointer tracking the next virgin integer that has never been popped yet. 2. added_back_heap: Min-Heap storing numbers smaller than curr_smallest that were popped and subsequently added back! 3. added_back_set: Hash set to prevent duplicates in the heap.

- popSmallest(): If added_back_heap is non-empty, pop its smallest element. Otherwise, return curr_smallest and increment curr_smallest += 1! - addBack(num): Only add if $num < curr\_smallest$ and $num \notin added\_back\_set$!

🐢 Brute force vs optimal

Heap + pointer simulates an infinite set in $O(\log K)$ time where $K$ is the count of re-added numbers.

💡 Key insight: Pointer curr_smallest tracks the infinite frontier. Min-heap stores re-added numbers that fall below the frontier. $O(\log K)$ operations!

✅ The solution

Reveal the commented solution (attempt it first!) 
import heapq

class SmallestInfiniteSet:
    def __init__(self):
        self.curr_smallest = 1
        self.added_heap = []
        self.added_set = set()

    def popSmallest(self) -> int:
        if self.added_heap:
            val = heapq.heappop(self.added_heap)
            self.added_set.remove(val)
            return val
        res = self.curr_smallest
        self.curr_smallest += 1
        return res

    def addBack(self, num: int) -> None:
        if num < self.curr_smallest and num not in self.added_set:
            self.added_set.add(num)
            heapq.heappush(self.added_heap, num)

Complexity

Time: $O(\log K)$ for popSmallest and addBack where $K$ is re-added numbers.
Space: $O(K)$ — Only stores numbers currently added back.
