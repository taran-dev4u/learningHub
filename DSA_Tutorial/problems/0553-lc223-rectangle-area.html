📋 The problem

Given two axis-aligned rectangles, return the total area they cover (sum minus overlap).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given the coordinates of two rectilinear rectangles in a 2D plane: rectangle 1 {2, 3, 5}(ax1, ay1){2, 3, 5} to {2, 3, 5}(ax2, ay2){2, 3, 5} and rectangle 2 {2, 3, 5}(bx1, by1){2, 3, 5} to {2, 3, 5}(bx2, by2){2, 3, 5}, return the total area covered by the two rectangles.

Key Insights

By the Principle of Inclusion-Exclusion: {2, 3, 5}{2, 3, 5} ext{Total Area} = ext{Area}_1 + ext{Area}_2 - ext{Overlap Area}{2, 3, 5}{2, 3, 5} The overlap rectangle's boundaries are:

  • {2, 3, 5} ext{overlap_width} = \max(0, \min(ax2, bx2) - \max(ax1, bx1)){2, 3, 5}
  • {2, 3, 5} ext{overlap_height} = \max(0, \min(ay2, by2) - \max(ay1, by1)){2, 3, 5}
If either overlap width or height {2, 3, 5}\le 0{2, 3, 5}, the rectangles do not intersect, and overlap area is 0.

Python 3 Solution (Click to Expand) 
class Solution:
    def computeArea(self, ax1: int, ay1: int, ax2: int, ay2: int, bx1: int, by1: int, bx2: int, by2: int) -> int:
        area1 = (ax2 - ax1) * (ay2 - ay1)
        area2 = (bx2 - bx1) * (by2 - by1)
        
        # Calculate intersection width and height
        overlap_width = max(0, min(ax2, bx2) - max(ax1, bx1))
        overlap_height = max(0, min(ay2, by2) - max(ay1, by1))
        overlap_area = overlap_width * overlap_height
        
        return area1 + area2 - overlap_area

Complexity & Edge Cases

  • Time Complexity: {2, 3, 5}O(1){2, 3, 5}.
  • Space Complexity: {2, 3, 5}O(1){2, 3, 5}.
  • Edge Cases: One rectangle fully inside another, non-overlapping rectangles separated by distance.
