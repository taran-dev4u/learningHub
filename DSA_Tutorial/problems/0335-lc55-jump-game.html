📋 The problem

Each value is your maximum jump length from that index. Decide whether you can reach the last index from the first.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an integer array nums. You are initially positioned at the array's first index, and each element in the array represents your maximum jump length at that position. Return true if you can reach the last index, or false otherwise.

🐢 Brute force vs optimal

Backtracking recursively explores all jump sizes: O(2^N). Dynamic programming caches reachability in O(N^2). The Greedy approach maintains the furthest reachable index in a single linear pass in O(N) time and O(1) space!

💡 Key insight: Maintain max_reach. Iterate index i from 0 to n - 1. If at any point i > max_reach, we have reached a position we could never have arrived at → return False! Otherwise, update max_reach = max(max_reach, i + nums[i]). If max_reach >= n - 1, return True immediately!

🪜 The approach, step by step

  1. Initialize max_reach = 0.
  2. For index i and value num in enumerate(nums):
    • If i > max_reach: return False (stranded!).
    • Update max_reach = max(max_reach, i + num).
    • If max_reach >= len(nums) - 1: return True.
  3. Return True.

🎞️ Visual dry run — nums = [2,3,1,1,4]:

i=0: num=2 -> max_reach = max(0, 0+2) = 2
i=1: num=3 -> 1 <= 2 -> max_reach = max(2, 1+3) = 4 >= 4 (last index)!
Reachable! Return True ✓

Counterexample: nums = [3,2,1,0,4]:
i=0: max_reach = 3
i=1: max_reach = max(3, 1+2) = 3
i=2: max_reach = max(3, 2+1) = 3
i=3: max_reach = max(3, 3+0) = 3
i=4: 4 > 3! Stranded at index 3 (zero jump)! Return False ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
def canJump(nums: list[int]) -> bool:
    """
    Determines if last index is reachable by tracking furthest boundary greedily.
    """
    max_reach = 0
    target = len(nums) - 1
    
    for i, jump in enumerate(nums):
        if i > max_reach:
            return False
        max_reach = max(max_reach, i + jump)
        if max_reach >= target:
            return True
            
    return True

⚡ Complexity analysis

  • Time Complexity: O(N). Single pass over the array.
  • Space Complexity: O(1). Only one integer tracker variable.
