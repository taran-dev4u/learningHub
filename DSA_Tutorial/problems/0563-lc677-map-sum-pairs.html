📋 The problem

Design a map of string→value where sum(prefix) returns the total of values whose keys start with the prefix.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Design a map that allows inserting a (key, val) pair (overwriting if key exists) and returning the sum of all values whose keys start with a given prefix.

Key Insights

Store a sum_val attribute on each TrieNode representing the total sum of all words passing through this node. When inserting (key, val):

  1. Find the difference $\Delta = val - ext{old_val}$ (where $ ext{old_val} = 0$ if key is new).
  2. Update the record in a hash map: key_map[key] = val.
  3. Traverse the trie path for key, adding $\Delta$ to curr.sum_val at each node!
For sum(prefix): Simply traverse to the prefix node and return its sum_val in $O(L)$ time!

Python 3 Solution (Prefix Sum Tracking on Nodes) 
class TrieNode:
    def __init__(self):
        self.children = {}
        self.sum_val = 0

class MapSum:
    def __init__(self):
        self.root = TrieNode()
        self.values = {}

    def insert(self, key: str, val: int) -> None:
        delta = val - self.values.get(key, 0)
        self.values[key] = val
        
        curr = self.root
        curr.sum_val += delta
        for ch in key:
            if ch not in curr.children:
                curr.children[ch] = TrieNode()
            curr = curr.children[ch]
            curr.sum_val += delta

    def sum(self, prefix: str) -> int:
        curr = self.root
        for ch in prefix:
            if ch not in curr.children:
                return 0
            curr = curr.children[ch]
        return curr.sum_val

Complexity & Edge Cases

  • Time Complexity: $O(L)$ for both insert and sum.
  • Space Complexity: $O(N imes L)$ nodes.
