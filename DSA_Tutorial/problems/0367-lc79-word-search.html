📋 The problem

Given a letter grid and a word, decide whether the word can be traced through adjacent cells without reusing a cell.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an m x n grid of characters board and a string word, return true if word exists in the grid. The word can be constructed from letters of sequentially adjacent cells (horizontally or vertically).

💡 Key insight: 1. In-Place Visited: Temporarily set board[r][c] = '#' to avoid an extra 2D visited array. Restore on backtrack: board[r][c] = temp. 2. Pruning Shortcut: If character count in word exceeds frequency in board, return False immediately. If word[-1] is rarer than word[0], reverse word to search from the rarer end!

✅ The solution

from collections import Counter

def exist(board: list[list[str]], word: str) -> bool:
    """
    Finds word in grid via in-place cell masking DFS with frequency pruning.
    """
    m, n = len(board), len(board[0])
    if len(word) > m * n:
        return False
        
    # Frequency check optimization
    board_counts = Counter(c for row in board for c in row)
    word_counts = Counter(word)
    for c, count in word_counts.items():
        if board_counts[c] < count:
            return False
            
    # Reverse word if last letter is rarer than first letter
    if board_counts[word[0]] > board_counts[word[-1]]:
        word = word[::-1]
        
    def dfs(r, c, k):
        if k == len(word):
            return True
        if r < 0 or r >= m or c < 0 or c >= n or board[r][c] != word[k]:
            return False
            
        temp = board[r][c]
        board[r][c] = '#'  # Mark visited in-place
        
        found = (dfs(r + 1, c, k + 1) or
                 dfs(r - 1, c, k + 1) or
                 dfs(r, c + 1, k + 1) or
                 dfs(r, c - 1, k + 1))
                 
        board[r][c] = temp  # Backtrack
        return found
        
    for r in range(m):
        for c in range(n):
            if board[r][c] == word[0] and dfs(r, c, 0):
                return True
                
    return False

⚡ Complexity analysis

  • Time Complexity: O(M × N × 3^L) where L = len(word) (3 choices per step after the first).
  • Space Complexity: O(L) recursion stack.
