📋 The problem

Return the largest string that divides both input strings (both are that string repeated).

For two strings {2, 3, 5}s{2, 3, 5} and {2, 3, 5}t{2, 3, 5}, we say "{2, 3, 5}t{2, 3, 5} divides {2, 3, 5}s{2, 3, 5}" if and only if {2, 3, 5}s = t + t + \dots + t{2, 3, 5} (i.e. {2, 3, 5}t{2, 3, 5} is concatenated with itself one or more times). import math

class Solution:
    def gcdOfStrings(self, str1: str, str2: str) -> str:
        if str1 + str2 != str2 + str1:
            return ""
        g = math.gcd(len(str1), len(str2))
        return str1[:g]
