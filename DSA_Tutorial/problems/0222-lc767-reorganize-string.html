📋 The problem

Rearrange a string so no two adjacent characters are equal (or return empty if impossible).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Rearrange characters in string s so that no two adjacent characters are identical. Return "" if impossible. A character appearing more than (len(s) + 1) // 2 times can never be separated. Greedily, always pick the character with the highest remaining frequency that differs from the previous character.

🐢 Brute force first

Backtracking through all permutations checking adjacency → O(n!).

💡 Key insight: use a max-heap of character frequencies. Pop the most frequent character. If it matches the previously placed character, pop the second most frequent character instead, place it, and push both back with decremented counts.

🪜 The approach, step by step

  1. Count frequencies. If any count > (len(s) + 1) // 2, return "".
  2. Push (-count, char) into a max-heap.
  3. Initialize res = [] and prev = (0, '').
  4. While heap is not empty:
  5. Pop (cnt, char). Append char to res.
  6. If prev[0] < 0 (still has remaining count), push prev back into the heap.
  7. Set prev = (cnt + 1, char) (decremented count).
  8. Return "".join(res).

🎞️ Visual dry run — s = "aab"

Counts: {'a': 2, 'b': 1}. len=3, max allowed = (3+1)//2 = 2. Valid!
Heap: [(-2, 'a'), (-1, 'b')]
1. Pop (-2, 'a') → res=['a'] → prev=(-1, 'a')
2. Pop (-1, 'b') → res=['a', 'b'] → push prev (-1, 'a') → prev=(0, 'b')
3. Pop (-1, 'a') → res=['a', 'b', 'a'] → prev=(0, 'a')
Result: "aba" ✓

✅ The solution

import heapq
from collections import Counter

def reorganizeString(s):
    count = Counter(s)
    if max(count.values()) > (len(s) + 1) // 2:
        return ""
        
    heap = [(-cnt, char) for char, cnt in count.items()]
    heapq.heapify(heap)
    
    res = []
    prev_cnt, prev_char = 0, ''
    
    while heap:
        cnt, char = heapq.heappop(heap)
        res.append(char)
        
        # If the previous character still has remaining count, re-add it to the heap
        if prev_cnt < 0:
            heapq.heappush(heap, (prev_cnt, prev_char))
            
        # Store current character as the waiting previous character
        prev_cnt, prev_char = cnt + 1, char
        
    return "".join(res)

⏱️ Complexity

Time O(n log A) = O(n) — where A is the alphabet size (at most 26), so heap ops are O(1). Space O(A) = O(1) for the heap.

⚠️ Edge cases

  • Majority character count exceeds threshold: immediately returns "".
  • Already alternating string (e.g. "abab"): preserved.
