📋 The problem

A sorted array of distinct values was rotated; find its minimum element in O(log n).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Suppose an array of length n sorted in ascending order is rotated between 1 and n times. Notice that all values are unique. Find the minimum element of this array in O(log n) time.

🐢 Brute force first

Scan array linearly to find min(nums) in O(n). To do O(log n), observe the inflection point.

💡 Key insight: Compare nums[mid] directly with nums[right]! If nums[mid] > nums[right], the minimum element MUST be strictly to the right of mid (in [mid + 1, right]), because the rotation point broke ascending order. If nums[mid] < nums[right], the minimum element is at mid or to its left (in [left, mid])!

🪜 The approach, step by step

  1. Initialize left = 0, right = len(nums) - 1.
  2. While left < right:
  3. Compute mid = left + (right - left) // 2.
  4. If nums[mid] > nums[right]: minimum must be to the right of mid → left = mid + 1.
  5. Else: nums[mid] <= nums[right]: mid could be the minimum itself or min is to the left → right = mid.
  6. When left == right, the search window converges on the minimum element. Return nums[left].

🎞️ Visual dry run — nums = [4, 5, 6, 7, 0, 1, 2]

Iter 1: left = 0, right = 6 → mid = 3, nums[3] = 7
        nums[3] (7) > nums[6] (2) → minimum is right of mid!
        left = mid + 1 = 4

Iter 2: left = 4, right = 6 → mid = 5, nums[5] = 1
        nums[5] (1) < nums[6] (2) → minimum is at mid or left!
        right = mid = 5

Iter 3: left = 4, right = 5 → mid = 4, nums[4] = 0
        nums[4] (0) < nums[5] (1) → right = mid = 4

left == right == 4.
Return nums[4] = 0! ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
def findMin(nums):
    """
    Binary search comparing with right boundary.
    Invariant: minimum element is always inside [left, right].
    """
    left, right = 0, len(nums) - 1
    
    while left < right:
        mid = left + (right - left) // 2
        
        if nums[mid] > nums[right]:
            # Min is in right portion
            left = mid + 1
        else:
            # Min is mid or in left portion
            right = mid
            
    return nums[left]

⏱️ Complexity

Time O(log n) — Binary search cuts interval in half each iteration. Space O(1).

⚠️ Edge cases

  • Array rotated 0 times (already fully sorted): nums[mid] < nums[right] immediately shrinks right to 0.
  • Single element array: loop terminates immediately, returns nums[0].
  • Two element array: correctly chooses the smaller.
