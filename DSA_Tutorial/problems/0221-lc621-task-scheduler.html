📋 The problem

Schedule tasks (each identical letter needs a cooldown of n slots between repeats); return the minimum total intervals including idles.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You have CPU tasks represented by characters, and an idle cooldown n between identical tasks. Find the minimum intervals to complete all tasks. Greedy intuition: always execute the task with the highest remaining frequency first, because tasks with high counts require the most cooldown slots.

🐢 Brute force first

Simulate execution step by step with a queue tracking cooling tasks → O(total_intervals * log 26).

💡 Key insight: math formula solution. The most frequent task with count max_freq creates max_freq - 1 empty chunks of size n. Total slots = (max_freq - 1) * (n + 1) + count_of_max_freq_tasks. The answer is max(len(tasks), formula_result).

🪜 The approach, step by step

  1. Count frequencies of all tasks using Counter(tasks).
  2. Find max_freq = max(counts.values()).
  3. Count how many tasks have frequency equal to max_freq (let this be max_count).
  4. Calculate minimum time needed: (max_freq - 1) * (n + 1) + max_count.
  5. Return max(len(tasks), empty_slots_time).

🎞️ Visual dry run — tasks = ["A","A","A","B","B","B"], n = 2

✅ The solution

Reveal the commented solution (attempt it first!) 
from collections import Counter

def leastInterval(tasks, n):
    count = Counter(tasks)
    max_freq = max(count.values())
    # Count how many tasks tie for the maximum frequency
    max_count = sum(1 for v in count.values() if v == max_freq)
    
    # Calculate required intervals based on the bottleneck task
    part_time = (max_freq - 1) * (n + 1) + max_count
    # Cannot be less than the total number of tasks
    return max(len(tasks), part_time)

⏱️ Complexity

Time O(N) — where N is the length of tasks, to count frequencies. Space O(1) — alphabet size is at most 26.

⚠️ Edge cases

  • n = 0: no cooldown needed, answer is simply len(tasks).
  • Enough other tasks to fill all idle slots: returns len(tasks).
