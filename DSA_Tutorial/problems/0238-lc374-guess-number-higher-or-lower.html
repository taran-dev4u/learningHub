#374 Guess Number Higher or Lower EasyLeetCode

 

Pattern: Binary Search Patterns › Subpattern 8.1: On Sorted Array/List · Problem 238 of 699

📋 The problem

Guess a number in 1..n using an API that says higher/lower/correct, with as few guesses as possible.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

We are playing the Guess Game. You pick a number from 1 to n. I have picked a number from 1 to n. You have to guess which number I picked. Call predefined API guess(num) which returns -1 if your guess is higher than picked, 1 if your guess is lower, and 0 if your guess is equal.

🐢 Brute force first

Guess each number 1, 2, ..., n one by one. O(n) guesses.

💡 Key insight: Standard binary search on range [1, n] using feedback from guess(mid). If guess(mid) == 0: return mid; if guess(mid) == -1: guess is too high, search left (right = mid - 1); if guess(mid) == 1: guess is too low, search right (left = mid + 1).

🪜 The approach, step by step

  1. Set left = 1, right = n.
  2. While left <= right:
  3. mid = left + (right - left) // 2.
  4. res = guess(mid).
  5. If res == 0, return mid.
  6. If res == -1, right = mid - 1.
  7. Else, left = mid + 1.

🎞️ Visual dry run — n = 10, pick = 6

Iter 1: left = 1, right = 10, mid = 5 → guess(5) = 1 (too low) → left = 6
Iter 2: left = 6, right = 10, mid = 8 → guess(8) = -1 (too high) → right = 7
Iter 3: left = 6, right = 7,  mid = 6 → guess(6) = 0 → MATCH! Return 6. ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
def guessNumber(n):
    left, right = 1, n
    
    while left <= right:
        mid = left + (right - left) // 2
        res = guess(mid)
        
        if res == 0:
            return mid
        elif res == -1:
            right = mid - 1
        else:
            left = mid + 1
            
    return -1

⏱️ Complexity

Time O(log n) — Halves search space each query. Space O(1).

⚠️ Edge cases

  • n = 1, pick = 1.
  • Pick is 1 or n (extreme bounds).
