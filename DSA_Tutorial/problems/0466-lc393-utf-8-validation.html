📋 The problem

Validate whether an integer array encodes a legal UTF-8 byte sequence.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer array data representing the data, return whether it is a valid UTF-8 encoding.

UTF-8 encoding rules: 1. 1-byte character: starts with bit 0 (0xxxxxxx). 2. n-byte character ($2 \le n \le 4$): - First byte has $n$ leading 1s followed by a 0 (e.g. 110xxxxx for 2 bytes, 1110xxxx for 3 bytes, 11110xxx for 4 bytes). - Followed by $n - 1$ continuation bytes, each strictly starting with 10xxxxxx.

🐢 Brute force vs optimal

Track n_bytes remaining. For each byte: - If n_bytes == 0: count leading 1s. If 0, it's 1-byte char; if 2, 3, or 4, set n_bytes = count - 1. If 1 or $> 4$, invalid! - If n_bytes > 0: verify byte starts with 10xxxxxx ((byte >> 6) == 0b10) and decrement n_bytes -= 1. At end, verify n_bytes == 0.

💡 Key insight: State machine tracking continuation bytes: inspect top bits via right-shifts. First byte dictates expected continuation count.

✅ The solution

Reveal the commented solution (attempt it first!) 
def validUtf8(data: list[int]) -> bool:
    n_bytes = 0
    
    for num in data:
        byte = num & 0xFF
        if n_bytes == 0:
            if (byte >> 7) == 0:
                continue
            elif (byte >> 5) == 0b110:
                n_bytes = 1
            elif (byte >> 4) == 0b1110:
                n_bytes = 2
            elif (byte >> 3) == 0b11110:
                n_bytes = 3
            else:
                return False
        else:
            if (byte >> 6) != 0b10:
                return False
            n_bytes -= 1
            
    return n_bytes == 0

Complexity

Time: $O(n)$ — Single linear pass over bytes.
Space: $O(1)$ — Single state tracker.
