📋 The problem

Return the length of the longest strictly increasing subsequence of an array (not necessarily contiguous).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer array nums, return the length of the longest strictly increasing subsequence.

🐢 Brute force vs optimal

Traditional DP takes O(N^2): dp[i] = max(dp[j] + 1) for j < i if nums[j] < nums[i]. Patience Sorting with Binary Search finds the LIS in O(N log N) time!

💡 Key insight (Patience Sorting): Maintain an array tails where tails[i] is the smallest tail element of all increasing subsequences of length i + 1 found so far. For each x in nums: Binary search for the first element ≥ x in tails (using bisect_left):
  • If x is larger than all elements in tails: append x to tails (extends LIS length!).
  • Else: replace the element at index idx with x (lowers the tail value, making future extensions easier!).
At the end, len(tails) is the exact length of the LIS!

✅ The solution

Reveal the commented solution (attempt it first!) 
from bisect import bisect_left

def lengthOfLIS(nums: list[int]) -> int:
    """
    Computes LIS length via Patience Sorting & Binary Search in O(N log N) time and O(N) space.
    """
    tails = []
    for x in nums:
        idx = bisect_left(tails, x)
        if idx == len(tails):
            tails.append(x)
        else:
            tails[idx] = x
            
    return len(tails)

⚡ Complexity analysis

  • Time Complexity: O(N log N). For each of the N numbers, binary search takes O(log N).
  • Space Complexity: O(N) for the tails array.
