📋 The problem

Return all unique permutations of an array that may contain duplicate numbers.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a collection of numbers, nums, that might contain duplicates, return all possible unique permutations in any order.

💡 Key insight: Sort nums. When iterating through candidate elements at index i: If used[i] is True: continue. If i > 0 and nums[i] == nums[i - 1] and not used[i - 1]: continue!

Why not used[i - 1]? Because if used[i - 1] == False, it means nums[i - 1] was just un-chosen during backtracking at the exact same depth! Picking the identical duplicate nums[i] now would generate a duplicate permutation subtree!

✅ The solution

def permuteUnique(nums: list[int]) -> list[list[int]]:
    """
    Generates unique permutations of array with duplicates via sorting and used-flag pruning.
    """
    nums.sort()
    n = len(nums)
    res = []
    path = []
    used = [False] * n
    
    def backtrack():
        if len(path) == n:
            res.append(list(path))
            return
            
        for i in range(n):
            if used[i]:
                continue
            # Prune duplicate siblings at the same recursion depth
            if i > 0 and nums[i] == nums[i - 1] and not used[i - 1]:
                continue
                
            used[i] = True
            path.append(nums[i])
            backtrack()
            path.pop()
            used[i] = False
            
    backtrack()
    return res

⚡ Complexity analysis

  • Time Complexity: O(N × N!).
  • Space Complexity: O(N).
