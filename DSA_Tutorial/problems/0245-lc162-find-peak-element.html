📋 The problem

Find any peak element (strictly greater than both neighbors) in an array in O(log n).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

A peak element is an element that is strictly greater than its neighbors. Given a 0-indexed integer array nums, find a peak element, and return its index. If the array contains multiple peaks, return the index to any of the peaks. Imagine nums[-1] = nums[n] = -inf. Must run in O(log n) time.

🐢 Brute force first

Linear scan comparing nums[i] > nums[i+1]. First element that decreases is a peak. Time: O(n).

💡 Key insight: Even though the array is NOT sorted, binary search still works! Compare nums[mid] with nums[mid + 1]: if nums[mid] < nums[mid + 1], we are on an upward slope, which guarantees at least one peak must exist to the right! If nums[mid] > nums[mid + 1], we are on a downward slope, so a peak exists at mid or to the left.

🪜 The approach, step by step

  1. Initialize left = 0, right = len(nums) - 1.
  2. While left < right:
  3. Compute mid = left + (right - left) // 2.
  4. If nums[mid] < nums[mid + 1]: climb up to the right → left = mid + 1.
  5. Else: nums[mid] > nums[mid + 1]: peak must be at mid or to the left → right = mid.
  6. When left == right, return left.

🎞️ Visual dry run — nums = [1, 2, 1, 3, 5, 6, 4]

Iter 1: left = 0, right = 6 → mid = 3
        nums[3] = 3 < nums[4] = 5 → Upward slope! Search right.
        left = mid + 1 = 4

Iter 2: left = 4, right = 6 → mid = 5
        nums[5] = 6 > nums[6] = 4 → Downward slope! Search left / mid.
        right = mid = 5

Iter 3: left = 4, right = 5 → mid = 4
        nums[4] = 5 < nums[5] = 6 → Upward slope!
        left = mid + 1 = 5

left == right == 5.
nums[5] = 6 > 5 and 6 > 4. Peak found at index 5! ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
def findPeakElement(nums):
    """
    Binary search following the upward slope.
    """
    left, right = 0, len(nums) - 1
    
    while left < right:
        mid = left + (right - left) // 2
        
        if nums[mid] < nums[mid + 1]:
            # Peak must be to the right
            left = mid + 1
        else:
            # Peak is at mid or to the left
            right = mid
            
    return left

⏱️ Complexity

Time O(log n) — Halves search window each step. Space O(1).

⚠️ Edge cases

  • Strictly increasing array: peak is at last index.
  • Strictly decreasing array: peak is at index 0.
  • Single element array: returns 0 immediately.
