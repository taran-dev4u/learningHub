#28 Find the Index of the First Occurrence in a String EasyLeetCode

📋 The problem

Return the index of the first occurrence of a needle string inside a haystack string, or -1 if absent.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given two strings needle and haystack, return the index of the first occurrence of needle in haystack, or -1 if needle is not part of haystack.

The standard benchmark algorithm for string searching is the Knuth-Morris-Pratt (KMP) Algorithm. Instead of resetting the search pointer all the way back upon a mismatch ($O(n \times m)$ worst case), KMP utilizes a precomputed LPS (Longest Proper Prefix which is also Suffix) table of the needle to skip redundant character comparisons!

LPS Array Construction: lps[i] stores the length of the longest proper prefix of needle[0..i] that is also a suffix of needle[0..i]. When a mismatch occurs at needle[j] against haystack[i], we don't back up i; we simply update j = lps[j - 1] and continue!

🐢 Brute force vs optimal

Naive sliding window takes $O((n - m + 1) \times m)$ time. KMP guarantees strict $O(n + m)$ linear time with $O(m)$ space.

💡 Key insight: KMP failure function: precompute lps array in $O(m)$. On mismatch at needle[j], roll back j = lps[j - 1] without ever rewinding pointer i in haystack!

✅ The solution

def strStr(haystack: str, needle: str) -> int:
    if not needle:
        return 0
    m, n = len(needle), len(haystack)
    if m > n:
        return -1
        
    # 1. Build KMP LPS array
    lps = [0] * m
    prev_lps = 0
    i = 1
    while i < m:
        if needle[i] == needle[prev_lps]:
            prev_lps += 1
            lps[i] = prev_lps
            i += 1
        elif prev_lps > 0:
            prev_lps = lps[prev_lps - 1]
        else:
            lps[i] = 0
            i += 1
            
    # 2. Search needle in haystack
    i = 0 # pointer for haystack
    j = 0 # pointer for needle
    while i < n:
        if haystack[i] == needle[j]:
            i += 1
            j += 1
            if j == m:
                return i - m # Match found!
        elif j > 0:
            j = lps[j - 1]
        else:
            i += 1
            
    return -1

Complexity

Time: $O(n + m)$ — $O(m)$ for LPS preprocessing, $O(n)$ for search pass.
Space: $O(m)$ — LPS array for needle of length $m$.
