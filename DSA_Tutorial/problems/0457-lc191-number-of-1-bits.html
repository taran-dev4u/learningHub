📋 The problem

Count how many bits are set to 1 in the binary representation of an integer.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Write a function that takes the binary representation of a positive integer and returns the number of set bits it has (also known as the Hamming weight).

Brian Kernighan's Algorithm: The bitwise operation: $$n \;\&\; (n - 1)$$ always clears the lowest set bit of $n$! - If $n = 12$ (1100): $n - 1 = 11$ (1011) $ o n \;\&\; (n - 1) = 8$ (1000). - If $n = 8$ (1000): $n - 1 = 7$ (0111) $ o n \;\&\; (n - 1) = 0$ (0000).

By repeatedly executing $n = n \;\&\; (n - 1)$ until $n == 0$, the loop runs in strictly $O(k)$ iterations where $k$ is the number of 1 bits, skipping all 0 bits entirely!

🐢 Brute force vs optimal

Testing all 32 bits takes 32 iterations. Brian Kernighan's algorithm takes only as many iterations as there are set bits.

💡 Key insight: while n: n &= (n - 1); count += 1. Clears one set bit per loop iteration.

✅ The solution

Reveal the commented solution (attempt it first!) 
def hammingWeight(n: int) -> int:
    count = 0
    while n:
        n &= (n - 1)
        count += 1
    return count

Complexity

Time: $O(k)$ where $k \le 32$ is the number of set bits.
Space: $O(1)$ — Single counter.
