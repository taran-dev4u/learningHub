#1254 Number of Closed Islands MediumLeetCode

 

Pattern: Graph Traversal Patterns (DFS & BFS) › Subpattern 9.1: Graph DFS - Connected Components / Island Counting · Problem 270 of 699

📋 The problem

Count the islands of 0s that never touch the grid border ('closed' islands).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a 2D grid consists of 0s (land) and 1s (water). An island is a maximal 4-directionally connected group of 0s and a closed island is totally surrounded by 1s (i.e. does not touch the boundary of the grid). Return the number of closed islands.

🐢 Brute force first

Notice the inverted notation: 0 is land, 1 is water! Any land component that touches the boundary is not closed.

💡 Key insight: First, eliminate all land (0s) connected to the grid boundary by running DFS from the 4 borders and turning them into water (1s). Then, standard island counting: any remaining 0 is guaranteed to be a closed island!

🪜 The approach, step by step

  1. Iterate borders: if grid[r][c] == 0, run dfs(r, c) to turn into 1.
  2. Now scan interior: if grid[r][c] == 0, closed_islands += 1, run dfs(r, c) to sink the island.
  3. Return closed_islands.

✅ The solution

def closedIsland(grid):
    m, n = len(grid), len(grid[0])
    
    def dfs(r, c):
        if r < 0 or r >= m or c < 0 or c >= n or grid[r][c] == 1:
            return
        grid[r][c] = 1  # Turn land into water
        dfs(r + 1, c)
        dfs(r - 1, c)
        dfs(r, c + 1)
        dfs(r, c - 1)
        
    # Step 1: Sink boundary-connected land
    for r in range(m):
        for c in (0, n - 1):
            if grid[r][c] == 0: dfs(r, c)
    for c in range(n):
        for r in (0, m - 1):
            if grid[r][c] == 0: dfs(r, c)
            
    # Step 2: Count closed islands
    closed = 0
    for r in range(1, m - 1):
        for c in range(1, n - 1):
            if grid[r][c] == 0:
                closed += 1
                dfs(r, c)
                
    return closed

⏱️ Complexity

Time O(m * n). Space O(m * n).

⚠️ Edge cases

  • Grid of size <= 2: no closed islands possible, returns 0.
