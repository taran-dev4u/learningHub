📋 The problem

Return all combinations of k numbers chosen from 1..n.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given two integers n and k, return all possible combinations of k numbers chosen from the range [1, n].

🐢 Brute force vs optimal

We can optimize the search by pruning the loop range: if the number of remaining elements in the range is strictly less than the number of elements we still need to complete k, stop looping!

💡 Key insight: Number of slots remaining = k - len(path). If we pick number i, there are n - i + 1 numbers available. Thus we only need to iterate i while n - i + 1 >= k - len(path) → i <= n - (k - len(path)) + 1! This avoids exploring dead-end branches.

✅ The solution

def combine(n: int, k: int) -> list[list[int]]:
    """
    Generates all combinations of k numbers from 1 to n with loop boundary pruning.
    """
    res = []
    path = []
    
    def backtrack(start):
        if len(path) == k:
            res.append(list(path))
            return
            
        # Pruned upper bound: no need to search if remaining elements < needed
        needed = k - len(path)
        upper_bound = n - needed + 1
        
        for i in range(start, upper_bound + 1):
            path.append(i)
            backtrack(i + 1)
            path.pop()
            
    backtrack(1)
    return res

⚡ Complexity analysis

  • Time Complexity: O(k × C(n, k)) where C(n, k) = n! / (k!(n-k)!).
  • Space Complexity: O(k) for the recursion stack.
