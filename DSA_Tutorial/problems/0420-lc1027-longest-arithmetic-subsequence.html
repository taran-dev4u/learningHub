📋 The problem

Return the length of the longest arithmetic subsequence (constant difference) of an array.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an array nums of integers, return the length of the longest arithmetic subsequence in nums. A subsequence is arithmetic if $nums[i_{k+1}] - nums[i_k]$ is constant for all $k$.

An arithmetic sequence is determined by its common difference $d = nums[i] - nums[j]$. Let $dp[i][d]$ be the length of the arithmetic subsequence ending at index $i$ with difference $d$. For each $j < i$: $$d = nums[i] - nums[j]$$ $$dp[i][d] = dp[j].get(d, 1) + 1$$ Global answer is $\max_{i, d} dp[i][d]$.

🐢 Brute force vs optimal

Using a list of hash maps $dp[i]$ where each map keys differences to subsequence lengths runs in $O(n^2)$ time and $O(n^2)$ space.

💡 Key insight: Maintain dp[i][diff] as the length of arithmetic subsequence ending at i with common difference diff. Transition: dp[i][diff] = dp[j].get(diff, 1) + 1.

✅ The solution

Reveal the commented solution (attempt it first!) 
def longestArithSeqLength(nums: list[int]) -> int:
    n = len(nums)
    dp = [{} for _ in range(n)]
    max_len = 2
    
    for i in range(n):
        for j in range(i):
            diff = nums[i] - nums[j]
            prev_len = dp[j].get(diff, 1)
            curr_len = prev_len + 1
            dp[i][diff] = curr_len
            if curr_len > max_len:
                max_len = curr_len
                
    return max_len

Complexity

Time: $O(n^2)$ — Double nested iteration over all index pairs $(j, i)$.
Space: $O(n^2)$ — Dictionary states across $n$ indices.
