#583 Delete Operation for Two Strings MediumLeetCode

 

Pattern: Dynamic Programming (DP) Patterns › Subpattern 12.6: 2D Array / Longest Common Subsequence (LCS) · Problem 400 of 699

📋 The problem

Return the minimum deletions (from either string) to make two strings equal.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given two strings word1 and word2, return the minimum number of steps required to make word1 and word2 the same. In one step, you can delete exactly one character in either string.

To make both strings equal with minimum deletions, we should preserve the Longest Common Subsequence (LCS) of the two strings! Let $L = \text{LCS}(word1, word2)$. Every character not in the LCS must be deleted. $$\text{Min Deletions} = (\text{len}(word1) - L) + (\text{len}(word2) - L) = \text{len}(word1) + \text{len}(word2) - 2L$$

🐢 Brute force vs optimal

Computing all common subsequences takes exponential time. Standard 2D LCS DP runs in $O(m \times n)$ time and $O(n)$ space.

💡 Key insight: Min deletions $= m + n - 2 \times \text{LCS}(s1, s2)$. Reduces directly to Longest Common Subsequence!

✅ The solution

def minDistance(word1: str, word2: str) -> int:
    m, n = len(word1), len(word2)
    dp = [0] * (n + 1)
    
    for i in range(1, m + 1):
        prev_diag = 0
        for j in range(1, n + 1):
            temp = dp[j]
            if word1[i - 1] == word2[j - 1]:
                dp[j] = prev_diag + 1
            else:
                dp[j] = max(dp[j], dp[j - 1])
            prev_diag = temp
            
    lcs = dp[n]
    return m + n - 2 * lcs

Complexity

Time: $O(m \times n)$ — Standard LCS calculation.
Space: $O(n)$ — 1D rolling array.
