Where this fits

State-Machine DP (Stock & Beyond) — State machine — track 'holding/sold/cooldown' or finite mode transitions for stock/path problems.

Why this pattern?

  • two strings/sequences compared → 2-D prefix DP
  • pick items under a budget → knapsack (0/1 vs unbounded!)
  • "longest increasing …" → LIS (O(n log n) with patience trick)
  • operations on ranges "burst/merge/remove" → interval DP over lengths

        if a[i-1] == b[j-1]:
            dp[i][j] = dp[i-1][j-1]         # free match
        else:
            dp[i][j] = 1 + min(dp[i-1][j],      # delete
                               dp[i][j-1],      # insert
                               dp[i-1][j-1])    # replace
