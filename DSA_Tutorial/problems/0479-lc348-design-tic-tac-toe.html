#348 Design Tic-Tac-Toe MediumLeetCode

📋 The problem

Design tic-tac-toe on an n×n board where move(row, col, player) reports a winner in O(1) per move.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Assume an $n \times n$ Tic-Tac-Toe board. Design a game class where players take turns placing marks. A player wins if they place $n$ marks in any row, column, or diagonal. The move(row, col, player) must return the winner if this move won the game, or 0 otherwise.

The $O(1)$ Line Counters Trick: Instead of maintaining an $n \times n$ board and scanning the row/column after every move ($O(n)$): Assign player 1 a score of +1 and player 2 a score of -1! Maintain: - rows[n]: running sum for each row. - cols[n]: running sum for each column. - diag: running sum for the main diagonal ($row == col$). - anti_diag: running sum for the anti-diagonal ($row + col == n - 1$).

When player makes a move: Add score ($+1$ or $-1$) to the corresponding row, column, and diagonals. If the absolute value of any updated counter reaches $n$, that player has won!

🐢 Brute force vs optimal

Scanning board takes $O(n)$ per move. Counter updates execute in strictly $O(1)$ time and $O(n)$ space.

💡 Key insight: Track line sums (+1 for P1, -1 for P2). If abs(rows[r]) == n or abs(cols[c]) == n or abs(diag) == n, the player won in $O(1)$ time!

✅ The solution

Reveal the commented solution (attempt it first!) 
class TicTacToe:
    def __init__(self, n: int):
        self.n = n
        self.rows = [0] * n
        self.cols = [0] * n
        self.diag = 0
        self.anti_diag = 0

    def move(self, row: int, col: int, player: int) -> int:
        score = 1 if player == 1 else -1
        n = self.n
        
        self.rows[row] += score
        self.cols[col] += score
        if row == col:
            self.diag += score
        if row + col == n - 1:
            self.anti_diag += score
            
        if (abs(self.rows[row]) == n or
            abs(self.cols[col]) == n or
            abs(self.diag) == n or
            abs(self.anti_diag) == n):
            return player
            
        return 0

Complexity

Time: $O(1)$ per move.
Space: $O(n)$ — Arrays for row and column sums.
