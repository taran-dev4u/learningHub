#719 Find K-th Smallest Pair Distance HardLeetCode

 

Pattern: Binary Search Patterns › Subpattern 8.3: On Answer / Condition Function · Problem 249 of 699

📋 The problem

Return the k-th smallest absolute difference among all pairs in an array.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

The distance of a pair of integers (a, b) is defined as the absolute difference |a - b|. Given an integer array nums and an integer k, return the k-th smallest distance among all the pairs. The number of pairs is n * (n - 1) // 2.

🐢 Brute force first

Calculate all pair differences, put in a list or heap, and find the k-th smallest. O(n^2 log n) space and time. For n = 10,000, pair count is ~50 million → Memory Limit Exceeded.

💡 Key insight: The pair distance must fall in range [0, max(nums) - min(nums)]. If we sort nums, for any distance D, we can count how many pairs have difference <= D in O(n) using a sliding window two-pointer! Binary search on the distance D.

🪜 The approach, step by step

  1. Sort nums ascending.
  2. left = 0, right = nums[-1] - nums[0].
  3. Helper countPairs(dist):
    • Use two pointers i and j: for each right_idx, advance left_idx until nums[right_idx] - nums[left_idx] <= dist.
    • Number of valid pairs ending at right_idx is right_idx - left_idx.
    • Return total pairs.
  4. While left < right: if countPairs(mid) >= k: right = mid; else left = mid + 1.
  5. Return left.

🎞️ Visual dry run — nums = [1, 3, 1], k = 1

left == right == 0.
Return 0! ✓

✅ The solution

def smallestDistancePair(nums, k):
    nums.sort()
    
    def countPairsWithDistanceLessThanOrEqual(dist):
        count = 0
        left_idx = 0
        for right_idx in range(len(nums)):
            while nums[right_idx] - nums[left_idx] > dist:
                left_idx += 1
            count += right_idx - left_idx
        return count

    left, right = 0, nums[-1] - nums[0]
    
    while left < right:
        mid = left + (right - left) // 2
        if countPairsWithDistanceLessThanOrEqual(mid) >= k:
            right = mid
        else:
            left = mid + 1
            
    return left

⏱️ Complexity

Time O(n log n + n * log(max_val - min_val)) — Sorting takes O(n log n). Each binary search step runs two pointers in O(n). Space O(1).

⚠️ Edge cases

  • All elements identical: distances are all 0, returns 0.
  • k = 1: returns smallest adjacent difference.
