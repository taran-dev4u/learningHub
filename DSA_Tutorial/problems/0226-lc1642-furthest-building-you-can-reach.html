📋 The problem

Climb buildings using b bricks and l ladders (ladders cover any jump, bricks the difference); go as far as possible (heap of jumps: ladders for the largest).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You have buildings with heights, bricks, and ladders. Moving from building i to i + 1: if height decreases or stays same, 0 cost; if height increases by diff, use 1 ladder OR diff bricks. Ladders can cover ANY height difference, no matter how tall. Greedily, ladders should be reserved for the largest height climbs.

🐢 Brute force first

Backtracking DFS: at each climb, try either ladder or bricks → O(2^n).

💡 Key insight: use a min-heap of size at most ladders. For every climb, assume we use a ladder and push diff to the heap. When climbs exceed available ladders, pop the smallest climb from the heap and pay for it with bricks. If bricks drop below 0, we can go no further.

🪜 The approach, step by step

  1. Initialize min-heap ladder_climbs = [].
  2. For i from 0 to len(heights) - 2:
  3. diff = heights[i + 1] - heights[i].
  4. If diff > 0: push diff to heap.
  5. If len(ladder_climbs) > ladders: pop smallest climb and deduct from bricks.
  6. If bricks < 0: return i (cannot make this climb).
  7. If loop completes, return len(heights) - 1.

🎞️ Visual dry run — heights=[4,2,7,6,9,14,12], bricks=5, ladders=1

i=0: 4->2 (down)
i=1: 2->7 (diff 5): heap=[5] (size 1 <= 1 ladder)
i=2: 7->6 (down)
i=3: 6->9 (diff 3): push 3 → heap=[3, 5] > 1 ladder → pop 3 → bricks = 5 - 3 = 2. heap=[5]
i=4: 9->14 (diff 5): push 5 → heap=[5, 5] > 1 ladder → pop 5 → bricks = 2 - 5 = -3 < 0!

✅ The solution

import heapq

def furthestBuilding(heights, bricks, ladders):
    ladder_allocations = []   # min-heap tracking climbs covered by ladders
    
    for i in range(len(heights) - 1):
        diff = heights[i + 1] - heights[i]
        if diff > 0:
            heapq.heappush(ladder_allocations, diff)
            # If we used more ladders than available, convert the smallest climb to bricks
            if len(ladder_allocations) > ladders:
                bricks -= heapq.heappop(ladder_allocations)
            if bricks < 0:
                return i
                
    return len(heights) - 1

⏱️ Complexity

Time O(n log L) — where n is number of buildings and L is number of ladders. Space O(L) for the heap.

⚠️ Edge cases

  • Decreasing heights throughout: reaches the final building with 0 resource usage.
  • 0 ladders: all climbs paid with bricks.
