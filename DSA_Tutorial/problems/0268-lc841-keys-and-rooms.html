#841 Keys and Rooms MediumLeetCode

📋 The problem

Rooms hold keys to other rooms; starting with room 0 unlocked, decide whether every room can be visited.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There are n rooms labeled 0 to n - 1, and all the rooms are locked except for room 0. Each room has a list of keys rooms[i] to other rooms. Return true if you can visit all the rooms, or false otherwise.

🐢 Brute force first

This is standard graph reachability starting from source node 0. Traverse all reachable nodes via BFS/DFS; check if len(visited) == n.

💡 Key insight: Standard BFS/DFS traversal with a visited set starting at 0. When traversal completes, if len(visited) == len(rooms), all rooms were unlocked!

🪜 The approach, step by step

  1. visited = {0}, stack = [0].
  2. While stack is not empty:
    • Pop room = stack.pop().
    • For key in rooms[room]: if key not in visited: add to visited, push to stack.
  3. Return len(visited) == len(rooms).

🎞️ Visual dry run — rooms = [[1],[2],[3],[]]

Start at 0: visited = {0}, keys: [1]
Visit 1: visited = {0, 1}, keys: [2]
Visit 2: visited = {0, 1, 2}, keys: [3]
Visit 3: visited = {0, 1, 2, 3}, keys: []
len(visited) == 4 == len(rooms) -> True! ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
def canVisitAllRooms(rooms):
    visited = {0}
    stack = [0]
    
    while stack:
        room = stack.pop()
        for key in rooms[room]:
            if key not in visited:
                visited.add(key)
                stack.append(key)
                
    return len(visited) == len(rooms)

⏱️ Complexity

Time O(V + E) where V = len(rooms) and E = total keys. Space O(V) for visited set.

⚠️ Edge cases

  • Cycles in keys (e.g. room 0 has key 1, room 1 has key 0): handled cleanly by visited set.
  • Isolated room with no incoming keys: returns False.
