#1312 Minimum Insertion Steps to Make a String Palindrome HardLeetCode

 

Pattern: Dynamic Programming (DP) Patterns › Subpattern 12.12: Palindrome DP · Problem 428 of 699

📋 The problem

Return the minimum insertions to make a string a palindrome (n − longest palindromic subsequence).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a string s. In one step you can insert any character at any position of the string. Return the minimum number of steps to make s a palindrome.

Any character that is already part of the Longest Palindromic Subsequence (LPS) does NOT need to be paired by insertion—it is already mirrored! Every character outside the LPS requires exactly one matching insertion on the opposite side. $$\text{Min Insertions} = \text{len}(s) - \text{LPS}(s)$$ Recall: $\text{LPS}(s) = \text{LCS}(s, \text{reverse}(s))$!

🐢 Brute force vs optimal

This problem reduces directly to finding the Longest Palindromic Subsequence (LC 516) or LCS with the reversed string in $O(n^2)$ time and $O(n)$ space.

💡 Key insight: Min Insertions $= n - \text{LPS}(s)$. Compute LPS bottom-up on intervals $[l, r]$ or via LCS with reversed string.

✅ The solution

Reveal the commented solution (attempt it first!) 
def minInsertions(s: str) -> int:
    n = len(s)
    dp = [0] * n
    
    # Bottom-up interval DP for Longest Palindromic Subsequence
    for l in range(n - 1, -1, -1):
        prev_diag = 0
        dp[l] = 1 # Single character is palindrome of length 1
        for r in range(l + 1, n):
            temp = dp[r]
            if s[l] == s[r]:
                dp[r] = prev_diag + 2
            else:
                dp[r] = max(dp[r], dp[r - 1])
            prev_diag = temp
            
    lps = dp[n - 1]
    return n - lps

Complexity

Time: $O(n^2)$ — Nested interval loops.
Space: $O(n)$ — 1D rolling array for LPS.
