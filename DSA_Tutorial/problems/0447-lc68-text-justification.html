📋 The problem

Greedily pack words into lines of exactly maxWidth characters, distributing spaces as evenly as possible (left-justify the last line).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

String Matching / Naive / KMP / Rabin-Karp — Naive O(nm) substring search; KMP and Rabin-Karp give O(n+m) and O(n) average.

Why this pattern?

  • "anagram", "permutation of", "rearrange"
  • "group the strings that…" → canonical key + dict
  • palindromes (two pointers or expand-from-center)
  • parse/normalize (spaces, signs, overflow) — careful state machines

for w in words:

    groups[key].append(w)

# Expand from center (palindromes)
def expand(s, l, r):
    while l >= 0 and r < len(s) and s[l] == s[r]:
        l -= 1; r += 1
    return s[l+1:r]               # overshoot by one on both sides
# try (i, i) and (i, i+1) for every center: odd + even lengths
