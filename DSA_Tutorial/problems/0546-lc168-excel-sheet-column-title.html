📋 The problem

Convert a positive integer to its Excel column title (1→A, 26→Z, 27→AA, …).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an integer columnNumber, return its corresponding column title as it appears in an Excel sheet (1 -> A, 2 -> B, ..., 26 -> Z, 27 -> AA, 28 -> AB, ...).

Key Insights

This is a bijective base-26 numeral system without a 0 digit (digits range from 1 to 26 rather than 0 to 25). To adapt standard base conversion: decrement columnNumber by 1 at each iteration before taking modulo 26!

rem = (columnNumber - 1) % 26
char = chr(ord('A') + rem)
columnNumber = (columnNumber - 1) // 26
Python 3 Solution (Click to Expand) 
class Solution:
    def convertToTitle(self, columnNumber: int) -> str:
        res = []
        while columnNumber > 0:
            columnNumber -= 1
            rem = columnNumber % 26
            res.append(chr(ord('A') + rem))
            columnNumber //= 26
        return "".join(reversed(res))

Complexity & Edge Cases

  • Time Complexity: {2, 3, 5}O(\log_{26}( ext{columnNumber})){2, 3, 5}.
  • Space Complexity: {2, 3, 5}O(1){2, 3, 5} auxiliary space.
  • Edge Cases: Exact multiples of 26 (e.g. 26 -> "Z", 52 -> "AZ", 702 -> "ZZ").
