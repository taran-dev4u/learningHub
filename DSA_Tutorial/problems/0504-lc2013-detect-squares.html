📋 The problem

Design a structure that adds points and counts axis-aligned squares completable with a query point (dict of point counts, iterate diagonal partners).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a data structure that counts the number of ways to form axis-aligned squares with given points. Support add(point) and count(point).

Let the query point be $P_1 = (x_1, y_1)$. A square is uniquely determined by choosing its diagonal opposite point $P_3 = (x_3, y_3)$! Iterate over all existing points $(x_3, y_3)$: 1. A valid diagonal must satisfy: $|x_1 - x_3| == |y_1 - y_3|$ and $x_1 e x_3$. 2. Once $P_1$ and $P_3$ are chosen, the other two corners are fixed and mandatory: $$P_2 = (x_1, y_3) \quad ext{and} \quad P_4 = (x_3, y_1)$$ 3. The number of squares formed with diagonal $(P_1, P_3)$ is: $$ ext{count}(P_3) \times ext{count}(P_2) \times ext{count}(P_4)$$

🐢 Brute force vs optimal

Checking all 3-tuples takes $O(N^3)$. Iterating only over diagonal points takes $O(N)$ where $N$ is distinct points added.

💡 Key insight: For query point $(x_1, y_1)$, iterate over all points $(x_3, y_3)$. If $|x_1 - x_3| == |y_1 - y_3| > 0$, multiply frequencies of $(x_1, y_3)$ and $(x_3, y_1)$!

✅ The solution

Reveal the commented solution (attempt it first!) 
from collections import Counter

class DetectSquares:
    def __init__(self):
        self.pts = Counter()

    def add(self, point: list[int]) -> None:
        self.pts[tuple(point)] += 1

    def count(self, point: list[int]) -> int:
        x1, y1 = point
        total = 0
        
        # Iterate over all registered points as potential diagonal opposites
        for (x3, y3), count3 in self.pts.items():
            # Must form non-zero square diagonal
            if abs(x1 - x3) == abs(y1 - y3) and x1 != x3:
                p2 = (x1, y3)
                p4 = (x3, y1)
                if p2 in self.pts and p4 in self.pts:
                    total += count3 * self.pts[p2] * self.pts[p4]
                    
        return total

Complexity

Time: add: $O(1)$. count: $O(N)$ where $N$ is distinct points.
Space: $O(N)$ — Frequency map of points.
