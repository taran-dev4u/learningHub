📋 The problem

Return the fewest perfect square numbers that sum to n.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer n, return the least number of perfect square numbers that sum to n. A perfect square is an integer that is the square of an integer (e.g., 1, 4, 9, 16...).

This is an unbounded knapsack problem where coin values are squares $1, 4, 9, \dots, s^2 \le n$. Let $dp[i]$ be the minimum number of square numbers summing to $i$: $$dp[i] = 1 + \min_{j \times j \le i} dp[i - j \times j]$$

🐢 Brute force vs optimal

Exhaustive search is exponential. Dynamic programming tabulates bottom-up in $O(n \sqrt{n})$ time. Alternatively, Legendre's Three-Square Theorem classifies answers into 1, 2, 3, or 4 in $O(\sqrt{n})$ time.

💡 Key insight: Standard 1D DP: initialize $dp[0]=0, dp[i]=\infty$. For each $i$ from 1 to $n$, iterate over all $j \times j \le i$ and minimize $1 + dp[i - j^2]$.

✅ The solution

def numSquares(n: int) -> int:
    dp = [float('inf')] * (n + 1)
    dp[0] = 0
    
    # Precompute squares <= n
    squares = [j * j for j in range(1, int(n**0.5) + 1)]
    
    for i in range(1, n + 1):
        for sq in squares:
            if sq > i:
                break
            if dp[i - sq] + 1 < dp[i]:
                dp[i] = dp[i - sq] + 1
                
    return dp[n]

Complexity

Time: $O(n \sqrt{n})$ — Outer loop runs $n$ times; inner loop runs $\sqrt{n}$ times.
Space: $O(n)$ — 1D array of size $n+1$.
