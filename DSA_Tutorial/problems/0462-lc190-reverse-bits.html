📋 The problem

Reverse the bits of a 32-bit unsigned integer.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Reverse bits of a given 32 bits unsigned integer.

Iterate 32 times: 1. Shift result left by 1: res = (res << 1). 2. Extract the lowest bit of $n$: res |= (n & 1). 3. Shift $n$ right by 1: n >>= 1.

🐢 Brute force vs optimal

32-step bit-by-bit reversal runs in $O(1)$ time. For frequent calls, precomputing a 256-entry lookup table reverses 8 bits per step (4 table lookups total).

💡 Key insight: 32-bit shift register: res = (res << 1) | (n & 1); n >>= 1 for 32 iterations.

✅ The solution

Reveal the commented solution (attempt it first!) 
def reverseBits(n: int) -> int:
    res = 0
    for _ in range(32):
        res = (res << 1) | (n & 1)
        n >>= 1
    return res

Complexity

Time: $O(1)$ — Exactly 32 operations.
Space: $O(1)$ — Single 32-bit register.
