📋 The problem

Apply flight bookings (first, last, seats) as range additions and return seats per flight (difference array).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There are n flights that are labeled from 1 to n. You are given an array of flight bookings bookings = [first, last, seats]. Return an array answer of length n where answer[i] is the total number of seats reserved for flight i.

Standard Difference Array on 1-based indices $1 \dots n$: For each booking $[first, last, seats]$: - diff[first - 1] += seats - If $last < n$: diff[last] -= seats.

Running prefix sum of diff reconstructs total seats per flight in $O(n)$ time!

🐢 Brute force vs optimal

Adding seats to each flight range directly takes $O(B imes n)$ time. Difference array takes $O(B + n)$ linear time.

💡 Key insight: Difference array: diff[first - 1] += seats; diff[last] -= seats. Cumulative sum produces flight reservations in $O(B + n)$ time!

✅ The solution

Reveal the commented solution (attempt it first!) 
def corpFlightBookings(bookings: list[list[int]], n: int) -> list[int]:
    diff = [0] * (n + 1)
    
    for first, last, seats in bookings:
        diff[first - 1] += seats
        diff[last] -= seats
        
    res = [0] * n
    curr = 0
    for i in range(n):
        curr += diff[i]
        res[i] = curr
        
    return res

Complexity

Time: $O(B + n)$ where $B$ is number of bookings.
Space: $O(n)$ — Difference array of size $n+1$.
