#699 Falling Squares HardLeetCode

 

Pattern: Segment Tree & Fenwick Tree Patterns › Subpattern 16.1: Segment Tree / Range Query with Updates · Problem 511 of 699

📋 The problem

Squares drop along a line Tetris-style; after each drop report the current tallest stack height.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There are several squares being dropped onto an X-axis. Each square is given by positions[i] = [left, side_length]. When a square falls, it drops until it lands on the top edge of another square or on the X-axis. Return a list of heights after each square falls.

For each newly dropped square with interval $[left, left + side)$: The landing height is: $$h_{land} = side + \max_{j < i, \; [l_j, r_j) ext{ overlaps } [l, r)} height[j]$$

🐢 Brute force vs optimal

With $N \le 1000$, checking previously dropped squares takes $O(N)$ per square, totaling $O(N^2)$ time. For $N = 10^5$, a Segment Tree with Lazy Propagation and Coordinate Compression solves it in $O(N \log N)$ time.

💡 Key insight: For current square $[l, r)$, find maximum height of all overlapping previous intervals, add $side$, and record. $O(N^2)$ interval check is optimal and clean for $N=1000$.

✅ The solution

Reveal the commented solution (attempt it first!) 
def fallingSquares(positions: list[list[int]]) -> list[int]:
    intervals = [] # stores (left, right, height)
    res = []
    max_h = 0
    
    for left, side in positions:
        right = left + side
        base_h = 0
        # Check all previous intervals for overlap
        for prev_l, prev_r, prev_h in intervals:
            # Overlap condition: max(left, prev_l) < min(right, prev_r)
            if left < prev_r and right > prev_l:
                base_h = max(base_h, prev_h)
                
        curr_h = base_h + side
        intervals.append((left, right, curr_h))
        max_h = max(max_h, curr_h)
        res.append(max_h)
        
    return res

Complexity

Time: $O(N^2)$ — Compares each square against previous intervals.
Space: $O(N)$ — Stores active intervals and results.
