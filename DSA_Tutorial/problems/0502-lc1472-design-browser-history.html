📋 The problem

Design browser history: visit clears forward history; back(steps) and forward(steps) move along it.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You have a browser of one tab where you start on the homepage and you can visit another url, get back in the history number of steps and move forward in the history number of steps.

Dynamic Array with Two Pointers: Instead of two stacks (back stack and forward stack): Maintain a single dynamic array history and two integer pointers: - curr: current page index. - max_bound: rightmost reachable history index.

- visit(url): advance curr += 1. If curr == len(history), append; otherwise overwrite history[curr] = url. Set max_bound = curr (clears forward history!). - back(steps): curr = max(0, curr - steps). Return history[curr]. - forward(steps): curr = min(max_bound, curr + steps). Return history[curr].

🐢 Brute force vs optimal

Two stacks require moving elements back and forth. A pointer on a single array executes all three operations in $O(1)$ time.

💡 Key insight: Single array with curr and max_bound pointers. visit overwrites forward history. back and forward are simple $O(1)$ integer clamping!

✅ The solution

Reveal the commented solution (attempt it first!) 
class BrowserHistory:
    def __init__(self, homepage: str):
        self.history = [homepage]
        self.curr = 0
        self.max_bound = 0

    def visit(self, url: str) -> None:
        self.curr += 1
        if self.curr < len(self.history):
            self.history[self.curr] = url
        else:
            self.history.append(url)
        self.max_bound = self.curr

    def back(self, steps: int) -> str:
        self.curr = max(0, self.curr - steps)
        return self.history[self.curr]

    def forward(self, steps: int) -> str:
        self.curr = min(self.max_bound, self.curr + steps)
        return self.history[self.curr]

Complexity

Time: $O(1)$ for visit, back, and forward.
Space: $O(N)$ where $N$ is total visited URLs.
