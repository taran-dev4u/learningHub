📋 The problem

Insert a new interval into a sorted list of non-overlapping intervals, merging where needed.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an array of non-overlapping intervals intervals sorted by start time, and a newInterval = [start, end]. Insert newInterval into intervals such that the list is still sorted and non-overlapping (merging if necessary).

Because the input is already sorted, we can partition the problem into three linear phases:

  1. Left Part: Add all intervals that finish strictly before newInterval begins (interval[1] < newInterval[0]).
  2. Overlap Part: Merge all intervals that overlap with newInterval (interval[0] <= newInterval[1]). Update newInterval = [min(start), max(end)].
  3. Right Part: Add all remaining intervals that start strictly after newInterval ends.

🐢 Brute force vs optimal

Appending newInterval and calling sort() takes O(N log N). By leveraging the existing sorted order, we achieve pure O(N) time in a single pass without sorting!

💡 Key insight: Loop through the sorted intervals. If curr[1] < new[0], add curr to result. If curr[0] > new[1], add new (if not added yet) and curr. Otherwise, they overlap—expand new[0] = min(new[0], curr[0]) and new[1] = max(new[1], curr[1]).

🪜 The approach, step by step

  1. Initialize result = [] and i = 0, n = len(intervals).
  2. Phase 1 (Before): While i < n and intervals[i][1] < newInterval[0]: result.append(intervals[i]); i += 1.
  3. Phase 2 (Overlap): While i < n and intervals[i][0] <= newInterval[1]: newInterval[0] = min(newInterval[0], intervals[i][0]); newInterval[1] = max(newInterval[1], intervals[i][1]); i += 1. Append merged newInterval to result.
  4. Phase 3 (After): While i < n: result.append(intervals[i]); i += 1.
  5. Return result.

🎞️ Visual dry run — intervals = [[1,3],[6,9]], newInterval = [2,5]:

1. Phase 1: [1,3] has 3 >= 2 -> does not finish before newInterval. Phase 1 ends.
2. Phase 2 (Overlap):
   - [1,3]: 1 <= 5 (overlap!) -> newInterval = [min(2,1), max(5,3)] = [1,5]
   - [6,9]: 6 > 5 -> stops overlap!
   Append [1,5] to result: result = [[1,5]]
3. Phase 3 (After):
   Append [6,9]: result = [[1,5], [6,9]]
Output: [[1,5], [6,9]] ✓

✅ The solution

def insert(intervals: list[list[int]], newInterval: list[int]) -> list[list[int]]:
    """
    Inserts and merges a new interval into sorted non-overlapping intervals in O(N) time.
    """
    res = []
    i = 0
    n = len(intervals)
    
    # 1. Add all intervals ending before newInterval starts
    while i < n and intervals[i][1] < newInterval[0]:
        res.append(intervals[i])
        i += 1
        
    # 2. Merge all overlapping intervals with newInterval
    while i < n and intervals[i][0] <= newInterval[1]:
        newInterval[0] = min(newInterval[0], intervals[i][0])
        newInterval[1] = max(newInterval[1], intervals[i][1])
        i += 1
    res.append(newInterval)
    
    # 3. Add all remaining intervals
    while i < n:
        res.append(intervals[i])
        i += 1
        
    return res

⚡ Complexity analysis

  • Time Complexity: O(N). Each interval is examined and pushed to the result array exactly once.
  • Space Complexity: O(N) to store the output array (or O(1) auxiliary space).

🚨 Edge cases to watch out for

  • intervals = []: Returns [newInterval].
  • newInterval goes at the very beginning or very end without overlapping any interval.
  • newInterval engulfs all existing intervals.
