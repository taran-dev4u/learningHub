📋 The problem

Return the n-th Fibonacci number.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

The Fibonacci numbers form a sequence where each number is the sum of the two preceding ones, starting from 0 and 1:

$$F(0) = 0, \quad F(1) = 1, \quad F(n) = F(n - 1) + F(n - 2) \quad \text{for } n \ge 2$$

🐢 Brute force vs optimal

Naive recursion computes the recurrence tree with branching factor 2, leading to exponential $O(2^n)$ time and $O(n)$ call stack depth. By recognizing that we only ever need the previous two terms ($F(i-1)$ and $F(i-2)$), we can iterate linearly with two variables, reducing time to $O(n)$ and space to $O(1)$.

💡 Key insight: Rolling state update with two scalar registers a, b = b, a + b computes the nth term in $O(n)$ time and $O(1)$ space. For astronomical $n$, Matrix Exponentiation or Binet's Formula solves it in $O(\log n)$.

✅ The solution

Reveal the commented solution (attempt it first!) 
def fib(n: int) -> int:
    """
    Computes F(n) in O(n) time and O(1) space.
    """
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b

Complexity

Time: $O(n)$ — Single linear pass from 2 to n.
Space: $O(1)$ — Only two integer variables maintained.
