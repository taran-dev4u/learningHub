#857 Minimum Cost to Hire K Workers HardLeetCode

 

Pattern: Heap (Priority Queue) Patterns › Subpattern 7.4: Scheduling / Minimum Cost with Priority Queue · Problem 223 of 699

📋 The problem

Hire exactly k workers, paying everyone the same wage-to-quality ratio and at least their minimum wage; minimize total cost.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Hire k workers paid in proportion to their quality, satisfying each worker's minimum wage. If we pick a group of workers, the wage is set by the worker with the highest wage-to-quality ratio R = max(wage[i] / quality[i]). Total cost is R * sum(qualities). To minimize cost, for a fixed ratio R, we want the k workers with the smallest qualities.

🐢 Brute force first

Try every combination of k workers, find max ratio, compute cost → exponential.

💡 Key insight: sort workers by wage / quality ratio ascending. Iterate through workers: maintain a max-heap of qualities of size k. When heap size reaches k, compute cost = ratio * quality_sum and keep the minimum. If heap exceeds k, pop the largest quality.

🪜 The approach, step by step

  1. Calculate ratios and sort: workers = sorted([(w / q, q) for w, q in zip(wage, quality)]).
  2. Initialize max-heap qual_heap = [], qual_sum = 0, min_cost = inf.
  3. For each ratio, q in workers:
  4. Push -q to heap, add q to qual_sum.
  5. If len(qual_heap) > k: qual_sum += heappop(qual_heap) (removes largest quality).
  6. If len(qual_heap) == k: min_cost = min(min_cost, ratio * qual_sum).
  7. Return min_cost.

✅ The solution

import heapq

def mincostToHireWorkers(quality, wage, k):
    # Sort workers by wage/quality ratio ascending
    workers = sorted([(w / q, q) for w, q in zip(wage, quality)])
    
    max_heap = []   # stores negative qualities to easily evict the largest
    qual_sum = 0
    min_cost = float('inf')
    
    for ratio, q in workers:
        heapq.heappush(max_heap, -q)
        qual_sum += q
        
        # Keep only k workers with the smallest qualities
        if len(max_heap) > k:
            qual_sum += heapq.heappop(max_heap)   # heappop returns negative q
            
        if len(max_heap) == k:
            min_cost = min(min_cost, ratio * qual_sum)
            
    return min_cost

⏱️ Complexity

Time O(n log n) — O(n log n) to sort workers, plus n heap operations of size k (O(n log k)). Space O(n) for sorted workers and heap.

⚠️ Edge cases

  • k = 1: simply pick the worker with minimal wage.
  • k = n: all workers hired, cost is max(ratios) * sum(qualities).
