#359 Logger Rate Limiter EasyLeetCode

 

Pattern: Design Patterns › Subpattern 15.1: General / Specific Data Structure Design · Problem 482 of 699

📋 The problem

Design a logger that prints a message only if that exact message wasn't printed in the last 10 seconds.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a logger system that receives a stream of messages along with their timestamps. Each unique message should only be printed at most once every 10 seconds.

Maintain a hash map last_printed[message] -> timestamp. When shouldPrintMessage(timestamp, message) is called: - If message not in map OR timestamp >= last_printed[message] + 10: Update last_printed[message] = timestamp and return True. - Otherwise, return False.

🐢 Brute force vs optimal

Hash map gives instant $O(1)$ verification per log entry.

💡 Key insight: Hash map maps msg -> next_allowed_timestamp. If timestamp >= next_allowed, update msg = timestamp + 10 and return True.

✅ The solution

Reveal the commented solution (attempt it first!) 
class Logger:
    def __init__(self):
        self.ok = {}

    def shouldPrintMessage(self, timestamp: int, message: str) -> bool:
        if timestamp < self.ok.get(message, 0):
            return False
        self.ok[message] = timestamp + 10
        return True

Complexity

Time: $O(1)$ per message.
Space: $O(M)$ where $M$ is the number of distinct messages seen.
