#2416 Sum of Prefix Scores of Strings HardLeetCode

 

Pattern: Trie / Prefix Tree Patterns › Subpattern 20.4: Streaming / Autocomplete / Suffix Trie · Problem 575 of 699

📋 The problem

For every word, sum the counts of all its prefixes across the list (trie with per-node counters).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

The score of a string is the number of strings in words that have this string as a prefix. Given an array words, return an array answer where answer[i] is the sum of scores of every non-empty prefix of words[i].

Key Insights

Build a Trie where each node records count (the number of words passing through it). For each word: Traverse its characters in the Trie; at each step, add node.count to the total sum of prefix scores for that word!

Python 3 Solution (Trie Prefix Frequency Accumulation) 
from typing import List

class TrieNode:
    __slots__ = ('children', 'count')
    def __init__(self):
        self.children = {}
        self.count = 0

class Solution:
    def sumPrefixScores(self, words: List[str]) -> List[int]:
        root = TrieNode()
        
        # 1. Insert and count prefix frequencies
        for w in words:
            curr = root
            for ch in w:
                if ch not in curr.children:
                    curr.children[ch] = TrieNode()
                curr = curr.children[ch]
                curr.count += 1
                
        # 2. Query prefix score sum
        ans = []
        for w in words:
            curr = root
            score = 0
            for ch in w:
                curr = curr.children[ch]
                score += curr.count
            ans.append(score)
            
        return ans

Complexity & Edge Cases

  • Time Complexity: $O(N imes L)$ strictly linear in total characters.
  • Space Complexity: $O(N imes L)$ Trie nodes.
