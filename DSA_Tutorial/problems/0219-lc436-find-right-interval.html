#436 Find Right Interval MediumLeetCode

 

Pattern: Heap (Priority Queue) Patterns › Subpattern 7.4: Scheduling / Minimum Cost with Priority Queue · Problem 219 of 699

📋 The problem

For each interval, find the interval whose start is the smallest that is ≥ its end (its 'right' interval), or -1.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

For each interval i, find interval j such that start_j >= end_i with minimum start_j. Return the index of j, or -1 if none exists. Sorting intervals by their start times allows us to use binary search (bisect_left) on the start times in O(n log n) time.

🐢 Brute force first

For each interval, scan all other intervals to find the one with minimal valid start time → O(n^2).

💡 Key insight: store (start, original_index) for all intervals and sort them. For each interval's end, binary search the sorted starts for the first start >= end.

🪜 The approach, step by step

  1. Create sorted array of pairs: starts = sorted((it[0], i) for i, it in enumerate(intervals)).
  2. Extract just start times for binary search: start_vals = [s[0] for s in starts].
  3. For each interval [start, end]:
  4. Use bisect_left(start_vals, end) to find the first start >= end.
  5. If index < n, its original index is starts[idx][1]; else -1.
  6. Return the collected indices.

✅ The solution

Reveal the commented solution (attempt it first!) 
from bisect import bisect_left

def findRightInterval(intervals):
    n = len(intervals)
    starts = sorted((it[0], i) for i, it in enumerate(intervals))
    start_vals = [s[0] for s in starts]
    
    res = []
    for it in intervals:
        idx = bisect_left(start_vals, it[1])
        if idx < n:
            res.append(starts[idx][1])
        else:
            res.append(-1)
            
    return res

⏱️ Complexity

Time O(n log n) — sorting starts takes O(n log n), plus n binary searches of O(log n). Space O(n) for the starts array.

⚠️ Edge cases

  • Interval is its own right interval (e.g. [1, 1]): valid because start >= end (1 >= 1).
  • No interval starts after an interval ends: returns -1.
