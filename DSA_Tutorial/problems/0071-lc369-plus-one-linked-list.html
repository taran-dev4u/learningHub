📋 The problem

A linked list stores a number most-significant digit first; add one to it.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Addition of Numbers — Add digit-by-digit with a carry, advancing both list pointers.

Why this pattern?

  • input is a linked list (that alone is the signal)
  • "reverse", "reorder", "swap in pairs", "rotate" nodes
  • "k-th from the end", "middle", "cycle" → fast & slow
  • "merge k sorted lists" → pairwise merge or heap of heads

Pattern template to adapt

Start from the Linked List Manipulation master template and adapt the marked parts to this problem:

dummy = ListNode(0, head)            # dummy head: prev of the real head
prev, cur = dummy, head

# In-place reversal core
p = None
while cur:
    cur.next, p, cur = p, cur, cur.next
# p is the new head

# Fast & slow
slow = fast = head
while fast and fast.next:
    slow, fast = slow.next, fast.next.next   # slow = middle when fast ends
