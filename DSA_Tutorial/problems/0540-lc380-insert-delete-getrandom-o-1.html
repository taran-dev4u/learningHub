📋 The problem

Design a set supporting insert, delete, and getRandom (uniform over current elements), each in O(1) average.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Implement the RandomizedSet class such that insert, remove, and getRandom operate in $O(1)$ average time.

Key Insights

  • A Hash Map allows $O(1)$ search and deletion, but does not support picking a uniform random element in $O(1)$ because hash keys cannot be indexed by an integer in $[0, n-1]$.
  • A Dynamic Array (List) supports $O(1)$ uniform random access via index, but deletion of an arbitrary element takes $O(n)$ because elements must shift.
  • Combination (The Swap Trick): Use an array nums and a hash map val_to_idx. To delete an element in $O(1)$ without shifting:
    1. Swap the target element with the last element in the array.
    2. Update the index of the swapped last element in the hash map.
    3. Pop the last element from the array in $O(1)$!
Python 3 Solution (Click to Expand) 
import random

class RandomizedSet:
    def __init__(self):
        self.nums = []
        self.val_to_idx = {}

    def insert(self, val: int) -> bool:
        if val in self.val_to_idx:
            return False
        self.val_to_idx[val] = len(self.nums)
        self.nums.append(val)
        return True

    def remove(self, val: int) -> bool:
        if val not in self.val_to_idx:
            return False
        idx = self.val_to_idx[val]
        last_val = self.nums[-1]
        
        # Move last element to the slot of the element to delete
        self.nums[idx] = last_val
        self.val_to_idx[last_val] = idx
        
        # Pop last element
        self.nums.pop()
        del self.val_to_idx[val]
        return True

    def getRandom(self) -> int:
        return random.choice(self.nums)

Complexity & Invariants

  • Time Complexity: $O(1)$ average for insert, remove, and getRandom.
  • Space Complexity: $O(N)$ to store $N$ elements.
