📋 The problem

Design a calendar that books an event only if it doesn't double-book (overlap any existing event).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Implement the MyCalendar class to store your events. A new event can be added if adding the event will not cause a double booking (two events have some non-empty intersection $[start, end)$).

Key Insights

Two intervals $[s_1, e_1)$ and $[s_2, e_2)$ overlap if and only if: $$\max(s_1, s_2) < \min(e_1, e_2) \iff s_1 < e_2 \quad ext{and} \quad s_2 < e_1$$ Maintain a sorted list of booked intervals using bisect. When booking $[start, end)$: Locate where $[start, end)$ would be inserted with binary search. Check only the immediate predecessor and successor intervals for conflicts in $O(1)$!

Python 3 Solution (Binary Search Insertion) 
import bisect

class MyCalendar:
    def __init__(self):
        self.calendar = []  # sorted by start time

    def book(self, start: int, end: int) -> bool:
        idx = bisect.bisect_right(self.calendar, (start, end))
        
        # Check predecessor conflict
        if idx > 0 and self.calendar[idx - 1][1] > start:
            return False
            
        # Check successor conflict
        if idx < len(self.calendar) and self.calendar[idx][0] < end:
            return False
            
        self.calendar.insert(idx, (start, end))
        return True

Complexity & Edge Cases

  • Time Complexity: $O(\log N)$ binary search check + $O(N)$ list insertion.
  • Space Complexity: $O(N)$.
