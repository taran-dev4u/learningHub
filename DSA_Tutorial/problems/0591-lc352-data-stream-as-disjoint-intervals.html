#352 Data Stream as Disjoint Intervals HardLeetCode

📋 The problem

Numbers arrive one at a time; at any point report the stream summarized as a sorted list of disjoint intervals.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given a data stream input of non-negative integers $a_1, a_2, \dots$, summarize the numbers seen so far as a list of disjoint intervals.

Key Insights

Store all unique numbers in a set or boolean array / sorted list. When returning intervals: Merge consecutive numbers $[start, end]$ where each adjacent pair differs by 1. Using a sorted structure or binary search tree (or maintaining a balanced set in Python with bisect), adjacent intervals can be merged dynamically upon insertion.

Python 3 Solution (Click to Expand) 
from typing import List
import bisect

class SummaryRanges:
    def __init__(self):
        self.intervals = []  # list of [start, end]

    def addNum(self, value: int) -> None:
        # Find insertion position
        idx = bisect.bisect_right(self.intervals, [value, float('inf')])
        
        # Check if already covered by previous interval
        if idx > 0 and self.intervals[idx - 1][1] >= value:
            return
            
        left_merge = (idx > 0 and self.intervals[idx - 1][1] + 1 == value)
        right_merge = (idx < len(self.intervals) and self.intervals[idx][0] == value + 1)
        
        if left_merge and right_merge:
            self.intervals[idx - 1][1] = self.intervals[idx][1]
            self.intervals.pop(idx)
        elif left_merge:
            self.intervals[idx - 1][1] = value
        elif right_merge:
            self.intervals[idx][0] = value
        else:
            self.intervals.insert(idx, [value, value])

    def getIntervals(self) -> List[List[int]]:
        return self.intervals

Complexity & Edge Cases

  • Time Complexity: addNum is $O(N)$ insertion in array, $O(\log N)$ in balanced BST; getIntervals is $O(1)$.
  • Space Complexity: $O(N)$.
