📋 The problem

Flatten a nested list of integers (integers or further nested lists) into an iterator with next()/hasNext().

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given a nested list of integers nestedList. Each element is either an integer, or a list whose elements may also be integers or other lists. Implement an iterator to flatten it.

The Stack of Reverse Generators: To achieve true lazy evaluation without flattening everything in the constructor ($O(1)$ memory consumption for deep trees): Maintain a stack storing elements in reverse order! - In hasNext(): While stack is not empty and the top element is a list: Pop the list, and push its sub-elements onto the stack in reverse order! - When the top element is an integer, return True! - If the stack becomes empty, return False.

🐢 Brute force vs optimal

Flattening in constructor takes $O(N)$ upfront time and space. The stack approach flattens on-demand in $O(D)$ space where $D$ is the maximum nesting depth.

💡 Key insight: Stack holds nested elements in reverse order. In hasNext(), unpack top lists in reverse until top is a plain integer.

✅ The solution

Reveal the commented solution (attempt it first!) 
class NestedIterator:
    def __init__(self, nestedList: list):
        # Push elements in reverse so top of stack is the first element
        self.stack = list(reversed(nestedList))

    def next(self) -> int:
        return self.stack.pop().getInteger()

    def hasNext(self) -> bool:
        while self.stack:
            top = self.stack[-1]
            if top.isInteger():
                return True
            # Pop list and push its items in reverse order
            self.stack.pop()
            for item in reversed(top.getList()):
                self.stack.append(item)
        return False

Complexity

Time: $O(1)$ amortized per next() and hasNext().
Space: $O(D)$ where $D$ is the maximum nesting depth.
