📋 The problem

A path moves counterclockwise with given segment lengths; decide whether it ever crosses itself.

Problem Overview

Given an array of integers distance, where you start at {2, 3, 5}(0,0){2, 3, 5} and move North, West, South, and East cyclically. Return true if your path crosses itself, and false otherwise.

Key Insights

There are only 3 fundamental geometric self-crossing configurations in this 4-directional spiral:

  1. Crossing 4th line (Self-intersection with 3 steps ago): {2, 3, 5}{2, 3, 5}d[i] \ge d[i-2] \quad ext{and} \quad d[i-1] \le d[i-3]{2, 3, 5}{2, 3, 5}
  2. Overlapping 5th line (Self-intersection with 4 steps ago): {2, 3, 5}{2, 3, 5}d[i-1] == d[i-3] \quad ext{and} \quad d[i] + d[i-4] \ge d[i-2]{2, 3, 5}{2, 3, 5}
  3. Crossing 6th line (Self-intersection with 5 steps ago): {2, 3, 5}{2, 3, 5}d[i-2] \ge d[i-4], \quad d[i] + d[i-4] \ge d[i-2], \quad d[i-1] \le d[i-3], \quad d[i-1] + d[i-5] \ge d[i-3]{2, 3, 5}{2, 3, 5}

Python 3 Solution (Click to Expand) 
from typing import List

class Solution:
    def isSelfCrossing(self, distance: List[int]) -> bool:
        d = distance
        n = len(d)
        if n < 4:
            return False
            
        for i in range(3, n):
            # Case 1: crosses line i - 3
            if d[i] >= d[i - 2] and d[i - 1] <= d[i - 3]:
                return True
            # Case 2: overlaps line i - 4
            if i >= 4 and d[i - 1] == d[i - 3] and d[i] + d[i - 4] >= d[i - 2]:
                return True
            # Case 3: crosses line i - 5
            if i >= 5 and d[i - 2] >= d[i - 4] and d[i] + d[i - 4] >= d[i - 2] and d[i - 1] <= d[i - 3] and d[i - 1] + d[i - 5] >= d[i - 3]:
                return True
                
        return False
