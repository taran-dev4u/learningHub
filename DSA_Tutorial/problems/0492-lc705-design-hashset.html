#705 Design HashSet EasyLeetCode

 

Pattern: Design Patterns › Subpattern 15.1: General / Specific Data Structure Design · Problem 492 of 699

📋 The problem

Implement a HashSet from scratch: add, remove, contains — no built-in hash structures.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a HashSet without using any built-in hash table libraries.

Separate Chaining with Prime Modulo: Pick a large prime number for bucket count to minimize collision clustering (e.g. $B = 769$ or $B = 2069$). Each bucket is a linked list or dynamic array. - hash(key) = key % B - add(key): check if key exists in bucket; if not, append. - remove(key): remove key from bucket if present. - contains(key): linear scan inside bucket $key \% B$.

🐢 Brute force vs optimal

Separate chaining with prime modulo ensures $O(1)$ average time per operation.

💡 Key insight: Array of buckets with prime length 769: bucket = buckets[key % 769]. Append on add, remove on delete. Average $O(1)$!

✅ The solution

Reveal the commented solution (attempt it first!) 
class MyHashSet:
    def __init__(self):
        self.buckets = 769
        self.table = [[] for _ in range(self.buckets)]

    def _hash(self, key: int) -> int:
        return key % self.buckets

    def add(self, key: int) -> None:
        idx = self._hash(key)
        if key not in self.table[idx]:
            self.table[idx].append(key)

    def remove(self, key: int) -> None:
        idx = self._hash(key)
        if key in self.table[idx]:
            self.table[idx].remove(key)

    def contains(self, key: int) -> bool:
        idx = self._hash(key)
        return key in self.table[idx]

Complexity

Time: $O(1)$ average, $O(N / B)$ worst case with heavy collisions.
Space: $O(K + B)$ where $K$ is total distinct keys and $B = 769$.
