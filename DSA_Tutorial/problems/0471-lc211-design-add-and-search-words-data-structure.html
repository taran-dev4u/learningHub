📋 The problem

Design a structure that adds words and searches them where '.' in the query matches any single letter.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a data structure that supports adding new words and finding if a string matches any previously added string, where dots '.' can match any letter.

Use a standard Trie for storing words. During search(word): - For a normal character ch: advance to child node.children[ch]. - For a wildcard dot '.': branch recursively across all child nodes present at the current level: for child in node.children.values(): if dfs(child, next_idx): return True

🐢 Brute force vs optimal

Without wildcards, lookup is $O(L)$. With wildcards, backtracking traverses only matching subtree branches.

💡 Key insight: Standard Trie with DFS recursion for dot wildcard: if ch == '.', try all active child branches any(dfs(child, i + 1) for child in curr.children.values()).

✅ The solution

Reveal the commented solution (attempt it first!) 
class WordDictionary:
    def __init__(self):
        self.root = {}

    def addWord(self, word: str) -> None:
        curr = self.root
        for ch in word:
            curr = curr.setdefault(ch, {})
        curr['#'] = True # Word termination marker

    def search(self, word: str) -> bool:
        def dfs(node, idx):
            if idx == len(word):
                return '#' in node
            ch = word[idx]
            if ch == '.':
                for child_key, child_node in node.items():
                    if child_key != '#' and dfs(child_node, idx + 1):
                        return True
                return False
            else:
                if ch not in node:
                    return False
                return dfs(node[ch], idx + 1)
                
        return dfs(self.root, 0)

Complexity

Time: addWord: $O(L)$. search: $O(L)$ for exact words, $O(26^L)$ worst case with all dots.
Space: $O(N \times L)$ total characters across dictionary.
