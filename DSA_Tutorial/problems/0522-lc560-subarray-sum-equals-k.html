📋 The problem

Count the contiguous subarrays whose elements sum exactly to k.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an array of integers nums and an integer k, return the total number of subarrays whose sum equals to k.

A subarray sum from $j$ to $i$ equals $k$ if: $$prefix[i] - prefix[j - 1] = k \iff prefix[j - 1] = prefix[i] - k$$ Maintain a frequency map prefix_counts tracking how many times each prefix sum has occurred so far. At each index $i$: 1. Add the number of times prefix[i] - k was seen to the answer: total += prefix_counts.get(curr_sum - k, 0). 2. Increment frequency of the current prefix sum: prefix_counts[curr_sum] = prefix_counts.get(curr_sum, 0) + 1. Base case: prefix_counts[0] = 1 (a prefix itself equalling $k$).

🐢 Brute force vs optimal

Evaluating all subarrays takes $O(n^2)$. Hash map frequency accumulation counts all valid subarrays in $O(n)$ time and $O(n)$ space.

💡 Key insight: Frequency map of prefix sums: count += seen[curr_sum - k]. Base case seen[0] = 1. Solves in $O(n)$ time!

✅ The solution

Reveal the commented solution (attempt it first!) 
from collections import defaultdict

def subarraySum(nums: list[int], k: int) -> int:
    counts = defaultdict(int)
    counts[0] = 1
    curr_sum = 0
    total = 0
    
    for x in nums:
        curr_sum += x
        total += counts[curr_sum - k]
        counts[curr_sum] += 1
        
    return total

Complexity

Time: $O(n)$ — Single pass over nums.
Space: $O(n)$ — Hash map of prefix sums.
