#1381 Design a Stack With Increment Operation MediumLeetCode

 

Pattern: Design Patterns › Subpattern 15.1: General / Specific Data Structure Design · Problem 500 of 699

📋 The problem

Design a stack with push, pop, and increment(k, val) — add val to the bottom k elements — all O(1) (lazy increments).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a stack that supports push, pop, and incrementing the bottom k elements of the stack by val in $O(1)$ time complexity!

If we literally iterate through the bottom $k$ elements on every increment, increment takes $O(k)$ time. The Lazy Propagation Array: Maintain a parallel array inc = [0] * maxSize: When increment(k, val) is called: Only add val to the boundary element at index $idx = \min(k, ext{len}(stack)) - 1$: inc[idx] += val!

When pop() is called: 1. The popped element value is: stack[-1] + inc[-1]. 2. Pass the lazy increment down to the element beneath it: If index $> 0$: inc[i - 1] += inc[i]! 3. Pop from stack and reset inc entry!

🐢 Brute force vs optimal

Lazy propagation reduces increment from $O(k)$ to strict $O(1)$ time while maintaining $O(1)$ push and pop.

💡 Key insight: Lazy propagation: record increment only at index $k-1$. On pop(), propagate the lazy increment down to index $k-2$. Strict $O(1)$!

✅ The solution

Reveal the commented solution (attempt it first!) 
class CustomStack:
    def __init__(self, maxSize: int):
        self.max_size = maxSize
        self.stack = []
        self.inc = []

    def push(self, x: int) -> None:
        if len(self.stack) < self.max_size:
            self.stack.append(x)
            self.inc.append(0)

    def pop(self) -> int:
        if not self.stack:
            return -1
        idx = len(self.stack) - 1
        val = self.stack.pop() + self.inc[idx]
        lazy = self.inc.pop()
        if idx > 0:
            self.inc[idx - 1] += lazy
        return val

    def increment(self, k: int, val: int) -> None:
        if self.stack:
            idx = min(k, len(self.stack)) - 1
            self.inc[idx] += val

Complexity

Time: $O(1)$ for push, pop, and increment.
Space: $O( ext{maxSize})$ — Pre-allocated stack buffers.
