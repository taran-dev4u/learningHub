📋 The problem

Design encode/decode so any list of strings becomes one string and back, safely handling any characters.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design an algorithm to encode a list of strings to a string. The encoded string is then sent over the network and decoded back to the original list of strings.

Length-Prefixed Framing: Any special delimiter character (like ,, :, or #) can legitimately appear inside the strings themselves. Instead of fragile character escaping, encode each string as: f"{len(s)}#{s}" During decoding: 1. Scan for the delimiter # to parse the integer length $L$. 2. Slice exactly the next $L$ characters as the payload. 3. Advance the index by $L$ and repeat!

🐢 Brute force vs optimal

Escaping delimiters requires complex string replacement. Length-prefix chunking is stateless, robust, and executes in $O(N)$ linear time.

💡 Key insight: Chunk format: length + '#' + string. Reading $L$ bytes directly bypasses any delimiters nested inside the string payload.

✅ The solution

Reveal the commented solution (attempt it first!) 
class Codec:
    def encode(self, strs: list[str]) -> str:
        """Encodes a list of strings to a single wire string."""
        return "".join(f"{len(s)}#{s}" for s in strs)

    def decode(self, s: str) -> list[str]:
        """Decodes a single wire string to a list of strings."""
        res = []
        i = 0
        while i < len(s):
            sep = s.find('#', i)
            length = int(s[i:sep])
            word = s[sep + 1 : sep + 1 + length]
            res.append(word)
            i = sep + 1 + length
        return res

Complexity

Time: $O(N)$ where $N$ is the total number of characters across all strings.
Space: $O(N)$ — Single wire string buffer.
