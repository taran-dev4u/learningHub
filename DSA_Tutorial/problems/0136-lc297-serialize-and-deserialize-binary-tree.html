📋 The problem

Design serialize/deserialize: turn a binary tree into a string and rebuild the identical tree from it.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Tree - Serialization and Deserialization — Encode a tree to a string (preorder with nulls) and decode it back; used for cloning across the wire.

💡 Key idea
Preorder with explicit null markers serializes uniquely; deserialize by consuming tokens with an iterator.

Why this pattern?

  • "level", "depth", "nearest", "zigzag by rows" → BFS
  • "path sum", "ancestor", "validate", "diameter" → DFS
  • BST + "k-th smallest / sorted order" → inorder
  • "serialize / reconstruct" → preorder
