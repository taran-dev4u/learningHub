📋 The problem

Given n nodes and undirected edges, count the connected components.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given n nodes labeled 0 to n - 1 and a list of undirected edges, return the total number of connected components in the graph.

Every node starts as its own independent component (total n components). Every time an edge connects two previously disconnected components, the total component count decreases by 1.

🐢 Brute force vs optimal

Standard DFS or BFS explores each component in O(V + E) time. Disjoint Set Union (DSU) solves this interactively in O(E × α(V)) time with clean, concise code.

💡 Key insight: Initialize count = n. For each edge (u, v), attempt union(u, v). If u and v were in different sets, decrement count -= 1. When all edges are processed, count is the exact number of connected components!

🪜 The approach, step by step

  1. Initialize count = n.
  2. Initialize parent = list(range(n)).
  3. Implement find(x) with path compression.
  4. Implement union(u, v):
    • If find(u) != find(v): set parent[find(u)] = find(v) and decrement count -= 1.
  5. Process all edges, return final count.

🎞️ Visual dry run — n=5, edges=[(0,1), (1,2), (3,4)]:

✅ The solution

Python 3 — Union-Find 
def countComponents(n: int, edges: list[list[int]]) -> int:
    """
    Returns the number of connected components in an undirected graph using DSU.
    """
    parent = list(range(n))
    count = n
    
    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]
        
    for u, v in edges:
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            count -= 1
            
    return count

⚡ Complexity analysis

  • Time Complexity: O(V + E × α(V)) ≈ O(V + E).
  • Space Complexity: O(V) for the parent array.

🚨 Edge cases to watch out for

  • edges = []: Returns n (every node is an isolated component).
  • Multiple edges connecting same components: Duplicate edges have ru == rv, which safely leaves count unchanged.
