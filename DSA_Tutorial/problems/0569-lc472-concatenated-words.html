📋 The problem

From a word list, return every word that is a concatenation of at least two other words from the list.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an array of strings words (without duplicates), return all the concatenated words in the given list of words. A concatenated word is a word that can be formed entirely by concatenating at least two shorter words of the given array.

Key Insights

Sort words by length ascending: words.sort(key=len). This guarantees that when evaluating word $w$, any shorter constituent word has already been processed and placed into our dictionary set word_set! For each word, check if it can be partitioned into words in word_set using standard 1D Word Break DP: $$dp[j] = ext{true if } \exists i < j ext{ s.t. } dp[i] ext{ is true and } w[i:j] \in word_set$$

Python 3 Solution (Click to Expand) 
from typing import List

class Solution:
    def findAllConcatenatedWordsInADict(self, words: List[str]) -> List[str]:
        words.sort(key=len)
        word_set = set()
        res = []
        
        def can_form(w: str) -> bool:
            if not word_set:
                return False
            n = len(w)
            dp = [False] * (n + 1)
            dp[0] = True
            for i in range(n):
                if not dp[i]:
                    continue
                for j in range(i + 1, n + 1):
                    if w[i:j] in word_set:
                        dp[j] = True
                if dp[n]:
                    return True
            return dp[n]
            
        for w in words:
            if can_form(w):
                res.append(w)
            word_set.add(w)
            
        return res

Complexity & Edge Cases

  • Time Complexity: $O(N \log N + N imes L^2)$.
  • Space Complexity: $O(N imes L)$.
