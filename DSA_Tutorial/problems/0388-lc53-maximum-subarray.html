📋 The problem

Find the contiguous subarray with the largest sum and return that sum.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer array nums, find the subarray with the largest sum, and return its sum.

🐢 Brute force vs optimal

Testing all subarrays takes O(N^2). Kadane's Algorithm computes the global maximum subarray in a single linear pass in O(N) time and O(1) space!

💡 Key insight: At element nums[i], we have two choices:
  1. Extend the existing subarray: curr_sum + nums[i].
  2. Discard previous sum (if it was negative) and start a new subarray at nums[i].
Thus: curr_sum = max(nums[i], curr_sum + nums[i]). Update max_sum = max(max_sum, curr_sum).

✅ The solution

def maxSubArray(nums: list[int]) -> int:
    """
    Kadane's algorithm for maximum subarray sum in O(N) time and O(1) space.
    """
    max_sum = nums[0]
    curr_sum = 0
    
    for x in nums:
        if curr_sum < 0:
            curr_sum = 0
        curr_sum += x
        if curr_sum > max_sum:
            max_sum = curr_sum
            
    return max_sum

⚡ Complexity analysis

  • Time Complexity: O(N). Single pass.
  • Space Complexity: O(1).
