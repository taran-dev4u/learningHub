📋 The problem

Given meeting intervals, decide whether one person can attend them all (no overlaps).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an array of meeting time intervals consisting of start and end times [[s1, e1], [s2, e2], ...], determine if a person could attend all meetings without any conflicts.

Key Insights

Sort meetings by start time: intervals.sort(key=lambda x: x[0]). A conflict exists if and only if any meeting starts before the previous meeting finishes: $$intervals[i][0] < intervals[i - 1][1]$$ If any adjacent pair violates this, return False. If all finish before the next begins, return True.

Python 3 Solution (Click to Expand) 
from typing import List

class Solution:
    def canAttendMeetings(self, intervals: List[List[int]]) -> bool:
        intervals.sort(key=lambda x: x[0])
        for i in range(1, len(intervals)):
            if intervals[i][0] < intervals[i - 1][1]:
                return False
        return True

Complexity & Edge Cases

  • Time Complexity: $O(N \log N)$ sorting.
  • Space Complexity: $O(1)$.
  • Edge Cases: Empty intervals or 1 interval (always True), meetings touching at border ($[1, 5], [5, 10]$ do not conflict).
