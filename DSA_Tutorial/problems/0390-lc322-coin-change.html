📋 The problem

Given coin denominations and an amount, return the fewest coins needed to make the amount exactly (or -1).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an integer array coins representing coins of different denominations and an integer amount. Return the fewest number of coins that you need to make up that amount. If that amount cannot be made up by any combination, return -1. Each coin can be used an unlimited number of times (Unbounded Knapsack).

💡 Key insight: Let dp[a] be the minimum coins to form amount a. For each amount a from 1 to amount: $$dp[a] = \min_{c \in coins, c \le a} (dp[a - c] + 1)$$ Initialize dp = [inf] * (amount + 1) with dp[0] = 0.

✅ The solution

Reveal the commented solution (attempt it first!) 
def coinChange(coins: list[int], amount: int) -> int:
    """
    Computes minimum coins to make amount using Unbounded Knapsack DP.
    """
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    
    for a in range(1, amount + 1):
        for c in coins:
            if a >= c:
                dp[a] = min(dp[a], dp[a - c] + 1)
                
    return dp[amount] if dp[amount] != float('inf') else -1

⚡ Complexity analysis

  • Time Complexity: O(amount × len(coins)).
  • Space Complexity: O(amount) for the DP array.
