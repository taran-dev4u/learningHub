📋 The problem

Group strings so that strings which become each other by shifting every letter the same amount (wrapping z→a) share a group.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an array of strings strings, group all strings that belong to the same shifting sequence. Two strings $s_1$ and $s_2$ belong to the same shifting sequence if $s_1$ can be converted into $s_2$ by shifting each character of $s_1$ forward by the same number of positions cyclically around the alphabet.

Key Insights

A string's shifting identity is invariant under cyclical character differences! For example, for "az": ('z' - 'a') % 26 = 25. For "ba": ('a' - 'b') % 26 = (-1) % 26 = 25.

Thus, any string can be represented by a canonical key: the tuple of cyclic differences between consecutive adjacent characters: $$key = \left( (s[i] - s[i - 1]) \pmod{26} ight)_{i=1}^{L-1}$$ Strings of length 1 all share the empty tuple () as key.

Python 3 Solution (Click to Expand) 
from typing import List
from collections import defaultdict

class Solution:
    def groupStrings(self, strings: List[str]) -> List[List[str]]:
        groups = defaultdict(list)
        
        for s in strings:
            # Compute canonical key of cyclical diffs
            diff_key = []
            for i in range(1, len(s)):
                diff = (ord(s[i]) - ord(s[i - 1])) % 26
                diff_key.append(diff)
            groups[tuple(diff_key)].append(s)
            
        return list(groups.values())

Complexity & Edge Cases

  • Time Complexity: $O(N \cdot L)$ where $N$ is the number of strings and $L$ is the maximum length of a string.
  • Space Complexity: $O(N \cdot L)$ to store all grouped strings in the hash map.
  • Edge Cases: Single character strings (e.g. ["a", "z"] both map to ()), wraps around 'z' -> 'a'.
