📋 The problem

A tree gained one extra undirected edge; return the edge whose removal restores a tree (the last such edge in input order).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

A tree is an undirected graph that is connected and has no cycles. You are given a graph that started as a tree with n nodes labeled 1 to n, but one extra edge was added. Find the edge that can be removed so that the resulting graph is a tree. If there are multiple answers, return the one that occurs last in the input.

🐢 Brute force vs optimal

For each edge, temporarily remove it and check if remaining graph is a tree via DFS: O(E × (V + E)) = O(N^2). With Union-Find, we can find the cycle in a single pass in O(N × α(N)) ≈ O(N)!

💡 Key insight: Iterate through edges in order. For each edge (u, v): check if find(u) == find(v). If they already share the same root, they are already connected through some path in the tree. Therefore, adding (u, v) directly creates a cycle! Since we iterate in order, the first edge that connects two already-connected nodes is our answer!

🪜 The approach, step by step

  1. Initialize parent = list(range(n + 1)) (1-indexed).
  2. Define find(x) with path compression.
  3. For each u, v in edges:
    • ru = find(u), rv = find(v).
    • If ru == rv: return [u, v] immediately!
    • Otherwise, union them: parent[ru] = rv.

🎞️ Visual dry run — edges=[(1,2), (1,3), (2,3)]:

1. Edge (1, 2): find(1)=1, find(2)=2. Union -> parent[1]=2.
2. Edge (1, 3): find(1)=2, find(3)=3. Union -> parent[2]=3.
   Now 1, 2, 3 all belong to component 3.
3. Edge (2, 3): find(2)=3, find(3)=3.
   find(2) == find(3)! Cycle detected!
   Return [2, 3] ✓

✅ The solution

Python 3 — DSU 
def findRedundantConnection(edges: list[list[int]]) -> list[int]:
    """
    Finds the redundant edge that creates a cycle in an undirected graph.
    """
    n = len(edges)
    parent = list(range(n + 1))
    
    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]
        
    for u, v in edges:
        ru, rv = find(u), find(v)
        if ru == rv:
            return [u, v]
        parent[ru] = rv
        
    return []

⚡ Complexity analysis

  • Time Complexity: O(N × α(N)) ≈ O(N).
  • Space Complexity: O(N) for parent array.
