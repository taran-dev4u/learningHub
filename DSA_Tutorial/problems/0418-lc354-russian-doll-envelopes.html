📋 The problem

Count the longest chain of envelopes that nest (each strictly larger in both width and height).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given a 2D array of integers envelopes where envelopes[i] = [w_i, h_i] represents the width and the height of an envelope. One envelope can fit into another if and only if both the width and height of one envelope are strictly greater than the other envelope. Return the maximum number of envelopes you can Russian doll (put inside one another).

This is a 2D variation of Longest Increasing Subsequence (LIS). If we sort envelopes by width ascending, we reduce one dimension! The Clever Sorting Trick: - Sort width ascending: w1 < w2 ensures width is non-decreasing. - If widths are equal, sort height descending: h1 > h2!

Why descending on height for identical widths? Because an envelope cannot contain another envelope of the same width! By sorting height descending, when we run standard 1D LIS on heights, we can never pick two envelopes with the same width!

🐢 Brute force vs optimal

Standard $O(n^2)$ LIS DP gets TLE ($n = 10^5$). With the sorting trick, binary search LIS (Patience Sorting / bisect_left) solves it in $O(n \log n)$ time!

💡 Key insight: Sort by (width, -height), then extract heights and run $O(n \log n)$ Patience Sorting LIS with binary search.

✅ The solution

import bisect

def maxEnvelopes(envelopes: list[list[int]]) -> int:
    # Sort width ascending, height descending
    envelopes.sort(key=lambda x: (x[0], -x[1]))
    
    # Run O(n log n) LIS on heights
    tails = []
    for _, h in envelopes:
        idx = bisect.bisect_left(tails, h)
        if idx == len(tails):
            tails.append(h)
        else:
            tails[idx] = h
            
    return len(tails)

Complexity

Time: $O(n \log n)$ — Sorting takes $O(n \log n)$ and binary search LIS takes $O(n \log n)$.
Space: $O(n)$ — tails array storing active increasing subsequence tails.
