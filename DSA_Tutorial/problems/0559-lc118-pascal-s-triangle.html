Problem Overview

Given an integer numRows, return the first numRows of Pascal's triangle, where each number is the sum of the two numbers directly above it.

Key Insights

Row {2, 3, 5}r{2, 3, 5} has {2, 3, 5}r + 1{2, 3, 5} elements. The first and last elements are always 1: row[0] = row[-1] = 1. Every intermediate element satisfies: {2, 3, 5}{2, 3, 5}row[c] = prev_row[c - 1] + prev_row[c]{2, 3, 5}{2, 3, 5}

Python 3 Solution (Click to Expand) 
from typing import List

class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        triangle = []
        for r in range(numRows):
            row = [1] * (r + 1)
            for c in range(1, r):
                row[c] = triangle[r - 1][c - 1] + triangle[r - 1][c]
            triangle.append(row)
        return triangle
