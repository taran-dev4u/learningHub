📋 The problem

Every number in the array appears exactly twice except one; find that one in O(n) time and O(1) space.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a non-empty array of integers nums, every element appears twice except for one. Find that single one. You must implement a solution with a linear runtime complexity and use only constant extra space.

The mathematical properties of the XOR ($\oplus$) operation: 1. Identity: $x \oplus 0 = x$ 2. Self-Inverse: $x \oplus x = 0$ 3. Commutative and Associative: order of XORing does not matter ($a \oplus b \oplus a = (a \oplus a) \oplus b = 0 \oplus b = b$).

If we XOR all elements in nums together, every pair cancels itself out to 0, leaving only the unique single number!

🐢 Brute force vs optimal

Hash set or frequency map takes $O(n)$ space. XOR reduction accumulates in $O(n)$ time with $O(1)$ constant memory.

💡 Key insight: XOR all numbers: res = 0; for x in nums: res ^= x. Paired duplicates cancel to 0; single element remains!

✅ The solution

Reveal the commented solution (attempt it first!) 
def singleNumber(nums: list[int]) -> int:
    res = 0
    for x in nums:
        res ^= x
    return res

Complexity

Time: $O(n)$ — Single linear pass over array.
Space: $O(1)$ — Single scalar variable.
