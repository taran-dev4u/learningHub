📋 The problem

Given a string of digits 2–9, return every possible letter combination the digits could represent on a phone keypad.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a string containing digits from 2-9 inclusive, return all possible letter combinations that the number could represent according to telephone keypad mappings.

🪜 The approach, step by step

  1. Define mapping PHONE = {'2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl', '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz'}.
  2. If not digits, return [].
  3. Backtracking state (index, path):
    • If index == len(digits): append "".join(path) to res; return.
    • For letter in PHONE[digits[index]]:
      • path.append(letter); backtrack(index + 1); path.pop().

✅ The solution

def letterCombinations(digits: str) -> list[str]:
    """
    Generates phone keypad letter combinations in O(4^N * N) time.
    """
    if not digits:
        return []
        
    phone = {
        '2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
        '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz'
    }
    
    res = []
    path = []
    
    def backtrack(idx):
        if idx == len(digits):
            res.append("".join(path))
            return
            
        for char in phone[digits[idx]]:
            path.append(char)
            backtrack(idx + 1)
            path.pop()
            
    backtrack(0)
    return res

⚡ Complexity analysis

  • Time Complexity: O(4^N × N) where N = len(digits). In the worst case (digits 7 and 9), each digit maps to 4 letters.
  • Space Complexity: O(N) recursion stack.
