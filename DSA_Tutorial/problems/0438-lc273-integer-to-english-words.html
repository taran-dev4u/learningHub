📋 The problem

Convert a non-negative integer into its English words ('12345' → 'Twelve Thousand Three Hundred Forty Five').

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Convert a non-negative integer num to its English words representation.

Every group of 3 digits is named in the exact same way with a thousands-magnitude suffix: - 10^9: "Billion" - 10^6: "Million" - 10^3: "Thousand" - 10^0: ""

Write a helper function words_under_1000(n) that converts any number from 1 to 999: - If $n \ge 100$: BELOW_20[n // 100] + " Hundred" - Remainder $< 20$: lookup in BELOW_20 - Remainder $\ge 20$: TENS[rem // 10] + " " + BELOW_20[rem % 10]

🐢 Brute force vs optimal

Chunk by 1,000 using division and modulo. Runs in $O(1)$ time because 32-bit integers are bounded by 2 Billion ($2^{31} - 1$).

💡 Key insight: Process chunks of 1,000 using triplets ("Billion", "Million", "Thousand", ""). Format 3-digit numbers with Hundreds + Tens + Ones lookup arrays.

✅ The solution

def numberToWords(num: int) -> str:
    if num == 0:
        return "Zero"
        
    LESS_THAN_20 = ["", "One", "Two", "Three", "Four", "Five", "Six", "Seven", "Eight", "Nine", "Ten",
                    "Eleven", "Twelve", "Thirteen", "Fourteen", "Fifteen", "Sixteen", "Seventeen", "Eighteen", "Nineteen"]
    TENS = ["", "Ten", "Twenty", "Thirty", "Forty", "Fifty", "Sixty", "Seventy", "Eighty", "Ninety"]
    THOUSANDS = ["", "Thousand", "Million", "Billion"]
    
    def helper(n):
        if n == 0:
            return ""
        elif n < 20:
            return LESS_THAN_20[n] + " "
        elif n < 100:
            return TENS[n // 10] + " " + helper(n % 10)
        else:
            return LESS_THAN_20[n // 100] + " Hundred " + helper(n % 100)
            
    res = ""
    for i, unit in enumerate(THOUSANDS):
        if num % 1000 != 0:
            res = helper(num % 1000) + unit + " " + res
        num //= 1000
        
    return res.strip()

Complexity

Time: $O(1)$ — At most 4 chunks of 3 digits.
Space: $O(1)$ — Constant size lookup tables.
