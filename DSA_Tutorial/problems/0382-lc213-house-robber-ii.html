📋 The problem

House Robber on a circle: first and last houses are adjacent; return the maximum loot.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

All houses at this place are arranged in a circle. That means the first house is the neighbor of the last one. Meanwhile, adjacent houses have a security system connected. Return the maximum amount of money you can rob tonight without alerting the police.

💡 Key insight: Because house 0 and house n - 1 are adjacent, you can NEVER rob both in the same night! This splits the circular problem into two linear subproblems:
  1. Rob houses from index 0 to n - 2 (exclude last house).
  2. Rob houses from index 1 to n - 1 (exclude first house).
The answer is simply max(nums[0], rob_linear(nums[:-1]), rob_linear(nums[1:]))!

✅ The solution

Reveal the commented solution (attempt it first!) 
def rob(nums: list[int]) -> int:
    """
    Solves circular house robber by taking maximum of two linear slices.
    """
    if len(nums) == 1:
        return nums[0]
        
    def rob_linear(houses):
        rob1, rob2 = 0, 0
        for h in houses:
            curr = max(rob2, rob1 + h)
            rob1 = rob2
            rob2 = curr
        return rob2
        
    return max(rob_linear(nums[:-1]), rob_linear(nums[1:]))

⚡ Complexity analysis

  • Time Complexity: O(N). Two linear passes.
  • Space Complexity: O(1).
