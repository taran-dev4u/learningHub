📋 The problem

Design a structure with inc(key), dec(key), getMaxKey(), getMinKey() — all O(1).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Design a data structure to store the strings' count with the ability to return the strings with minimum and maximum counts in $O(1)$ time complexity for all operations: inc(key), dec(key), getMaxKey(), and getMinKey().

Key Insights

Multiple strings can have the same frequency. If we maintain individual nodes per string, finding min/max in $O(1)$ is difficult. Instead, maintain a Doubly Linked List of Frequency Buckets, where each bucket holds a frequency count and a set() of all strings having that exact frequency!

  • head sentinel points to the lowest frequency bucket; tail sentinel points to the highest.
  • key_to_bucket hash map maps each key to its containing BucketNode.
  • inc(key): Move key from bucket $f$ to bucket $f+1$. If bucket $f+1$ doesn't exist, insert it immediately after bucket $f$. If bucket $f$ becomes empty, remove it.
  • dec(key): Move key from bucket $f$ to bucket $f-1$. If $f-1 == 0$, delete key entirely.
  • getMaxKey(): Return any key from tail.prev.keys (or "" if empty).
  • getMinKey(): Return any key from head.next.keys (or "" if empty).

class Bucket:
    def __init__(self, freq: int):
        self.freq = freq
        self.keys = set()
        self.prev = None
        self.next = None

class AllOne:
    def __init__(self):
        self.head = Bucket(0)  # Min sentinel
        self.tail = Bucket(0)  # Max sentinel
        self.head.next = self.tail
        self.tail.prev = self.head
        self.key_bucket = {}   # key -> Bucket

    def _insert_after(self, prev_bucket: Bucket, new_bucket: Bucket) -> None:
        new_bucket.next = prev_bucket.next
        new_bucket.prev = prev_bucket
        prev_bucket.next.prev = new_bucket
        prev_bucket.next = new_bucket

    def _remove_bucket(self, bucket: Bucket) -> None:
        bucket.prev.next = bucket.next
        bucket.next.prev = bucket.prev

    def inc(self, key: str) -> None:
        if key not in self.key_bucket:
            # Insert key into freq 1 bucket
            if self.head.next.freq == 1:
                target = self.head.next
            else:
                target = Bucket(1)
                self._insert_after(self.head, target)
            target.keys.add(key)
            self.key_bucket[key] = target
        else:
            curr = self.key_bucket[key]
            curr.keys.remove(key)
            if curr.next.freq == curr.freq + 1:
                target = curr.next
            else:
                target = Bucket(curr.freq + 1)
                self._insert_after(curr, target)
            target.keys.add(key)
            self.key_bucket[key] = target
            if not curr.keys:
                self._remove_bucket(curr)

    def dec(self, key: str) -> None:
        if key not in self.key_bucket:
            return
        curr = self.key_bucket[key]
        curr.keys.remove(key)
        if curr.freq == 1:
            del self.key_bucket[key]
        else:
            if curr.prev.freq == curr.freq - 1:
                target = curr.prev
            else:
                target = Bucket(curr.freq - 1)
                self._insert_after(curr.prev, target)
            target.keys.add(key)
            self.key_bucket[key] = target
        if not curr.keys:
            self._remove_bucket(curr)

    def getMaxKey(self) -> str:
        if self.tail.prev == self.head:
            return ""
        return next(iter(self.tail.prev.keys))

    def getMinKey(self) -> str:
        if self.head.next == self.tail:
            return ""
        return next(iter(self.head.next.keys))

Complexity & Invariants

  • Time Complexity: Strictly $O(1)$ for all operations (inc, dec, getMaxKey, getMinKey).
  • Space Complexity: $O(N)$ where $N$ is the number of distinct string keys.
