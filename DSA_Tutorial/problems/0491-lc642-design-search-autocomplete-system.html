📋 The problem

Design search autocomplete: given typed prefixes ('#' ends a sentence), return the top 3 historical sentences by frequency.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a search autocomplete system for a search engine. Users may input a sentence character by character. For each character typed (except '#' which terminates the sentence), return the top 3 historical hot sentences that have the same prefix as the sentence typed so far.

Trie with Pre-sorted Top Suggestions: Each TrieNode maintains: - children: map of character to child node. - hotness: a dictionary or list mapping sentence -> total_frequency across all sentences passing through this node.

When typing character c: 1. Advance cursor curr = curr.children[c]. 2. Sort candidate sentences in curr.hotness by (-count, sentence) and return top 3! 3. If c == '#': record the full completed sentence into the Trie, increment count, and reset cursor to root!

🐢 Brute force vs optimal

Scanning all historical sentences on every keystroke takes $O(N \log N)$. Storing sentence frequencies directly on Trie nodes provides rapid prefix retrieval.

💡 Key insight: Trie node caches sentence frequencies: node.counts[sentence] += 1. Top 3 suggestions are sorted by (-frequency, ascii_sentence).

✅ The solution

class TrieNode:
    def __init__(self):
        self.children = {}
        self.counts = {} # sentence -> frequency

class AutocompleteSystem:
    def __init__(self, sentences: list[str], times: list[int]):
        self.root = TrieNode()
        self.curr_node = self.root
        self.curr_str = []
        
        for s, t in zip(sentences, times):
            self._insert(s, t)

    def _insert(self, sentence: str, count: int):
        curr = self.root
        for ch in sentence:
            if ch not in curr.children:
                curr.children[ch] = TrieNode()
            curr = curr.children[ch]
            curr.counts[sentence] = curr.counts.get(sentence, 0) + count

    def input(self, c: str) -> list[str]:
        if c == '#':
            sentence = "".join(self.curr_str)
            self._insert(sentence, 1)
            self.curr_str = []
            self.curr_node = self.root
            return []
            
        self.curr_str.append(c)
        if self.curr_node:
            self.curr_node = self.curr_node.children.get(c, None)
            
        if not self.curr_node:
            return []
            
        # Sort by: 1) frequency descending (-count), 2) ASCII ascending (s)
        candidates = sorted(self.curr_node.counts.items(), key=lambda x: (-x[1], x[0]))
        return [s for s, _ in candidates[:3]]

Complexity

Time: Typing a character: $O(K \log K)$ where $K$ is number of candidate matches with this prefix. Adding sentence: $O(L)$ where $L$ is sentence length.
Space: $O(N \times L)$ — Trie nodes with sentence references.
