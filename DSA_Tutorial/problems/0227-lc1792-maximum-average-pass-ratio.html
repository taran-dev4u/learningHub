#1792 Maximum Average Pass Ratio MediumLeetCode

 

Pattern: Heap (Priority Queue) Patterns › Subpattern 7.4: Scheduling / Minimum Cost with Priority Queue · Problem 227 of 699

📋 The problem

Add extra students to classes to maximize average pass ratio; each student goes where the ratio gains most (heap by marginal gain).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You have classes with [pass, total] and extraStudents who always pass. Assign extra students to maximize the average pass ratio. Greedily, each extra student should be assigned to the class where they provide the greatest marginal increase in pass ratio: gain = (pass + 1)/(total + 1) - pass/total.

🐢 Brute force first

For each of the extra students, compute gains across all classes and pick maximum → O(extraStudents * n).

💡 Key insight: use a max-heap storing (-gain, pass, total). Each student is assigned to the class at the root. Pop the class, increment pass and total, recalculate its new gain, and push it back.

🪜 The approach, step by step

  1. Define gain helper: gain(p, t) = (p + 1) / (t + 1) - p / t.
  2. Push (-gain(p, t), p, t) into heap for each class.
  3. Repeat extraStudents times:
  4. Pop (-g, p, t).
  5. Push (-gain(p + 1, t + 1), p + 1, t + 1).
  6. Return sum(p / t for _, p, t in heap) / len(classes).

🎞️ Visual dry run — classes = [[1,2],[3,5],[2,2]], extra = 2

✅ The solution

Reveal the commented solution (attempt it first!) 
import heapq

def maxAverageRatio(classes, extraStudents):
    def gain(p, t):
        return (p + 1) / (t + 1) - p / t
        
    heap = [(-gain(p, t), p, t) for p, t in classes]
    heapq.heapify(heap)
    
    for _ in range(extraStudents):
        g, p, t = heapq.heappop(heap)
        p, t = p + 1, t + 1
        heapq.heappush(heap, (-gain(p, t), p, t))
        
    return sum(p / t for _, p, t in heap) / len(classes)

⏱️ Complexity

Time O(n + k log n) — where n is number of classes and k is extraStudents. Space O(n) for the heap.

⚠️ Edge cases

  • Classes with 100% pass ratio (e.g. [5, 5]): gain is 0, pushed to bottom of heap.
  • extraStudents = 0: returns current average.
