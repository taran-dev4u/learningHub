📋 The problem

Given meeting intervals, return the minimum number of conference rooms needed.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an array of meeting time intervals [start, end], find the minimum number of conference rooms required. Two meetings can share a room if the earlier meeting ends before or at the time the next starts. When a new meeting starts, can we reuse a room that just freed up? We only care about the room with the earliest end time.

🐢 Brute force first

For every meeting, compare with all other rooms to find a conflict-free room; if none, allocate a new room → O(n^2).

💡 Key insight: sort meetings by start_time. Maintain a min-heap of active meeting end times. For each meeting, if start >= heap[0], the earliest room is free—pop it and reuse. Push the current meeting's end_time. The size of the heap is the number of rooms needed.

🪜 The approach, step by step

  1. Sort intervals by start time.
  2. Initialize min-heap rooms = [].
  3. For each interval [start, end]:
  4. If rooms is not empty and start >= rooms[0], pop the room (it is now free).
  5. Push end onto rooms.
  6. Return len(rooms).

🎞️ Visual dry run — intervals = [[0,30],[5,10],[15,20]]

Sorted: [[0, 30], [5, 10], [15, 20]]
[0, 30]  → heap: [30] (1 room)
[5, 10]  → 5 < 30 (conflict!) → push 10 → heap: [10, 30] (2 rooms)
[15, 20] → 15 >= 10 (room freed!) → pop 10, push 20 → heap: [20, 30] (2 rooms)
Result: len(heap) = 2 rooms ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
import heapq

def minMeetingRooms(intervals):
    if not intervals:
        return 0
        
    # Sort meetings by start time
    intervals.sort(key=lambda x: x[0])
    
    # Min-heap stores end times of active meetings
    rooms = []
    
    for start, end in intervals:
        # If the earliest ending meeting has finished, reuse that room
        if rooms and start >= rooms[0]:
            heapq.heappop(rooms)
            
        heapq.heappush(rooms, end)
        
    return len(rooms)

⏱️ Complexity

Time O(n log n) — O(n log n) to sort intervals, plus n heap pushes/pops of size at most n. Space O(n) — to store end times in the heap.

⚠️ Edge cases

  • Non-overlapping meetings: len(rooms) stays 1.
  • Simultaneous start times: sorted properly, multiple rooms allocated.
  • Meeting starts exactly when another ends: start == end, room successfully reused.
