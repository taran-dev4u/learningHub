#308 Range Sum Query 2D - Mutable HardLeetCode

 

Pattern: Segment Tree & Fenwick Tree Patterns › Subpattern 16.1: Segment Tree / Range Query with Updates · Problem 510 of 699

📋 The problem

Support updating one cell and querying any rectangle sum of a matrix, both efficiently.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a 2D matrix matrix, handle multiple queries of updating a cell $(row, col)$ and retrieving the sum of elements inside a submatrix defined by $[row1, col1]$ to $[row2, col2]$.

2D Fenwick Tree (Binary Indexed Tree): Extend the 1D Fenwick tree to two dimensions: - bit[m + 1][n + 1] - update(r, c, delta): Nested loops running $r += (r \;\&\; (-r))$ and $c += (c \;\&\; (-c))$. - query(r, c): Returns sum in rectangle $[1, 1]$ to $[r, c]$. - Submatrix sum by 2D Inclusion-Exclusion: $$ ext{Sum} = Q(r_2, c_2) - Q(r_1 - 1, c_2) - Q(r_2, c_1 - 1) + Q(r_1 - 1, c_1 - 1)$$

🐢 Brute force vs optimal

Scanning submatrix takes $O(m \times n)$. 2D Fenwick Tree updates and queries in strictly $O(\log m \times \log n)$ time!

💡 Key insight: 2D Fenwick tree: nested $(r \;\&\; -r)$ and $(c \;\&\; -c)$ loops. Inclusion-exclusion evaluates 2D range sum in $O(\log m \log n)$.

class NumMatrix:
    def __init__(self, matrix: list[list[int]]):
        if not matrix or not matrix[0]:
            return
        self.m, self.n = len(matrix), len(matrix[0])
        self.matrix = [[0] * self.n for _ in range(self.m)]
        self.bit = [[0] * (self.n + 1) for _ in range(self.m + 1)]
        
        for r in range(self.m):
            for c in range(self.n):
                self.update(r, c, matrix[r][c])

    def update(self, row: int, col: int, val: int) -> None:
        delta = val - self.matrix[row][col]
        self.matrix[row][col] = val
        r = row + 1
        while r <= self.m:
            c = col + 1
            while c <= self.n:
                self.bit[r][c] += delta
                c += c & (-c)
            r += r & (-r)

    def _query(self, row: int, col: int) -> int:
        s = 0
        r = row
        while r > 0:
            c = col
            while c > 0:
                s += self.bit[r][c]
                c -= c & (-c)
            r -= r & (-r)
        return s

    def sumRegion(self, row1: int, col1: int, row2: int, col2: int) -> int:
        return (self._query(row2 + 1, col2 + 1)
              - self._query(row1, col2 + 1)
              - self._query(row2 + 1, col1)
              + self._query(row1, col1))

Complexity

Time: $O(\log m \times \log n)$ for update and sumRegion.
Space: $O(m \times n)$ — 2D Fenwick tree array.
