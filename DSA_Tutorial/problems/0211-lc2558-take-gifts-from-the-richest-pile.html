#2558 Take Gifts From the Richest Pile EasyLeetCode

 

Pattern: Heap (Priority Queue) Patterns › Subpattern 7.1: Top K Elements / Selection / Frequency · Problem 211 of 699

📋 The problem

Each second take the richest pile and replace it with floor(sqrt) of itself, k times; return the remaining total (max-heap).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You have gift piles. For k seconds: choose the pile with the maximum gifts and replace it with floor(sqrt(gifts)). Return the sum of remaining gifts. At every second, we need the maximum element, so maintain a max-heap.

🐢 Brute force first

Find the maximum element linearly k times, replace it with its square root → O(k * n). When n, k = 10^5, this results in TLE.

💡 Key insight: negate all pile values and push to a max-heap. Each second, pop the maximum m, compute floor(sqrt(m)), and push it back in O(log n). Total time is O(n + k log n).

🪜 The approach, step by step

  1. Negate elements in gifts and heapify in O(n).
  2. Loop k times:
  3. Pop largest pile val = -heappop(heap).
  4. Compute remaining = math.isqrt(val).
  5. Push -remaining into heap.
  6. Return -sum(heap).

🎞️ Visual dry run — gifts = [25, 64, 9, 4, 100], k = 4

1. Pop 100 → sqrt(100) = 10 → push 10
2. Pop 64  → sqrt(64) = 8   → push 8
3. Pop 25  → sqrt(25) = 5   → push 5
4. Pop 10  → sqrt(10) = 3   → push 3

✅ The solution

Reveal the commented solution (attempt it first!) 
import heapq
import math

def pickGifts(gifts, k):
    # Store negated values to simulate a max-heap in Python
    heap = [-g for g in gifts]
    heapq.heapify(heap)
    
    for _ in range(k):
        max_gift = -heapq.heappop(heap)
        heapq.heappush(heap, -math.isqrt(max_gift))
        
    return -sum(heap)

⏱️ Complexity

Time O(n + k log n) — O(n) to heapify, k heap replacements taking O(log n) each. Space O(n) for the heap.

⚠️ Edge cases

  • Pile value is 1: isqrt(1) = 1, pile remains 1.
  • k > sum(gifts): piles reduce to 1 and stay there.
