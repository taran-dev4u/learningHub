📋 The problem

Design a structure that adds, removes, and queries coverage of number ranges (interval set with add/remove/query).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

A Range Module is a module that tracks ranges of numbers. Design a data structure to add, query, and remove intervals in half-open intervals $[left, right)$.

Disjoint Sorted Intervals: Maintain intervals in sorted, non-overlapping order: [[l1, r1], [l2, r2], ...]. - addRange(left, right): Merge all intervals that overlap or touch $[left, right)$ into one expanded interval. - queryRange(left, right): Binary search for the interval covering $left$. If that interval also satisfies $interval.right \ge right$, return True! - removeRange(left, right): Split and trim any intervals that intersect with $[left, right)$.

🐢 Brute force vs optimal

Using a sorted list with binary search (bisect) allows $O(\log N)$ search and $O(N)$ interval slicing.

💡 Key insight: Disjoint intervals array: binary search finds overlapping candidates in $O(\log N)$. Merge overlapping blocks on addRange; punch holes on removeRange.

✅ The solution

import bisect

class RangeModule:
    def __init__(self):
        # Flat list of alternating boundary points: [l0, r0, l1, r1, ...]
        # Represents disjoint intervals [l0, r0), [l1, r1)...
        self.track = []

    def addRange(self, left: int, right: int) -> None:
        l = bisect.bisect_left(self.track, left)
        r = bisect.bisect_right(self.track, right)
        sub = []
        if l % 2 == 0:
            sub.append(left)
        if r % 2 == 0:
            sub.append(right)
        self.track[l:r] = sub

    def queryRange(self, left: int, right: int) -> bool:
        l = bisect.bisect_right(self.track, left)
        r = bisect.bisect_left(self.track, right)
        return l % 2 == 1 and l == r

    def removeRange(self, left: int, right: int) -> None:
        l = bisect.bisect_left(self.track, left)
        r = bisect.bisect_right(self.track, right)
        sub = []
        if l % 2 == 1:
            sub.append(left)
        if r % 2 == 1:
            sub.append(right)
        self.track[l:r] = sub

Complexity

Time: queryRange: $O(\log N)$ binary search. addRange, removeRange: $O(N)$ array slice.
Space: $O(N)$ — Disjoint interval boundaries.
