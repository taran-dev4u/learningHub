#44 Wildcard Matching HardLeetCode

📋 The problem

Wildcard matching over the whole string: '?' matches any one character and '*' matches any sequence (including empty).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an input string s and a pattern p, implement wildcard pattern matching with support for '?' and '*': - '?' Matches any single character. - '*' Matches any sequence of characters (including the empty sequence).

Notice the critical difference from Regex (LC 10): in Wildcard, '*' stands by itself and matches any sequence, without needing a preceding character! - If $p[j - 1] == \text{'?'}$ or $p[j - 1] == s[i - 1]$: $dp[i][j] = dp[i - 1][j - 1]$. - If $p[j - 1] == \text{'*'}'$: $dp[i][j] = dp[i][j - 1] \lor dp[i - 1][j]$ - $dp[i][j - 1]$ means '*' matches empty string. - $dp[i - 1][j]$ means '*' matches at least one character (consumes $s[i-1]$).

🐢 Brute force vs optimal

2D DP takes $O(m \times n)$ time. Alternatively, a greedy two-pointer approach tracking the last seen '*' and match index runs in $O(m)$ average time with $O(1)$ space!

💡 Key insight: Greedy two-pointer: record star_idx and match_idx. When mismatch occurs, backtrack to star_idx, expand match length by 1, and resume.

✅ The solution

def isMatch(s: str, p: str) -> bool:
    s_idx, p_idx = 0, 0
    star_idx = -1
    match_idx = 0
    
    while s_idx < len(s):
        # 1. Characters match or pattern has '?'
        if p_idx < len(p) and (p[p_idx] == '?' or p[p_idx] == s[s_idx]):
            s_idx += 1
            p_idx += 1
        # 2. Pattern has '*'
        elif p_idx < len(p) and p[p_idx] == '*':
            star_idx = p_idx
            match_idx = s_idx
            p_idx += 1
        # 3. Last pattern char was '*' - backtrack and match one more char in s
        elif star_idx != -1:
            p_idx = star_idx + 1
            match_idx += 1
            s_idx = match_idx
        # 4. Mismatch and no '*' to fall back on
        else:
            return False
            
    # Check remaining chars in pattern (must all be '*')
    while p_idx < len(p) and p[p_idx] == '*':
        p_idx += 1
        
    return p_idx == len(p)

Complexity

Time: $O(m)$ average, $O(m \times n)$ worst case (e.g. s="aaaa", p="*a").
Space: $O(1)$ — Only a few pointer variables.
