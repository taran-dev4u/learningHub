#1187 Make Array Strictly Increasing HardLeetCode

 

Pattern: Dynamic Programming (DP) Patterns › Subpattern 12.11: Longest Increasing Subsequence (LIS) · Problem 421 of 699

📋 The problem

Make arr1 strictly increasing by replacing elements with elements of arr2; return the minimum replacements (-1 if impossible) (DP + binary search).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given two integer arrays arr1 and arr2, return the minimum number of operations needed to make arr1 strictly increasing. In one operation, you can choose any index in arr1 and replace the value with any element from arr2. If not possible, return -1.

Pre-sort and deduplicate arr2 so we can use binary search (bisect_right) to find the smallest element strictly greater than a threshold.

Let $dp$ be a dictionary mapping the current valid ending value to the minimum replacements used so far. For each element $x \in arr1$: 1. Keep $x$ (no operation): if $x > prev$, we can transition to $x$ with $ops$ operations. 2. Replace $x$ with smallest valid element from $arr2$: find smallest $y \in arr2$ with $y > prev$ using bisect_right. Transition to $y$ with $ops + 1$ operations.

🐢 Brute force vs optimal

DP state compression keeping only the minimum operations for each reachable value bounds state space to $O(n \times \min(m, n))$, executing within milliseconds.

💡 Key insight: Maintain map dp[last_value] = min_ops. For each position, greedily try either keeping arr1[i] or replacing it with the smallest strictly larger element in arr2 via binary search.

✅ The solution

import bisect

def makeArrayIncreasing(arr1: list[int], arr2: list[int]) -> int:
    arr2 = sorted(set(arr2))
    # dp maps: last_value_in_arr1 -> min_operations
    dp = {-1: 0}
    
    for x in arr1:
        new_dp = {}
        for prev_val, ops in dp.items():
            # Option 1: Keep x if strictly greater than prev_val
            if x > prev_val:
                if x not in new_dp or ops < new_dp[x]:
                    new_dp[x] = ops
                    
            # Option 2: Replace x with smallest element in arr2 > prev_val
            idx = bisect.bisect_right(arr2, prev_val)
            if idx < len(arr2):
                y = arr2[idx]
                if y not in new_dp or ops + 1 < new_dp[y]:
                    new_dp[y] = ops + 1
                    
        dp = new_dp
        if not dp:
            return -1
            
    return min(dp.values())

Complexity

Time: $O(n \times \min(n, m) \log m)$ — At each index, binary search into sorted arr2.
Space: $O(\min(n, m))$ — State map holding active branch endpoints.
