📋 The problem

Design a circular double-ended queue with fixed capacity.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design your implementation of the circular double-ended queue (deque) supporting insertions and deletions at both front and rear ends.

Similar to Circular Queue (LC 622), maintain: - head: points to front element. - count: number of items currently in deque. - insertFront(val): decrements head: head = (head - 1 + k) % k; q[head] = val; count += 1. - insertLast(val): inserts at tail: tail = (head + count) % k; q[tail] = val; count += 1. - deleteFront(): head = (head + 1) % k; count -= 1. - deleteLast(): count -= 1.

🐢 Brute force vs optimal

All operations execute in $O(1)$ time with modulo arithmetic on a fixed pre-allocated array.

💡 Key insight: Front insertion wraps left: head = (head - 1 + k) % k. Rear insertion wraps right: (head + count) % k.

✅ The solution

class MyCircularDeque:
    def __init__(self, k: int):
        self.k = k
        self.q = [0] * k
        self.head = 0
        self.count = 0

    def insertFront(self, value: int) -> bool:
        if self.isFull():
            return False
        self.head = (self.head - 1 + self.k) % self.k
        self.q[self.head] = value
        self.count += 1
        return True

    def insertLast(self, value: int) -> bool:
        if self.isFull():
            return False
        tail = (self.head + self.count) % self.k
        self.q[tail] = value
        self.count += 1
        return True

    def deleteFront(self) -> bool:
        if self.isEmpty():
            return False
        self.head = (self.head + 1) % self.k
        self.count -= 1
        return True

    def deleteLast(self) -> bool:
        if self.isEmpty():
            return False
        self.count -= 1
        return True

    def getFront(self) -> int:
        return -1 if self.isEmpty() else self.q[self.head]

    def getRear(self) -> int:
        if self.isEmpty():
            return -1
        tail = (self.head + self.count - 1) % self.k
        return self.q[tail]

    def isEmpty(self) -> bool:
        return self.count == 0

    def isFull(self) -> bool:
        return self.count == self.k

Complexity

Time: $O(1)$ for all 8 operations.
Space: $O(k)$ — Fixed circular array.
