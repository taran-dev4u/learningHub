📋 The problem

Count the subarrays whose sum is divisible by k.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an integer array nums and an integer k, return the number of non-empty subarrays that have a sum divisible by k.

Two prefix sums $prefix[i]$ and $prefix[j]$ produce a subarray divisible by $k$ if: $$prefix[i] \equiv prefix[j] \pmod k$$ Count the frequency of each remainder $r = curr_sum % k$. If a remainder $r$ has appeared $C$ times previously, the current prefix sum forms $C$ new valid subarrays! Increment answer by $C$, then increment remainder frequency $C += 1$. Base case: remainder_counts[0] = 1.

🐢 Brute force vs optimal

Modulo remainder hash table/array of size $k$ counts all matching pairs in $O(n)$ time and $O(k)$ space.

💡 Key insight: Frequency array of size $k$: rem = curr_sum % k. Add counts[rem] to answer, then increment counts[rem] += 1. Base case counts[0] = 1.

✅ The solution

Reveal the commented solution (attempt it first!) 
def subarraysDivByK(nums: list[int], k: int) -> int:
    counts = [0] * k
    counts[0] = 1
    curr_sum = 0
    total = 0
    
    for x in nums:
        curr_sum += x
        rem = curr_sum % k
        total += counts[rem]
        counts[rem] += 1
        
    return total

Complexity

Time: $O(n)$ — Single pass.
Space: $O(k)$ — Remainder array of size $k$.
