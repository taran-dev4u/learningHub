📋 The problem

Return the diameter of a binary tree — the longest path between any two nodes, in edges.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Tree DFS - Recursive Postorder Traversal — Visit left, right, then root — used when children's results are needed before computing the parent.

💡 Key idea
Diameter through a node = leftHeight + rightHeight; return 1 + max to the parent, update global with the sum.

Why this pattern?

  • "level", "depth", "nearest", "zigzag by rows" → BFS
  • "path sum", "ancestor", "validate", "diameter" → DFS
  • BST + "k-th smallest / sorted order" → inorder
  • "serialize / reconstruct" → preorder
