📋 The problem

Split a string into pieces so every piece is a palindrome; return all such partitions.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a string s, partition s such that every substring of the partition is a palindrome. Return all possible palindrome partitionings of s.

💡 Key insight: Backtracking explores split points. For i from start to len(s) - 1: check if prefix s[start:i+1] is a palindrome (sub == sub[::-1]). If it is, append to path and recurse on i + 1. When start == len(s), append list(path)!

✅ The solution

def partition(s: str) -> list[list[str]]:
    """
    Finds all palindrome partitions using backtracking with substring verification.
    """
    res = []
    path = []
    n = len(s)
    
    def is_palindrome(left, right):
        while left < right:
            if s[left] != s[right]:
                return False
            left += 1
            right -= 1
        return True
        
    def backtrack(start):
        if start == n:
            res.append(list(path))
            return
            
        for end in range(start, n):
            if is_palindrome(start, end):
                path.append(s[start:end + 1])
                backtrack(end + 1)
                path.pop()
                
    backtrack(0)
    return res

⚡ Complexity analysis

  • Time Complexity: O(N × 2^N). There are 2^(N-1) possible partitions, and verifying palindromes takes O(N).
  • Space Complexity: O(N) recursion stack.
