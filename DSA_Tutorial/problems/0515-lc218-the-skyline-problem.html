📋 The problem

Given building rectangles on a skyline, return the key points that outline their combined silhouette.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Segment Tree / Range Query with Updates — Build a binary tree of intervals; each internal node stores an aggregate (sum/min/max). Lazy propagation handles range updates.

Why this pattern?

  • interleaved "update element" + "query range sum/min/max"
  • "count of smaller elements after self" (offline index counting)
  • k-th smallest with insertions/deletions
  • huge value range → coordinate-compress first

Pattern template to adapt

# Fenwick / BIT — shortest correct implementation (1-indexed)
tree = [0] * (n + 1)
def update(i, delta):            # a[i] += delta, O(log n)
    while i <= n:
        tree[i] += delta
        i += i & (-i)            # next block responsible for i
def prefix(i):                   # sum a[1..i], O(log n)
    s = 0
    while i > 0:
        s += tree[i]
        i -= i & (-i)
    return s
def range_sum(l, r):
    return prefix(r) - prefix(l - 1)
