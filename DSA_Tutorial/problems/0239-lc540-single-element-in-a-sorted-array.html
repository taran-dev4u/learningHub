#540 Single Element in a Sorted Array MediumLeetCode

 

Pattern: Binary Search Patterns › Subpattern 8.1: On Sorted Array/List · Problem 239 of 699

📋 The problem

Every element of a sorted array appears exactly twice except one; find it in O(log n).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given a sorted array consisting of only integers where every element appears exactly twice, except for one element which appears exactly once. Find this single element that appears only once. Your solution must run in O(log n) time and O(1) space.

🐢 Brute force first

XOR all elements together: x ^ x = 0 and x ^ 0 = x. Time: O(n), Space: O(1). Or linear scan checking adjacent pairs in O(n). To achieve O(log n), we must leverage the sorted structure with binary search.

💡 Key insight: Before the unique element, pairs always start at an even index and end at an odd index: (0, 1), (2, 3), (4, 5).... After the unique element, every pair gets shifted right by 1, so pairs start at an odd index and end at an even index! Thus, if mid's pair is correctly positioned, the unique element is to the right; otherwise it's at mid or to the left!

🪜 The approach, step by step

  1. Set left = 0, right = len(nums) - 1.
  2. While left < right:
  3. Compute mid = left + (right - left) // 2.
  4. If mid % 2 == 1, decrement mid -= 1 so that mid is always the first element of an expected pair.
  5. If nums[mid] == nums[mid + 1]: The pair is properly aligned! The single element has not disrupted pairing yet, so it lies strictly to the right: left = mid + 2.
  6. Else: The alignment is broken! The single element is either at mid or to its left: right = mid.
  7. When left == right, return nums[left].

🎞️ Visual dry run — nums = [1, 1, 2, 3, 3, 4, 4, 8, 8]

left == right == 2.
Return nums[2] = 2! ✓

✅ The solution

def singleNonDuplicate(nums):
    """
    Binary search on even indices to find the parity disruption.
    """
    left, right = 0, len(nums) - 1
    
    while left < right:
        mid = left + (right - left) // 2
        # Ensure mid is even
        if mid % 2 == 1:
            mid -= 1
            
        if nums[mid] == nums[mid + 1]:
            # Pair is intact; anomaly is to the right
            left = mid + 2
        else:
            # Pair broken; anomaly is at mid or left
            right = mid
            
    return nums[left]

⏱️ Complexity

Time O(log n) — Standard binary search halving the search space each step. Space O(1).

⚠️ Edge cases

  • Single element array [1]: returns 1 immediately.
  • Single element at index 0 (first element unique): nums[0] != nums[1] collapses right to 0.
  • Single element at last index: left advances all the way to len(nums) - 1.
