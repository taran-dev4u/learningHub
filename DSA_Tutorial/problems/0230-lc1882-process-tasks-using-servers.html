📋 The problem

Assign tasks to servers: free servers by (weight, index), busy ones by release time; simulate with two heaps.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You have n servers with weights and m tasks with execution times. At second j, task j arrives. Available servers are chosen by smallest weight (tiebreaker: smallest index). If no server is free, tasks wait in queue until a server frees up. We need two heaps: free servers (ordered by weight, index) and busy servers (ordered by finish time).

🐢 Brute force first

Scan all servers at each second to check availability and assign → O(total_time * n).

💡 Key insight: use two min-heaps: free_servers (weight, index) and busy_servers (finish_time, weight, index). Fast-forward current time to the earliest finish time when no servers are available.

🪜 The approach, step by step

  1. Initialize free = [(servers[i], i) for i in range(n)] and heapify.
  2. Initialize busy = [] (min-heap by finish time).
  3. For each task j arriving at time j:
  4. Time cur_time = max(cur_time, j). If free is empty, fast-forward cur_time = busy[0][0].
  5. Move all servers from busy with finish_time <= cur_time back to free.
  6. Pop server (w, i) from free.
  7. Push (cur_time + tasks[j], w, i) to busy.
  8. Record i in result.
  9. Return result.

✅ The solution

import heapq

def assignTasks(servers, tasks):
    # free: (weight, index)
    free = [(w, i) for i, w in enumerate(servers)]
    heapq.heapify(free)
    
    # busy: (finish_time, weight, index)
    busy = []
    
    res = []
    cur_time = 0
    
    for j, duration in enumerate(tasks):
        cur_time = max(cur_time, j)
        
        # If no servers are available, jump time forward to when the first server frees up
        if not free:
            cur_time = busy[0][0]
            
        # Free up all servers that have finished by cur_time
        while busy and busy[0][0] <= cur_time:
            _, w, i = heapq.heappop(busy)
            heapq.heappush(free, (w, i))
            
        w, i = heapq.heappop(free)
        res.append(i)
        heapq.heappush(busy, (cur_time + duration, w, i))
        
    return res

⏱️ Complexity

Time O((n + m) log n) — each task pushes and pops from the heaps in O(log n). Space O(n + m) for the heaps and result array.

⚠️ Edge cases

  • More tasks than servers: time fast-forward ensures no idle CPU spinning.
  • Equal weights: broken by original server index.
