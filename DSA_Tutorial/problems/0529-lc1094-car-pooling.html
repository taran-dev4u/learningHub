📋 The problem

A shuttle with fixed capacity drives one way; given trips (passengers, from, to), decide whether it ever overflows (difference array).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There is a car with capacity empty seats. The vehicle only drives east. Given integer capacity and array trips = [numPassengers, from, to], return true if you can pick up and drop off all passengers without exceeding capacity.

This is range addition: passengers occupy the vehicle on half-open interval $[from, to)$! Use a Difference Array over kilometers $0 \dots 1000$: - At departure $from$: passengers board $ o$ diff[from] += passengers. - At arrival $to$: passengers get off $ o$ diff[to] -= passengers.

Sweep from kilometer 0 to 1000 tracking running passenger count: If running passengers exceeds capacity at any kilometer, return False!

🐢 Brute force vs optimal

Difference array sweeps in $O(N + D)$ time where $D = 1001$ is the distance bound.

💡 Key insight: Difference array: delta[from] += count; delta[to] -= count. Running prefix sum tracks passengers aboard; reject if passenger count $> capacity$.

✅ The solution

Reveal the commented solution (attempt it first!) 
def carPooling(trips: list[list[int]], capacity: int) -> bool:
    # Max location is 1000
    timeline = [0] * 1001
    
    for passengers, start, end in trips:
        timeline[start] += passengers
        timeline[end] -= passengers
        
    curr_passengers = 0
    for count in timeline:
        curr_passengers += count
        if curr_passengers > capacity:
            return False
            
    return True

Complexity

Time: $O(N + 1000)$ where $N$ is number of trips.
Space: $O(1)$ — Fixed array of 1001 integers.
