#2296 Design a Text Editor HardLeetCode

 

Pattern: Design Patterns › Subpattern 15.1: General / Specific Data Structure Design · Problem 506 of 699

📋 The problem

Design a text editor with cursor: addText, deleteText, cursorLeft, cursorRight — two stacks around the cursor.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a text editor with a cursor that supports: - addText(text): Insert text at cursor. - deleteText(k): Delete up to $k$ characters to the left of cursor. - cursorLeft(k): Move cursor left up to $k$ times and return last min(10, len) characters to the left. - cursorRight(k): Move cursor right up to $k$ times and return last min(10, len) characters to the left.

The Two Stacks (Gap Buffer) Pattern: Maintain two stacks of characters: - left: characters strictly to the left of the cursor. - right: characters strictly to the right of the cursor (in reverse order, top of stack is immediately right of cursor!).

Operations: - addText(text): append characters to left. - deleteText(k): pop up to $k$ characters from left in $O(1)$! - cursorLeft(k): pop from left and push to right up to $k$ times. - cursorRight(k): pop from right and push to left up to $k$ times.

🐢 Brute force vs optimal

Single string slicing takes $O(N)$ per edit. The two-stack gap buffer executes all character additions and deletions in $O(k)$ time without shifting arrays.

💡 Key insight: Two stacks representing text to left and right of cursor. Moving cursor transfers characters between stacks in $O(1)$ per step!

✅ The solution

Reveal the commented solution (attempt it first!) 
class TextEditor:
    def __init__(self):
        self.left = []
        self.right = []

    def addText(self, text: str) -> None:
        self.left.extend(list(text))

    def deleteText(self, k: int) -> int:
        num_delete = min(k, len(self.left))
        for _ in range(num_delete):
            self.left.pop()
        return num_delete

    def cursorLeft(self, k: int) -> str:
        num_move = min(k, len(self.left))
        for _ in range(num_move):
            self.right.append(self.left.pop())
        return "".join(self.left[-10:])

    def cursorRight(self, k: int) -> str:
        num_move = min(k, len(self.right))
        for _ in range(num_move):
            self.left.append(self.right.pop())
        return "".join(self.left[-10:])

Complexity

Time: $O(k)$ for all operations where $k$ is characters added/moved.
Space: $O(N)$ where $N$ is total text characters.
