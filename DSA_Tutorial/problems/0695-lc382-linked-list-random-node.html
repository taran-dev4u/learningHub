📋 The problem

Given a linked list of unknown length, return a uniformly random node's value using O(1) extra space (reservoir sampling).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Reservoir Sampling — Reservoir sampling — keep one (or k) sample(s) and replace with probability k/i at step i.

💡 Key idea
Reservoir sampling: keep node i with probability 1/i while walking the list.

Why this pattern?

  • "shuffle" / "random pick" with uniformity required
  • stream or linked list of unknown length + "pick one uniformly"
  • pick index proportional to weight → prefix sums + bisect
  • O(1) getRandom in a set → array + swap-delete
