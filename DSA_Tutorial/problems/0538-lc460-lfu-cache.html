📋 The problem

Design an LFU cache: evict the least frequently used key (ties: least recently used), all operations O(1).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Design and implement an LFU (Least Frequently Used) cache with $O(1)$ runtime for get and put. When the cache reaches its capacity, it should invalidate and evict the least frequently used key. If there is a tie in frequency, the least recently used key among them should be evicted.

Core Data Structures

  1. key_to_node: maps key -> Node(key, val, freq).
  2. freq_to_dll: maps freq -> DoublyLinkedList. Each DLL maintains LRU order for all items with that frequency.
  3. min_freq: an integer tracking the lowest frequency currently present in the cache. When evicting, we pop from freq_to_dll[min_freq].pop_lru().

from collections import defaultdict

class Node:
    __slots__ = ('key', 'val', 'freq', 'prev', 'next')
    def __init__(self, key: int = 0, val: int = 0, freq: int = 1):
        self.key = key
        self.val = val
        self.freq = freq
        self.prev = None
        self.next = None

class DLinkedList:
    def __init__(self):
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head
        self.size = 0

    def add_node(self, node: Node) -> None:
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node
        self.size += 1

    def remove_node(self, node: Node) -> None:
        p, n = node.prev, node.next
        p.next = n
        n.prev = p
        self.size -= 1

    def pop_tail(self) -> Node:
        if self.size == 0:
            return None
        lru = self.tail.prev
        self.remove_node(lru)
        return lru

class LFUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.key_to_node = {}
        self.freq_to_dll = defaultdict(DLinkedList)
        self.min_freq = 0

    def _update_freq(self, node: Node) -> None:
        freq = node.freq
        self.freq_to_dll[freq].remove_node(node)
        if freq == self.min_freq and self.freq_to_dll[freq].size == 0:
            self.min_freq += 1
        node.freq += 1
        self.freq_to_dll[node.freq].add_node(node)

    def get(self, key: int) -> int:
        if key not in self.key_to_node:
            return -1
        node = self.key_to_node[key]
        self._update_freq(node)
        return node.val

    def put(self, key: int, value: int) -> None:
        if self.capacity <= 0:
            return
        if key in self.key_to_node:
            node = self.key_to_node[key]
            node.val = value
            self._update_freq(node)
        else:
            if len(self.key_to_node) >= self.capacity:
                lru = self.freq_to_dll[self.min_freq].pop_tail()
                del self.key_to_node[lru.key]
            new_node = Node(key, value, 1)
            self.key_to_node[key] = new_node
            self.freq_to_dll[1].add_node(new_node)
            self.min_freq = 1

Complexity & Invariants

  • Time Complexity: $O(1)$ for both get and put.
  • Space Complexity: $O( ext{capacity})$ to store elements and frequency lists.
