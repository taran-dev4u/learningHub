📋 The problem

Design the classic Snake game: the snake moves, grows on food, and dies on hitting a wall or itself.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a Snake game that is played on a device with screen size $height \times width$. The snake starts at position $(0, 0)$ with length 1. You are given a list of food positions. When the snake eats food, its length and score increase by 1. If it hits a wall or bites its own body, the game ends (returns -1).

Data Structures: 1. body (Double-ended Queue / deque): stores coordinates of snake body segments from head to tail. 2. body_set (Hash Set): stores body coordinates for $O(1)$ self-collision checks! 3. food_idx: pointer to the current food item.

The Tail Movement Nuance: When moving to a new cell: - If food is eaten: tail does not move (snake grows). - If no food is eaten: tail must move forward (pop tail from body and remove from body_set) before checking if the new head collides with the body! (Moving into the tail's old spot is valid!).

🐢 Brute force vs optimal

Scanning the entire body list for collisions takes $O(L)$ per move. The hash set allows $O(1)$ collision detection.

💡 Key insight: Pop tail first if not eating food, then check wall boundaries and body collision in $O(1)$ using body_set, then append new head.

✅ The solution

from collections import deque

class SnakeGame:
    def __init__(self, width: int, height: int, food: list[list[int]]):
        self.w = width
        self.h = height
        self.food = food
        self.food_idx = 0
        self.score = 0
        
        # Snake starts at (0, 0)
        self.body = deque([(0, 0)])
        self.body_set = {(0, 0)}
        self.dirs = {'U': (-1, 0), 'D': (1, 0), 'L': (0, -1), 'R': (0, 1)}

    def move(self, direction: str) -> int:
        dr, dc = self.dirs[direction]
        head_r, head_c = self.body[0]
        new_r, new_c = head_r + dr, head_c + dc
        
        # 1. Wall collision
        if not (0 <= new_r < self.h and 0 <= new_c < self.w):
            return -1
            
        # 2. Check food
        is_food = (self.food_idx < len(self.food) and 
                   [new_r, new_c] == self.food[self.food_idx])
                   
        if is_food:
            self.food_idx += 1
            self.score += 1
        else:
            # Pop tail to free its cell
            tail = self.body.pop()
            self.body_set.remove(tail)
            
        # 3. Body collision (after tail is freed)
        if (new_r, new_c) in self.body_set:
            return -1
            
        # 4. Add new head
        self.body.appendleft((new_r, new_c))
        self.body_set.add((new_r, new_c))
        
        return self.score

Complexity

Time: $O(1)$ per move().
Space: $O(N)$ where $N$ is the number of food items eaten (max snake length).
