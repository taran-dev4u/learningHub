📋 The problem

Given building rectangles on a skyline, return the key points that outline their combined silhouette.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

A city's skyline is the outer contour of the silhouette formed by all the buildings. Given the locations and heights of all buildings [left, right, height], return the key points that outline the skyline.

Key Insights

Line Sweep with Max-Heap: Convert each building into two events along the X-axis:

  1. Start of building at $x = left$: adds height $h$ (represented as $-h$ for max-heap).
  2. End of building at $x = right$: removes height $h$.
Sort events by X coordinate. At each critical X position, maintain active building heights in a max-heap. If the maximum height changes after processing all events at position X, record $[X, current_max_height]$ as a skyline keypoint! Use lazy deletion to pop expired buildings from the heap top.

Python 3 Solution (Click to Expand) 
from typing import List
import heapq

class Solution:
    def getSkyline(self, buildings: List[List[int]]) -> List[List[int]]:
        # Events: (x, -h, right) for start, (right, 0, 0) for end
        events = []
        for l, r, h in buildings:
            events.append((l, -h, r))
            events.append((r, 0, 0))
        # Sort events: on tie, higher building first, start before end
        events.sort()
        
        # Max-heap storing (-h, right)
        heap = [(0, float('inf'))]
        skyline = []
        prev_h = 0
        
        for x, neg_h, r in events:
            if neg_h < 0:
                heapq.heappush(heap, (neg_h, r))
                
            # Pop expired buildings from heap top
            while heap[0][1] <= x:
                heapq.heappop(heap)
                
            curr_h = -heap[0][0]
            if curr_h != prev_h:
                skyline.append([x, curr_h])
                prev_h = curr_h
                
        return skyline

Complexity & Edge Cases

  • Time Complexity: $O(N \log N)$.
  • Space Complexity: $O(N)$.
