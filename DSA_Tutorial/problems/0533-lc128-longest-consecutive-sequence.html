📋 The problem

Given an unsorted array, return the length of the longest run of consecutive integer values, in O(n).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given an unsorted array of integers nums, return the length of the longest consecutive elements sequence. The algorithm must run in $O(n)$ time.

Key Insights

A sorting solution takes $O(n \log n)$, which violates the linear time requirement. To achieve $O(n)$, we use a Hash Set for $O(1)$ average lookups.

Crucial realization: A number $x$ can only be the start of a consecutive streak if $x - 1$ is not in the set! If $x - 1$ is present, $x$ cannot be the beginning of a maximal streak, so we skip it immediately. This ensures each number is visited at most twice (once in the outer loop, and once during sequence extension).

Brute Force / Sorting$O(n \log n)$$O(1)$ or $O(n)$Sort and scan consecutive deltas.

Step-by-Step Algorithm

  1. Convert nums to a set num_set = set(nums). This handles duplicates and provides $O(1)$ lookups.
  2. Initialize max_streak = 0.
  3. Iterate through each number $x$ in num_set:
    • Check if $x - 1 otin num_set$. If false, continue to the next number (not a sequence start).
    • If true, $x$ starts a streak: set current_num = x and current_streak = 1.
    • While current_num + 1 \in num_set, increment current_num += 1 and current_streak += 1.
    • Update max_streak = max(max_streak, current_streak).
  4. Return max_streak.
Python 3 Solution (Click to Expand) 
from typing import List

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        num_set = set(nums)
        longest = 0
        
        for num in num_set:
            # Only start counting if num is the beginning of a sequence
            if num - 1 not in num_set:
                curr = num
                streak = 1
                
                while curr + 1 in num_set:
                    curr += 1
                    streak += 1
                    
                longest = max(longest, streak)
                
        return longest

Complexity & Edge Cases

  • Time Complexity: $O(n)$. Each number is checked as a start element in $O(1)$. The inner while loop only runs when $x$ is the head of a sequence, traversing each consecutive chain once across the entire algorithm.
  • Space Complexity: $O(n)$ to store unique elements in the HashSet.
  • Edge Cases: Empty array (returns 0), duplicate elements (e.g. [0, 1, 1, 2]), negative numbers.
