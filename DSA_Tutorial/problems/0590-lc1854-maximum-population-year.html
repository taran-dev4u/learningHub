#1854 Maximum Population Year EasyLeetCode

📋 The problem

Given birth/death years, return the earliest year with the most people alive (difference array over years).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given a 2D integer array logs where logs[i] = [birth_i, death_i], return the earliest year with the maximum population. A person is considered alive during the years in $[birth_i, death_i - 1]$.

Key Insights

The year range is small and fixed: $1950 \le year \le 2050$ (101 years). Use a Difference Array of size 101: For each person $[birth, death]$:

  • Increment delta[birth - 1950] += 1
  • Decrement delta[death - 1950] -= 1 (death year is not counted)
Prefix sum over the difference array reveals the maximum population year in $O(N + 101)$ time.

Python 3 Solution (Click to Expand) 
from typing import List

class Solution:
    def maximumPopulation(self, logs: List[List[int]]) -> int:
        delta = [0] * 102
        for b, d in logs:
            delta[b - 1950] += 1
            delta[d - 1950] -= 1
            
        max_pop = curr_pop = 0
        best_year = 1950
        
        for i in range(101):
            curr_pop += delta[i]
            if curr_pop > max_pop:
                max_pop = curr_pop
                best_year = 1950 + i
                
        return best_year

Complexity & Edge Cases

  • Time Complexity: $O(N + Y)$ where $Y = 100$.
  • Space Complexity: $O(Y) = O(1)$.
