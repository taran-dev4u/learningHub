#1348 Tweet Counts Per Frequency MediumLeetCode

 

Pattern: Design Patterns › Subpattern 15.1: General / Specific Data Structure Design · Problem 498 of 699

📋 The problem

Design tweet-frequency queries: record tweets by time and answer per-minute/hour/day counts in a time range.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

A social media company wants to track frequency of tweets. Implement recordTweet(tweetName, time) and getTweetCountsPerFrequency(freq, tweetName, startTime, endTime) where freq is "minute" (60s), "hour" (3600s), or "day" (86400s).

For each tweetName, maintain a sorted list of tweet timestamps (or insert using bisect.insort). During query: 1. Bucket interval length $\Delta = 60, 3600, ext{or } 86400$. 2. Total chunks $k = (endTime - startTime) // \Delta + 1$. 3. Binary search for timestamps in range $[startTime, endTime]$. 4. For each timestamp $t$, map it into chunk index: chunk = (t - startTime) // delta and increment res[chunk] += 1.

🐢 Brute force vs optimal

Sorting or maintaining binary search lists ensures queries inspect only relevant timestamps in $O(\log N + M)$ time.

💡 Key insight: Sorted timestamps: binary search slice $[start, end]$, map each timestamp into bucket (t - start) // delta in $O(M)$ time.

✅ The solution

Reveal the commented solution (attempt it first!) 
from collections import defaultdict
import bisect

class TweetCounts:
    def __init__(self):
        self.tweets = defaultdict(list)

    def recordTweet(self, tweetName: str, time: int) -> None:
        bisect.insort(self.tweets[tweetName], time)

    def getTweetCountsPerFrequency(self, freq: str, tweetName: str, startTime: int, endTime: int) -> list[int]:
        delta = 60 if freq == "minute" else (3600 if freq == "hour" else 86400)
        chunks = (endTime - startTime) // delta + 1
        res = [0] * chunks
        
        times = self.tweets[tweetName]
        l = bisect.bisect_left(times, startTime)
        r = bisect.bisect_right(times, endTime)
        
        for i in range(l, r):
            bucket = (times[i] - startTime) // delta
            res[bucket] += 1
            
        return res

Complexity

Time: recordTweet: $O(N)$ insertion. getTweetCountsPerFrequency: $O(\log N + M)$ where $M$ is tweets in interval.
Space: $O(N)$ timestamps stored per tweet.
