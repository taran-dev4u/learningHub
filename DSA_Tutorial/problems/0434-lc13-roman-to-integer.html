📋 The problem

Convert a Roman numeral string into its integer value, honoring subtractive pairs like IV and CM.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Roman numerals are represented by seven symbols: I(1), V(5), X(10), L(50), C(100), D(500), M(1000).

Roman numerals are usually written largest to smallest from left to right. The Subtraction Rule: If a smaller numeral appears immediately before a larger numeral (e.g. IV = 4, IX = 9, XL = 40), it is subtracted instead of added! Therefore: - If val[s[i]] < val[s[i + 1]]: subtract val[s[i]]. - Otherwise: add val[s[i]].

🐢 Brute force vs optimal

Linear scan from left to right with a simple one-character lookahead runs in $O(n)$ time and $O(1)$ space.

💡 Key insight: Lookahead comparison: if current symbol value is strictly less than next symbol value, subtract it; else add it.

✅ The solution

Reveal the commented solution (attempt it first!) 
def romanToInt(s: str) -> int:
    values = {'I': 1, 'V': 5, 'X': 10, 'L': 50, 'C': 100, 'D': 500, 'M': 1000}
    total = 0
    n = len(s)
    
    for i in range(n):
        curr = values[s[i]]
        if i + 1 < n and curr < values[s[i + 1]]:
            total -= curr
        else:
            total += curr
            
    return total

Complexity

Time: $O(n)$ — Single pass through the string (max length 15).
Space: $O(1)$ — Fixed dictionary of 7 symbols.
