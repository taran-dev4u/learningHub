📋 The problem

Convert an Excel column title to its number (A→1, Z→26, AA→27, …).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Problem Overview

Given a string columnTitle that represents the column title as appears in an Excel sheet, return its corresponding column number (A -> 1, B -> 2, ..., Z -> 26, AA -> 27).

Key Insights

Polynomial evaluation in base 26: For a string {2, 3, 5}c_0 c_1 \dots c_{k-1}{2, 3, 5}, each character contributes {2, 3, 5}(ord(c_i) - ord('A') + 1) imes 26^{k - 1 - i}{2, 3, 5}. Accumulate from left to right: res = res * 26 + (ord(ch) - ord('A') + 1).

Python 3 Solution (Click to Expand) 
class Solution:
    def titleToNumber(self, columnTitle: str) -> int:
        res = 0
        for ch in columnTitle:
            digit = ord(ch) - ord('A') + 1
            res = res * 26 + digit
        return res

Complexity & Edge Cases

  • Time Complexity: {2, 3, 5}O(L){2, 3, 5} where {2, 3, 5}L{2, 3, 5} is length of string ({2, 3, 5}L \le 7{2, 3, 5}).
  • Space Complexity: {2, 3, 5}O(1){2, 3, 5}.
  • Edge Cases: Single character "A" (1), multi-character "FXSHRXW" ({2, 3, 5}2^{31} - 1{2, 3, 5}).
