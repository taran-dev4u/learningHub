📋 The problem

A stream of (timestamp, price) updates (corrections allowed); report latest, maximum, and minimum current prices (dict + lazy heaps).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Design a stock price fluctuation system that can receive out-of-order price records, correct existing prices, and retrieve current(), maximum(), and minimum() stock prices in $O(\log N)$ time.

Hash Map + Min/Max Heaps with Lazy Deletion: 1. prices: timestamp -> latest_price (authoritative ground truth!). 2. max_timestamp: scalar tracking the latest timestamp seen so far (for current() in $O(1)$). 3. max_heap: stores (-price, timestamp). 4. min_heap: stores (price, timestamp).

Lazy Deletion on Heap Reads: When retrieving maximum(): While -max_heap[0][0] != prices[max_heap[0][1]]: The heap top price is stale (it was updated later)! Discard it with heappop()! Return the first valid top element!

🐢 Brute force vs optimal

Scanning all prices for min/max takes $O(N)$ per query. Two heaps with lazy garbage collection execute in $O(\log N)$ time.

💡 Key insight: Hash map holds true latest price per timestamp. Min/max heaps discard stale entries lazily: while heap[0].price != map[heap[0].time]: heappop().

✅ The solution

Reveal the commented solution (attempt it first!) 
import heapq

class StockPrice:
    def __init__(self):
        self.prices = {} # timestamp -> price
        self.latest_time = 0
        self.max_heap = [] # (-price, timestamp)
        self.min_heap = [] # (price, timestamp)

    def update(self, timestamp: int, price: int) -> None:
        self.prices[timestamp] = price
        self.latest_time = max(self.latest_time, timestamp)
        heapq.heappush(self.max_heap, (-price, timestamp))
        heapq.heappush(self.min_heap, (price, timestamp))

    def current(self) -> int:
        return self.prices[self.latest_time]

    def maximum(self) -> int:
        while -self.max_heap[0][0] != self.prices[self.max_heap[0][1]]:
            heapq.heappop(self.max_heap) # Discard stale entry
        return -self.max_heap[0][0]

    def minimum(self) -> int:
        while self.min_heap[0][0] != self.prices[self.min_heap[0][1]]:
            heapq.heappop(self.min_heap) # Discard stale entry
        return self.min_heap[0][0]

Complexity

Time: update, maximum, minimum: $O(\log N)$ amortized. current: $O(1)$.
Space: $O(N)$ — Map and heaps storing price history.
