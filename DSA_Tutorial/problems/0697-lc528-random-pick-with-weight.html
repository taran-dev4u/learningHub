📋 The problem

Design pickIndex() returning index i with probability proportional to weights[i].

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

Where this fits

Weighted Random (Prefix Sum + Binary Search) — Weighted random pick — build prefix sums of weights, then binary search a uniform random in [0, total).

💡 Key idea
Prefix sums of weights + bisect on a uniform random in [0, total).

Why this pattern?

  • "shuffle" / "random pick" with uniformity required
  • stream or linked list of unknown length + "pick one uniformly"
  • pick index proportional to weight → prefix sums + bisect
  • O(1) getRandom in a set → array + swap-delete
