📋 The problem

Each minute rotten oranges rot their fresh 4-neighbors; return the minutes until no fresh orange remains (-1 if some never rot).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

You are given an m x n grid where 0 represents an empty cell, 1 represents a fresh orange, and 2 represents a rotten orange. Every minute, any fresh orange that is 4-directionally adjacent to a rotten orange becomes rotten. Return the minimum number of minutes that must elapse until no cell has a fresh orange. If this is impossible, return -1.

🐢 Brute force first

Simulate minute-by-minute with full grid scans: O((m*n)^2). Multi-source BFS simulates simultaneous propagation in a single pass.

💡 Key insight: All rotten oranges rot their neighbors simultaneously! This is the signature textbook problem for Multi-Source BFS. 1. Add all initially rotten oranges (r, c) into a FIFO queue at time 0. 2. Count initial fresh oranges. 3. Pop level-by-level (by minutes): for each rotten orange, infect adjacent fresh oranges, decrement fresh, and append newly infected oranges to queue. 4. When queue is empty, if fresh == 0 return minutes; else return -1 (some fresh oranges were unreachable).

🪜 The approach, step by step

  1. Initialize queue = deque() and fresh = 0.
  2. Scan grid: if cell == 2, queue.append((r, c)); if cell == 1, fresh += 1.
  3. If fresh == 0, return 0 immediately.
  4. minutes = 0. While queue and fresh > 0:
    • For _ in range(len(queue)):
    • Pop (r, c). For 4 neighbors: if in bounds and cell == 1: turn to 2, fresh -= 1, queue.append((nr, nc)).
    • minutes += 1.
  5. Return minutes if fresh == 0 else -1.

✅ The solution

from collections import deque

def orangesRotting(grid):
    m, n = len(grid), len(grid[0])
    queue = deque()
    fresh = 0
    
    # 1. Enqueue all rotten oranges & count fresh ones
    for r in range(m):
        for c in range(n):
            if grid[r][c] == 2:
                queue.append((r, c))
            elif grid[r][c] == 1:
                fresh += 1
                
    if fresh == 0:
        return 0
        
    minutes = 0
    # 2. Multi-source BFS level-by-level
    while queue and fresh > 0:
        minutes += 1
        for _ in range(len(queue)):
            r, c = queue.popleft()
            for dr, dc in [(1, 0), (-1, 0), (0, 1), (0, -1)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == 1:
                    grid[nr][nc] = 2
                    fresh -= 1
                    queue.append((nr, nc))
                    
    return minutes if fresh == 0 else -1

⏱️ Complexity

Time O(m * n) — Each cell is processed at most once. Space O(m * n) for the BFS queue.

⚠️ Edge cases

  • No fresh oranges at start: returns 0.
  • Fresh orange isolated by empty cells: cannot be reached, returns -1.
