Problem Overview

Given an array of meeting time intervals consisting of start and end times, return the minimum number of conference rooms required.

Key Insights

This asks for the maximum number of concurrent overlapping meetings at any point in time. Two optimal techniques:

  1. Min-Heap: Sort intervals by start time. Keep a min-heap of active meeting end times. If the earliest finishing meeting in the heap finishes before the current meeting starts ($heap[0] \le start$), reuse that room (pop from heap). Push current meeting's end time. The heap size is the number of rooms needed: $O(N \log N)$.
  2. Line Sweep / Chronological Event Separation: Separate starts and ends into two sorted arrays. Track current active rooms: increment on start, decrement on end.

Python 3 Solution (Min-Heap Simulation) 
from typing import List
import heapq

class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        if not intervals:
            return 0
            
        intervals.sort(key=lambda x: x[0])
        rooms = []  # stores end times
        
        for start, end in intervals:
            if rooms and rooms[0] <= start:
                heapq.heappop(rooms)  # reuse room
            heapq.heappush(rooms, end)
            
        return len(rooms)

Complexity & Edge Cases

  • Time Complexity: $O(N \log N)$.
  • Space Complexity: $O(N)$ for heap.
