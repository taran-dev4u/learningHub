📋 The problem

Return the k elements of a sorted array closest to x, in ascending order.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given a sorted integer array arr, two integers k and x, return the k closest integers to x in the array. An integer a is closer to x than b if |a - x| < |b - x|, or |a - x| == |b - x| and a < b.

🐢 Brute force first

Sort the entire array by distance abs(num - x) and take first k, then sort those k elements. Time: O(n log n). Space: O(k).

💡 Key insight: The result is always a contiguous subarray of length k because the input array is already sorted! We simply need to find the optimal starting index left in range [0, len(arr) - k]. For any candidate start mid, compare the distance of element arr[mid] vs element arr[mid + k]: if x - arr[mid] > arr[mid + k] - x, arr[mid + k] is closer to x than arr[mid], so the window must shift right!

🪜 The approach, step by step

  1. Set binary search range for starting index: left = 0, right = len(arr) - k.
  2. While left < right:
  3. mid = left + (right - left) // 2.
  4. Compare distance of boundary elements: if x - arr[mid] > arr[mid + k] - x, arr[mid] is farther from x than arr[mid + k], so shift right: left = mid + 1.
  5. Else: right = mid.
  6. Return arr[left : left + k].

🎞️ Visual dry run — arr = [1, 2, 3, 4, 5], k = 4, x = 3

n = 5, k = 4. Search range for left bound: [0, 1]
mid = 0: compare arr[0]=1 vs arr[0+4]=arr[4]=5
dist to x(3): |3 - 1| = 2 vs |5 - 3| = 2
Tie broken by smaller value (1 < 5) → arr[0] is preferred!
right = mid = 0.
left == right == 0.
Subarray is arr[0:4] = [1, 2, 3, 4]. ✓

✅ The solution

Reveal the commented solution (attempt it first!) 
def findClosestElements(arr, k, x):
    left, right = 0, len(arr) - k
    
    while left < right:
        mid = left + (right - left) // 2
        # If arr[mid] is further from x than arr[mid + k], shift window right
        if x - arr[mid] > arr[mid + k] - x:
            left = mid + 1
        else:
            right = mid
            
    return arr[left : left + k]

⏱️ Complexity

Time O(log(n - k) + k) — Binary search takes O(log(n - k)) to find start index; slicing takes O(k). Space O(1).

⚠️ Edge cases

  • x <= arr[0]: returns first k elements.
  • x >= arr[-1]: returns last k elements.
  • k == len(arr): returns entire array.
