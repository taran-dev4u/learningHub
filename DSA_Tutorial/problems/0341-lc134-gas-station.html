📋 The problem

Gas stations on a circle each give gas[i] and cost cost[i] to reach the next; return the unique starting station from which you can complete the loop, or -1.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There are n gas stations along a circular route, where the amount of gas at the i-th station is gas[i]. It costs cost[i] of gas to travel from the i-th station to its next (i + 1)-th station. You begin the journey with an empty tank at one of the gas stations. Return the starting gas station's index if you can travel around the circuit once in the clockwise direction, otherwise return -1. If there exists a solution, it is guaranteed to be unique.

🐢 Brute force vs optimal

Simulating every possible starting station takes O(N^2). The Greedy approach solves this in O(N) time using two core mathematical principles:

  1. If sum(gas) < sum(cost), the total gas in the system is insufficient to complete the circuit → return -1 immediately.
  2. If sum(gas) >= sum(cost), a valid starting station is guaranteed to exist! Furthermore, if starting at station A fails at station B, no station between A and B could possibly be the start! The next candidate must be B + 1.
💡 Key insight: Maintain total_tank and curr_tank. Iterate i from 0 to n - 1. Add gas[i] - cost[i] to both. If curr_tank < 0, we cannot reach station i + 1 from our current start → reset start = i + 1 and curr_tank = 0!

🪜 The approach, step by step

  1. If sum(gas) < sum(cost), return -1.
  2. Initialize start = 0, curr_tank = 0.
  3. For i in range len(gas):
    • curr_tank += gas[i] - cost[i]
    • If curr_tank < 0: start = i + 1; curr_tank = 0.
  4. Return start.

✅ The solution

def canCompleteCircuit(gas: list[int], cost: list[int]) -> int:
    """
    Finds unique starting gas station to complete circuit in O(N) time and O(1) space.
    """
    if sum(gas) < sum(cost):
        return -1
        
    start = 0
    curr_tank = 0
    
    for i in range(len(gas)):
        curr_tank += gas[i] - cost[i]
        if curr_tank < 0:
            start = i + 1
            curr_tank = 0
            
    return start

⚡ Complexity analysis

  • Time Complexity: O(N). Single pass to sum and single pass to find the starting index.
  • Space Complexity: O(1).
