📋 The problem

Implement regular-expression matching over the full input string where '.' matches any single character and '*' means zero or more of the preceding element.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an input string s and a pattern p, implement regular expression matching with support for '.' and '*': - '.' Matches any single character. - '*' Matches zero or more of the preceding element.

Let $dp[i][j]$ be whether $s[0 \dots i-1]$ matches $p[0 \dots j-1]$. 1. Exact match or '.' : If $p[j - 1] == s[i - 1]$ or $p[j - 1] == \text{'.'}$, then $dp[i][j] = dp[i - 1][j - 1]$. 2. Star '*' : If $p[j - 1] == \text{'*'}$, look at the preceding element $p[j - 2]$: - Zero occurrences: ignore the star and preceding char: $dp[i][j] = dp[i][j - 2]$. - One or more occurrences: if $s[i - 1]$ matches $p[j - 2]$ (or $p[j-2] == \text{'.'}$, then $dp[i][j] = dp[i][j] \lor dp[i - 1][j]$.

🐢 Brute force vs optimal

Star wildcards create recursive trees of depth $O(2^{m+n})$. Memoizing subproblems on the $(m+1) \times (n+1)$ state grid solves it in $O(m \times n)$ time.

💡 Key insight: For '*': dp[i][j] = dp[i][j - 2] (zero occurrences) or (matches(s[i-1], p[j-2]) and dp[i - 1][j]) (consume one more char from s).

✅ The solution

def isMatch(s: str, p: str) -> bool:
    m, n = len(s), len(p)
    dp = [[False] * (n + 1) for _ in range(m + 1)]
    dp[0][0] = True
    
    # Handle patterns like a*, a*b*, a*b*c* matching empty string s
    for j in range(2, n + 1):
        if p[j - 1] == '*':
            dp[0][j] = dp[0][j - 2]
            
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if p[j - 1] == '*':
                # Case 1: zero occurrences of preceding element
                dp[i][j] = dp[i][j - 2]
                # Case 2: one or more occurrences
                if p[j - 2] == '.' or p[j - 2] == s[i - 1]:
                    dp[i][j] = dp[i][j] or dp[i - 1][j]
            elif p[j - 1] == '.' or p[j - 1] == s[i - 1]:
                dp[i][j] = dp[i - 1][j - 1]
                
    return dp[m][n]

Complexity

Time: $O(m \times n)$ — Grid filled cell by cell.
Space: $O(m \times n)$ — 2D DP matrix (can be optimized to $O(n)$).
