📋 The problem

Reverse the order of words in a string, cleaning up any extra spaces.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an input string s, reverse the order of the words. A word is defined as a sequence of non-space characters. The words in s will be separated by at least one space. Return a string of the words in reverse order concatenated by a single space.

To solve in $O(1)$ auxiliary space (in mutable char arrays / C++ / Java): 1. Reverse the entire string. 2. Reverse each individual word in place. 3. Clean up multiple consecutive spaces and trim edges.

In Python: " ".join(reversed(s.split())) handles multi-spaces and edge whitespaces naturally.

🐢 Brute force vs optimal

Splitting on whitespace skips all multiple spaces and reverses words in $O(n)$ time.

💡 Key insight: s.split() in Python automatically strips leading/trailing spaces and groups runs of spaces. Reverse the word list and join with a single space.

✅ The solution

Reveal the commented solution (attempt it first!) 
def reverseWords(s: str) -> str:
    """
    Reverses words in string, cleaning excess whitespace in O(n) time.
    """
    return " ".join(reversed(s.split()))

Complexity

Time: $O(n)$ — Single pass to split, reverse, and join.
Space: $O(n)$ — Words list buffer.
