📋 The problem

Starting from a pixel, recolor its entire connected same-color region with a new color (paint-bucket fill).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

An image is represented by an m x n integer grid image where image[i][j] represents the pixel value. You are given sr, sc and color. Perform a flood fill on the image starting from pixel image[sr][sc]: change the color of the starting pixel and all 4-directionally connected pixels with the same initial color to color.

🐢 Brute force first

Standard BFS/DFS traversal. The critical trap is an infinite loop when the target color is already equal to the starting cell's color (image[sr][sc] == color)!

💡 Key insight: If image[sr][sc] == color, return image immediately without any traversal! Otherwise, record original_color = image[sr][sc] and run DFS from (sr, sc), replacing any neighboring cell with original_color with color.

🪜 The approach, step by step

  1. Let orig = image[sr][sc].
  2. If orig == color, return image immediately (prevents infinite recursion).
  3. Define dfs(r, c):
    • If r, c out of bounds or image[r][c] != orig, return.
    • Change color: image[r][c] = color.
    • Recurse 4 directions: (r+1, c), (r-1, c), (r, c+1), (r, c-1).
  4. Call dfs(sr, sc) and return image.

🎞️ Visual dry run — image = [[1,1,1],[1,1,0],[1,0,1]], sr=1, sc=1, color=2

orig = image[1][1] = 1. color = 2.
DFS starts at (1,1):

  (0,1) -> 2, (0,0) -> 2, (0,2) -> 2
  (1,0) -> 2, (2,0) -> 2
  (2,2) remains 1 because it's separated by 0!

✅ The solution

Reveal the commented solution (attempt it first!) 
def floodFill(image, sr, sc, color):
    orig = image[sr][sc]
    if orig == color:
        return image
        
    m, n = len(image), len(image[0])
    
    def dfs(r, c):
        if r < 0 or r >= m or c < 0 or c >= n or image[r][c] != orig:
            return
            
        image[r][c] = color
        dfs(r + 1, c)
        dfs(r - 1, c)
        dfs(r, c + 1)
        dfs(r, c - 1)
        
    dfs(sr, sc)
    return image

⏱️ Complexity

Time O(m * n). Space O(m * n) call stack.

⚠️ Edge cases

  • orig == color: handled immediately by upfront check.
  • 1x1 image.
