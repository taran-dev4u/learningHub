📋 The problem

Given an adjacency matrix of friendships, count the friend circles (connected components).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

There are n cities. Some are connected, some are not. If city a is connected to b, and b is connected to c, then a is connected indirectly to c. A province is a group of directly or indirectly connected cities. Given an n x n adjacency matrix isConnected where isConnected[i][j] = 1 if connected, return the total number of provinces.

🐢 Brute force first

Standard connected component counting on an undirected graph with n nodes. Can be solved with DFS, BFS, or Union-Find.

💡 Key insight: Maintain a visited set. Loop through each city i from 0 to n-1: if i is not visited, we found a new province! Increment count, and run DFS from i to visit all cities connected to i.

🪜 The approach, step by step

  1. Let n = len(isConnected), visited = set(), provinces = 0.
  2. For city i in 0 .. n-1:
  3. If i not in visited:
    • provinces += 1.
    • Run dfs(i): mark i visited; for each neighbor j, if isConnected[i][j] == 1 and j not in visited, recurse dfs(j).
  4. Return provinces.

✅ The solution

def findCircleNum(isConnected):
    n = len(isConnected)
    visited = set()
    provinces = 0
    
    def dfs(city):
        visited.add(city)
        for neighbor in range(n):
            if isConnected[city][neighbor] == 1 and neighbor not in visited:
                dfs(neighbor)
                
    for i in range(n):
        if i not in visited:
            provinces += 1
            dfs(i)
            
    return provinces

⏱️ Complexity

Time O(n^2) — Traverses the n x n adjacency matrix. Space O(n) for visited set and recursion stack.

⚠️ Edge cases

  • All cities disconnected (identity matrix): n provinces.
  • All cities connected: 1 province.
