#1137 N-th Tribonacci Number EasyLeetCode

📋 The problem

Tribonacci: T(n) = T(n-1) + T(n-2) + T(n-3) with T(0..2) = 0,1,1; return T(n).

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

The Tribonacci sequence $T_n$ is defined as:

$$T_0 = 0, \quad T_1 = 1, \quad T_2 = 1$$ $$T_{n+3} = T_n + T_{n+1} + T_{n+2} \quad \text{for } n \ge 0$$

🐢 Brute force vs optimal

Recursive branching of 3 yields $O(3^n)$ time. Rolling three registers ($t_0, t_1, t_2$) allows $O(n)$ computation in $O(1)$ extra memory.

💡 Key insight: Shift three scalar values on each step: t0, t1, t2 = t1, t2, t0 + t1 + t2.

✅ The solution

Reveal the commented solution (attempt it first!) 
def tribonacci(n: int) -> int:
    if n == 0:
        return 0
    if n <= 2:
        return 1
    t0, t1, t2 = 0, 1, 1
    for _ in range(3, n + 1):
        t0, t1, t2 = t1, t2, t0 + t1 + t2
    return t2

Complexity

Time: $O(n)$ — Linear iterative progression.
Space: $O(1)$ — Three rolling variables.
