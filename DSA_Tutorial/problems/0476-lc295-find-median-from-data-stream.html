📋 The problem

Design a structure that accepts a stream of numbers and can return the median of everything seen so far at any time.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

The median is the middle value in an ordered integer list. Design a data structure that supports adding numbers from a continuous stream and finding the current median in $O(1)$ time.

The Two Heaps Balancing Pattern: Divide the numbers into two equal halves: 1. Max-Heap (small): Stores the smaller half of the numbers. The root gives the largest of the small half. 2. Min-Heap (large): Stores the larger half of the numbers. The root gives the smallest of the large half.

Invariants to Maintain: 1. len(small) == len(large) (if total numbers even) OR len(small) == len(large) + 1 (if odd). 2. Every element in small must be $\le$ every element in large.

Then: - If odd: $ ext{median} = ext{small.root}$. - If even: $ ext{median} = ( ext{small.root} + ext{large.root}) / 2.0$.

🐢 Brute force vs optimal

Sorting an array takes $O(n \log n)$ per query. Two heaps add elements in $O(\log n)$ time and return the median in $O(1)$ time.

💡 Key insight: Max-heap for lower half, min-heap for upper half. Balance sizes so 0 <= len(small) - len(large) <= 1. Median is calculated in $O(1)$!

import heapq

class MedianFinder:
    def __init__(self):
        # small: max-heap (invert signs in Python)
        # large: min-heap
        self.small = []
        self.large = []

    def addNum(self, num: int) -> None:
        # Step 1: Push to max-heap small
        heapq.heappush(self.small, -num)
        
        # Step 2: Ensure small's largest <= large's smallest
        if self.small and self.large and (-self.small[0] > self.large[0]):
            val = -heapq.heappop(self.small)
            heapq.heappush(self.large, val)
            
        # Step 3: Balance sizes (small can have at most 1 more element than large)
        if len(self.small) > len(self.large) + 1:
            val = -heapq.heappop(self.small)
            heapq.heappush(self.large, val)
        elif len(self.large) > len(self.small):
            val = heapq.heappop(self.large)
            heapq.heappush(self.small, -val)

    def findMedian(self) -> float:
        if len(self.small) > len(self.large):
            return float(-self.small[0])
        return (-self.small[0] + self.large[0]) / 2.0

Complexity

Time: addNum: $O(\log n)$ heap pushes/pops. findMedian: $O(1)$ peek.
Space: $O(n)$ — Two heaps storing all stream elements.
