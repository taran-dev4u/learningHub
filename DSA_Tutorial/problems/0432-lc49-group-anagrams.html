📋 The problem

Group a list of words so that words that are anagrams of each other end up in the same group.

Restated in our own words — the LeetCode icon above opens the formal statement with exact constraints and examples.

🧭 How to think about it

Given an array of strings strs, group the anagrams together. You can return the answer in any order.

Two strings are anagrams if and only if they contain the exact same characters with identical frequencies. We can map each word to a canonical key in a hash table: 1. Sorting Key: tuple(sorted(word)). Time per word: $O(L \log L)$. 2. Character Count Tuple Key: a 26-element tuple of counts for 'a' through 'z'. Time per word: $O(L)$.

🐢 Brute force vs optimal

Comparing every pair takes $O(n^2 \cdot L)$. Hash map grouping with character count or sorted tuple runs in $O(n \cdot L)$ or $O(n \cdot L \log L)$.

💡 Key insight: Group in a hash map using the 26-character frequency tuple tuple(count) as the dictionary key. Appends anagrams in $O(n \cdot L)$ time!

✅ The solution

Reveal the commented solution (attempt it first!) 
from collections import defaultdict

def groupAnagrams(strs: list[str]) -> list[list[str]]:
    groups = defaultdict(list)
    
    for s in strs:
        count = [0] * 26
        for ch in s:
            count[ord(ch) - ord('a')] += 1
        groups[tuple(count)].append(s)
        
    return list(groups.values())

Complexity

Time: $O(n \cdot L)$ where $n = ext{len}(strs)$ and $L$ is max word length.
Space: $O(n \cdot L)$ to store grouped strings in the hash map.
