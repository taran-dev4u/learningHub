🧩 Heap (Priority Queue) Patterns

4 subpatterns · 30 problems ·

1. Intuition — the mental model

When you repeatedly need "the current smallest/largest" from a changing pool, a heap keeps just enough order to answer in O(log n) per operation. The art is choosing what to put in the heap and how big to let it grow.

💡 The “aha” insight
For the k largest elements keep a min-heap capped at size k: anything smaller than the heap's minimum can never be top-k, so pop it. You process n items but the heap stays tiny — O(n log k) beats sorting whenever k ≪ n.

2. Recognition signals

Think of this pattern when the problem says:

  • "k largest / k closest / k most frequent / k-th …"
  • merge k sorted lists/streams
  • "median of a stream" / balance two halves → two heaps
  • scheduling: always take the earliest end / most frequent / cheapest next
  • Dijkstra-style "expand the best frontier node"

3. Master template

import heapq
# Top-k largest: min-heap of size k
h = []
for x in nums:
    heapq.heappush(h, x)
    if len(h) > k:
        heapq.heappop(h)                 # evict the smallest of the k+1
# h holds the k largest; h[0] is the k-th largest

# k-way merge: heap of (value, which_list, index)
h = [(lst[0], i, 0) for i, lst in enumerate(lists) if lst]
heapq.heapify(h)
while h:
    val, i, j = heapq.heappop(h)
    out.append(val)
    if j + 1 < len(lists[i]):
        heapq.heappush(h, (lists[i][j+1], i, j+1))

Python's heap is min-only: negate values for max behavior. Tuples give tie-breaking and payloads: (priority, counter, item) — the counter avoids comparing unorderable items.

4. Complexity of the template

Push/pop O(log size), peek O(1), heapify O(n). Top-k: O(n log k) time, O(k) space. Two-heaps median: O(log n) insert, O(1) query.

5. Common mistakes

  • Max-heap via negation, then forgetting to negate on the way out.
  • k largest with a max-heap of ALL n items — works but O(n log n); the size-k min-heap is the intended answer.
  • Lazy deletion forgotten: when items expire (window moved), skip stale heap tops on pop.
  • Assuming the heap array is sorted — only index 0 is guaranteed.
