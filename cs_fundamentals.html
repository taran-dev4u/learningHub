Processes & Threads

6 concepts
Units of execution and their resources.
  1. ☆
    Process: isolated address space
    PID, memory regions, file descriptors. fork() creates child.
    🔍YT🔍G
  2. ☆
    Thread: shares process memory
    Same heap/code, own stack. pthreads, Java Thread.
    🔍YT🔍G
  3. ☆
    Context switching
    Save/restore registers + page tables. Microsecond cost.
    🔍YT🔍G
  4. ☆
    Process states (Ready/Running/Blocked)
    State machine driven by scheduler + events.
    🔍YT🔍G
  5. ☆
    fork() / exec() / wait()
    Duplicate, replace image, reap child. Unix process API.
    🔍YT🔍G
  6. ☆
    Zombies & orphans
    Zombie = dead, not reaped. Orphan = parent died first.
    🔍YT🔍G

CPU Scheduling

5 concepts
Picking which ready process runs next.
  1. ☆
    FCFS / SJF / SRTF
    First-come, shortest-job, shortest-remaining.
    🔍YT🔍G
  2. ☆
    Round Robin
    Time quantum per process. Fair, interactive.
    🔍YT🔍G
  3. ☆
    Multilevel feedback queue
    Multi-priority queues, long jobs demoted.
    🔍YT🔍G
  4. ☆
    Linux CFS (Completely Fair Scheduler)
    Red-black tree of vruntime. Picks smallest.
    🔍YT🔍G
  5. ☆
    Preemptive vs cooperative
    Preemptive: kernel can interrupt. Cooperative: must yield.
    🔍YT🔍G
