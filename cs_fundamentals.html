6 concepts

    Process: isolated address space
    PID, memory regions, file descriptors. fork() creates child.

  2. ☆

    Context switching
    Save/restore registers + page tables. Microsecond cost.
    🔍YT🔍G
  4. ☆
    Process states (Ready/Running/Blocked)
    State machine driven by scheduler + events.
    🔍YT🔍G
  5. ☆
    fork() / exec() / wait()
    Duplicate, replace image, reap child. Unix process API.
    🔍YT🔍G
  6. ☆
    Zombies & orphans
    Zombie = dead, not reaped. Orphan = parent died first.
    🔍YT🔍G

    Preemptive: kernel can interrupt. Cooperative: must yield.
