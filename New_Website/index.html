🧭 Pattern Recognition Cheat Sheet — "the problem says X → think pattern Y"

Interviews are pattern-matching under pressure. Scan the problem statement for these signals:

If the problem says / involves…Think…

Matching brackets, undo/redo, nested structure, evaluate expressionStack
